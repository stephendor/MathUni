Linear maps (la-05)

The only functions algebra truly loves — and why derivatives qualify.

Up to now every object in this module has been a place: a vector space, a subspace, a basis sitting inside one. Nothing has moved. Linear algebra only becomes interesting when you start sending one space to another, and it becomes tractable because only a very restricted class of functions is allowed to do the sending — the ones that respect addition and scaling, and nothing else.

The restriction sounds severe until you notice what it admits. Differentiation is a linear map. So is definite integration. So is multiplication by x², so is shifting a sequence, so is every system of simultaneous linear equations you have ever solved. Half of analysis and all of matrix theory turn out to be about maps that satisfy two lines of definition — and the reason a two-line definition can carry that much is Theorem 3.5, which says a linear map is completely determined by what it does to a basis. Fix finitely many values and the whole function is forced.

Prediction gate — commit before reading on. The definition of a linear map has two clauses: additivity and homogeneity. Suppose a function φ : R² → R satisfies homogeneity on its own — φ(av) = aφ(v) for every scalar a ∈ R and every v ∈ R². Do you predict that φ must then be linear — that is, must additivity come free? Commit to yes or no before Segment 1 ends.

Why this matters for the mission: Boundary operators ∂ are linear maps; homology is their study.

Segment 1 · ~20 min

The definition, and the company it keeps

Throughout, F is R or C, and V and W are vector spaces over F. — Axler, Chapter 3 opening, Notation 3.1, p. 51

Definition 3.2 (linear map). A linear map from V to W is a function T : V → W such that
additivity: T(u + v) = Tu + Tv for all u, v ∈ V;
homogeneity: T(λv) = λ(Tv) for all λ ∈ F and all v ∈ V.
The set of all linear maps from V to W is written ℒ(V, W). — Axler §3.A, Definition 3.2 and Notation 3.3, p. 52

Read each equation carefully: on the left the operation happens in V, on the right it happens in W. The two spaces have different additions and different scalar multiplications, and the definition asserts that T converts one into the other. That is the whole content — "structure-preserving", made precise.

Worked example — the standard catalogue (fully worked). Each of these is in ℒ(V, W) for the spaces named, and it is worth checking two or three of them yourself against Definition 3.2 rather than taking the list on trust.

Zero. 0 ∈ ℒ(V, W) sends every v to the additive identity of W. Identity. I ∈ ℒ(V, V) sends every v to itself.

Differentiation. D ∈ ℒ(𝒫(R), 𝒫(R)) defined by Dp = p′. Saying this is linear is precisely restating (f + g)′ = f′ + g′ and (λf)′ = λf′ — two rules from calculus, recognised as one algebraic fact.

Integration. T ∈ ℒ(𝒫(R), R) defined by Tp = ∫₀¹ p(x) dx. Multiplication by x². (Tp)(x) = x²p(x). Backward shift. T ∈ ℒ(F∞, F∞) with T(x₁, x₂, x₃, …) = (x₂, x₃, …).

From R³ to R². T(x, y, z) = (2x − y + 3z, 7x + 5y − 6z). Generalising, any array of scalars Aj,k defines a linear map Fⁿ → Fᵐ by taking the j-th output slot to be Aj,1x₁ + ⋯ + Aj,nxn — and every linear map Fⁿ → Fᵐ has this form. That last sentence is the seed of la-07. — Axler §3.A, Example 3.4, pp. 52–53

Theorem 3.11 (linear maps take 0 to 0). If T is a linear map from V to W, then T(0) = 0. — Axler §3.A, Theorem 3.11, p. 57
Why it is true — two lines, and note which clause is used. By additivity alone, T(0) = T(0 + 0) = T(0) + T(0). Adding the additive inverse of T(0) to both sides gives 0 = T(0).

Homogeneity is never invoked. You could also argue T(0) = T(0·0) = 0·T(0) = 0 using homogeneity and la-01's rule that 0 times a vector is 0 — either route works, but knowing that additivity alone suffices is what makes Theorem 3.11 usable in the situations of the prediction gate. — Axler §3.A, p. 57

Resolving the prediction gate

Verdict: no — homogeneity alone does not give linearity. Define φ : R² → R by φ(x, y) = (x³ + y³)1/3, using the real cube root, which is defined for every real number.

It is homogeneous. φ(a(x, y)) = ((ax)³ + (ay)³)1/3 = (a³(x³ + y³))1/3 = a(x³ + y³)1/3 = aφ(x, y), where pulling a out of the cube root is legitimate for every real a, negative ones included, because the real cube root is an odd function.

It is not additive. φ(1, 0) + φ(0, 1) = 1 + 1 = 2, while φ((1, 0) + (0, 1)) = φ(1, 1) = 21/3, and 21/3 ≠ 2 since 2 ≠ 8. So φ satisfies one clause of Definition 3.2 and fails the other, and is not linear. — cf. Axler §3.A, Exercise 8, p. 58

The mirror-image question — is additivity alone enough? — has the same answer, and its counterexample is a problem in this unit's set.

Where the intuition goes wrong. Homogeneity is a statement about each line through the origin separately: it says φ is linear along that one line. Additivity is what ties different lines to each other. A function can behave impeccably on every line through the origin and still be wild in between, which is exactly what the cube-root example does. Axler's own version of this warning is aimed at students who write cos 2x = 2 cos x — a claim about one clause — and cos(x + y) = cos x + cos y — a claim about the other. — Axler §3.A, p. 55

Self-check 1. A function T : V → W satisfies T(0) ≠ 0. What can you conclude?

Theorem 3.11 says linear ⟹ T(0) = 0, so contrapositively T(0) ≠ 0 ⟹ not linear. This is the cheapest linearity test there is and should be your first move. The second option overstates: T(0) ≠ 0 rules out additivity and homogeneity separately, since either clause alone forces T(0) = 0. The third confuses the direction of a contrapositive with a converse.

Self-check 2. Is T : R³ → R², T(x, y, z) = (2x − 4y + 3z + 1, 6x) linear?

The constant +1 breaks Theorem 3.11 immediately, so no further checking is needed. "Degree 1" is the trap: a linear map permits no constant term, whereas the "linear functions" of school algebra, y = mx + c, do. The third option is a red herring — a linear map may certainly ignore some inputs; the zero map ignores all of them.

Segment 2 · ~25 min

A linear map is its values on a basis

Theorem 3.5 (linear maps and a basis of the domain). Suppose v₁, …, vn is a basis of V and w₁, …, wn ∈ W. Then there exists a unique linear map T : V → W with Tvj = wj for each j. — Axler §3.A, Theorem 3.5, p. 54

Two separate assertions live in that sentence, and each is worth stating in words. Existence: you may prescribe the values on a basis completely arbitrarily — any n vectors of W, in any order, with repeats allowed — and a linear map realising them exists. Uniqueness: having done so, there is nothing left to choose. A linear map is exactly as much data as its values on one basis, no more and no less.

Why it is true (the shape of Axler's proof). Existence. Define T(c₁v₁ + ⋯ + cnvn) = c₁w₁ + ⋯ + cnwn. The first thing to check is not that T is linear but that T is a function at all: the recipe assigns an output to an input by way of the input's coefficients, so it is well defined only because la-04's Theorem 2.29 says each v ∈ V has exactly one such list of coefficients. Take cj = 1 and the rest 0 to get Tvj = wj. Additivity and homogeneity then reduce to collecting coefficients, since adding two vectors adds their coefficient lists and scaling a vector scales its list.

Uniqueness. Suppose S is any linear map with Svj = wj. Homogeneity gives S(cjvj) = cjwj, and additivity assembles these into S(c₁v₁ + ⋯ + cnvn) = c₁w₁ + ⋯ + cnwn. So S is pinned on span(v₁, …, vn), which is V because the list is a basis, and S = T. — Axler §3.A, p. 54

Both halves of "basis" are used, and used for different things. Uniqueness of the coefficient list — the independence half — is what makes the formula define a function. Spanning is what makes the formula define a function on all of V. Drop independence and the recipe would assign two different outputs to one input; drop spanning and it would assign none to some inputs. A list that is merely independent, or merely spanning, gives you exactly one of the two conclusions of Theorem 3.5, and the problem set explores what goes wrong for a dependent list.

Theorem 3.5 is also the machine that extends a linear map from a subspace to the whole space, and every ingredient is already in hand. A subspace of a finite-dimensional space is itself finite-dimensional and therefore has a basis, and any basis of it extends to a basis of the whole space. — Axler §2.A, Theorem 2.26, p. 36 — Axler §2.B, Theorem 2.32 and Theorem 2.33, p. 41 Prescribe the old values on the old basis vectors and anything you please on the new ones, and the theorem above hands back a linear map agreeing with the original throughout the subspace. The problem set asks you to run that construction, and to compare it with a simpler-looking extension that turns out not to be linear at all.

Canvas: a linear map does not bend the grid

The blue grid is the standard one on R²; the amber grid is its image under a linear map T. The map shears and stretches, but straight lines stay straight, evenly spaced lines stay evenly spaced, and the origin does not move. That rigidity is Definition 3.2, drawn.

Self-check 3. V has basis v₁, v₂ and W = R³. How many linear maps T : V → W satisfy Tv₁ = (1, 0, 0) and Tv₂ = (1, 0, 0)?

Theorem 3.5 allows any choice of w₁, …, wn in W, including repeats, and yields exactly one map for each choice. The first option imports an injectivity requirement that is nowhere in the definition — this map sends v₁ − v₂ to 0, which is permitted and is la-06's subject. The third forgets uniqueness: values elsewhere are not free, they are forced by the values on the basis.

Segment 3 · ~20 min

Linear maps as a space, and as a multiplication

Definition 3.6 and Theorem 3.7 (ℒ(V, W) is itself a vector space). For S, T ∈ ℒ(V, W) and λ ∈ F, define (S + T)(v) = Sv + Tv and (λT)(v) = λ(Tv). With these operations ℒ(V, W) is a vector space, whose additive identity is the zero map. — Axler §3.A, Definition 3.6 and Theorem 3.7, p. 55

This is the first time the maps have become the vectors, and it is the move that makes the rest of the subject possible: la-10 studies ℒ(V, F) as a space in its own right, and la-08 computes its dimension. Notice that the definitions are the only ones available — a sum of functions must be computed pointwise — so the content is not the recipe but the claim that the results are still linear, which is what makes ℒ(V, W) closed under the operations.

Definition 3.8 (product of linear maps). If T ∈ ℒ(U, V) and S ∈ ℒ(V, W), the product ST ∈ ℒ(U, W) is defined by (ST)(u) = S(Tu). — Axler §3.A, Definition 3.8, p. 55

ST is ordinary composition S ∘ T, written multiplicatively because that is the convention once both functions are linear. Two consequences of writing it as a product should be resisted, and one should be embraced. It is defined only when T maps into the domain of S, so the notation hides a compatibility condition. It is not commutative. But it is associative, has the identity map as a unit, and distributes over addition on both sides. — Axler §3.A, Theorem 3.9, p. 56

Worked example — the product is genuinely not commutative (fully worked). Let D be differentiation on 𝒫(R) and let T be multiplication by x², both linear maps from 𝒫(R) to itself, so that TD and DT both make sense and both live in ℒ(𝒫(R), 𝒫(R)).

((TD)p)(x) means: differentiate first, then multiply by x². That gives x²p′(x).

((DT)p)(x) means: multiply by x² first, then differentiate. By the product rule, that gives x²p′(x) + 2xp(x).

These differ — take p(x) = 1, where TD gives 0 and DT gives 2x — so TD ≠ DT. The discrepancy 2xp(x) is exactly the product rule's extra term, which is a good way to remember that non-commutativity here is not an exotic pathology but something you have been computing since first-year calculus. — Axler §3.A, Example 3.10, p. 56

Self-check 4. S ∈ ℒ(R³, R²) and T ∈ ℒ(R², R³). Which products are defined?

ST needs T to map into S's domain: T lands in R³, which is S's domain, so ST is defined and maps R² → R². Symmetrically TS maps R³ → R³. Both exist, and they are not even maps between the same pair of spaces — a vivid reason why ST = TS is not something to expect.

Self-check 5. Why does Theorem 3.7 need proving at all, given that the definitions of S + T and λT are the only sensible ones?

Closure is the part that is not free: S + T is obviously a function, and the axioms do follow pointwise from those in W, but that S + T is again linear is a claim about Definition 3.2 and must be verified. It is the same structure as la-02's subspace test, where the axioms are inherited and only closure and the identity need checking. The third option is wrong: the zero map is already available, and is the identity.

Guided proof practice

Write your own proof. Suppose T ∈ ℒ(V, W) and v₁, …, vm is a list of vectors in V such that Tv₁, …, Tvm is linearly independent in W. Prove that v₁, …, vm is linearly independent. (Start from a dependence relation among the v's and apply T to it. You will need Theorem 3.11 at one specific step — notice where.) — cf. Axler §3.A, Exercise 4, p. 57

Reveal model answer

Proof. Suppose a₁, …, am ∈ F satisfy a₁v₁ + ⋯ + amvm = 0. Apply T to both sides. On the left, additivity (used m − 1 times) and homogeneity (used m times) give T(a₁v₁ + ⋯ + amvm) = a₁Tv₁ + ⋯ + amTvm. On the right, T(0) = 0 by Theorem 3.11 — this is the step that needs it, and without it the right-hand side would be an unknown vector rather than 0.

So a₁Tv₁ + ⋯ + amTvm = 0. Since Tv₁, …, Tvm is linearly independent, every aj = 0. Hence the only dependence relation among v₁, …, vm is the trivial one, and the list is linearly independent by la-03's Definition 2.17. ∎

The converse is false, and knowing why is worth as much as the proof. Take T = 0, the zero map: v₁, …, vm may be as independent as you like, and Tv₁, …, Tvm is a list of zeros, which is dependent. Independence transfers backwards along a linear map for free, and forwards only under a condition — injectivity — that la-06 identifies.

Reveal the skeleton to check against
  1. A linear map (Definition 3.2) is a function satisfying additivity and homogeneity — the operations on the left happening in V and on the right in W. The two clauses are genuinely independent: either can hold without the other, so neither may be dropped. An immediate consequence, and the cheapest test available, is T(0) = 0 (Theorem 3.11).
  2. On a finite-dimensional domain, a linear map is its values on a basis: those values may be prescribed arbitrarily, and once prescribed the map is unique (Theorem 3.5). Independence of the basis is what makes the defining formula single-valued; spanning is what makes it defined everywhere.
  3. The maps themselves form a vector space ℒ(V, W) under pointwise operations (Theorem 3.7), and composable maps multiply (Definition 3.8). That multiplication is associative, unital and distributive (Theorem 3.9) but not commutative — differentiation and multiplication by x² differ by exactly the product rule's extra term (Example 3.10).
