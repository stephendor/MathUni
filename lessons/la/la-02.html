Subspaces, sums, direct sums (la-02)

When does a plane plus a line fill space? Direct sums as jigsaw pieces.

Take the xy-plane sitting inside R³, and the z-axis, a line through the origin poking straight through it. Add every point of the plane to every point of the line — all possible sums — and you get the whole of R³ back. Every point in space is some plane-point plus some line-point, and — this is the part that makes it a genuine jigsaw rather than a sloppy overlap — there is exactly one way to split any given point into its plane-piece and its line-piece. No ambiguity, no double-counting.

Contrast that with three flat pieces glued clumsily: if any two of your "puzzle pieces" already overlap in more than just the corner point, the decomposition stops being unique, and the jigsaw metaphor breaks. This lesson makes that difference precise. First we pin down exactly which subsets of a vector space deserve to be called subspaces — the legitimate jigsaw pieces — and then we pin down exactly when gluing them back together, via a sum, gives a direct sum: a reconstruction with no seams doubled and nothing wasted.

Prediction gate — commit before reading on. Suppose U₁, U₂, U₃ are three subspaces of a vector space V, and every pair of them intersects only at 0 (Uᵢ ∩ Uⱼ = {0} for every i ≠ j). Do you predict this is enough to guarantee that U₁ + U₂ + U₃ is a direct sum — yes or no? Hold that answer in your head; the lesson will hand you the verdict, with a concrete example, before the first break.

Why this matters for the mission: Cycles and boundaries sit inside chains as subspaces.

Segment 1 · ~20 min

Subspaces: legitimate pieces of a vector space

Recall from la-01 that a vector space is a set with an addition and scalar multiplication satisfying Definition 1.19's eight properties. A subspace asks: what if a subset of an existing vector space is, on its own, also a vector space, using the same operations inherited from the bigger space?

Definition 1.32. A subset U of V is called a subspace of V if U is also a vector space (using the same addition and scalar multiplication as on V). — Axler §1.C, Definition 1.32, p. 18

Checking all eight vector-space axioms every time would be tedious — and unnecessary, because a subset of V already inherits commutativity, associativity, and the distributive laws for free (they hold on all of V, so they certainly hold on any subset). What can actually fail are just three things: does the subset contain the zero vector, is it closed under addition, and is it closed under scalar multiplication? That collapses the check to a three-item test.

Theorem 1.34 (subspace test). A subset U of V is a subspace of V if and only if U satisfies: additive identity 0 ∈ U; closed under addition u, w ∈ U implies u + w ∈ U; closed under scalar multiplication a ∈ F and u ∈ U implies au ∈ U. — Axler §1.C, Theorem 1.34, pp. 18–19

Axler flags a subtlety worth holding onto: the additive-identity condition could technically be replaced by "U is nonempty", since a nonempty U closed under scaling automatically contains 0 (take any u ∈ U and multiply by the scalar 0). — Axler §1.C, p. 18 But in practice, checking 0 ∈ U directly is almost always the fastest move, and it's usually the first thing that fails — so it earns its place as the first checklist item, not an afterthought.

The classic traps: examples and non-examples

The subspace test is easy to state and easy to misapply. The traps below are exactly the ones Cummings-style faded proofs are built to catch — read the non-examples as carefully as the examples.

Worked example — a genuine subspace (fully worked). Show that U = {(x₁, x₂, 0) : x₁, x₂ ∈ F} is a subspace of F³.

Proof. Additive identity: 0 = (0, 0, 0) has third coordinate 0, so 0 ∈ U. Closed under addition: if u = (a₁, a₂, 0) and w = (b₁, b₂, 0) are both in U, then u + w = (a₁ + b₁, a₂ + b₂, 0), which still has third coordinate 0, so u + w ∈ U. Closed under scalar multiplication: if λ ∈ F and u = (a₁, a₂, 0) ∈ U, then λu = (λa₁, λa₂, 0), still third coordinate 0, so λu ∈ U. All three conditions of Theorem 1.34 hold, so U is a subspace of F³. ∎

— Axler §1.C, Example 1.33, p. 18

Faded example — the classic offset trap (your turn to fill the gaps). Fix b ∈ F. Show that W = {(x₁, x₂, x₃, x₄) ∈ F⁴ : x₃ = 5x₄ + b} is a subspace of F⁴ if and only if b = 0.

Proof (the "if b = 0" direction). Suppose b = 0, so W = {(x₁, x₂, x₃, x₄) : x₃ = 5x₄}. Additive identity: for 0 = (0,0,0,0), check 0 = 5·0, so ⟨your step: state the conclusion for this condition⟩. Closed under addition: if (a₁,a₂,a₃,a₄) and (c₁,c₂,c₃,c₄) both satisfy the defining equation, so a₃ = 5a₄ and c₃ = 5c₄, then adding these two equations gives ⟨your step: write the equation the sum's third and fourth coordinates satisfy⟩, so the sum lies in W too. Closed under scalar multiplication: similarly, scaling a₃ = 5a₄ by λ gives ⟨your step: write the scaled equation⟩, so λ(a₁,a₂,a₃,a₄) ∈ W.

Proof (the "only if" direction — why b ≠ 0 fails). Suppose b ≠ 0. Then 0 = (0,0,0,0) would need to satisfy 0 = 5·0 + b, i.e. ⟨your step: what does this force b to equal, and why does that contradict b ≠ 0?⟩. So the additive identity condition fails, and by Theorem 1.34, W is not a subspace when b ≠ 0. ∎

— Axler §1.C, Example 1.35(a), p. 19

That offset trap is the single most common mistake: a set defined by a linear but inhomogeneous equation (one with a leftover constant, like "= b" instead of "= 0") almost never contains the zero vector unless the constant happens to be zero. Spot the "+b" or "= 4" in a defining equation, and check 0 first — it usually fails instantly.

Two more useful facts to hold onto before moving on: {0} alone is always a subspace (the smallest one), and V itself is always a subspace of V (the largest one). The empty set, meanwhile, is never a subspace of anything — a subspace must be a vector space, and every vector space contains at least one element, its additive identity. — Axler §1.C, p. 19

Self-check 1. A subset U of V contains 0, and is closed under addition, but is not closed under scalar multiplication. Is U a subspace of V?

Theorem 1.34 is an "if and only if" over all three conditions together. Failing closure under scalar multiplication alone is enough to disqualify U as a subspace, no matter how the other two conditions fare.

Self-check 2. {(x₁, x₂, x₃) ∈ F³ : x₁ + 2x₂ + 3x₃ = 4} fails to be a subspace of F³ because…

0 + 2·0 + 3·0 = 0 ≠ 4, so 0 ∉ the set — the additive-identity condition of Theorem 1.34 already fails, exactly the offset trap of Example 1.35(a) with b = 4 ≠ 0.

Segment 2 · ~20 min

Sums of subspaces, and why "cancellation" fails

Subspaces are the pieces. The sum of subspaces is the set of all ways of adding one element from each piece:

Definition 1.36. Suppose U₁, …, Um are subsets of V. The sum of U₁, …, Um, denoted U₁ + ⋯ + Um, is U₁ + ⋯ + Um = {u₁ + ⋯ + um : u₁ ∈ U₁, …, um ∈ Um}. — Axler §1.C, Definition 1.36, p. 20

Sums of subspaces play the role for vector spaces that unions play for sets: the sum U₁ + ⋯ + Um is provably the smallest subspace of V containing all of U₁, …, Um.

Theorem 1.39 (sum is the smallest containing subspace). Suppose U₁, …, Um are subspaces of V. Then U₁ + ⋯ + Um is the smallest subspace of V containing U₁, …, Um. — Axler §1.C, Theorem 1.39, pp. 20–21

Axler notes why we bother with sums rather than plain unions at all: "the union of subspaces is rarely a subspace" — union alone doesn't stay closed under addition, so sum is the operation that actually produces another vector space. — Axler §1.C, p. 20

Before the next worked example, one small fact needs pinning down explicitly — it is exactly the kind of "obvious" sub-step Axler doesn't dignify with its own numbered result, but the problem set leans on it directly, so it earns a proof here rather than being invented cold during grading.

Intermediate lemma (idempotence of self-sum). If U is a subspace of V, then U + U = U.

Proof. Two inclusions. (⊆) If u₁, u₂ ∈ U, then u₁ + u₂ ∈ U since U is closed under addition (Theorem 1.34's second condition). So every element of U + U already lies in U. (⊇) If u ∈ U, write u = u + 0, and since 0 ∈ U (Theorem 1.34's first condition), this exhibits u as a sum of two elements of U, so u ∈ U + U. Both inclusions give U + U = U. ∎

Notice what made that proof work: subspaces absorb their own sum precisely because they already contain everything a sum could produce, plus the zero vector to pad out any "single" element into a two-term sum. This is the template for Problem 2 on the problem set.

The cancellation trap

Ordinary arithmetic has a cancellation law: if a + c = b + c, then a = b. It is tempting to assume the analogous statement for subspaces — if U₁ + W = U₂ + W, surely U₁ = U₂? — but sums of subspaces do not behave like sums of numbers, because a "big enough" W can absorb the entire difference between two very different subspaces.

Faded example — cancellation fails (your turn to fill the gaps). Give a counterexample to: "if U₁, U₂, W are subspaces of V with U₁ + W = U₂ + W, then U₁ = U₂."

Construction. Work in V = F². Let W = F² itself (the whole space is always a subspace of itself). Let U₁ = {0} and U₂ = F² (two subspaces that are as different as possible). Then U₁ + W = ⟨your step: compute {0} + F² using Definition 1.36⟩, and U₂ + W = ⟨your step: compute F² + F²⟩. So U₁ + W = U₂ + W ⟨your step: state which specific subspace both sides equal⟩, yet U₁ ≠ U₂ since one is {0} and the other is all of F². This refutes the claim. ∎

— cf. Axler §1.C, Exercise 19, p. 26

The lesson: when W is large enough to swallow both U₁ and U₂ on its own, the sum records nothing about which of U₁ or U₂ was actually added — exactly the information a genuine "cancellation" would need to recover. Whenever a sum of subspaces looks like it should cancel, check first whether one of the summands is already big enough to make the equation trivially true.

Self-check 3. If U is a subspace of V, what is U + {0}?

Every u ∈ U can be written u + 0 with 0 ∈ {0}, and every element of U + {0} has the form u + 0 = u ∈ U. So U + {0} = U — the same idempotence idea as the U + U = U lemma, just with the trivial subspace instead of U itself.

Self-check 4. U₁ + W = U₂ + W does NOT in general imply U₁ = U₂. What does the F² counterexample above rely on to break the "cancellation"?

The trick is entirely about W's size: once W = V, adding literally any subspace U to W gives V back, erasing all information about which U was used. Addition of subspaces is commutative — that's not the issue.

Segment 3 · ~25 min

Direct sums: the jigsaw made precise

A sum can be generous to the point of redundancy — the same vector might be reachable as u₁ + ⋯ + um in more than one way. When it can't — when every vector in the sum has exactly one such decomposition — the sum earns a special name and a special symbol.

Definition 1.40. Suppose U₁, …, Um are subspaces of V. The sum U₁ + ⋯ + Um is called a direct sum if each element of U₁ + ⋯ + Um can be written in only one way as a sum u₁ + ⋯ + um, where each uj ∈ Uj. When it is, we write U₁ ⊕ ⋯ ⊕ Um. — Axler §1.C, Definition 1.40, p. 21

The ⊕ symbol — a plus sign wrapped in a circle — is a deliberate visual reminder that something extra beyond a mere sum is being promised: uniqueness of decomposition. — Axler §1.C, p. 22 This is precisely the jigsaw property from the hook: R³ = (xy-plane) ⊕ (z-axis) because every point splits into a plane-part and an axis-part in exactly one way.

A rotating wireframe of the xy-plane (blue mesh) and the z-axis (amber line) inside a projected R³. Together they sweep out all of space — and any point you'd mark decomposes into exactly one plane-point plus one axis-point.

Worked example — a genuine direct sum (fully worked). Let U = {(x, y, 0) ∈ F³ : x, y ∈ F} and W = {(0, 0, z) ∈ F³ : z ∈ F}. Show F³ = U ⊕ W.

Proof. Sum equals F³: any (x,y,z) ∈ F³ can be written (x,y,z) = (x,y,0) + (0,0,z), with the first summand in U and the second in W. So U + W = F³. Directness: by Theorem 1.44 it suffices to show 0 decomposes uniquely. Suppose 0 = u + w with u = (a,b,0) ∈ U and w = (0,0,c) ∈ W. Then (a,b,c) = (0,0,0), forcing a = b = c = 0, so u = w = 0 — the only decomposition of 0 is the trivial one. Hence F³ = U ⊕ W. ∎

— Axler §1.C, Example 1.41, p. 21

Checking directness via "0 decomposes uniquely" rather than checking every single vector is not a shortcut invented for the example above — it's a theorem, and it's the tool that makes direct-sum verification tractable in general:

Theorem 1.44. Suppose U₁, …, Um are subspaces of V. Then U₁ + ⋯ + Um is a direct sum if and only if the only way to write 0 as u₁ + ⋯ + um, each uj ∈ Uj, is by taking every uj = 0. — Axler §1.C, Theorem 1.44, pp. 22–23

For exactly two subspaces this collapses further, to a test about intersection:

Theorem 1.45. Suppose U and W are subspaces of V. Then U + W is a direct sum if and only if U ∩ W = {0}. — Axler §1.C, Theorem 1.45, p. 23

Resolving the prediction gate

Time to settle the question posed before Segment 1: is pairwise intersection {0} enough for three subspaces to form a direct sum? The faded example below is the answer, and it is deliberately unsettling.

Faded example — a sum that is not direct, despite pairwise-trivial intersections (your turn to fill the gaps). Let U₁ = {(x,y,0)}, U₂ = {(0,0,z)}, U₃ = {(0,y,y)} (all inside F³, coordinates ranging over F). Show U₁ + U₂ + U₃ = F³, that every pairwise intersection is {0}, yet the sum is not direct.

Solution. The sum is all of F³: any (x,y,z) = (x,y,0) + (0,0,z) + (0,0,0), with the pieces in U₁, U₂, U₃ respectively. Pairwise intersections: a vector in U₁ ∩ U₂ has both third coordinate free-yet-0 and first two coordinates 0, forcing the zero vector; similarly for the other two pairs — check U₁ ∩ U₃ and U₂ ∩ U₃ each force ⟨your step: which single coordinate value being forced to 0 collapses each intersection to {0}?⟩. Not direct: by Theorem 1.44 it suffices to exhibit two different ways to write 0 as u₁ + u₂ + u₃. One way is the trivial (0,0,0)+(0,0,0)+(0,0,0). For the other, try u₃ = (0,1,1) ∈ U₃. Then u₁ must supply ⟨your step: what vector in U₁ cancels the y-coordinate contributed by u₃, and what must its own z-coordinate be?⟩, and u₂ must supply ⟨your step: what vector in U₂ cancels the remaining z-coordinate?⟩. Check: u₁ + u₂ + u₃ = ⟨your step: add the three vectors and confirm the total is (0,0,0)⟩. Since 0 has two distinct decompositions — the trivial one and this one — Theorem 1.44 says the sum is not direct, even though every pairwise intersection is {0} and the sum equals all of F³. ∎

— Axler §1.C, Example 1.43, pp. 21–22

So the verdict on the prediction gate is no: pairwise-trivial intersection is necessary for three or more subspaces to sum directly, but nowhere near sufficient. Theorem 1.45's clean intersection test is a genuine special privilege of the two-subspace case — it does not generalise verbatim. For three or more subspaces, Theorem 1.44's "0 decomposes uniquely" condition is the only fully general tool, and there is no shortcut through pairwise checks.

A direct sum that isn't made of coordinate slots: even and odd functions

Every example so far has split coordinates of Fⁿ. Direct sums show up far more generally — the next one lives inside the (infinite-dimensional) vector space RR of all real-valued functions on R, and it is the technique behind Problem 4 on the problem set.

Worked example — even and odd functions (fully worked). Let Ue = {f ∈ RR : f(−x) = f(x) for all x} (the even functions) and Uo = {f ∈ RR : f(−x) = −f(x) for all x} (the odd functions). Show RR = Ue ⊕ Uo.

Proof. Ue and Uo are subspaces of RR by Theorem 1.34 (both contain the zero function, and both are closed under addition and scalar multiplication — routine checks directly from the defining equations). Sum is everything: given any f ∈ RR, define g(x) = ½(f(x) + f(−x)) and h(x) = ½(f(x) − f(−x)). Then g(−x) = ½(f(−x) + f(x)) = g(x), so g ∈ Ue; and h(−x) = ½(f(−x) − f(x)) = −h(x), so h ∈ Uo. Adding, g(x) + h(x) = f(x), so f = g + h ∈ Ue + Uo. Hence RR = Ue + Uo. Directness: by Theorem 1.44, suppose 0 = g + h with g ∈ Ue, h ∈ Uo. Then g(x) = −h(x) for every x. Substituting −x: g(−x) = −h(−x), and since g is even and h is odd this reads g(x) = −(−h(x)) = h(x). Combined with g(x) = −h(x) from before, h(x) = −h(x), so 2h(x) = 0, i.e. h(x) = 0 for every x — so h is the zero function, and then g = −h = 0 too. The only decomposition of 0 is the trivial one, so by Theorem 1.44 the sum is direct: RR = Ue ⊕ Uo. ∎

— cf. Axler §1.C, Exercise 24, p. 26

Self-check 5. Subspaces U and W of V satisfy U ∩ W = {0}. What can you conclude?

Theorem 1.45 says exactly this for two subspaces: the intersection being {0} is equivalent to directness. It says nothing about whether the sum fills all of V — that's a separate question. And two subspaces can never be fully disjoint since both always contain 0.

Self-check 6. To check whether U₁ + U₂ + U₃ (three subspaces) is a direct sum, which is the correct tool?

Example 1.43 is the cautionary tale: three subspaces can be pairwise-{0}-intersecting and still fail to form a direct sum. Theorem 1.45's pairwise test is only valid for exactly two subspaces; for three or more, Theorem 1.44's "0 decomposes uniquely" test is the one that actually works.

Self-check 7. In Example 1.43, U₁+U₂+U₃ = F³ but the sum is not direct. What does this demonstrate?

The whole point of the jigsaw metaphor: reconstructing the full space is easy to arrange, but directness additionally demands that the reconstruction be unique. F³ = U₁ ⊕ U₂ ⊕ U₃ can be achieved with a better choice of pieces (e.g. Example 1.42's coordinate-slot subspaces) — it's this particular triple that fails.

Guided proof practice

Write your own proof. Prove: if U is a subspace of a vector space V, then U ⊕ {0} = U — that is, summing any subspace with the trivial subspace {0} is always direct, and gives back U exactly. (You already showed U + {0} = U in Self-check 3; now you must additionally establish directness, using Theorem 1.44 or Theorem 1.45.)

Reveal model answer

Proof. From Self-check 3 (or the U + U = U lemma's method), U + {0} = U, so it remains only to check directness. By Theorem 1.45 (valid here since we have exactly two subspaces, U and {0}), U + {0} is direct if and only if U ∩ {0} = {0}. Now U ∩ {0} ⊆ {0} trivially (since {0} has only one element), and 0 ∈ U always (Theorem 1.34's additive-identity condition), so 0 ∈ U ∩ {0}, giving {0} ⊆ U ∩ {0} as well. Hence U ∩ {0} = {0}, so by Theorem 1.45 the sum U + {0} is direct. Combining with U + {0} = U, we get U ⊕ {0} = U. ∎

Equivalent route via Theorem 1.44 directly: if 0 = u + z with u ∈ U and z ∈ {0}, then z = 0 automatically (the only element of {0}), forcing u = 0 too — so the only decomposition of 0 is trivial, giving directness.

Reveal the skeleton to check against
  1. A subspace is a subset that is itself a vector space — which reduces, via Theorem 1.34, to just three checks (0 ∈ U, closed under +, closed under scalar multiplication), because the other vector-space axioms are inherited for free from the ambient space.
  2. Gluing subspaces back together via sum (Definition 1.36) always gives the smallest subspace containing them (Theorem 1.39) — but a sum can be redundant: the same vector can be reachable in more than one way, and "cancellation" (U₁+W=U₂+W ⟹ U₁=U₂) fails for exactly this reason.
  3. A sum is called direct exactly when that redundancy vanishes — every vector has a unique decomposition — and this reduces (Theorem 1.44) to checking only whether 0 decomposes uniquely. For two subspaces this becomes a clean intersection test (Theorem 1.45); for three or more, pairwise-trivial intersections are not enough (Example 1.43), and only the direct 0-decomposition check (Theorem 1.44) is fully general.
