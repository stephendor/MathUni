Span and linear independence (la-03)

Redundancy detection: which vectors are freeloaders?

Hand someone four vectors in R³ and ask what they generate. Whatever the answer is, at least one of the four is dead weight: you could delete it and generate exactly the same set. That is not a fact about those particular four vectors — it is forced, and by the end of this lesson you will be able to prove it without looking at a single coordinate.

The two ideas that make it work are opposites. Span measures how much a list generates: bigger lists span more. Linear independence measures how efficiently it does so: no vector in the list is reachable from the others. Push them together and you get a squeeze — an independent list can never be longer than a spanning list — and every dimension count in the rest of mathematics is a consequence of that one inequality.

Prediction gate — commit before reading on. A list of vectors is called linearly dependent when it has redundancy in it. Suppose you are told that v₁, …, vm is linearly dependent. Do you predict it follows that every vector in the list is a linear combination of the others — yes or no? Write down your answer, and if you predict "no", try to produce a three-vector list in F² that settles it. The verdict arrives in Segment 3.

Why this matters for the mission: Betti numbers count independent cycles — independence is the point.

Segment 1 · ~20 min

Span: everything a list can reach

Fix a vector space V over F, where F is R or C. Lists of vectors are written without parentheses — v₁, v₂, v₃ — to keep them visually distinct from the tuples inside Fⁿ. — Axler §2.A, Notation 2.2, p. 28

Definition 2.3 (linear combination). A linear combination of a list v₁, …, vm of vectors in V is a vector of the form a₁v₁ + ⋯ + amvm, where a₁, …, am ∈ F. — Axler §2.A, Definition 2.3, p. 28

Two operations, nothing else: scale each vector, then add. That is the whole vocabulary la-01 gave us, and the whole vocabulary linear algebra will ever use.

Worked example — deciding membership by hand (fully worked). In F³, is (17, −4, 2) a linear combination of (2, 1, −3) and (1, −2, 4)?

We are asking whether scalars a₁, a₂ exist with (17, −4, 2) = a₁(2, 1, −3) + a₂(1, −2, 4). Comparing slots gives three equations: 17 = 2a₁ + a₂, −4 = a₁ − 2a₂, 2 = −3a₁ + 4a₂. From the first two, a₂ = 17 − 2a₁ and a₁ − 2(17 − 2a₁) = −4, so 5a₁ = 30 and a₁ = 6, a₂ = 5. The third equation is not automatic — it is a genuine constraint and must be checked: −3(6) + 4(5) = −18 + 20 = 2. ✓ So (17, −4, 2) = 6(2, 1, −3) + 5(1, −2, 4).

Change the last slot to 5 and the same first two equations still force a₁ = 6, a₂ = 5, but now the third demands −18 + 20 = 5, which is false. So (17, −4, 5) is not a linear combination of that pair. The lesson to carry: solving a subsystem does not settle the question. The leftover equations are where the answer actually lives. — Axler §2.A, Example 2.4, p. 28

Definition 2.5 (span). The set of all linear combinations of v₁, …, vm in V is called the span of the list, written span(v₁, …, vm) = {a₁v₁ + ⋯ + amvm : a₁, …, am ∈ F}. The span of the empty list ( ) is defined to be {0}. — Axler §2.A, Definition 2.5, p. 29

That last clause looks like bookkeeping and is not. Defining span( ) = {0} rather than ∅ is what makes the empty list behave like a legitimate list all the way through the theory — it is the reason the results below need no exception for m = 0, and it is exactly the convention that Segment 3's lemma leans on.

Theorem 2.7 (span is the smallest containing subspace). The span of a list of vectors in V is the smallest subspace of V containing all the vectors in the list. — Axler §2.A, Theorem 2.7, p. 29
Why it is true (the shape of Axler's proof). Two halves, and it is worth seeing that they are genuinely different jobs.

Half one: the span is a subspace. Run la-02's Theorem 1.34 checklist. 0 = 0v₁ + ⋯ + 0vm is a linear combination, so 0 is in. Adding two linear combinations gives (a₁ + c₁)v₁ + ⋯ + (am + cm)vm, again a linear combination. Scaling gives λa₁v₁ + ⋯ + λamvm, likewise. All three conditions hold.

Half two: it is the smallest such. Each vj is itself in the span (take aj = 1 and the rest 0), so the span does contain the list. Conversely, let U be any subspace containing every vj. Being closed under scalar multiplication and addition, U must contain every a₁v₁ + ⋯ + amvm — that is, U ⊇ span(v₁, …, vm). So the span sits inside every competitor, which is what "smallest" means. — Axler §2.A, p. 29

Reading a "smallest object" claim. "Smallest X containing Y" is always two obligations: it is an X and it contains Y, and it fits inside every X that contains Y. Proving only the first is the standard way to lose half the marks. You will meet this exact pattern again in la-04 (extending to a basis) and in every "generated by" construction in the semester.
Definition 2.8 (spans) and Definition 2.10 (finite-dimensional). If span(v₁, …, vm) equals V, we say the list spans V. A vector space is finite-dimensional if some list of vectors in it spans the space; it is infinite-dimensional if it is not finite-dimensional. — Axler §2.A, Definitions 2.8, 2.10, pp. 30, and Definition 2.15, p. 31

Note what "finite-dimensional" does not yet say: no number has been attached to V. It says only that some finite list is enough. Pinning down a number — and showing every honest count gives the same one — is la-04's entire job, and it depends on the theorem in Segment 3.

Worked example — Fⁿ is finite-dimensional (fully worked). Let ej be the n-tuple with 1 in slot j and 0 elsewhere. For any (x₁, …, xn) ∈ Fⁿ we have (x₁, …, xn) = x₁e₁ + ⋯ + xnen, so every element of Fⁿ lies in span(e₁, …, en). Hence that list spans Fⁿ, and Fⁿ is finite-dimensional. — Axler §2.A, Example 2.9, p. 30
Contrast — 𝒫(F) is infinite-dimensional (fully worked). Let 𝒫(F) be the space of all polynomials with coefficients in F, and 𝒫m(F) those of degree at most m. Take any list of polynomials and let m be the largest degree appearing in it. Every linear combination of the list has degree at most m, so zm+1 is not in its span. No list spans 𝒫(F), so 𝒫(F) is infinite-dimensional.

The move worth stealing: to show no list works, you do not enumerate lists. You take an arbitrary one, extract one number from it (here the top degree), and build the escapee out of that number. — Axler §2.A, Example 2.16, p. 32, with Definitions 2.11–2.13, pp. 30–31

Self-check 1. In R³, what is span((1, 0, 0), (2, 0, 0))?

Every linear combination is a₁(1,0,0) + a₂(2,0,0) = (a₁ + 2a₂, 0, 0), and as the scalars range over R the quantity a₁ + 2a₂ takes every real value. So the span is a line, even though the list has length 2 — the second vector adds nothing, which is precisely the redundancy Segment 2 names.

Self-check 2. Why is span( ) defined to be {0} rather than the empty set?

Theorem 2.7 says every span is a subspace, and la-02 established that ∅ is never a subspace — a subspace must contain 0. {0} is the only candidate that keeps Theorem 2.7 true with no exception carved out for the empty list. The third option is tempting but backwards: Definition 2.3 needs at least one vector before it produces anything, so it does not by itself deliver 0 from an empty list; the value {0} is a definition made to keep the theory seamless.

Segment 2 · ~20 min

Linear independence: spanning without waste

Here is the question that produces the definition. Suppose v ∈ span(v₁, …, vm), so v = a₁v₁ + ⋯ + amvm for some scalars. Are those scalars forced? Suppose v = c₁v₁ + ⋯ + cmvm as well. Subtracting,

0 = (a₁ − c₁)v₁ + ⋯ + (am − cm)vm.

So the two representations agree exactly when the only way to write 0 as a combination of the list is with all scalars 0. Uniqueness of representation and triviality of the zero-representation are the same condition, transported. That single observation is why the definition below is stated about 0 and not about a general vector. — Axler §2.A, p. 32

Definition 2.17 (linearly independent). A list v₁, …, vm of vectors in V is linearly independent if the only choice of a₁, …, am ∈ F making a₁v₁ + ⋯ + amvm equal 0 is a₁ = ⋯ = am = 0. The empty list ( ) is declared linearly independent. — Axler §2.A, Definition 2.17, p. 32
Definition 2.19 (linearly dependent). A list is linearly dependent if it is not linearly independent — equivalently, if there exist a₁, …, am ∈ F, not all 0, with a₁v₁ + ⋯ + amvm = 0. — Axler §2.A, Definition 2.19, p. 33
The two words that carry the definition. "Not all 0" is not the same as "all nonzero". A dependence relation is allowed — usually required — to have some zero coefficients; it must merely have at least one nonzero one. Students who read it as "all nonzero" conclude, wrongly, that a list containing 0 might be independent. It never is: 1·0 = 0 is a dependence relation with a single nonzero coefficient. — Axler §2.A, Example 2.20, p. 33

Small cases are worth memorising, because they turn a definition into something you can see. A one-vector list v is independent exactly when v ≠ 0. A two-vector list is independent exactly when neither vector is a scalar multiple of the other. And any list containing 0 is dependent. — Axler §2.A, Example 2.18, p. 33

Canvas: independence and redundancy in R³

Two vectors (blue, green) span a plane through the origin; the third (amber) is drawn sweeping in and out of that plane. When it lies in the plane the list is dependent and the span stays two-dimensional; when it leaves, the span jumps to all of R³. The plane mesh is the span of the first two.

Worked example — a dependence relation, found by hand (fully worked). Show (2, 3, 1), (1, −1, 2), (7, 3, 8) is linearly dependent in F³.

We must produce scalars, not all zero, killing the combination. Try a(2, 3, 1) + b(1, −1, 2) + c(7, 3, 8) = (0, 0, 0). Set c = −1 and solve the first two slots: 2a + b = 7 and 3a − b = 3. Adding, 5a = 10, so a = 2 and b = 3. As always, the remaining slot is a real check, not a formality: a + 2b + 8c = 2 + 6 − 8 = 0. ✓

So 2(2, 3, 1) + 3(1, −1, 2) + (−1)(7, 3, 8) = (0, 0, 0), with coefficients 2, 3, −1 — not all zero. The list is dependent. — Axler §2.A, Example 2.20, p. 33

You try (solo). Regard C as a vector space over R and show that the list 1 + i, 1 − i is linearly independent. Then regard C as a vector space over C and show the same list is linearly dependent. (Hint: independence is a statement about a list and the field of scalars you are allowed to use, and nothing about the vectors changes between the two parts. In the second part, ask what you may multiply 1 + i by to reach 1 − i.) — cf. Axler §2.A, Exercise 5, p. 37

Self-check 3. The list (1, 2), (2, 4), (0, 1) in R² is linearly dependent. Which of these is a correct dependence relation?

2(1, 2) − 1(2, 4) = (2 − 2, 4 − 4) = (0, 0), and the coefficients 2, −1, 0 are not all zero — the zero coefficient on (0, 1) is entirely legitimate, which is the "not all 0" point above. The third option is simply false: it sums to (3, 7). The second confuses "having three vectors" with "having a relation"; three vectors in R² are always dependent, but that is a theorem (Segment 3), not a definition.

Segment 3 · ~25 min

The squeeze: independent ≤ spanning

Resolving the prediction gate

The verdict: no. Dependence does not make every vector in the list a combination of the others. Take (1, 0), (2, 0), (0, 1) in F². It is dependent — 2(1, 0) + (−1)(2, 0) + 0(0, 1) = (0, 0). But (0, 1) is not a linear combination of (1, 0) and (2, 0): every such combination has second slot 0, and (0, 1) does not.

What dependence gives you is some removable vector, not any one you nominate. The lemma below says precisely which ones qualify, and it is sharper than "some": it hands you a specific position j, and it guarantees that deleting that one does not shrink the span at all.

Lemma 2.21 (Linear Dependence Lemma). Suppose v₁, …, vm is a linearly dependent list in V. Then there exists j ∈ {1, …, m} such that (a) vj ∈ span(v₁, …, vj−1), and (b) removing the j-th term from the list leaves the span unchanged. — Axler §2.A, Lemma 2.21, p. 34
Why it is true (the shape of Axler's proof). Dependence gives scalars a₁, …, am, not all 0, with a₁v₁ + ⋯ + amvm = 0. Let j be the largest index with aj ≠ 0 — the choice of largest is the whole trick, because it makes every term after position j vanish. Then all the surviving terms sit at positions below j, and dividing by aj (legal exactly because aj ≠ 0) gives

vj = −(a₁/aj)v₁ − ⋯ − (aj−1/aj)vj−1,

which is (a). For (b), any u in the original span is some c₁v₁ + ⋯ + cmvm; substitute the displayed expression for vj and u is exhibited as a combination of the shortened list. The reverse inclusion is free, since the shortened list is part of the original. — Axler §2.A, pp. 34

The j = 1 case is where the empty-list convention earns its keep: (a) then reads v₁ ∈ span( ) = {0}, i.e. v₁ = 0, which is exactly right and needs no separate clause. — Axler §2.A, p. 34

Theorem 2.23 (independent ≤ spanning). In a finite-dimensional vector space, the length of every linearly independent list of vectors is less than or equal to the length of every spanning list of vectors. — Axler §2.A, Theorem 2.23, p. 35
Why it is true (the shape of Axler's proof). Let u₁, …, um be independent and w₁, …, wn spanning; we want m ≤ n. Run a swap process, keeping a list B of length exactly n that spans V at every stage.

Step 1. Start with B = w₁, …, wn. Adjoining u₁ makes it dependent (the newcomer is already in the span). Apply the Linear Dependence Lemma: some term is in the span of its predecessors and can be deleted without changing the span. It cannot be u₁, since u₁ sits first and span( ) = {0} while u₁ ≠ 0. So a w goes, and B — now u₁ plus n − 1 of the w's — still spans, still has length n.

Step j. Adjoin uj just after u₁, …, uj−1. The result is dependent, so the lemma removes something. The removed term cannot be one of the u's: that would put some u in the span of earlier u's, contradicting independence of u₁, …, uj. So again a w goes.

Each of the m steps consumes one w, and there are only n of them, so m ≤ n. — Axler §2.A, p. 35

What the theorem is for. It converts counting into proof. Two corollaries fall out with no computation at all: a list longer than some spanning list cannot be independent, and a list shorter than some independent list cannot span. Both are used constantly, and both look like magic the first time — you settle a question about specific vectors by never looking at them.
Worked example — two verdicts with no arithmetic (fully worked).

(i) Is (1, 2, 3), (4, 5, 8), (9, 6, 7), (−3, 2, 8) linearly independent in R³? The list (1, 0, 0), (0, 1, 0), (0, 0, 1) spans R³ and has length 3. By Theorem 2.23 no independent list in R³ can exceed length 3. Ours has length 4. So no — and we never touched the entries.

(ii) Does (1, 2, 3, −5), (4, 5, 8, 3), (9, 6, 7, −1) span R⁴? The four standard vectors are independent in R⁴, so by Theorem 2.23 every spanning list of R⁴ has length at least 4. Ours has length 3. So no. — Axler §2.A, Examples 2.24 and 2.25, p. 36

Theorem 2.26 (subspaces inherit finite-dimensionality). Every subspace of a finite-dimensional vector space is finite-dimensional. — Axler §2.A, Theorem 2.26, p. 36

The proof builds an independent list inside the subspace one vector at a time, and Theorem 2.23 is what stops the construction: the list can never outgrow a spanning list of the ambient space, so the process must terminate, and when it does the list it has built spans the subspace. Termination is the content here — the construction itself is obvious, and the reason it halts is not. — Axler §2.A, pp. 36

Self-check 4. A list of 5 vectors spans V, and a different list of 5 vectors in V is linearly independent. What does Theorem 2.23 let you conclude about a list of 6 vectors in V?

A spanning list of length 5 exists, so every independent list has length ≤ 5; a list of 6 therefore fails independence. Spanning is not obstructed at all: you may always adjoin extra vectors to a spanning list and it still spans. The asymmetry is worth holding onto — long lists are bad for independence, short lists are bad for spanning.

Self-check 5. In the Linear Dependence Lemma, why is j chosen to be the largest index with aj ≠ 0, rather than any index with aj ≠ 0?

Any index with aj ≠ 0 would let you solve for vj and would deliver conclusion (b). Choosing the largest is what makes the solved expression involve only v₁, …, vj−1 — the strictly-earlier form that Theorem 2.23's proof needs to argue "the removed vector cannot be one of the u's". The third option is false: a dependent list can perfectly well have am = 0, as Self-check 3's relation shows.

Guided proof practice

Write your own proof. Suppose v₁, …, vm is linearly independent in V and w ∈ V. Prove that v₁, …, vm, w is linearly independent if and only if w ∉ span(v₁, …, vm). (Two directions. For one of them, contraposition is much the easier route — and note which hypothesis, independence of the original list, is used in which direction.) — cf. Axler §2.A, Exercise 11, p. 38

Reveal model answer

Proof. (⇐, by contraposition.) Suppose v₁, …, vm, w is dependent: there are scalars a₁, …, am, b, not all 0, with a₁v₁ + ⋯ + amvm + bw = 0. If b = 0, the relation reduces to a nontrivial dependence among v₁, …, vm alone — impossible, since that list is independent and the remaining coefficients cannot all be 0 either. Hence b ≠ 0, and dividing by it gives w = −(a₁/b)v₁ − ⋯ − (am/b)vm ∈ span(v₁, …, vm). So dependence forces w into the span; contrapositively, w ∉ span implies independence.

(⇒, by contraposition.) Suppose w ∈ span(v₁, …, vm), say w = c₁v₁ + ⋯ + cmvm. Then c₁v₁ + ⋯ + cmvm + (−1)w = 0 is a dependence relation whose coefficients are not all 0 — the coefficient −1 on w is nonzero regardless of what the cj happen to be. So the extended list is dependent. ∎

Where the hypotheses are used: independence of v₁, …, vm is needed only in (⇐), to rule out b = 0. Direction (⇒) holds for any list at all, independent or not — worth noticing, because it means the theorem is not symmetric in the work it demands.

Reveal the skeleton to check against
  1. Span (Definition 2.5) is everything a list reaches by scaling and adding, and it is exactly the smallest subspace containing the list (Theorem 2.7) — so "generated by" is a subspace notion, not merely a set notion. A space is finite-dimensional when some list spans it (Definition 2.10); no number is attached yet.
  2. Independence (Definition 2.17) is the statement that 0 has only the trivial representation — equivalently, that every vector in the span has only one representation. The Linear Dependence Lemma (2.21) turns dependence into something usable: some term is in the span of its predecessors, and deleting it does not shrink the span.
  3. Feeding the lemma a swap process proves the squeeze: every independent list is at most as long as every spanning list (Theorem 2.23). This settles independence and spanning questions by length alone (Examples 2.24, 2.25), and its termination argument is what makes subspaces of finite-dimensional spaces finite-dimensional (Theorem 2.26). la-04 turns the squeeze into an actual number.
