Null space, range, fundamental theorem (la-06)

Conservation law for dimensions: nothing is created or destroyed.

Every linear map T : V → W carries two subspaces around with it. One sits in the domain — the vectors T crushes to zero — and one sits in the codomain — the vectors T actually reaches. They live in different spaces, they measure opposite things, and there is no reason on the face of it for their sizes to be related.

They are related, exactly, and by an equation with no error term: dim V = dim null T + dim range T. Every dimension of the domain is either destroyed or transmitted, never both and never neither. Axler calls this the Fundamental Theorem of Linear Maps, and it earns the name: almost everything in the rest of the module is a rearrangement of it. It is also, quite literally, the arithmetic behind Betti numbers — a homology group is a null space modulo a range, and its dimension is what this equation lets you compute.

Prediction gate — commit before reading on. Ask whether a linear map can send exactly what it kills. That is, is there a linear map T : R⁴ → R⁴ with range T = null T? And is there one T : R⁵ → R⁵ with range T = null T? Commit to yes or no for each of the two, before Segment 3 — and if your two answers differ, say what distinguishes 4 from 5.

Why this matters for the mission: Homology literally = null space of one map modulo range of another.

Segment 1 · ~20 min

The null space, and what it detects

Definition 3.12 (null space). For T ∈ ℒ(V, W), the null space of T is null T = {v ∈ V : Tv = 0}. — Axler §3.B, Definition 3.12, p. 59

Many authors, and essentially all of topology, write kernel and ker T for the same set. The two names are interchangeable, and this unit's mission strip uses the topologists' one — when you meet ker ∂ in a chain complex, it is Definition 3.12 and nothing more. — Axler §3.B, p. 59

Worked example — five null spaces (fully worked). Computing a null space means solving Tv = 0, and the answers are more varied than the definition suggests.

Zero map V → W: everything is killed, so null T = V. φ(z₁, z₂, z₃) = z₁ + 2z₂ + 3z₃ on C³: null φ is the plane z₁ + 2z₂ + 3z₃ = 0, with basis (−2, 1, 0), (−3, 0, 1).

Differentiation D on 𝒫(R): the polynomials with zero derivative are exactly the constants, so null D is the constant polynomials. Multiplication by x²: x²p(x) is the zero polynomial only when p is, so null T = {0}. Backward shift on F∞: T(x₁, x₂, x₃, …) = (x₂, x₃, …) vanishes exactly when every entry after the first does, so null T = {(a, 0, 0, …) : a ∈ F}. — Axler §3.B, Example 3.13, p. 59

Look back over the five: each is a subspace of the domain. That is not a coincidence about these examples.

Theorem 3.14 (the null space is a subspace). If T ∈ ℒ(V, W), then null T is a subspace of V. — Axler §3.B, Theorem 3.14, p. 60
Why it is true (the shape of Axler's proof). Run la-02's three-condition test. Contains 0: T(0) = 0 by la-05's Theorem 3.11, so 0 ∈ null T. Closed under addition: if Tu = Tv = 0 then T(u + v) = Tu + Tv = 0 + 0 = 0. Closed under scalar multiplication: if Tu = 0 then T(λu) = λTu = λ0 = 0.

Each of the three checks is one clause of Definition 3.2 used once, in the same order. That is the pattern for every "this set is a subspace" proof in this unit, and the interest lies not in the verification but in which clause supplies which condition. — Axler §3.B, p. 60

Definition 3.15 (injective). A function T : V → W is injective if Tu = Tv implies u = v — equivalently, if distinct inputs always have distinct outputs. Many authors say one-to-one. — Axler §3.B, Definition 3.15, p. 60
Theorem 3.16 (injectivity is a condition at 0). Let T ∈ ℒ(V, W). Then T is injective if and only if null T = {0}. — Axler §3.B, Theorem 3.16, p. 61
Why it is true (the shape of Axler's proof). (⇒) {0} ⊆ null T always. For the reverse, take v ∈ null T; then Tv = 0 = T(0), and injectivity forces v = 0.

(⇐) Suppose null T = {0} and Tu = Tv. Then T(u − v) = Tu − Tv = 0, so u − v ∈ null T = {0}, giving u = v. — Axler §3.B, p. 61

Why this theorem is a gift. Injectivity as defined quantifies over every pair of vectors in V. Theorem 3.16 replaces that with a condition at the single point 0. The reason it can is linearity: the difference u − v converts any statement about a pair into a statement about one vector, and there is nothing special about the pair beyond their difference. Expect this reduction wherever linearity is available — the definition of linear independence in la-03 is the same trick applied to representations.

Self-check 1. The backward shift T on F∞ has null T = {(a, 0, 0, …) : a ∈ F}. Is T injective?

null T is one-dimensional, not {0}, so Theorem 3.16 says T is not injective — for instance (1, 0, 0, …) and (0, 0, 0, …) have the same image. "Forgets only one entry" is exactly the failure: distinct first entries produce identical outputs. Injectivity and surjectivity are logically independent for maps on infinite-dimensional spaces, and the backward shift is in fact surjective while not being injective.

Segment 2 · ~20 min

The range, and what it depends on

Definition 3.17 (range) and Definition 3.20 (surjective). For T a function from V to W, range T = {Tv : v ∈ V}. The function T is surjective if range T equals W. Many authors write image for the range and onto for surjective. — Axler §3.B, Definition 3.17, p. 61, and Definition 3.20, p. 62
Theorem 3.19 (the range is a subspace). If T ∈ ℒ(V, W), then range T is a subspace of W. — Axler §3.B, Theorem 3.19, p. 62
Why it is true, and how the proof differs from Theorem 3.14's. Again three checks, but each now begins by naming a preimage. 0 = T(0) is in the range. If w₁, w₂ ∈ range T, choose v₁, v₂ with Tv1 = w₁ and Tv2 = w₂; then T(v₁ + v₂) = w₁ + w₂, so the sum is in the range. Similarly T(λv) = λw.

The difference is worth noticing because it recurs. A null-space proof assumes an equation about the vector in hand; a range proof produces a witness and then computes with it. Membership of a null space is a property you can check; membership of a range is an existence claim. — Axler §3.B, p. 62

In practice a range is computed, not guessed at. If v₁, …, vn spans V, then range T = span(Tv₁, …, Tvn): every output is a combination of those images, and conversely each image is an output, so the smallest-subspace characterisation of span applies, which is la-03's. — Axler §2.A, Theorem 2.7, p. 29 Proving this identity is one of the problems in this unit's set, and it is the tool that turns "find the range" into "find a basis of a span".

Worked example — surjectivity is not a property of the map alone (fully worked). Let D ∈ ℒ(𝒫₅(R), 𝒫₅(R)) be differentiation. It is not surjective: x⁵ has no preimage, since a polynomial of degree at most 5 differentiates to one of degree at most 4.

Now let S ∈ ℒ(𝒫₅(R), 𝒫₄(R)) be given by the very same formula Sp = p′. This map is surjective, since every polynomial of degree at most 4 is the derivative of one of degree at most 5. Nothing about the rule changed; only the declared codomain did. Surjectivity is a statement about the pair (map, codomain), and range T — which is intrinsic — is the thing that does not move. — Axler §3.B, Example 3.21, p. 62

Contrast — a range computed by hand. Let T ∈ ℒ(R², R³) be T(x, y) = (2x, 5y, x + y). Then range T = {(2x, 5y, x + y) : x, y ∈ R}, which splitting by parameter is span((2, 0, 1), (0, 5, 1)); those two are independent, so they form a basis and dim range T = 2. Since dim R³ = 3, the range is a proper subspace and T is not surjective. — Axler §3.B, Example 3.18, p. 61

Self-check 2. Which is the correct reading of "range T is a subspace of W"?

The range consists of outputs, which are vectors of W. Keeping the two straight matters throughout: null T lives in the domain, range T in the codomain, and the Fundamental Theorem in Segment 3 relates their dimensions across that divide. The third option would make every linear map surjective, which Example 3.21 disproves.

Segment 3 · ~25 min

The Fundamental Theorem, and what it forbids

Theorem 3.22 (Fundamental Theorem of Linear Maps). Suppose V is finite-dimensional and T ∈ ℒ(V, W). Then range T is finite-dimensional and
dim V = dim null T + dim range T. — Axler §3.B, Theorem 3.22, p. 63
Why it is true (the shape of Axler's proof). The construction is la-04's "extend a basis" move, aimed at the null space. Take a basis u₁, …, um of null T, so dim null T = m, and extend it to a basis u₁, …, um, v₁, …, vn of V, so dim V = m + n. The claim is that Tv₁, …, Tvn is a basis of range T, which gives dim range T = n and finishes the arithmetic.

It spans. Any v ∈ V expands along the full basis; applying T, every Tuj term vanishes — that is what it means for the u's to be in the null space — leaving Tv = b₁Tv₁ + ⋯ + bnTvn. So every element of the range is reached.

It is independent. If c₁Tv₁ + ⋯ + cnTvn = 0, then T(c₁v₁ + ⋯ + cnvn) = 0, so that combination lies in null T and is therefore expressible in the u's alone. Comparing the two expressions gives a dependence relation among u₁, …, um, v₁, …, vn — a basis of V — so every coefficient vanishes, the c's included. — Axler §3.B, pp. 63–64

The single sentence to carry away: the range is a faithful copy of any complement of the null space. The v's span such a complement, and T transports them to a basis of the range without collapsing anything, because everything collapsible was put into the u's first.

Canvas: the conservation law

A bar of fixed length dim V, splitting into the part destroyed (null space, red) and the part transmitted (range, green) as the map varies. The two pieces trade against each other; their total never changes.

Theorems 3.23 and 3.24 (what dimension forbids). If V and W are finite-dimensional and dim V > dim W, no linear map from V to W is injective. If dim V < dim W, no linear map from V to W is surjective. — Axler §3.B, Theorem 3.23 and Theorem 3.24, p. 64
Why they are true — the Fundamental Theorem rearranged twice. For 3.23: dim null T = dim V − dim range T ≥ dim V − dim W > 0, the middle step because range T is a subspace of W and so has dimension at most dim W (la-04, Theorem 2.38). A positive-dimensional null space contains a nonzero vector, so Theorem 3.16 denies injectivity.

For 3.24: dim range T = dim V − dim null T ≤ dim V < dim W, so range T cannot be all of W. Each proof is one line of arithmetic plus one inequality; the theorem doing the work is 3.22 in both cases. — Axler §3.B, p. 64

Worked example — two facts about linear systems, for free (fully worked). Fix scalars Aj,k and define T : Fⁿ → Fᵐ by sending (x₁, …, xn) to the list whose j-th slot is Aj,1x₁ + ⋯ + Aj,nxn, as in la-05.

Homogeneous systems. Solving Ax = 0 is asking for null T, and asking for a nonzero solution is asking whether null T ≠ {0}, i.e. whether T fails to be injective (Theorem 3.16). If there are more variables than equations, n > m, so dim Fⁿ > dim Fᵐ and Theorem 3.23 applies: a homogeneous system with more variables than equations has nonzero solutions. — Axler §3.B, Example 3.25, p. 65, and Theorem 3.26, p. 65

Inhomogeneous systems. Solving Ax = c for every right-hand side c is asking whether range T = Fᵐ. If there are more equations than variables, n < m, and Theorem 3.24 applies: an inhomogeneous system with more equations than variables has no solution for some choice of constant terms. — Axler §3.B, Example 3.27, p. 66, and Theorem 3.29, p. 66

Both are usually proved by Gaussian elimination. Neither proof here computes anything at all — the entire content is a dimension count, and the elimination algorithm is nowhere in sight. — Axler §3.B, p. 66

Resolving the prediction gate

Verdict: yes for R⁴, no for R⁵ — and the reason is parity. Suppose T ∈ ℒ(V, V) with range T = null T. Then the two have the same dimension, call it k, and Theorem 3.22 gives dim V = k + k = 2k. So dim V must be even. That instantly rules out R⁵ — 5 is not twice an integer — with no need to inspect any particular map.

For R⁴, the count permits k = 2, and a map achieving it exists: define T(x₁, x₂, x₃, x₄) = (0, 0, x₁, x₂). Its range is {(0, 0, a, b)}, and its null space is the set where x₁ = x₂ = 0, which is the same subspace {(0, 0, a, b)}. Both have dimension 2, and 2 + 2 = 4 as the theorem requires. — cf. Axler §3.B, Exercises 5 and 6, p. 67

That map was given by a formula, but it could equally have been specified by its values on the standard basis — sending e₁ and e₂ to e₃ and e₄, and e₃ and e₄ to 0, which is la-05's route. — Axler §3.A, Theorem 3.5, p. 54 Prescribing values on a basis is usually the quicker route when a map has to be built to a specification rather than analysed.

Hold onto the configuration range T ⊆ null T, because it is the defining condition of a chain complex: applying the map twice gives zero. The mission strip's ∂ satisfies exactly this, homology measures the gap null ∂ / range ∂, and the case above — where the two coincide — is the case where that gap is trivial and the Betti number is 0.

Self-check 3. T ∈ ℒ(R⁷, R⁴) and dim null T = 3. Is T surjective?

Theorem 3.22 gives dim range T = 4, and range T is a subspace of R⁴ of the same dimension as R⁴, so it equals R⁴ by la-04's guided-proof result. Theorem 3.24 does not apply: it forbids surjectivity only when dim V < dim W, and here 7 > 4. Note the two-step shape — the theorem yields a number, and a further argument is needed to turn that number into a statement about a set.

Self-check 4. A homogeneous system of 4 linear equations in 5 unknowns is given. What can be said?

Theorem 3.26: more variables (5) than equations (4) forces a nonzero solution. The third option adds a hypothesis that is not needed — repeated or redundant equations only make the null space bigger, never smaller, so the conclusion survives them. Note also what is not claimed: nothing is said about how many solutions, only that the zero one is not alone.

Self-check 5. Where in the proof of Theorem 3.22 is it used that the u's lie in the null space?

Applying T to v = Σajuj + Σbjvj leaves only the v-terms precisely because Tuj = 0 — that is what makes Tv₁, …, Tvn span the range rather than merely sit inside it. The independence half uses instead that the u's span the null space, a different property of the same list, which is why the proof needs a basis of null T and not just any independent list inside it.

Guided proof practice

Write your own proof. Suppose T ∈ ℒ(V, W) is injective and v₁, …, vn is linearly independent in V. Prove that Tv₁, …, Tvn is linearly independent in W. (This is the converse of la-05's guided proof, which needed no hypothesis on T at all. Notice where injectivity enters — there is exactly one step that cannot be taken without it.) — cf. Axler §3.B, Exercise 9, p. 67

Reveal model answer

Proof. Suppose a₁, …, an ∈ F satisfy a₁Tv₁ + ⋯ + anTvn = 0. By linearity of T the left-hand side equals T(a₁v₁ + ⋯ + anvn), so a₁v₁ + ⋯ + anvn ∈ null T.

Because T is injective, null T = {0} by Theorem 3.16 — this is the step, and the only one, at which injectivity is used. Hence a₁v₁ + ⋯ + anvn = 0, and independence of v₁, …, vn forces every aj = 0. So the only relation among Tv₁, …, Tvn is the trivial one. ∎

Put beside la-05's result — independence of the images forces independence of the originals, for any linear map — this completes a small dictionary. Independence travels backwards along every linear map, and forwards along the injective ones. The zero map on a space of dimension at least 1 shows the hypothesis cannot simply be dropped: it sends an independent list to a list of zeros.

Reveal the skeleton to check against
  1. Every linear map carries a null space in its domain (Definition 3.12, a subspace by Theorem 3.14) and a range in its codomain (Definition 3.17, a subspace by Theorem 3.19). Injectivity — a condition on all pairs — collapses to the single condition null T = {0} (Theorem 3.16), because linearity turns a pair into its difference.
  2. The Fundamental Theorem (3.22) says dim V = dim null T + dim range T. Its proof takes a basis of the null space, extends it to a basis of V, and shows T carries the new vectors to a basis of the range: the range is a faithful copy of any complement of the null space.
  3. Rearranging it forbids things. A map to a smaller-dimensional space cannot be injective, one to a larger cannot be surjective (Theorems 3.23, 3.24) — and those two facts are the standard theorems on homogeneous and inhomogeneous linear systems (3.26, 3.29), proved with no elimination. The same count shows range T = null T forces dim V even, which is the arithmetic homology runs on.
