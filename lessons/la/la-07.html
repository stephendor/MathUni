Matrices as linear maps (la-07)

Matrices are the shadows linear maps cast once you pick a basis.

la-05 established that a linear map is nothing more than its values on a basis. la-04 established that a vector is nothing more than its coefficients in a basis. Put the two together and a linear map between finite-dimensional spaces becomes a finite table of scalars — an m-by-n array, one column per basis vector of the domain. That table is the matrix, and every rule you were ever taught about matrices is a consequence of the map it encodes rather than a convention.

Matrix multiplication is the case worth watching. The rule is famously peculiar — go along a row, down a column, multiply, sum — and nobody meeting it first as an algorithm has any reason to expect it. It is not a choice. Composition of linear maps was defined in la-05, matrices were defined here, and there is exactly one product on matrices that makes the two agree. The strange rule is what falls out.

Prediction gate — commit before reading on. The matrix of a linear map depends on T and on two chosen bases, one for the domain and one for the codomain — and you may choose both freely. Ask how far that freedom goes. Do you predict that for every linear map T between finite-dimensional spaces there exist bases making ℳ(T) as simple as it could possibly be: entries equal to 1 in the first few diagonal slots and 0 everywhere else? Or do you predict some maps resist? Commit before Segment 3.

Why this matters for the mission: Persistence software reduces boundary matrices — this is that bridge.

Segment 1 · ~20 min

The matrix of a linear map

Definition 3.30 (matrix). For positive integers m, n, an m-by-n matrix A is a rectangular array of elements of F with m rows and n columns. Aj,k is the entry in row j, column k — first index the row, second the column. — Axler §3.C, Definition 3.30, p. 70
Definition 3.32 (matrix of a linear map). Suppose T ∈ ℒ(V, W), that v₁, …, vn is a basis of V, and that w₁, …, wm is a basis of W. The matrix of T with respect to these bases is the m-by-n matrix ℳ(T) whose entries Aj,k are defined by
Tvk = A1,kw₁ + ⋯ + Am,kwm. — Axler §3.C, Definition 3.32, p. 70
The one sentence that makes matrices make sense. Column k of ℳ(T) is Tvk, written in the codomain's basis. Everything else follows from that. The domain's basis indexes the columns, so there are n of them; the codomain's basis indexes the rows, so there are m. A map from an n-dimensional space to an m-dimensional space has an m-by-n matrix, which is the opposite order to the one most people guess. — Axler §3.C, p. 71

Because ℳ(T) depends on two bases as well as on T, the honest notation is ℳ(T, (v₁, …, vn), (w₁, …, wm)). It is almost always abbreviated, on the understanding that the bases are fixed and known. For a map Fⁿ → Fᵐ the standard bases are assumed unless stated, and for 𝒫m(F) the basis 1, x, …, xm. — Axler §3.C, pp. 70–72

Worked example — a matrix computed from the definition (fully worked). Let T ∈ ℒ(F², F³) be T(x, y) = (x + 3y, 2x + 5y, 7x + 9y). Find ℳ(T) with respect to the standard bases.

Apply the heuristic: hit each domain basis vector and record the result as a column. T(1, 0) = (1, 2, 7), so column 1 is (1, 2, 7). T(0, 1) = (3, 5, 9), so column 2 is (3, 5, 9). Hence ℳ(T) is the 3-by-2 matrix with rows (1, 3), (2, 5), (7, 9).

Sanity check the shape before anything else: the domain is 2-dimensional and the codomain 3-dimensional, so the matrix must be 3-by-2, not 2-by-3. Getting this backwards is the single most common error in the topic and it is detectable in one glance. — Axler §3.C, Example 3.33, p. 71

Contrast — differentiation as a matrix (fully worked). Let D ∈ ℒ(𝒫₃(R), 𝒫₂(R)) be Dp = p′, with standard bases 1, x, x², x³ and 1, x, x².

D(1) = 0 → column 1 is (0, 0, 0). D(x) = 1 → column 2 is (1, 0, 0). D(x²) = 2x → column 3 is (0, 2, 0). D(x³) = 3x² → column 4 is (0, 0, 3). So ℳ(D) is the 3-by-4 matrix with rows (0, 1, 0, 0), (0, 0, 2, 0), (0, 0, 0, 3).

Two things to read off it. The first column is zero, which says D(1) = 0 — the constants are in the null space, exactly as la-06 computed. And the three nonzero columns are visibly independent, so the range is 3-dimensional and D is surjective onto 𝒫₂(R). The matrix has made both facts visible without any further argument. — Axler §3.C, Example 3.34, p. 72

Self-check 1. T maps a 4-dimensional space to a 7-dimensional space. What size is ℳ(T)?

Columns are indexed by the domain's basis, so there are 4 of them; rows by the codomain's basis, so there are 7. That is 7-by-4. The size does not depend on the bases — only the entries do, since every basis of a given space has the same length (la-04, Theorem 2.35).

Self-check 2. Column 3 of ℳ(T) is entirely zero. What does that say?

Column 3 records Tv₃ in the codomain basis, so an all-zero column says Tv₃ = 0. This is exactly how the zero first column of ℳ(D) above encoded "constants differentiate to zero". A zero row would be the statement about the codomain, and it says the corresponding wj never appears in any image.

Segment 2 · ~25 min

Matrix algebra is map algebra, transported

The pattern in this segment repeats three times, and it is the point of the segment. An operation is already defined on maps. We then define the corresponding operation on matrices — and each time the definition is chosen so that ℳ turns one into the other. The matrix operations are not primitive; they are whatever they have to be.

Definitions 3.35 and 3.37, and Theorems 3.36 and 3.38 (addition and scaling). Matrices of the same size add entrywise, (A + C)j,k = Aj,k + Cj,k, and scale entrywise, (λA)j,k = λAj,k. With one fixed pair of bases throughout, ℳ(S + T) = ℳ(S) + ℳ(T) and ℳ(λT) = λℳ(T). — Axler §3.C, Definition 3.35, p. 72, Theorem 3.36, Definition 3.37 and Theorem 3.38, p. 73
Notation 3.39 and Theorem 3.40 (the space of matrices). Fm,n denotes the set of all m-by-n matrices over F. With those operations it is a vector space, and dim Fm,n = mn. — Axler §3.C, Notation 3.39, p. 73, and Theorem 3.40, p. 74

The basis witnessing the dimension is the obvious one: the mn matrices with a single 1 and zeros elsewhere. Note that this makes ℳ a map between two vector spaces — from ℒ(V, W), which la-05 showed is a vector space, to Fm,n — and Theorems 3.36 and 3.38 say precisely that ℳ is linear. la-08 shows it is in addition invertible, which is what licenses treating maps and matrices as the same thing. — Axler §3.C, p. 74

Where matrix multiplication comes from

Now take T ∈ ℒ(U, V) and S ∈ ℒ(V, W) with bases u₁, …, up, v₁, …, vn, w₁, …, wm. We want ℳ(ST) = ℳ(S)ℳ(T). Nothing forces a definition of the right-hand side yet, so compute the left-hand side and read the answer off.

The computation that defines the product. Write A = ℳ(S) and C = ℳ(T). Column k of ℳ(ST) records (ST)uk, so expand it one map at a time.

(ST)uk = S(Tuk) = S(Σr Cr,kvr) = Σr Cr,k Svr = Σr Cr,k Σj Aj,rwj = Σj (Σr Aj,rCr,k) wj.

The step that does the work is the third: S is linear, so it passes through the sum and past the scalars. Everything after that is exchanging the order of two finite sums. Reading off the coefficient of wj, the entry in row j, column k of ℳ(ST) must be Σr Aj,rCr,k. — Axler §3.C, p. 74

Definition 3.41 (matrix multiplication). If A is m-by-n and C is n-by-p, then AC is the m-by-p matrix with (AC)j,k = Σr=1n Aj,rCr,k. The product is defined only when the number of columns of A equals the number of rows of C. — Axler §3.C, Definition 3.41, p. 75
Theorem 3.43 (the matrix of a product). If T ∈ ℒ(U, V) and S ∈ ℒ(V, W), then ℳ(ST) = ℳ(S)ℳ(T). — Axler §3.C, Theorem 3.43, p. 75

Theorem 3.43 needs no proof: the computation above is its proof, run before the definition rather than after. And the shape condition in Definition 3.41 is not a technicality either — it is the shadow of la-05's rule that ST is defined only when T maps into the domain of S. Matrix multiplication is non-commutative for the same reason composition is. — Axler §3.C, p. 75

Self-check 3. Why is matrix multiplication defined by that particular sum, rather than entrywise like addition?

The definition was read off the computation of ℳ(ST), not chosen and then justified — Axler does the calculation first and defines the product to match. Entrywise multiplication is perfectly associative; it simply does not correspond to composing the maps, which makes it useless for the purpose at hand.

Segment 3 · ~20 min

Three readings of a product, and the simplest possible matrix

The same product can be read at three grains, and fluency means switching between them without thinking. Write Aj,· for row j of A and A·,k for column k. — Axler §3.C, Notation 3.44, p. 76

Theorems 3.47, 3.49 and 3.52 (entry, column, combination). For A an m-by-n matrix and C an n-by-p matrix:
entry: (AC)j,k = Aj,·C·,k — row times column;
column: (AC)·,k = AC·,k — column k of the product is A applied to column k;
combination: for a single column c with entries c₁, …, cn, the product Ac is c₁A·,1 + ⋯ + cnA·,n. — Axler §3.C, Theorem 3.47, p. 76, Theorem 3.49 and Theorem 3.52, p. 77
Which reading to reach for. The entry reading is for computing one number by hand. The column reading is for seeing that multiplication acts on columns independently, which is why an algorithm can process them one at a time. The combination reading is the conceptual one: Ac is a linear combination of the columns of A, so the set of all products Ac is exactly the span of A's columns — which la-06 called the range. That last identification is what makes column operations a legitimate way to compute a range, and it is the foundation of the reduction algorithms in the mission strip. — Axler §3.C, Example 3.51, p. 77

Resolving the prediction gate

Verdict: yes — and the construction is la-06's proof, reordered. Let T ∈ ℒ(V, W) with V, W finite-dimensional and write r = dim range T. There are bases of V and W making every entry of ℳ(T) zero except for a 1 in row j, column j for j = 1, …, r.

Building the domain basis. By the Fundamental Theorem's proof, take a basis u₁, …, um of null T, extend to a basis of V, and call the added vectors v₁, …, vr — that proof showed Tv₁, …, Tvr is a basis of range T, so there are exactly r of them. Now list the domain basis in the order v₁, …, vr, u₁, …, um, images first.

Building the codomain basis. Tv₁, …, Tvr is independent in W, so extend it to a basis w₁, …, wq of W with wj = Tvj for j ≤ r. Extending an independent list to a basis is la-04's. — Axler §2.B, Theorem 2.33, p. 41 Reordering the domain list changes nothing, since neither independence nor spanning depends on the order, and where a reordering is replaced by a genuinely different list the quickest check is the length one. — Axler §2.C, Theorem 2.39, p. 45

Reading the matrix. For k ≤ r, Tvk = wk, so column k is a 1 in row k and zeros elsewhere. For the remaining columns, Tuj = 0, so they are entirely zero. That is exactly the claimed form. — cf. Axler §3.C, Exercise 3, p. 78

What this says is worth stating baldly: up to a change of basis at each end, a linear map is determined by one number, its rank. Everything else in a matrix is an artefact of the coordinates you happened to choose. It also explains why "reduce the matrix" is a sensible instruction in the first place — reduction is the search for coordinates in which the map is transparent, and in persistent homology it is exactly what turns a boundary matrix into a barcode.

Self-check 4. Two matrices A and C are both 3-by-3, and AC is the zero matrix. Must CA be the zero matrix?

Both products are defined here, and they still need not agree: AC and CA correspond to ST and TS, which la-05 showed can differ even when both make sense. A concrete pair is the subject of a problem in this unit's set. The third option gets it backwards — non-commutativity is easiest to exhibit with nonzero matrices.

Self-check 5. The columns of a 5-by-3 matrix A span a 2-dimensional subspace of F⁵. What is dim range T for the map T : F³ → F⁵ with ℳ(T) = A in the standard bases?

By the combination reading, every Ac is a linear combination of A's columns and every such combination is some Ac, so range T is precisely the span of the columns — dimension 2. The second option would need T injective, which Theorem 3.22 rules out here since dim null T = 3 − 2 = 1. The third confuses the codomain with the range.

Guided proof practice

Write your own proof. Suppose V and W are finite-dimensional and T ∈ ℒ(V, W). Show that with respect to every choice of bases of V and W, the matrix of T has at least dim range T nonzero entries. (Argue by contradiction, and count columns rather than entries — the bridge between the two counts is that a column with no nonzero entry is a zero column.) — cf. Axler §3.C, Exercise 1, p. 78

Reveal model answer

Proof. Fix bases v₁, …, vn of V and w₁, …, wm of W, write r = dim range T, and suppose for contradiction that ℳ(T) has fewer than r nonzero entries.

Every nonzero column contains at least one nonzero entry, and distinct columns share no entry, so the number of nonzero columns is at most the number of nonzero entries, hence fewer than r. If column k is zero then Tvk = 0, because column k lists the coefficients of Tvk in the basis w₁, …, wm and a vector all of whose coefficients vanish is 0.

By la-06, range T = span(Tv₁, …, Tvn). Dropping the zero vectors from a list does not change its span, so range T is spanned by the Tvk whose columns are nonzero — fewer than r vectors. But a space spanned by fewer than r vectors has dimension less than r (la-03, Theorem 2.23, applied to a basis of range T as an independent list against that spanning list), contradicting dim range T = r. ∎

The bound is sharp, and the prediction gate's construction is why: the canonical form has exactly r nonzero entries, all of them 1. So "at least dim range T" cannot be improved, and the bases achieving equality are precisely the ones that make the map transparent.

Reveal the skeleton to check against
  1. Once bases are chosen at both ends, a linear map becomes an array: column k of ℳ(T) is Tvk written in the codomain's basis (Definition 3.32). A map from an n-dimensional to an m-dimensional space therefore has an m-by-n matrix.
  2. Every matrix operation is defined so that ℳ converts the corresponding operation on maps. Addition and scaling are entrywise, making ℳ linear (Theorems 3.36, 3.38) and Fm,n a vector space of dimension mn (Theorem 3.40). Multiplication is read off the expansion of ℳ(ST) rather than chosen — which is why the rule looks strange and why Theorem 3.43 needs no separate proof.
  3. A product can be read entry-wise, column-wise, or as a linear combination of the columns (Theorems 3.47, 3.49, 3.52) — the last identifying the range with the column span. Because both bases are free, every map can be put in the canonical form with 1s in the first dim range T diagonal slots and 0 elsewhere: a linear map is, up to change of basis, its rank and nothing more.
