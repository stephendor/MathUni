Homology by matrix reduction (tda1-02)

Homology as pure linear algebra over 𝔽₂: one Gaussian elimination on the boundary matrix (la-07, cashed in).

Predict before we start. Reducing the p-th boundary matrix to Smith normal form uses row operations, column operations, and exchanges of both. Which of those could a filtered version of the algorithm still afford to use?

A filtration gives each simplex a grade — the index at which it enters — and REDUCE moves a pivot to wherever it finds one, with no regard for grades. Segment 3 turns this into a constraint any persistence algorithm must satisfy, derived from these pages without reading the chapter where that algorithm lives. It also shows that the quick answer "no exchanges" is too strong: an exchange within a grade is harmless.

Why this matters for the mission: The computational-topology view of at1's homology — the exact operation the persistence algorithm iterates.

The second half of that strip is not on these pages, and the book says where it is. Chapter IV contains no persistence. Its opening paragraph says that assessing the importance of topological information and ranking it accordingly is "a topic we will address directly in Chapter VII" (p. 93). Chapter VII belongs to two later units and neither is this one: §VII.1, which carries both the definitions and the persistence algorithm itself, is tda1-03's resource, and §VII.2, which gives a sparse implementation of that same algorithm, is tda1-09's. So what follows establishes the reduction; that the persistence algorithm iterates this operation is a forward claim, and Segment 3 shows that as stated it cannot be quite right.

Segment 1 · ~25 min

Homology with the arithmetic turned down

Everything in at1 is here, and almost everything is easier, for one reason: the coefficients are 0 and 1 with 1 + 1 = 0. Edelsbrunner calls these modulo 2 coefficients and writes the coefficient group ℤ₂; it is the two-element field, the same object la-07 calls 𝔽₂ and the hook above names that way. Nothing in this unit distinguishes them — Edelsbrunner §IV.1, p. 94.

A p-chain is a formal sum c = Σ aᵢσᵢ over the p-simplices of K. Chains add componentwise, and since 1 + 1 = 0 the sum of two chains is, read as sets of simplices, their symmetric difference. The p-chains form a group Cp = Cp(K), abelian, with neutral element 0 and — the axiom worth pausing on — every element its own inverse, since c + c = 0 gives −c = c. Over ℤ that is false for every non-zero chain, and the difference is the whole reason the algorithm at the end of this lesson is short.

The boundary of σ = [u₀, …, up] is the sum of its (p−1)-faces, ∂pσ = Σj [u₀, …, ûj, …, up], the hat marking omission. Extended additively to chains it commutes with addition, so it is a homomorphism ∂p : Cp → Cp−1, and the sequence of chain groups strung together by these maps is the chain complex. Notice there are no signs. Over ℤ the boundary formula carries (−1)j; here the signs are invisible because −1 = 1 — pp. 94–95.

Cycles, boundaries, homology — Edelsbrunner, pp. 95–96

A p-cycle is a p-chain with ∂c = 0, so Zp = ker ∂p. A p-boundary is a p-chain of the form ∂d with d ∈ Cp+1, so Bp = im ∂p+1. The p-th homology group is Hp = Zp/Bp, and the p-th Betti number is βp = rank Hp.

Fundamental Lemma of Homology — Edelsbrunner, p. 95

∂p∂p+1d = 0 for every integer p and every (p+1)-chain d.

The proof is two sentences and one fact. It suffices to check a single (p+1)-simplex τ. Its boundary is all p-faces of τ, and every (p−1)-face of τ lies in exactly two of them — so in the sum each appears twice, and 1 + 1 = 0. That is where the arithmetic enters: over ℤ the two appearances come with opposite signs and cancel for a different reason, but cancel they must, and the lemma is the same lemma. Its consequence is that Bp ⊆ Zp, which is what makes the quotient defining Hp legal at all.

Because the coefficients are a field with two elements, Cp is a vector space ℤ₂n with n the number of p-simplices, and order and rank come apart in a way worth keeping straight: a group with n generators has order 2n, so rank is the base-2 logarithm of order. From ord Hp = ord Zp / ord Bp one takes logarithms and gets βp = rank Zp − rank Bp, which is the identity the whole of Segment 3 exists to evaluate — p. 97.

Self-check 1. Figure IV.2's torus has H₁ of order 4 and rank 2, with classes B₁, x + B₁, y + B₁ and (x+y) + B₁. Why is there no fifth class?

Order 4 is the answer: H₁ is a 2-dimensional vector space over a 2-element field, so it has four elements and they are the four listed. The first option gets the rank right for the wrong reason — it explains why the rank is 2, not why the group is finite. Over ℤ the same torus has H₁ ≅ ℤ², which is infinite: rank 2 in both cases, order 4 in one and unbounded in the other.

One irritation is worth removing before Segment 3, because the worked computation there depends on it. A ball should have no holes, and it nearly does: Hp = 0 for p ≠ 0, but H₀ has rank 1, because β₀ counts components and one component is not zero. Appending the augmentation map ε : C₀ → ℤ₂ with ε(u) = 1 for every vertex to the bottom of the chain complex fixes it. Cycles and boundaries are defined as before, and the only change is that a 0-cycle must now have an even number of vertices. The result is the reduced homology H̃p and Betti numbers β̃p, with β̃p = βp for p ≥ 1 and β̃₀ = β₀ − 1 for non-empty K — p. 98.

Segment 2 · ~25 min

Induced maps, a degree with two values, and a formula that does not typecheck

A simplicial f : K → L induces f# on chains: send c = Σaᵢσᵢ to Σaᵢτᵢ where τᵢ = f(σᵢ) if that image still has dimension p, and τᵢ = 0 if f collapses σᵢ to something lower. The point of the convention is that f# then commutes with the boundary. Edelsbrunner checks both cases. If f(σᵢ) has dimension p the faces correspond one for one. If it drops dimension, the (p−1)-faces map to simplices of dimension below p−1 with the possible exception of exactly two whose images coincide — and coincide means cancel, so both sides are zero — p. 99.

The next sentence cannot be read literally, and the conclusion it states is true. The text concludes that f# takes cycles to cycles and boundaries to boundaries, writing f#(Zp(K)) ⊆ f#(Zp(L)) and f#(Bp(K)) ⊆ f#(Bp(L)). But f# is defined on chains of K, and Zp(L) consists of chains of L, so the right-hand side does not typecheck. The intended statements are f#(Zp(K)) ⊆ Zp(L) and f#(Bp(K)) ⊆ Bp(L): the stray f# on the right is the error, and both sides being decorated identically is what makes it easy to slide past. Everything downstream — that f# descends to the quotients, giving f∗ : Hp(K) → Hp(L) — is correct.

The induced map on homology satisfies rank f∗(Hp(K)) ≤ min{βp(K), βp(L)}, for the reason any linear map does: the image is a quotient of the source and a subspace of the target.

Worked, then fading: a degree with only two values. — Edelsbrunner, pp. 99–100

Let g : 𝕊p → 𝕊p be continuous and let c generate Hp(𝕊p), a group with exactly two elements. Then g∗(c) is homologous to c or to 0, so g∗(c) ∼ αc with α ∈ {0, 1} — the modulo 2 degree. Continuous maps are handled by triangulating and approximating, which is where tda1-01's Simplicial Approximation Theorem is spent.

Two values. The identity gives α = 1. If g extends to g₀ : 𝔹p+1 → 𝕊p then g∗ factors as Hp(𝕊p) → Hp(𝔹p+1) → Hp(𝕊p) with the middle group ⟨ what? ⟩, so α = 0.

Now compare with at1-08, where the degree of a self-map of 𝕊n is an integer. The cause of the difference is not the geometry but the coefficient group: Hn(𝕊n; ℤ) ≅ ℤ has infinitely many elements and can record how many times and with what sign, while Hn(𝕊n; ℤ₂) has two and can record only ⟨ what? ⟩. The antipodal map on 𝕊¹ has integer degree ⟨ ? ⟩ and modulo 2 degree ⟨ ? ⟩; z ↦ z² has integer degree ⟨ ? ⟩ and modulo 2 degree ⟨ ? ⟩. One of those two pairs shows the mod 2 degree discarding information that at1-08's degree keeps.

Brouwer follows. Suppose f : 𝔹p+1 → 𝔹p+1 has no fixed point. Then A(x) = (x − f(x))/‖x − f(x)‖ is defined on 𝕊p and extends a map from the ball, so its degree is 0; the identity B(x) = x has degree 1; and H(x,t) = (x − tf(x))/‖x − tf(x)‖ is a homotopy between them, well defined at t = 1 because there is no fixed point and at t < 1 because ‖x‖ = 1 > ‖tf(x)‖. Homotopic maps have equal degree, and 0 ≠ 1.

Self-check 2. Where in the Brouwer proof would ℤ coefficients change anything?

Nothing essential changes. The argument needs only that degree is a homotopy invariant, that the identity has degree 1, and that a map extending over the ball has degree 0 — all true over ℤ, where the same proof gives the same contradiction. The mod 2 degree is weaker, and Brouwer is a theorem the weaker invariant is already strong enough to prove. That is the general shape of the trade this chapter is making.

Segment 3 · ~30 min

The matrix, the reduction, and one thing the reduction cannot be

Write np = rank Cp for the number of p-simplices, zp = rank Zp and bp = rank Bp. Rank–nullity applied to ∂p : Cp → Cp−1 gives np = zp + bp−1 — note the index: the kernel of ∂p is Zp and its image is Bp−1, one dimension down. Taking the alternating sum and reindexing the second term turns the Euler characteristic into the alternating sum of Betti numbers — §IV.2, p. 101.

Euler–Poincaré Theorem — Edelsbrunner, p. 101

The Euler characteristic of a topological space is the alternating sum of its Betti numbers, χ = Σp≥0 (−1)p βp.

Edelsbrunner is careful to say what the theorem needs and does not supply: that homology does not depend on the triangulation chosen. He calls that proof "difficult", refers the reader to more advanced texts, and offers the weaker-sounding fact that homotopy equivalent spaces have isomorphic homology as plausible. That weaker fact is exactly at1-07's Corollary 2.11, proved there from Hatcher — and it does the job here given one further ingredient, that two triangulations of the same space have homeomorphic, hence homotopy equivalent, underlying spaces. So this unit can supply what Edelsbrunner declines to prove, but only by reaching into at1, and the theorem it reaches for is Hatcher's, not Edelsbrunner's.

Now the matrices. The p-th boundary matrix has the (p−1)-simplices as rows and the p-simplices as columns, with entry 1 exactly when the row simplex is a face of the column simplex. A set of columns is a p-chain and the sum of those columns is its boundary — the boundary map is matrix multiplication. Two column operations are allowed, exchanging two columns and adding one column to another, and two matching row operations; each is multiplication by an invertible matrix, V on the right and U on the left — pp. 102–103.

The index conditions for U and V are corrupt in the extraction, and the figure captions say what they should be. As extracted, adding column k to column l is described by "vkl = 1 and vil = 1 for all i" — which would fill the whole l-th column with ones, giving a matrix of rank 1 that is not invertible and would not preserve the rank the operations are said to preserve. What is meant is the elementary matrix V = I + Ekl: the identity plus a single off-diagonal one. Figure IV.3's caption states this in words — "the effect of a single off-diagonal one in the matrix V" — and Figure IV.4 says the same for U. The text is right, the transcription of its indices is not, and the captions are the warrant for the reading used here.

Reducing with these operations gives the Smith normal form Np = Up−1 ∂p Vp: over modulo 2 arithmetic, an initial segment of the diagonal is 1 and everything else is 0. Split np = bp−1 + zp. The leftmost bp−1 columns carry the diagonal ones and represent p-chains whose boundaries generate Bp−1; the rightmost zp columns are zero and represent p-cycles generating Zp. The new cycle basis is read off the last zp columns of Vp, and the boundary basis off the first bp−1 columns of the inverse of Up−1 — p. 103.

Worked, then fading: the tetrahedron, one dimension at a time. — Edelsbrunner, pp. 105–106

Take the 3-ball triangulated as the faces of a single tetrahedron on vertices 1, 2, 3, 4, and compute the reduced homology of each skeleton as it is built.

0-skeleton. Four vertices. In the reduced complex the only non-trivial matrix is ∂₀, a single row of four ones — the augmentation ε from Segment 1. Three column operations clear three of them, leaving one non-zero and three zero columns, so β̃₀ = 3. Four points, three gaps.

1-skeleton. Add all six edges. The matrix drawn above reduces to three ones on the diagonal, so b₀ = 3 and β̃₀ = 3 − 3 = 0: connected. The three zero columns give z₁ = 3, so β̃₁ = 3 — the complete graph on four vertices carries three independent cycles.

The solid. Add the tetrahedron itself. ∂₃ is four by one and reduces to ⟨ ? ⟩ diagonal one(s), so β̃₂ drops to ⟨ ? ⟩ and every reduced Betti number is now zero — a ball, as expected. Say in one sentence what was added between the step where β̃₂ became 1 and the step where it returned to 0.

The procedure that does this is Gaussian elimination with the arithmetic simplified away. Find any 1 at or below-right of the current diagonal position, move it there with at most two exchanges, clear the rest of its row and column by additions, recurse on the submatrix. At most np−1 row and np column operations per call and at most min{np−1, np} calls give (np−1 + np) min{np−1, np} operations; multiplying by the length of a row and of a column gives a running time of a constant times 2 np−1 np min{np−1, np}, and memory a constant times (np−1 + np)². Cubic time, quadratic memory, in the number of simplices — pp. 104–105.

Guided derivation — a constraint on the persistence algorithm, from these pages only.

The strip says this reduction is "the exact operation the persistence algorithm iterates". Chapter VII, where that algorithm lives, is not in this unit's resources, and the book itself defers the topic there (p. 93). But something can be settled here without it.

Observe two things. First, tda1-01's Definition 2.1 gives every simplex a grade: the smallest index at which it is present. It does not give an ordering. Several simplices may share a grade and enter together, and the subcomplex condition says only that a face's grade is no larger than its coface's. Second, the reduction above exchanges rows and columns freely — the very first thing REDUCE does is "exchange rows x and k; exchange columns x and l" — and the resulting bases, read off Vp and the inverse of Up−1, bear no relation to the grading at all.

Your task: state the consequence as a constraint any persistence algorithm must satisfy, not as a claim about what Chapter VII does. Phrase it in terms of grades, and be careful about what it does not forbid. Then write down one thing you will check first in tda1-03, where the algorithm appears.

Reveal the model answer

The constraint. If an algorithm is to compute homology along a filtration rather than at one index, every basis element it manipulates must carry a grade, and no operation may introduce a simplex into a chain before that chain's own grade. So: an operation is admissible only if it preserves grades and face precedence — it may replace a basis element by a combination of elements of grade no larger, and nothing else. That is the whole constraint, and it is derived from Definition 2.1 plus the description of REDUCE, with nothing about Chapter VII assumed.

What it forbids, and what it does not. Adding an earlier column to a later one is admissible: it replaces the p-chain in a column by a sum of p-chains all of which have already entered, which is a change of representative within the same class at every index from that grade onward. Adding a later column to an earlier one is not — it back-dates a simplex. Row operations mix (p−1)-simplices and are subject to exactly the same test, so a row may only absorb rows of grade no larger.

Exchanges need more care than the quick answer gives them, and this is where reading "filtration" as "ordering" would mislead. An exchange of two columns of the same grade changes nothing about the filtration — the two simplices enter together, and which of them is listed first is a tie-break the filtration never fixed. What is forbidden is an exchange that crosses a grade boundary. So the honest conclusion is not "no exchanges" but "no exchange that reorders grades", and Smith normal form is unreachable because REDUCE exchanges to place a pivot wherever it finds one, with no regard for grade.

Therefore the strip overstates. Smith normal form is not what a persistence algorithm can iterate, because Smith normal form is reachable only with tools most of which the constraint forbids. What survives is a strictly poorer reduction, and the interesting question — which this unit cannot answer — is what such a restricted reduction still computes.

To check first in tda1-03. Whether the reduction there is column-only and left-to-right, and what replaces the diagonal of the normal form as the thing you read the answer off. A one-sided reduction cannot produce a diagonal, so something else must be carrying the information; find out what before anything else.

Self-check 3. The reduction produces Np = Up−1 ∂p Vp. Why does the Betti number computation need both Vp and Vp+1 — that is, two different reductions?

zp is the number of zero columns of Np and bp is the number of diagonal ones of Np+1. Each reduction sees only one of the two, which is why Edelsbrunner's tetrahedron is worked one dimension at a time and why each Betti number is only finalised when the next matrix has been reduced. Non-squareness is true and is not the reason.

Self-check 4. Edelsbrunner writes "we reduce the boundary matrices in time at most cubic and in memory at most quadratic in the number of simplices in K". Which of these is the honest reading?

The derived bound is 2 np−1 np min{np−1, np} up to a constant, which is a statement about one dimension. Since each of np−1 and np is at most the total number of simplices, the summary in terms of that total follows — and is weaker than what was proved. The first option is a real claim about a real algorithm but it is not what was established: it silently generalises from modulo 2 coefficients, and the bibliographic notes on p. 106 say that already over ℤ "it is no longer straightforward to guarantee a running time that is polynomial in the number of simplices".

Reveal the skeleton

1. Modulo 2 coefficients turn homology into linear algebra over a two-element field. Chains are vectors, the boundary is a homomorphism with no signs, and every element is its own inverse. The Fundamental Lemma holds because each (p−1)-face of a (p+1)-simplex lies in exactly two p-faces and 1 + 1 = 0; it gives Bp ⊆ Zp, which is what licenses the quotient. Order and rank differ by a logarithm, and βp = rank Zp − rank Bp is the identity everything else computes.

2. The invariant is weaker than at1's, and knowingly so. Induced maps work the same way; the degree of a self-map of a sphere collapses from an integer to an element of {0,1}. Brouwer still follows, which is the point of the trade — the cheap invariant proves the theorem anyway. Euler–Poincaré needs triangulation-independence, which Edelsbrunner declines to prove and at1-07's Corollary 2.11 supplies from Hatcher.

3. Reduction to Smith normal form computes the Betti numbers, and cannot be what a persistence algorithm iterates. The boundary map is matrix multiplication; row and column operations are elementary matrices; Np = Up−1 ∂p Vp has bp−1 diagonal ones and zp zero columns, giving both ranks and both bases in cubic time. But a filtration grades the simplices, and an operation is admissible only if it preserves grades and face precedence: a basis element may absorb elements of grade no larger and nothing else. Adding an earlier column to a later one passes; adding a later to an earlier does not; and an exchange passes exactly when it stays within a grade, which REDUCE's pivot search does not respect. So the strip's "exact operation" is too strong, and what a filtered reduction computes is tda1-03's question.
