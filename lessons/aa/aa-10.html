Isomorphism theorems for rings; the Chinese Remainder Theorem (aa-10)

Every ring homomorphism, no matter how complicated, is the same three steps in a row: throw away what it kills, rename what is left, and drop the result into the target.

That sentence is Theorem 5.37, and everything else today falls out of it. aa-09 discovered that "kernel" and "ideal" — two definitions that look nothing alike — describe exactly the same objects. Now we cash that in. The First Isomorphism Theorem lets you identify a quotient without computing anything: find a surjection, compute its kernel, done. And the Chinese Remainder Theorem, which you last met as an unexplained coincidence between ℤ/6ℤ and ℤ/2ℤ × ℤ/3ℤ, turns out to be one application of that recipe.

Predict before we start. aa-09 showed every kernel is an ideal. Is every ideal a kernel?

The projection π : R → R/I, π(r) = r + I, is a surjective homomorphism, and π(a) = 0 + I exactly when a ∈ I. So ker π = I, for every ideal of every ring. Aluffi asks you to find this striking, and it is: Definition 5.3 (things sent to zero by some map) and Definition 5.8 (closed under +, absorbs multiplication) do not look alike at all, and they turn out to be the same concept. — Aluffi §5.4, Proposition 5.35 and Remark 5.36, p. 89

Why this matters for the mission: First pass at the isomorphism theorems, the engine of every homology computation.

Segment 1 · ~25 min

Canonical decomposition and the First Isomorphism Theorem

Proposition 5.35. Let I be an ideal of R. The natural projection π : R → R/I, π(r) = r + I, is a surjective ring homomorphism, and ker π = I. — Aluffi §5.4, Proposition 5.35, p. 89
Proof. π is a homomorphism because that is precisely what Definition 5.24 says: π(a) + π(b) = (a + I) + (b + I) = (a + b) + I = π(a + b), the same for ·, and π(1) = 1 + I is the identity of R/I by Theorem 5.26 — so all three clauses of Definition 4.15 hold. It is surjective because every coset is a + I = π(a) for some a. And

π(a) = 0 + I ⟺ a + I = 0 + I ⟺ a − 0 = a ∈ I,

so ker π = I. ∎ — Aluffi §5.4, p. 89

Remark 5.36. Combined with aa-09's Proposition 5.7, this closes the loop: the kernels are exactly the ideals. Nothing more, nothing less. — Aluffi §5.4, Remark 5.36, p. 89

Now the missing piece of aa-09's programme. Given f : R → S we wanted a factorisation through a surjection, an isomorphism, and an injection. We already had im f for the third stage. The first stage is π : R → R/ker f. The middle map is defined by the only formula available: — Aluffi §5.4, p. 90

f̃(a + ker f) := f(a).   (5.7)

Why (5.7) is well defined. Suppose a′ + ker f = a + ker f, i.e. a′ − a ∈ ker f. Since f is a homomorphism,

f(a′) − f(a) = f(a′ − a) = 0,

so f(a′) = f(a) and the value does not depend on the representative. That f̃ is then a homomorphism is a one-line check in each clause. — Aluffi §5.4, p. 90

Note how little this costs, and why. The kernel is by construction the set of differences f cannot see, so quotienting by it is exactly the right amount of forgetting — no more, no less.

Theorem 5.37 (Canonical decomposition). For every ring homomorphism f : R → S there is a commutative diagram

R  —π→  R/ker f  —f̃→  im f  —ι→  S,

with ι ∘ f̃ ∘ π = f, where π is surjective, ι is injective, and f̃ is an isomorphism. — Aluffi §5.4, Theorem 5.37, p. 90
Proof. π is surjective and ι injective, already known. Commutativity: for a ∈ R,

(ι ∘ f̃ ∘ π)(a) = ι(f̃(a + ker f)) = ι(f(a)) = f(a).

f̃ is surjective onto im f: any s ∈ im f is f(a) for some a, and f̃(a + ker f) = s. f̃ is injective: if f̃(a + ker f) = f̃(b + ker f) then f(a) = f(b), so f(b − a) = 0, so b − a ∈ ker f, so a + ker f = b + ker f. ∎ — Aluffi §5.4, p. 90

Read the injectivity argument backwards. It says the quotient by the kernel has precisely the right number of elements — one for each value f actually takes. That is why an isomorphism appears rather than merely a homomorphism.

Theorem 5.38 (First Isomorphism Theorem). If f : R → S is a surjective ring homomorphism, then S ≅ R/ker f, via f̃(a + ker f) = f(a). — Aluffi §5.5, Theorem 5.38, p. 91

Proof: Theorem 5.37 gives R/ker f ≅ im f, and surjectivity says im f = S. — Aluffi §5.5, p. 91

Proposition 5.39 (universal property of quotients). Let f : R → S be a ring homomorphism and let I be an ideal with I ⊆ ker f. Then f induces a unique ring homomorphism f̃ : R/I → S with f̃ ∘ π = f. — Aluffi §5.5, Proposition 5.39, p. 91

Uniqueness needs no proof at all: since a + I = π(a), the requirement f̃ ∘ π = f forces f̃(a + I) = f(a), and there is no choice. The content is that this forced prescription is well defined — which is where I ⊆ ker f is spent. The induced map is injective exactly when I = ker f, and surjective exactly when f was. — Aluffi §5.5, pp. 91–92

What the theorem is for. Two things. It recognises a quotient — given R/I, find a surjection out of R whose kernel is I, and the target names the quotient. And it identifies an image — given f, restrict to f : R → im f, which is surjective, and read off im f ≅ R/ker f. Either way, the only real work is computing a kernel. — Aluffi §5.5, p. 92

Three recognitions, no computation.

Example 5.40. Identify ℤ[x]/(x). Take f : ℤ[x] → ℤ, f(α) = α(0), which is surjective (constants hit everything). Its kernel is the polynomials with zero constant term, which is (x). So ℤ[x]/(x) ≅ ℤ — the whole of aa-09's faded example, in three lines. — Aluffi §5.5, Example 5.40, p. 92

Example 5.41. More generally, for commutative R and r ∈ R take the evaluation er : R[x] → R. Since f(x) = (x − r)q(x) + f(r) for every f, we get f(r) = 0 ⟺ f ∈ (x − r), so ker er = (x − r) and R[x]/(x − r) ≅ R. That was aa-09's guided proof; here it costs one kernel computation. — Aluffi §5.5, Example 5.41, p. 92

Example 5.42. Identify ℝ[x]/(x² + 1). Take f : ℝ[x] → ℂ, f(α) = α(i), which is surjective. By long division every α is β(x)(x² + 1) + a + bx, so α(i) = a + bi, which is 0 exactly when a = b = 0, i.e. exactly when α ∈ (x² + 1). Hence ℝ[x]/(x² + 1) ≅ ℂ. The identical argument gives ℤ[x]/(x² + 1) ≅ ℤ[i], the Gaussian integers of aa-07. — Aluffi §5.5, Example 5.42, p. 93

Compare with aa-09, where ℝ[x]/(x² + 1) ≅ ℂ took an explicit multiplication of cosets. The theorem has replaced a computation with a choice of map.

Self-check 1. To identify a quotient R/I by the First Isomorphism Theorem, what must you produce?

Surjectivity gives im f = S, and ker f = I then gives R/I ≅ S. Both halves are needed: if f is not surjective you learn only that R/I ≅ im f, and if the kernel is bigger or smaller than I you are identifying a different quotient. Note that no map out of R/I is ever constructed by hand — the theorem builds it. — Aluffi §5.5, Theorem 5.38, p. 91

The Chinese Remainder Theorem

Let I and J be ideals of a ring R and consider the natural map — Aluffi §5.6, p. 94

ρ : R → (R/I) × (R/J),    ρ(r) = (r + I, r + J).

It is a ring homomorphism (check it — one line per clause). It need not be surjective: with R = ℤ and I = J = 2ℤ, every ρ(r) has equal coordinates, so the image is the diagonal subring of aa-07's Example 4.9 and misses (1, 0). But with I = 2ℤ, J = 3ℤ it is surjective. — Aluffi §5.6, p. 94

The image, computed once and for all. ρ restricts to a surjection R → ρ(R), so the First Isomorphism Theorem gives ρ(R) ≅ R/ker ρ, and

ker ρ = { r : r + I = 0 + I and r + J = 0 + J } = { r : r ∈ I and r ∈ J } = I ∩ J.

Hence ρ(R) ≅ R/(I ∩ J), whether or not ρ is surjective. — Aluffi §5.6, p. 94

A free corollary, worth noticing: kernels are ideals, so this shows I ∩ J is an ideal without any direct verification.

To go further we need arithmetic on ideals.

Definition 5.43 (sum). I + J = { a + b : a ∈ I, b ∈ J } — an ideal, and the smallest ideal containing both I and J. — Aluffi §5.6, Definition 5.43, p. 94

Definition 5.44 (product). IJ = { Σi aibi : ai ∈ I, bi ∈ J } — an ideal. — Aluffi §5.6, Definition 5.44, p. 95

Watch out, in Aluffi's own words: IJ is not the set of products ab; it is the set of finite sums of such products. The set of bare products need not be closed under addition, so it need not be an ideal at all. And since each aibi lies in I by absorption and also in J by absorption, we always have IJ ⊆ I ∩ J. The inclusion is often strict: in ℤ[x] with I = J = (x), IJ = (x²) while I ∩ J = (x). — Aluffi §5.6, p. 95

What all three mean in ℤ. With I = (a) and J = (b):

Example 5.45. (a) + (b) = (gcd(a, b)). One inclusion: d = gcd(a, b) divides both, so (a) ⊆ (d) and (b) ⊆ (d), and (a) + (b) is the smallest ideal containing both. The other: d is an integer linear combination of a and b by Theorem 1.8 — Bézout, from aa-02 — so d ∈ (a) + (b). — Aluffi §5.6, Example 5.45, p. 95; §1.3, Theorem 1.8, p. 8

Example 5.46. (a) ∩ (b) = (lcm(a, b)): the common multiples of a and b are exactly the multiples of their least common multiple. — Aluffi §5.6, Example 5.46, p. 95

Example 5.47. (a)·(b) = (ab). — Aluffi §5.6, Example 5.47, p. 95

So in ℤ the gap between IJ and I ∩ J is exactly the gap between ab and lcm(a, b) — and those agree precisely when a and b are relatively prime. Everything below is that observation, generalised.

Proposition 5.48. If I + J = (1), then ρ is surjective. — Aluffi §5.6, Proposition 5.48, p. 96

The hypothesis I + J = (1) says the smallest ideal containing both is the whole ring. In ℤ with I = (a), J = (b) it says gcd(a, b) = 1 by Example 5.45 — so I + J = (1) is the general form of "relatively prime". — Aluffi §5.6, p. 96

Proof. Given a target (a + I, b + J), we need r with r − a ∈ I and r − b ∈ J. By hypothesis there are i ∈ I, j ∈ J with i + j = 1. Set

r = bi + aj.

Then r − a = r − a(i + j) = (bi + aj) − (ai + aj) = (b − a)i ∈ I by absorption, and r − b = r − b(i + j) = (bi + aj) − (bi + bj) = (a − b)j ∈ J likewise. ∎ — Aluffi §5.6, p. 96

Remark 5.49 — where r = bi + aj comes from. It is not a rabbit. Since i = 1 − j, ρ(i) = (i + I, (1 − j) + J) = (0, 1), and symmetrically ρ(j) = (1, 0). So i and j are the two "indicator" elements, and the target (a, b) is assembled as b·(0,1) + a·(1,0) = ρ(bi) + ρ(aj) = ρ(bi + aj). — Aluffi §5.6, Remark 5.49, pp. 96–97

Corollary 5.50. If I + J = (1) then R/(I ∩ J) ≅ (R/I) × (R/J). — Aluffi §5.6, Corollary 5.50, p. 97

Lemma 5.51. If R is commutative and I + J = (1), then I ∩ J = IJ. — Aluffi §5.6, Lemma 5.51, p. 97

Theorem 5.52 (Chinese Remainder Theorem). Let R be a commutative ring and I, J ideals with I + J = (1). Then R/IJ ≅ (R/I) × (R/J). — Aluffi §5.6, Theorem 5.52, p. 97

Proof of Lemma 5.51. IJ ⊆ I ∩ J always. For the reverse, take i ∈ I, j ∈ J with i + j = 1, and let r ∈ I ∩ J. Then

r = r·1 = r(i + j) = ri + rj = ir + rj.

Now ir ∈ IJ because i ∈ I and r ∈ J; and rj ∈ IJ because r ∈ I and j ∈ J. ∎ — Aluffi §5.6, p. 97

Commutativity is used exactly once, in the step ri = ir — and it is needed, because IJ is built from products with the I-factor on the left. Aluffi flags this explicitly; it is why Theorem 5.52 assumes commutativity while Corollary 5.50 does not.

Theorem 5.52 is then Corollary 5.50 with I ∩ J rewritten as IJ. ∎

Specialising to ℤ. Take R = ℤ, I = (m), J = (n) with gcd(m, n) = 1. Then IJ = (mn) and the theorem reads

ℤ/mnℤ ≅ ℤ/mℤ × ℤ/nℤ.

The case m = 2, n = 3 has been unexplained since aa-07's Example 4.3. Coprimality is not only sufficient but necessary. — Aluffi §5.6, p. 98

Corollary 5.53. For pairwise relatively prime n₁, …, nr with N = n₁⋯nr,   ℤ/Nℤ ≅ (ℤ/n₁ℤ) × ⋯ × (ℤ/nrℤ); in particular ℤ/Nℤ splits along the prime factorisation of N. — Aluffi §5.6, Corollary 5.53, p. 98

Below, each integer a is plotted at (a mod m, a mod n). When m and n are coprime the grid fills completely — that is surjectivity, Proposition 5.48 — and when they are not, whole rows and columns stay empty. The number of filled cells is always lcm(m, n), which is the size of ℤ/(I ∩ J).

Application — Euler's totient is multiplicative. Write φ(n) for the number of k in 1 ≤ k ≤ n with gcd(k, n) = 1.

Proposition 5.56. If a and b are relatively prime then φ(ab) = φ(a)φ(b). — Aluffi §5.6, Proposition 5.56, p. 100

Proof. First, φ(n) counts the units of ℤ/nℤ, since [ℓ]n is a unit exactly when gcd(n, ℓ) = 1 — aa-04's Proposition 2.16. By the Chinese Remainder Theorem ℤ/abℤ ≅ ℤ/aℤ × ℤ/bℤ, and (r, s) is a unit in a product exactly when r and s are units in the factors, so

(ℤ/abℤ)∗ ≅ (ℤ/aℤ)∗ × (ℤ/bℤ)∗.

Counting both sides gives φ(ab) = φ(a)φ(b). ∎ For instance φ(105) = φ(3)φ(5)φ(7) = 2·4·6 = 48. — Aluffi §5.6, p. 100

Notice what happened: a statement about counting coprime integers was proved by an isomorphism of rings. No integer was examined.

You try (solo). Aluffi leaves Corollary 5.53 with "Prove it yourself (by induction)". Do it: from Theorem 5.52 for two factors, derive the r-factor version for pairwise coprime n₁, …, nr. The step that needs care is the inductive one — you must check that n₁ and n₂⋯nr are relatively prime, which is not immediate from "pairwise" and needs aa-02's Corollary 1.11 or Proposition 1.25. Then use it to compute φ(360) and check your answer by a second route.

Self-check 2. For ideals I, J of a ring, which inclusion always holds?

Every generator aibi of IJ lies in I by absorption (ai ∈ I) and in J by absorption (bi ∈ J), and both I and J are closed under sums — so IJ ⊆ I ∩ J always. The reverse can fail badly: with I = J = (x) in ℤ[x], IJ = (x²) is strictly inside I ∩ J = (x). Lemma 5.51 says the two coincide when I + J = (1) and R is commutative — which in ℤ is the statement that lcm(a, b) = ab exactly for coprime a, b. — Aluffi §5.6, Definition 5.44, p. 95

Self-check 3. In ℤ, what does the hypothesis I + J = (1) say for I = (a), J = (b)?

By Example 5.45, (a) + (b) = (gcd(a, b)), and that equals (1) = ℤ exactly when the gcd is 1. So I + J = (1) is the ideal-theoretic form of "relatively prime" — and by Bézout it is also the statement that 1 = ma + nb is solvable, which is exactly the ingredient Proposition 5.48's proof consumes when it writes i + j = 1. Both a and b prime is neither necessary (4 and 9) nor sufficient (2 and 2). — Aluffi §5.6, p. 96

Segment 3 · ~25 min

The Third Isomorphism Theorem, and the dictionary

Write A/I for π(A) = { r + I : r ∈ A } whenever I ⊆ A ⊆ R. The question is: what are the ideals of R/I? — Aluffi §5.7, p. 100

Theorem 5.57 (Third Isomorphism Theorem). Let I be an ideal of R and let J be an ideal of R containing I. Then J/I is an ideal of R/I, every ideal of R/I arises this way, and

(R/I)/(J/I) ≅ R/J.

— Aluffi §5.7, Theorem 5.57, p. 100
Proof. J/I is an ideal: it is closed under +, and for any coset r + I and any a + I ∈ J/I, (r + I)(a + I) = ra + I ∈ J/I because ra ∈ J — absorption in R becoming absorption in R/I. All ideals arise this way: given an ideal J̄ of R/I, put J = π−1(J̄); this is an ideal of R containing I = π−1(0), and π(J) = J̄.

The isomorphism: let ρ = π′ ∘ π be the composite R → R/I → (R/I)/(J/I). Both projections are surjective, so ρ is. By the First Isomorphism Theorem, (R/I)/(J/I) ≅ R/ker ρ, and

ker ρ = ρ−1(0) = π−1(π′−1(0)) = π−1(J/I) = J. ∎

— Aluffi §5.7, pp. 100–101

The whole proof is the First Isomorphism Theorem plus one kernel computation. That is the pattern of the entire chapter.

The dictionary. Theorem 5.57 says the ideals of R/I correspond one-to-one with the ideals of R containing I. So quotienting by I is a way of discarding exactly the ideals that do not contain I. — Aluffi §5.7, p. 102

Example 5.59 — the ideals of ℤ/12ℤ, counted without working. Every ideal of ℤ is nℤ (aa-09's worked example). Which contain 12ℤ? Exactly those with 12 ∈ nℤ, i.e. n ∣ 12, i.e. n = ±1, ±2, ±3, ±4, ±6, ±12. So ℤ/12ℤ has exactly six ideals:

(1̄), (2̄), (3̄), (4̄), (6̄), (0̄),

the last being the ideal generated by the class of 12, which is 0̄. (Write that last generator as 0̄ rather than stacking bars over the digits of 12: read as a product, 1̄·2̄ is just 2̄, whose ideal has six elements and is not the zero ideal at all.)

and inclusions mirror divisibility: 3 ∣ 6 corresponds to (6̄) = {0̄, 6̄} ⊆ (3̄) = {0̄, 3̄, 6̄, 9̄}. — Aluffi §5.7, Example 5.59, p. 102

And a theorem you already paid for, refunded. A commutative ring is a field exactly when its only ideals are (1) and (0). By the same argument, ℤ/pℤ has only those two ideals exactly when the only divisors of p are ±1 and ±p — that is, exactly when p is irreducible. That is aa-04's Theorem 2.15, which cost real work there and now costs none. Aluffi's comment is worth keeping: the point of abstraction is to move the difficulty out of the proofs and into the language. — Aluffi §5.7, p. 102

Faded example — Example 5.58: identify ℤ[x]/(2, x). Recall (2, x) is the ideal of linear combinations of 2 and x — concretely, the polynomials with even constant term.

Apply Theorem 5.57 with I = (x) and J = (2, x). First check I ⊆ J: every multiple of x is a combination of 2 and x, with coefficient ⟨your step⟩ on 2. So

ℤ[x]/(2, x) ≅ (ℤ[x]/(x)) / ((2, x)/(x)).

Now Example 5.40 gives ℤ[x]/(x) ≅ ⟨your step: which ring?⟩. Under that isomorphism the coset 2 + (x) corresponds to the integer ⟨your step⟩, and since (2, x) = (2) + (x), the ideal (2, x)/(x) is generated by that coset.

So the outer quotient is ℤ modulo the ideal generated by 2, namely ⟨your step⟩. Conclusion: ℤ[x]/(2, x) ≅ ℤ/2ℤ. — Aluffi §5.7, Example 5.58, p. 101

Sanity check by a second route: the map ℤ[x] → ℤ/2ℤ sending α(x) to [α(0)]₂ is a surjective homomorphism whose kernel is the polynomials with even constant term — and the First Isomorphism Theorem gives the same answer.

Guided proof (write it yourself)

Aluffi states Proposition 5.39 and then declines to prove it: "You should now grab a piece of paper and just do it yourself." Let f : R → S be a ring homomorphism and let I be an ideal of R with I ⊆ ker f. Prove that f̃(a + I) := f(a) is well defined, is a ring homomorphism, and is the only function making f̃ ∘ π = f. Then answer: at which single step is the hypothesis I ⊆ ker f used, and what goes wrong without it?

Reveal model answer

Uniqueness. Any f̃ with f̃ ∘ π = f must satisfy f̃(a + I) = f̃(π(a)) = f(a). Every coset of R/I is of the form a + I = π(a), so this determines f̃ completely. No hypothesis is needed for this half — it is forced by the equation.

Well defined. Suppose a + I = b + I, i.e. b − a ∈ I. Since I ⊆ ker f, we get b − a ∈ ker f, so f(b − a) = 0, so f(b) = f(a). Hence the prescribed value does not depend on the representative.

Homomorphism. f̃((a + I) + (b + I)) = f̃((a + b) + I) = f(a + b) = f(a) + f(b) = f̃(a + I) + f̃(b + I), using Definition 5.24 then that f is a homomorphism; multiplication is the same line; and f̃(1 + I) = f(1) = 1S.

Where the hypothesis is used, and what breaks. Exactly once, in well-definedness. Without it there is some i ∈ I with f(i) ≠ 0, and then 0 + I = i + I are the same coset while the recipe assigns them the different values f(0) = 0 and f(i). The "function" would not be a function at all. ∎

Grade yourself on separating the three claims. Uniqueness is free, the homomorphism clauses are mechanical, and all of the mathematical content is in one line of well-definedness — which is the same line, in the same place, as in aa-04's Claim 2.12 and aa-09's Lemma 5.25.

Self-check 4. How many ideals does ℤ/12ℤ have?

By Theorem 5.57 they correspond to the ideals nℤ of ℤ containing 12ℤ, and nℤ ⊇ 12ℤ exactly when n ∣ 12. The positive divisors 1, 2, 3, 4, 6, 12 give six ideals. Only two would mean ℤ/12ℤ is a field, which it is not; and the elements are not in bijection with the ideals — (2̄) already contains six elements. — Aluffi §5.7, Example 5.59, p. 102

Self-check 5. ρ : ℤ → ℤ/4ℤ × ℤ/6ℤ, ρ(r) = ([r]₄, [r]₆). How large is its image?

ker ρ = 4ℤ ∩ 6ℤ = (lcm(4, 6)) = 12ℤ by Example 5.46, so the image is ℤ/12ℤ with 12 elements — half of the 24 available. It is not surjective because gcd(4, 6) = 2 ≠ 1, so (4) + (6) = (2) ≠ (1) and Proposition 5.48 does not apply. And it is not the diagonal either: that would need I = J. This is the general statement ρ(R) ≅ R/(I ∩ J), which holds whether or not ρ is onto. — Aluffi §5.6, p. 94

Then check yourself
  1. Kernels are exactly the ideals (Proposition 5.35, Remark 5.36), and every homomorphism factors canonically as surjection, isomorphism, injection (Theorem 5.37) — the isomorphism being f̃(a + ker f) = f(a). The First Isomorphism Theorem is the surjective case: S ≅ R/ker f. To identify a quotient, find a surjection with that kernel; to identify an image, compute the kernel. Either way the work is one kernel.
  2. The Chinese Remainder Theorem is an image computation. For ρ : R → R/I × R/J, ker ρ = I ∩ J, so ρ(R) ≅ R/(I ∩ J) always. If I + J = (1) — the general form of "relatively prime" — then ρ is onto (Proposition 5.48), and in a commutative ring I ∩ J = IJ (Lemma 5.51), giving R/IJ ≅ R/I × R/J. In ℤ this is ℤ/mnℤ ≅ ℤ/mℤ × ℤ/nℤ for coprime m, n, and it makes φ multiplicative.
  3. The Third Isomorphism Theorem (R/I)/(J/I) ≅ R/J puts the ideals of R/I in bijection with the ideals of R containing I. So ℤ/12ℤ has six ideals, one per divisor of 12, and "ℤ/pℤ is a field iff p is irreducible" becomes a remark rather than a theorem.
The habit: stop computing inside quotients. Find a map, compute its kernel, and let the theorem name the answer. This is the pattern that will compute homology.
