Rings: definition, examples, basic properties (aa-05)

Aluffi opens this chapter by saying that this is where the text really begins — and then defines a structure you have already been carrying around for four units without a name.

The integers are one. So is every ℤ/nℤ. So are ℚ, ℝ, ℂ, the 2 × 2 matrices, the polynomials, the real-valued functions of a real variable, and the linear maps of a vector space to itself. Seven axioms, and all of those at once. The gain is that anything you prove from the axioms alone is true in every one of them, forever. The cost — and this is the part to take seriously — is that you must stop reading 0, 1, + and · as facts about numbers. They are names for whatever plays those roles.

Predict before we start. Is the set 2ℤ of even integers, with ordinary + and ·, a ring in Aluffi's sense?

It is closed, associative, commutative, distributive, has 0, and has additive inverses. What it lacks is 1: the only candidate is the number 1, which is not even. Under this book's Definition 3.1 that disqualifies it. Aluffi is explicit that this is a convention — other authors call this a ring and call his a "ring with identity", and the half-joking term for the weaker notion is rng. Every ring in this text has a 1. — Aluffi §3.1, Example 3.5, pp. 42–43

Why this matters for the mission: Coefficients for homology come from a ring; everything downstream lives here.

Segment 1 · ~25 min

Seven axioms, and what fails when one is dropped

First the vocabulary. A binary operation on a set R is a function R × R → R. If a ∗ b lands back in R for all a, b ∈ R we say R is closed under ∗; in the definition below closure is built in, because the operations are declared to be operations on R. — Aluffi §3.1, p. 41

Definition 3.1 (ring). A ring (R, +, ·) is a set R with two binary operations, satisfying:
  1. (i) associativity of +: (a + b) + c = a + (b + c) for all a, b, c;
  2. (ii) additive identity: there is 0R ∈ R with a + 0R = 0R + a = a for all a;
  3. (iii) additive inverses: for every a there is z ∈ R with a + z = z + a = 0R;
  4. (iv) commutativity of +: a + b = b + a for all a, b;
  5. (v) associativity of ·: (a·b)·c = a·(b·c) for all a, b, c;
  6. (vi) multiplicative identity: there is 1R ∈ R with a·1R = 1R·a = a for all a;
  7. (vii) distributivity: a·(b + c) = a·b + a·c and (a + b)·c = a·c + b·c for all a, b, c.
— Aluffi §3.1, Definition 3.1, pp. 41–42

Three things to notice immediately. Addition is required to be commutative; multiplication is not. Uniqueness of 0R and 1R is not an axiom — Segment 3 has to prove it before the names are even legitimate. And this list is character-for-character the list (2.3) from §2.4, so aa-04 already proved: — Aluffi §3.1, p. 42

Example 3.2. ℤ is a ring.   Example 3.3. ℚ, ℝ, ℂ are rings.   Example 3.4. For every n ≥ 0, ℤ/nℤ is a ring. — Aluffi §3.1, Examples 3.2–3.4, p. 42

The non-examples are more instructive, because each one fails exactly one clause and shows you what that clause is buying.

Three failures, each of a different kind.

Example 3.5 — 5ℤ fails (vi). The multiples of 5 are closed under + and ·, have 0, have negatives, and inherit every associativity and distributivity law from ℤ. But the only possible multiplicative identity is 1, and 1 ∉ 5ℤ. A rng, not a ring — and the same for nℤ whenever n ≠ ±1. — Aluffi §3.1, Example 3.5, pp. 42–43

Example 3.6 — ℕ fails (iii). The natural numbers ℤ≥0 satisfy every axiom except additive inverses: nothing in ℕ can be added to 1 to give 0. Aluffi's comment is that axiom (iii) is so fundamental that "nobody on this planet" calls ℕ a ring — unlike (vi), this failure is not a matter of convention. — Aluffi §3.1, Example 3.6, p. 43

Example 3.7 — ℤ≤0 fails before you get that far. The nonpositive integers are not closed under multiplication: (−1)·(−1) = 1 escapes. With no multiplication on the set at all, axioms (v), (vi), (vii) cannot even be stated. Failing closure is worse than failing an axiom; it means the structure was never a candidate. — Aluffi §3.1, Example 3.7, p. 43

Example 3.8 — how small can a ring be? Not empty: axioms (ii) and (vi) both demand an element. So the smallest possible ring has one element r, with r + r := r and r·r := r. Every axiom holds trivially. In it 0R = 1R = r — there is no room for anything else — so 0 = 1 in the trivial ring.

We have met it already: ℤ/1ℤ has the single class [0]₁ = [1]₁. And the converse holds too: if 0 = 1 in a ring R then R is trivial. That is Aluffi's Exercise 3.5, and it is your guided proof at the end of this lesson. — Aluffi §3.1, Example 3.8, pp. 43–44

Self-check 1. Which clause of Definition 3.1 does ℕ = ℤ≥0 fail?

ℕ has 1, and distributivity is inherited from ℤ. What it does not have is negatives: no natural number solves 1 + z = 0. Contrast 5ℤ, which has all the inverses and lacks the 1 — the two non-examples are deliberately chosen to fail different clauses, so that neither can be mistaken for the general reason a set fails to be a ring. — Aluffi §3.1, Examples 3.5 and 3.6, pp. 42–43

Segment 2 · ~25 min

Rings whose elements are not numbers

Aluffi is blunt about the shift required: dissociate the symbols 0, 1, +, · from their meaning as numbers. In ℤ/nℤ the element 0 is really the infinite set [0]n. In the examples below it is a matrix, a polynomial, or a function. The symbols are recycled to avoid a proliferation of notation and because these things behave similarly — not because they are numbers. — Aluffi §3.1, p. 43

Example 3.9 — matrices. M2,2(ℝ), the 2 × 2 real matrices, with the usual entrywise addition and the usual row-times-column multiplication, is a ring, with

0 = the all-zero matrix,    1 = the identity matrix,

and the additive inverse of a matrix obtained by negating each entry. Associativity of multiplication is a genuine computation; Aluffi works one entry of it, and the punchline is that it reduces to associativity of · and commutativity of + among the entries — both true in any ring. So the same argument gives a ring Mn,n(R) for every n ≥ 1 and every ring R, including strange ones like M2,2(ℤ/2ℤ) or M2,2(M2,2(ℤ)). — Aluffi §3.1, Example 3.9, pp. 44–45

And this is the first non-commutative ring in the book. Nothing in Definition 3.1 demands ab = ba, and matrices are where that omission stops being theoretical.

Below, the unit square is pushed through two matrices in both orders. A is a horizontal shear, B a quarter-turn. Same two matrices; the outputs are not the same shape.

Example 3.10 — polynomials. A polynomial in one indeterminate x over ℝ is a formal expression a₀ + a₁x + ⋯ + anxn with real coefficients, only finitely many nonzero. Addition is coefficient by coefficient, and multiplication collects like powers:

(α + β)i = ai + bi,     (α·β)k = a₀bk + a₁bk−1 + ⋯ + akb₀.

Then ℝ[x] is a ring; so is R[x] for any ring R, and so is R[x₁, …, xn] in any number of indeterminates. Polynomial rings will carry a large share of the rest of the module. — Aluffi §3.1, Example 3.10, pp. 45–46

Remark 3.12 — a polynomial is not a function. A polynomial does determine a function R → R by substitution (Example 3.11), but different polynomials can determine the same function: over ℤ/2ℤ the polynomial x(x − 1) evaluates to 0 at both elements, yet it is not the zero polynomial. Keep the two ideas apart; aa-13 will need them apart. — Aluffi §3.1, Example 3.11 and Remark 3.12, p. 46

Functions into a ring, pointwise. Let S be any set and R any ring, and let RS be the set of all functions S → R, with

(f + g)(s) := f(s) + g(s),     (f·g)(s) := f(s)·g(s).

This is a ring. Its 0 is the function sending every s to 0R; its 1 is the function sending every s to 1R. Every axiom holds because it holds at each point separately: to check f(g + h) = fg + fh, evaluate both sides at an arbitrary s and apply distributivity in R. — Aluffi §3.1, pp. 46–47

This "check it pointwise" argument is a technique, not just an example. Any construction that defines operations coordinate by coordinate inherits every axiom that is a universally quantified identity — which is all seven. That is exactly how the product ring R × S is verified in Problem 5(a), and it is why aa-07 can treat products so quickly.

Example 3.13 — linear transformations. For a vector space V, the linear maps V → V form a ring under (α + β)(v) := α(v) + β(v) and (αβ)(v) := α(β(v)) — note that the multiplication is composition, not a pointwise product. It generalises the matrix ring, and Aluffi flags it as more representative of what a general ring looks like than ℤ or ℤ/nℤ, which are unusually well behaved. — Aluffi §3.1, Example 3.13, p. 47

Self-check 2. Over ℤ/2ℤ, the polynomial x(x − 1) evaluates to 0 at every element. Is it the zero polynomial?

x(x − 1) = x² − x has coefficients 0, −1, 1, so it is not the zero polynomial. That it computes the zero function on ℤ/2ℤ (both 0 and 1 are roots) is a fact about a two-element domain, not about the polynomial. Aluffi's Remark 3.12 warns against the identification precisely here; the ring ℝ[x] and the ring of real functions are different rings, and the map between them is the subject of Example 4.22. — Aluffi §3.1, Remark 3.12, p. 46

Segment 3 · ~25 min

Consequences of the axioms — and one non-consequence

Aluffi issues a warning before starting: "obvious" is a forbidden word. Ring notation was chosen to evoke familiar facts, and many of them do turn out true — but each one needs a derivation from the seven axioms, and some familiar ones are simply false. — Aluffi §3.2, pp. 47–48

Proposition 3.14. In a ring R, the additive identity is unique, and so is the multiplicative identity: if 0′ and 0″ both satisfy (ii) then 0′ = 0″, and if 1′ and 1″ both satisfy (vi) then 1′ = 1″. — Aluffi §3.2, Proposition 3.14, p. 48
Proof. Prove the general fact once. Call e an identity for an operation ∗ if a ∗ e = e ∗ a = a for all a. Suppose e′ and e″ are both identities. Then

e′ = e′ ∗ e″  (because e″ is an identity)   and   e′ ∗ e″ = e″  (because e′ is an identity),

so e′ = e″. Apply this to + and to ·. ∎

Two things worth extracting. First, the proof needs only that e′ is an identity on the left and e″ on the right; the two-sided hypothesis is more than required. Second, note why this had to be proved at all: until it is, writing "0R" names an element that might not be determined, and giving one name to several elements is not an option. — Aluffi §3.1, p. 42; §3.2, p. 48

Proposition 3.15. Let R be a ring and a ∈ R. The additive inverse of a is unique: if z′ and z″ both satisfy a + z = z + a = 0, then z′ = z″. — Aluffi §3.2, Proposition 3.15, p. 48
Proof — one line, five justifications.

z′ = z′ + 0 = z′ + (a + z″) = (z′ + a) + z″ = 0 + z″ = z″,

using in order: axiom (ii); the hypothesis on z″; axiom (i), associativity; the hypothesis on z′; axiom (ii) again. ∎ — Aluffi §3.2, p. 49

Only now is it legitimate to write −a, and axiom (iii) becomes a + (−a) = (−a) + a = 0. And a first dividend: what is −(−a)? Call it b, so (−a) + b = b + (−a) = 0. But a satisfies exactly that requirement, so by uniqueness b = a: −(−a) = a. Expected, yes; obvious, no. It is a consequence of Proposition 3.15 and of nothing else. We write b − a for b + (−a).

Remark 3.16 — the multiple notation is a trap. In any ring, 2a means a + a. It does not mean "the element 2 times a" — in a general ring there may be no element called 2 at all. Similarly 18a is a added to itself eighteen times, 0a = 0, and (−5)a = −(a + a + a + a + a). — Aluffi §3.2, Remark 3.16, p. 50

Proposition 3.17 (additive cancellation). Let R be a ring and a, b, c ∈ R. If a + b = a + c then b = c. — Aluffi §3.2, Proposition 3.17, p. 50
Proof.

b = 0 + b = ((−a) + a) + b = (−a) + (a + b) = (−a) + (a + c) = ((−a) + a) + c = 0 + c = c,

by (ii), then (iii), then (i), then the hypothesis, then (i) again, then (iii), then (ii). ∎ — Aluffi §3.2, p. 50

Corollary 3.18. Let R be a ring and a ∈ R. Then 0·a = a·0 = 0. — Aluffi §3.2, Corollary 3.18, p. 51
Proof. By distributivity and axiom (ii),

a·0 + a·0 = a·(0 + 0) = a·0 = a·0 + 0,

and additive cancellation (Proposition 3.17) strips the a·0 from the front of both sides, leaving a·0 = 0. The identity 0·a = 0 is the mirror image, using the other distributive law. ∎ — Aluffi §3.2, p. 51

Note that this is not an axiom, and could not be: nothing in Definition 3.1 mentions how · interacts with 0 except through distributivity. That single link is enough.

Two more that the problem set uses: (−a)b = −(ab) and (−a)(−b) = ab.

For the first, it is enough to show ab + (−a)b = 0, since then (−a)b satisfies the defining property of −(ab), and Proposition 3.15 says nothing else does. Indeed

ab + (−a)b = (a + (−a))·b = 0·b = 0,

by distributivity and Corollary 3.18. For the second, apply the first twice: (−a)(−b) = −(a(−b)) = −(−(ab)) = ab, the last step being −(−x) = x. ∎

Notice the shape of both arguments, because it recurs: to prove something equals −x, do not compute it — show it has the property that defines −x, and let uniqueness do the rest.

And the non-consequence. Multiplicative cancellation — "ab = ac and a ≠ 0 imply b = c" — is not a theorem about rings, however obvious it looks. We already have the counterexample: in ℤ/6ℤ, [2]·[2] = [4] = [2]·[5] while [2] ≠ [5] (Remark 2.17). Aluffi's phrasing is worth keeping: no matter how clever you are, you will not prove it from the axioms. It becomes true under an extra hypothesis, which is exactly what aa-06 is about. — Aluffi §3.2, p. 51

Faded example — verifying an axiom pointwise. Let S be a set, R a ring, and RS the functions S → R with pointwise operations. Check axiom (iii), the existence of additive inverses.

Given f ∈ RS, the candidate is the function g defined by g(s) := ⟨your step: what should g(s) be, in terms of f(s)?⟩. This is a legitimate element of RS because f(s) ∈ R and R has additive inverses by ⟨your step: which axiom, in R?⟩.

Then for every s ∈ S, (f + g)(s) = f(s) + g(s) = ⟨your step⟩, which is the value at s of the zero function. Since two functions agreeing at every point are equal, f + g = 0RS, and the other order is the same computation.

Now use the same template on axiom (vi): the candidate for 1 is the function sending every s to ⟨your step⟩, and the verification is one line.

Guided proof (write it yourself)

Aluffi asserts that the trivial ring is the only ring in which 0 = 1, and defers it to Exercise 3.5. Prove it. Let R be a ring with 0R = 1R. Show that R has exactly one element. Name every axiom or result you use — in particular, be sure you know why you are entitled to the step that makes a·1 collapse.

Reveal model answer

Let a ∈ R be arbitrary. By axiom (vi), a = a·1R. By hypothesis 1R = 0R, so a = a·0R. By Corollary 3.18, a·0R = 0R. Hence a = 0R.

Since a was arbitrary, every element of R equals 0R, so R = {0R}. And R is nonempty, because axiom (ii) requires 0R to exist. So R has exactly one element. ∎

The converse is Example 3.8: in a one-element ring the single element must be both the additive and the multiplicative identity, so 0 = 1 there. Together: R is trivial if and only if 0R = 1R.

Grade yourself on the middle step. If you wrote "a·0 = 0 because anything times zero is zero", that is the forbidden word — a·0 = 0 is Corollary 3.18, proved from distributivity and additive cancellation, and it is the only reason available.

Self-check 3. Why does Aluffi prove Proposition 3.14 before allowing himself to write "0R"?

Axiom (ii) asserts existence, not uniqueness. Until uniqueness is proved, "0R" might be a name shared by several elements, which is not a viable notation. Existence is not in question — it is an axiom — and 0 = 1 is perfectly allowed, as the trivial ring shows. — Aluffi §3.1, p. 42; §3.2, p. 48

Self-check 4. Can "ab = ac with a ≠ 0 implies b = c" be proved from the ring axioms?

A single counterexample settles it: in ℤ/6ℤ, [2][2] = [4] = [2][5] with [2] ≠ [0] and [2] ≠ [5]. The first option assumes a has an inverse, which the axioms do not provide — that is precisely the property (2.4) that ℤ itself lacks. And commutativity is irrelevant: ℤ/6ℤ is commutative. — Aluffi §3.2, p. 51; §2.4, Remark 2.17, p. 34

Self-check 5. In an arbitrary ring, what does the expression 3a mean?

Multiple notation abbreviates repeated addition. There need not be any element called 3 in R — in ℤ/2ℤ there is not — so reading 3a as a product is meaningless in general. And a·a·a is a³, the power notation, which is a different abbreviation. Aluffi flags this in Remark 3.16 exactly because the notation invites the wrong reading. — Aluffi §3.2, Remark 3.16, p. 50

Then check yourself
  1. Definition 3.1 is seven axioms, and it is the list (2.3) that ℤ and every ℤ/nℤ were already shown to satisfy. Addition is commutative by fiat; multiplication is not. The non-examples separate the clauses: 5ℤ fails only (vi), ℕ fails only (iii), ℤ≤0 fails closure and so cannot even be asked.
  2. The elements need not be numbers: matrices (non-commutative), polynomials (not the same objects as the functions they compute), and all functions S → R with pointwise operations — where every axiom holds because it holds at each point, a template that also delivers product rings.
  3. What the axioms yield, and what they do not. Yield: uniqueness of 0 and 1 (Proposition 3.14), uniqueness of −a (Proposition 3.15) and hence −(−a) = a, additive cancellation (Proposition 3.17), 0·a = a·0 = 0 (Corollary 3.18), and (−a)b = −(ab). Do not yield: multiplicative cancellation — false in ℤ/6ℤ, and no cleverness will derive it.
The habit to carry forward: every identity you believe about a ring is either derived from these seven lines or is false somewhere. The gap between those two cases is where aa-06 lives.
