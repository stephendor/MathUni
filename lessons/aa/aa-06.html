Domains, fields, and zero-divisors (aa-06)

In ℤ/10ℤ, 2 × 5 = 0. Neither factor is zero. Nothing has gone wrong — that is simply what multiplication does there.

aa-05 left us with a warning: multiplicative cancellation is not a theorem about rings, and no cleverness will make it one. This lesson turns the warning into a taxonomy. Ban zero-divisors and you get an integral domain, where cancellation returns. Demand inverses instead and you get a field, where division returns. Fields sit inside domains sit inside commutative rings sit inside rings, and every containment is strict — except, remarkably, when the ring is finite, where the bottom two collapse into one.

Predict before we start. Every field is an integral domain. Is every integral domain a field?

ℤ has no zero-divisors and 0 ≠ 1, so it is an integral domain; but 2 has no integer inverse, so it is not a field. Aluffi's advice is to "always carry a copy of ℤ in your pocket to remind you of this fact". A second witness with a different flavour: ℚ[x] is a domain built over a field, and still not a field, because x has no inverse. Domains are strictly more common than fields — and Proposition 3.33 will show exactly when the distinction disappears. — Aluffi §3.3, Remark 3.32, p. 56

Why this matters for the mission: Field coefficients make homology a vector space; over a ring you keep torsion. This is that fork.

Segment 1 · ~25 min

Commutativity, zero-divisors, and integral domains

Two properties of ℤ are not in the ring axioms, and the first order of business is to show that neither is hiding inside them.

Example 3.19 — multiplication need not commute. One example settles it. In M2,2(ℝ), taking the two shears,

(1 1 / 0 1)·(1 0 / 1 1) = (2 1 / 1 1)   while   (1 0 / 1 1)·(1 1 / 0 1) = (1 1 / 1 2),

writing (a b / c d) for the matrix with rows (a b) and (c d). The two results differ, so no derivation of ab = ba from Definition 3.1 can exist. — Aluffi §3.3, Example 3.19, p. 52

Definition 3.20 (commutative ring). A commutative ring is a ring R in which ab = ba for all a, b ∈ R. — Aluffi §3.3, Definition 3.20, p. 52

A "random" ring should not be expected to be commutative — the linear transformations of V are noncommutative as soon as dim V > 1, and matrix rings are everywhere in physics. But commutative rings abound, they are the subject of a discipline of their own, and most examples in this text are commutative. For the rest of this section, assume the ring is commutative. — Aluffi §3.3, pp. 52–53

Now the second property, the one aa-05 flagged as underivable:

for all a, b:   ab = 0 ⟹ a = 0 or b = 0.   (3.7)

Example 3.21. In ℤ/10ℤ, [2]₁₀·[5]₁₀ = [0]₁₀ while [2]₁₀ ≠ [0]₁₀ and [5]₁₀ ≠ [0]₁₀. So (3.7) fails, in a commutative ring. — Aluffi §3.3, Example 3.21, p. 53
Definition 3.22 (zero-divisor). Let R be a ring. An element a ∈ R is a zero-divisor if there exists a nonzero b ∈ R with ab = 0 or ba = 0. An element that is not a zero-divisor is a non-zero-divisor (nzd). — Aluffi §3.3, Definition 3.22, p. 53

Read the definition carefully; two details bite. First, it is two-sided: a is a zero-divisor if it kills something on either side, so in a noncommutative ring you must check both. Consequently a is an nzd precisely when ab = 0 forces b = 0 and ba = 0 forces b = 0. Second, 0 is itself a zero-divisor in any nontrivial ring, since 0·1 = 0 and 1 ≠ 0. Aluffi calls the terminology "somewhat unfortunate" — every element divides 0 — but this is the convention in force, and Definition 3.23 below is phrased to work around it. — Aluffi §3.3, p. 53

Definition 3.23 (integral domain). A commutative ring R is an integral domain if

for all a, b ∈ R:   ab = 0 ⟹ a = 0 or b = 0,   and   0 ≠ 1 in R.

— Aluffi §3.3, Definition 3.23, p. 53

Equivalently: a nontrivial commutative ring in which every nonzero element is a non-zero-divisor. The clause 0 ≠ 1 is not decoration — it excludes the trivial ring by hand, for reasons that Aluffi ties to not wanting to treat 1 as irreducible, and that resurface when domains are matched with prime ideals in §6.1. — Aluffi §3.3, p. 53

Example 3.24 — the ℤ/nℤ verdict, restated. aa-04's Theorem 2.15 proved that (3.7) holds in ℤ/nℤ exactly when n is prime, for n > 1; and ℤ/0ℤ is a domain because ℤ is. So ℤ/nℤ is an integral domain precisely when n is a prime integer — with Aluffi's convention that 0 is prime doing exactly the work it was designed for at the n = 0 end. — Aluffi §3.3, Example 3.24, pp. 53–54

And most of §3.1's examples are domains: ℤ[x], ℚ[x], ℝ[x], ℂ[x] all are. A "random" commutative ring should not be expected to be one, but the familiar ones mostly are. — Aluffi §3.3, Example 3.25, p. 54

Self-check 1. In a nontrivial ring, is 0 a zero-divisor?

Definition 3.22 asks for a nonzero b with ab = 0; taking a = 0 and b = 1 works in any nontrivial ring. So 0 is always a zero-divisor, in ℤ as much as in ℤ/10ℤ. That is why Definition 3.23 says "every nonzero element is a non-zero-divisor" rather than "there are no zero-divisors" — the latter would be false everywhere. — Aluffi §3.3, Definition 3.22, p. 53

Segment 2 · ~25 min

Cancellation returns; units and the group of units

Proposition 3.26. Let R be a ring and a ∈ R a non-zero-divisor. Then multiplicative cancellation holds for a:

ab = ac ⟹ b = c   and   ba = ca ⟹ b = c.

In particular, in an integral domain cancellation holds for every nonzero element. — Aluffi §3.3, Proposition 3.26, p. 54
Proof. Suppose ab = ac. Then ab − ac = 0, and distributivity gives a(b − c) = 0. Since a is a non-zero-divisor and it kills b − c on the left, b − c = 0, i.e. b = c. For the right-hand version, from ba = ca we get (b − c)a = 0, and the other half of Definition 3.22 gives b − c = 0. ∎

Both halves are needed and neither implies the other in a noncommutative ring — this is exactly why Definition 3.22 was stated with "ab = 0 or ba = 0" rather than one side only. In a commutative ring the two arguments are the same argument written twice.

Compare aa-04's Remark 2.17, which proved this for ℤ/pℤ. That was the special case; this is the statement it was a shadow of, and the proof is shorter because there is no arithmetic in it at all.

Definition 3.27 (unit). An element b of a ring R is a multiplicative inverse of a ∈ R if ab = ba = 1R. An element with an inverse is invertible, or a unit; the set of units of R is written R∗. — Aluffi §3.3, Definition 3.27, p. 54

The inverse, when it exists, is unique — the argument is the one you ran in aa-05's you-try, verbatim from Proposition 3.15 with · in place of + — so it may be written a−1, and then a−n means (a−1)n and am+n = aman for all integers m, n. — Aluffi §3.3, p. 54

Invertibility is not typical: 2 is not a unit in ℤ though it is in ℚ, and [2]n is a unit in ℤ/nℤ exactly when n is odd — for n = 2k + 1, [2]n[−k]n = [−2k]n = [1 − n]n = [1]n. — Aluffi §3.3, p. 54

Proposition 3.28. For n > 0,   (ℤ/nℤ)∗ = { [a]n : gcd(a, n) = 1 }. — Aluffi §3.3, Proposition 3.28, p. 55

No proof is needed: this is aa-04's Proposition 2.16 with the word "unit" substituted for "has a multiplicative inverse". Note what has happened, though — a fact that was a piece of number theory has become a description of R∗ for one family of rings. — Aluffi §3.3, p. 55

Faded example — sorting ℤ/12ℤ into units and zero-divisors.

By Proposition 3.28 the units are the classes [a]₁₂ with gcd(a, 12) = 1. Running through 0, …, 11 that gives ⟨your step: list them⟩ — four classes.

Now the zero-divisors. [4]₁₂ is one, because [4]₁₂[3]₁₂ = [12]₁₂ = [0]₁₂ with [3]₁₂ ≠ 0. In general [a]₁₂ is a zero-divisor when gcd(a, 12) = d > 1: take b = 12/d, so ab is a multiple of 12 while [b]₁₂ ≠ ⟨your step: why is b not 0 mod 12?⟩.

Count them: 4 units, and the remaining ⟨your step: how many?⟩ classes are all zero-divisors, 0 included. There is nothing left over — in ℤ/nℤ every class is a unit or a zero-divisor, and never both.

Finally, since ℤ/12ℤ has a nonzero zero-divisor it is not an integral domain, which agrees with Example 3.24 because 12 is not prime.

Self-check 2. Proposition 3.26 assumes a is a non-zero-divisor, not that a is nonzero. Why?

In ℤ/10ℤ, [2][5] = [0] = [2][0] while [5] ≠ [0], so the nonzero element [2] cannot be cancelled. Being nonzero is the weaker condition; being a non-zero-divisor is what the proof actually consumes. The two coincide exactly in an integral domain, which is why the "in particular" clause can be stated at all. — Aluffi §3.3, Proposition 3.26, p. 54

Segment 3 · ~25 min

Fields, and where the tower collapses

Definition 3.29 (field). A field is a nontrivial commutative ring R in which every nonzero element is invertible — equivalently, R∗ = R \ {0}. — Aluffi §3.3, Definition 3.29, p. 55

Example 3.30. ℚ, ℝ, ℂ are fields, and ℤ/pℤ is a field whenever p is a positive prime, by Theorem 2.15 — so ℤ/2ℤ, ℤ/3ℤ, ℤ/5ℤ, ℤ/7ℤ, ℤ/11ℤ and so on all are. — Aluffi §3.3, Example 3.30, p. 55

Aluffi then states the ℤ/nℤ verdict in its final, sharpest form, valid for all integers n: — Aluffi §3.3, p. 55

ℤ/nℤ is an integral domain ⟺ n is prime;    ℤ/nℤ is a field ⟺ n is irreducible.

The two lines differ only at n = 0, where Aluffi's convention makes 0 prime but not irreducible — and correspondingly ℤ/0ℤ = ℤ is a domain but not a field. That is the whole reason the nonstandard convention was adopted back in Definition 1.19.

Proposition 3.31. Fields are integral domains. — Aluffi §3.3, Proposition 3.31, p. 55
Proof. Let R be a field. It is nontrivial, so 0 ≠ 1. Suppose ab = 0. If a = 0 we are done; otherwise a has an inverse a−1, and

b = 1·b = (a−1a)b = a−1(ab) = a−1·0 = 0,

the last step by aa-05's Corollary 3.18. ∎ — Aluffi §3.3, p. 55

Remark 3.32. Read what that argument actually proved: an invertible element is a non-zero-divisor. Since in a field every nonzero element is invertible, every nonzero element is an nzd, which is the definition of a domain. The field hypothesis was used only to supply the inverse. — Aluffi §3.3, Remark 3.32, p. 56

Notice also that this is the same computation as aa-04's (iii) ⟹ (ii) in Theorem 2.15 — the one flagged there as never mentioning modular arithmetic. Here is the general theorem it was a special case of.

The converse fails, twice over. ℤ is a domain and not a field (2 has no inverse). And ℚ[x] is a domain and not a field even though its coefficients form a field: an inverse of x would be a polynomial α(x) with xα(x) = 1, and no such polynomial exists. — Aluffi §3.3, Remark 3.32, p. 56

Proposition 3.33. Every finite integral domain is a field. — Aluffi §3.3, Proposition 3.33, p. 56
Proof. Let R be a finite integral domain with elements r₁, …, rm listed without repetition, and let a ∈ R be nonzero. Consider

ar₁, ar₂, …, arm.

These have no repetitions: if ari = arj then ri = rj by cancellation (Proposition 3.26, available because a is nonzero in a domain), so i = j. That is m distinct elements of a set with m elements, so the list is all of R. In particular 1 appears: ari = 1 for some i, and ria = 1 follows by commutativity. So a is invertible. ∎ — Aluffi §3.3, p. 56

Where finiteness enters. Only at one step, and it is decisive: "m distinct elements inside a set of size m must be all of it" is false for infinite sets. In ℤ the list 2r₁, 2r₂, … is also repetition-free, and it is simply the even numbers — a proper subset, missing 1. That is why ℤ escapes.

This is the same counting move as the proof of Fermat's little theorem in aa-04, where multiplication by [a]p permuted the nonzero classes. Here it is stated for what it is: a fact about injective self-maps of a finite set.

So the tower is rings ⊃ commutative rings ⊃ integral domains ⊃ fields, each containment strict — and the bottom containment ceases to be strict as soon as the ring is finite. This is why "field" and "domain" coincided for ℤ/nℤ with n ≠ 0: not for a reason about arithmetic, but because those rings are finite. Explore it below. — Aluffi §3.3, p. 56

Guided proof (write it yourself)

Remark 3.32 says the proof of Proposition 3.31 really shows something more general. Extract it. Let R be any ring (not assumed commutative) and let a ∈ R be invertible. Prove that a is a non-zero-divisor. Definition 3.22 is two-sided, so your proof must be too — handle ab = 0 and ba = 0 separately. Then deduce Proposition 3.31 in one further line.

Reveal model answer

Let a−1 be the inverse of a, so a−1a = aa−1 = 1.

Left. Suppose ab = 0. Multiply on the left by a−1:   b = 1·b = (a−1a)b = a−1(ab) = a−1·0 = 0, the last step by Corollary 3.18.

Right. Suppose ba = 0. Multiply on the right by a−1:   b = b·1 = b(aa−1) = (ba)a−1 = 0·a−1 = 0, again by Corollary 3.18.

So no nonzero b is killed by a on either side: a is a non-zero-divisor. ∎

Deducing Proposition 3.31. Let R be a field. It is commutative and nontrivial, so 0 ≠ 1, and every nonzero element is invertible, hence by the above a non-zero-divisor. That is exactly Definition 3.23. ∎

Grade yourself on the two sides. If you proved only the left case and wrote "similarly" for the right, check that your "similarly" multiplies on the correct side — the whole point of the two-sided definition is that in a noncommutative ring left and right are different statements, and the two computations use the two different halves of aa−1 = a−1a = 1.

Self-check 3. Why does Definition 3.23 explicitly require 0 ≠ 1?

In the trivial ring the only element is 0 = 1, and "ab = 0 ⟹ a = 0 or b = 0" holds because everything is 0. Without the clause it would count as a domain. Aluffi excludes it deliberately, tying the choice to not wanting 1 to count as irreducible, and the same exclusion appears in Definition 3.29 as the word "nontrivial". aa-05's guided proof showed 0 = 1 happens exactly in the one-element ring. — Aluffi §3.3, Definition 3.23, p. 53

Self-check 4. Where exactly does the proof of Proposition 3.33 use that R is finite?

Distinctness comes from cancellation, which holds in every domain, finite or not — in ℤ the list 2r₁, 2r₂, … is also repetition-free. What fails for infinite R is the counting step: an injective self-map of an infinite set need not be surjective, and 2·ℤ is precisely a repetition-free list that misses 1. This is the same permutation-by-counting argument as Fermat's little theorem. — Aluffi §3.3, p. 56

Self-check 5. ℚ is a field. Is ℚ[x] a field?

An inverse of x would be a polynomial α(x) with xα(x) = 1, and no such polynomial exists — multiplying by x can never produce a nonzero constant term. ℚ[x] does have no zero-divisors, so it is a domain, and it is infinite, so Proposition 3.33 does not apply. It is the second of Aluffi's two witnesses that domain does not imply field, and the more instructive one, because the failure survives even when the coefficients are as good as possible. — Aluffi §3.3, Remark 3.32, p. 56

Then check yourself
  1. Two properties of ℤ are not axioms. Commutativity of · fails in M2,2(ℝ) (Example 3.19); the law ab = 0 ⟹ a = 0 or b = 0 fails in ℤ/10ℤ (Example 3.21). Elements witnessing the second failure are zero-divisors (Definition 3.22, two-sided, and 0 always counts). A nontrivial commutative ring in which every nonzero element is a non-zero-divisor is an integral domain.
  2. What each layer buys. Non-zero-divisor ⟹ cancellation (Proposition 3.26) — the property aa-05 proved underivable in general. Unit ⟹ non-zero-divisor (Remark 3.32), so field ⟹ domain (Proposition 3.31). Both converses fail: ℤ and ℚ[x] are domains that are not fields.
  3. Finiteness collapses the last step (Proposition 3.33): in a finite domain, multiplication by a nonzero a is injective by cancellation, hence surjective by counting, hence hits 1. That — not anything about arithmetic — is why domain and field coincide for ℤ/nℤ with n ≠ 0.
And the summary line to keep: ℤ/nℤ is a domain exactly when n is prime, and a field exactly when n is irreducible. The two statements differ only at n = 0, which is exactly the gap Definition 1.19's convention was built to expose.
