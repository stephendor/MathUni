Modules and the category of R-modules (aa-15)

An ideal is a vector space whose scalars happen to be a ring.

That is Aluffi's opening observation, and it is the whole of today. A vector space is a set you can add and scale, where the scalars form a field. Loosen "field" to "ring" and you get a module — and suddenly ideals, abelian groups, vector spaces, and quotient rings are four instances of one definition. Almost nothing changes in the axioms. Everything changes in what is true, because you can no longer divide by a scalar. That single loss is the difference between a homology group with field coefficients, which is a vector space, and one with integer coefficients, which carries torsion.

Predict before we start. How many ring homomorphisms ℤ → ℤ are there, and how many homomorphisms of abelian groups?

A ring homomorphism must send 1 to 1, and then n to n for every n — so the identity is the only one. But a ℤ-module homomorphism need only respect + and scaling, and fn(a) = na works for every integer n: fn(a + b) = na + nb and fn(ra) = n(ra) = r(na). Only f₁ is a ring homomorphism. Being a ring homomorphism is a much stronger demand than being a module homomorphism, and that gap is a recurring theme today. — Aluffi §8.2, Example 8.15, pp. 158–159

Why this matters for the mission: Homology's true home: chain groups are modules, not merely vector spaces.

Segment 1 · ~25 min

One definition, four familiar objects

Recall the axioms for a vector space V over a field k: addition satisfies (i)–(iv) of Definition 3.1, and scalar multiplication satisfies — Aluffi §8.1, p. 153

1kv = v,   (ab)v = a(bv),   (a + b)v = av + bv,   a(v + w) = av + aw.

Those look like ring axioms — identity, associativity, two distributivities — but they are not, because scalar multiplication is not an operation inside V: it combines an element of V with an element of something else. The name for that is an action of k on V, and actions return in force in aa-24. — Aluffi §8.1, pp. 153–154

Now the observation. If I is an ideal of a ring R, then I satisfies exactly these requirements with scalars taken from R: the absorption property of aa-09's Definition 5.8 says precisely that multiplication gives a map R × I → I, and the four axioms hold because associativity and distributivity hold in R. An ideal satisfies every one of the vector-space requirements, with scalars taken from R. — Aluffi §8.1, p. 154

And yet it is not a vector space, because R is not a field. Take I = 2ℤ inside R = ℤ: the axioms above all hold, but the scalar 2 has no inverse, so there is no dividing by scalars and none of the arguments that make linear algebra easy are available. What has just been described is a structure the existing vocabulary has no name for — which is the entire reason for the next definition.

Definition 8.1 (module). Let R be a ring. An R-module (M, +, ·) is a set M with operations + : M × M → M and · : R × M → M satisfying
  1. (i)–(iv): + is associative, has an identity 0M, has inverses, and is commutative;
  2. (v) 1R·a = a for all a ∈ M;
  3. (vi) (rs)·a = r·(s·a) for all r, s ∈ R, a ∈ M;
  4. (vii) (r + s)·a = r·a + s·a;
  5. (viii) r·(a + b) = r·a + r·b.
— Aluffi §8.1, Definition 8.1, p. 154

Strictly this defines a left-module; a left-ideal is already one, since only left absorption appears in the axioms. — Aluffi §8.1, p. 154

The examples, which are almost everything you know.

8.2. A one-element set is an R-module for every R — the trivial module, written 0. — Aluffi §8.1, Example 8.2, p. 154

8.3. A k-vector space is exactly an R-module in which R = k is a field. — Aluffi §8.1, Example 8.3, p. 155

8.4. R is a module over itself, with scalar multiplication = ring multiplication. — Aluffi §8.1, Example 8.4, p. 155

8.5. A left-ideal I ⊆ R is an R-module, with R's own operations. — Aluffi §8.1, Example 8.5, p. 155

8.6 — the construction to remember. A ring homomorphism f : R → S makes S an R-module by r·s := f(r)s. (Two different products in that formula: the left one is being defined, the right one is multiplication in S.) — Aluffi §8.1, Example 8.6, p. 155

8.8 — the ground ring is part of the data. ℤ is a module over itself; it is also a ℤ[x]-module, via the homomorphism ℤ[x] → ℤ sending x to 0 and Example 8.6. These are different modules. Likewise ℂ is a ℂ-vector space of dimension 1, an ℝ-vector space of dimension 2, and a ℚ-vector space of uncountable dimension — same set, three answers. — Aluffi §8.1, Example 8.8, p. 155

Faded example — Example 8.7: R/I is a cyclic R-module.

Let I be an ideal of R. There is a ring homomorphism R → R/I, namely the natural projection of aa-10's ⟨your step: which proposition?⟩. So Example 8.6 makes R/I into an ⟨your step: a module over which ring?⟩, with scalar multiplication r·(s + I) = rs + I.

Now notice something about generation: every element of R/I is a coset r + I, and

r + I = r·(⟨your step: which single coset?⟩).

So one element, together with scalar multiplication, produces the entire module. We say that element generates R/I, and a module generated by a single element is called cyclic. — Aluffi §8.1, Example 8.7, p. 155

Keep this: ℤ/nℤ as a ℤ-module is cyclic, generated by 1 + nℤ, and aa-22's classification of finitely generated abelian groups is a statement that everything is built from cyclic pieces.

Proposition 8.9. For every R-module M and every m ∈ M,   0R·m = 0M. — Aluffi §8.1, Proposition 8.9, p. 156
Proof. 0R·m = (0R + 0R)·m = 0R·m + 0R·m by axiom (vii), and additive cancellation gives 0R·m = 0M. ∎ Then 1·a + (−1)·a = (1 − 1)·a = 0, so (−1)·a = −a. — Aluffi §8.1, p. 156

Notice what was reused rather than reproved. Additive cancellation is aa-05's Proposition 3.17, whose proof used only ring axioms (i)–(iii) — and those are module axioms (i)–(iii) verbatim. For the same reason 0M is unique, additive inverses are unique, and −a is well defined. Aluffi declines to rewrite any of these proofs, and the reason is worth stating: they were never about rings. They were about the additive structure, which modules share.

Self-check 1. Which of these is not automatically an R-module?

Ideals are modules by absorption (Example 8.5), R/I by Example 8.7, R by Example 8.4. But a subring need not absorb multiplication by R — that is precisely aa-09's distinction, with ℤ ⊆ ℚ the witness: ½·3 ∉ ℤ, so ℚ does not act on ℤ. Ideals are modules for exactly the property that stops them being subrings. — Aluffi §8.1, Example 8.5, p. 155; §5.2, Definition 5.8, p. 80

Segment 2 · ~25 min

ℤ-modules are abelian groups

Suppose R = ℤ. Axiom (v) forces 1·a = a, and then there is no choice about n·a: for n > 0, axioms (vii) and (v) give — Aluffi §8.1, p. 156

n·a = (1 + ⋯ + 1)·a = 1·a + ⋯ + 1·a = a + ⋯ + a   (n summands),

and (−n)·a is the corresponding sum of −a. That is aa-05's multiple notation from Remark 3.16, arriving here as a theorem rather than a convention.

Proposition 8.10. If (M, +) satisfies axioms (i)–(iv), then the ℤ-action just described satisfies (v)–(viii) automatically. So M is a ℤ-module in a natural way. — Aluffi §8.1, Proposition 8.10, p. 156

Axiom (v) is the definition of 1·a; (vi), (vii), (viii) amount to regrouping and reordering finite sums, which is legal by associativity and commutativity of +. For instance (viii) at r = 3 says (a + b) + (a + b) + (a + b) = (a + a + a) + (b + b + b). — Aluffi §8.1, p. 156

Definition 8.11 (abelian group). An abelian group (A, +) is a set with a binary operation + that is associative, has an identity 0A, has inverses, and is commutative — axioms (i)–(iv). — Aluffi §8.1, Definition 8.11, p. 157

By Proposition 8.10, an abelian group is exactly a ℤ-module: axioms (v)–(viii) come free. There is a pleasant paradox here — abelian groups are a special case of modules (R = ℤ), and simultaneously more general, since every module is an abelian group once you forget the action. — Aluffi §8.1, p. 157

So you already know hundreds of abelian groups.

Example 8.12. If (R, +, ·) is a ring, then (R, +) is an abelian group — ring axioms (i)–(iv) are Definition 8.11. Forget the multiplication and an abelian group is what remains. — Aluffi §8.1, Example 8.12, p. 157

Example 8.13. Every R-module is an abelian group, by forgetting R. So every vector space is one, and every ideal in every ring is one. — Aluffi §8.1, Example 8.13, p. 157

Aluffi notes that the material is often built in the opposite order: define abelian groups first, then rings as abelian groups with a second operation, then modules as abelian groups whose natural ℤ-action is replaced by an action of a larger ring. Which comes first is a chicken-and-egg question.

The summary, and a warning. R-modules over a general ring; k-modules are k-vector spaces; ℤ-modules are abelian groups. The basic theory is the same in all cases. But — Aluffi is emphatic — ℤ is a very special ring, so abelian groups are a very special case. To name the paramount example: every finitely generated ℤ-module is a product of cyclic modules, and that is simply false over an arbitrary ring. Do not let intuition about abelian groups set your expectations for modules. — Aluffi §8.1, p. 158

Self-check 2. Why do axioms (v)–(viii) come free for a ℤ-module?

Axiom (v) pins 1·a = a, and (vii) then forces n·a = a + ⋯ + a with no freedom left. Once the action is that, (vi), (vii), (viii) are statements about moving parentheses and reordering summands, which axioms (i) and (iv) already supply. Being a domain or a PID is irrelevant here — what matters is that ℤ is generated by 1 under addition. — Aluffi §8.1, Proposition 8.10, p. 156

Segment 3 · ~25 min

The category of R-modules

Definition 8.14 (R-module homomorphism). For R-modules M, N, a function f : M → N is an R-module homomorphism, or an R-linear map, if for all r ∈ R and a, b ∈ M

f(a + b) = f(a) + f(b)   and   f(r·a) = r·f(a).

— Aluffi §8.2, Definition 8.14, p. 158

Two conditions, not three — there is no identity element to preserve. Over a field this is the definition of a linear map from linear algebra, unchanged. — Aluffi §8.2, p. 158

How module homomorphisms differ from ring homomorphisms.

Example 8.15. A ring homomorphism f : R → S is also an R-module homomorphism, when S carries the action of Example 8.6: f(r·a) = f(ra) = f(r)f(a) = r·f(a). But the converse gap is enormous — the prediction gate's fn(a) = na are infinitely many ℤ-module homomorphisms ℤ → ℤ, of which only f₁ is a ring homomorphism. — Aluffi §8.2, Example 8.15, pp. 158–159

Example 8.16. More generally, for commutative R and any r ∈ R, multiplication by r is an R-module homomorphism M → M. (It suffices that r be central.) Note that this map is not a ring homomorphism when M = R and r ≠ 1, since it sends 1 to r — and aa-08's Example 4.24 flagged exactly this: a ↦ 2a fails to be a ring homomorphism and is "a fine module homomorphism". Here is the promised meaning of that remark. — Aluffi §8.2, Example 8.16, p. 159; §4.3, Example 4.24, p. 67

Example 8.17 — every pair of modules is connected. The map sending everything to 0N is an R-module homomorphism M → N, the trivial one. Contrast rings: for two random rings there may be no homomorphism at all — aa-08's Example 4.25 showed there is none from ℤ/nℤ to ℤ — because the zero map is disqualified by the requirement 1 ↦ 1. In the category of modules, Hom(M, N) is never empty. — Aluffi §8.2, Example 8.17, p. 159; §4.3, Example 4.25, p. 67

Example 8.18 — a homomorphism out of R is one element. To define an R-module homomorphism f : R → M it is enough to name f(1) = m: then f(r) = f(r·1) = r·f(1) = rm for every r, with no choice. Conversely f(r) = rm is a homomorphism for any fixed m, by axioms (viii) and (vi). So HomR(R, M) corresponds to the elements of M. — Aluffi §8.2, Example 8.18, p. 159

Proposition 8.19. For R-modules L, M, N, P: the identity idM is an R-module homomorphism; a composite of R-module homomorphisms is one; and composition is associative. — Aluffi §8.2, Proposition 8.19, p. 160

So R-modules and R-linear maps form a category, one for each ring R. Note there is no notion of homomorphism between an R-module and an S-module for different rings; each ring gets its own category. And f(0M) = 0N for every homomorphism, by the ring-theoretic proof of aa-08's Proposition 4.16, unchanged. — Aluffi §8.2, pp. 159–160

Definition 8.20 (isomorphism). An R-module homomorphism f : M → N is an isomorphism if it is a bijection — equivalently, if there is an R-module homomorphism g : N → M with g ∘ f = idM and f ∘ g = idN. — Aluffi §8.2, Definition 8.20, p. 160

Definition 8.21. M and N are isomorphic, M ≅ N, if such an f exists; and ≅ is an equivalence relation. — Aluffi §8.2, Definition 8.21, p. 160

Aluffi points out that Definition 8.20 conceals a small proposition — the equivalence of its two clauses requires knowing the set-theoretic inverse of a bijective homomorphism is itself a homomorphism. That is your guided proof. — Aluffi §8.2, p. 160

The payoff: 2ℤ ≅ ℤ as modules, though not as rings. In ring theory 2ℤ and ℤ are very different: 2ℤ is a rng, not even a ring, since it has no 1 (aa-05's Example 3.5). But the map

ℤ → 2ℤ,   a ↦ 2a

is surjective by definition of 2ℤ, injective, and a ℤ-module homomorphism by Example 8.16. So 2ℤ ≅ ℤ as ℤ-modules — as abelian groups — and the same holds for every nℤ with n ≠ 0, and for every PID in place of ℤ. — Aluffi §8.2, pp. 160–161

Guided proof (write it yourself)

Definition 8.20 asserts that two conditions are equivalent, and Aluffi says the proof "would be entirely similar" to Proposition 4.30 and adds "Make sure you agree with me!". Check it. Let f : M → N be a bijective R-module homomorphism, and let g : N → M be its set-theoretic inverse. Prove that g is an R-module homomorphism, and then deduce the equivalence of the two clauses of Definition 8.20 in both directions.

Reveal model answer

g respects addition. Let b₁, b₂ ∈ N and put a₁ = g(b₁), a₂ = g(b₂), so bk = f(ak). Then

g(b₁ + b₂) = g(f(a₁) + f(a₂)) = g(f(a₁ + a₂)) = a₁ + a₂ = g(b₁) + g(b₂),

the middle step because f respects addition and g ∘ f = idM.

g respects scalars. For r ∈ R and b ∈ N with a = g(b),

g(r·b) = g(r·f(a)) = g(f(r·a)) = r·a = r·g(b),

using that f respects scalars.

The equivalence. (⟹) If f is a bijective homomorphism, its set-theoretic inverse g exists and, by the above, is a homomorphism, with g ∘ f = idM and f ∘ g = idN. (⟸) If such a homomorphism g exists, then f is injective (f(a) = f(a′) gives a = g(f(a)) = g(f(a′)) = a′) and surjective (b = f(g(b))), so f is a bijective homomorphism. ∎

Grade yourself on noticing that the reverse direction never uses that g is a homomorphism — only that it is a two-sided inverse function. That is the same observation as aa-12's guided proof, and it is why Definition 8.20 can offer the second clause as an alternative definition: it makes sense in any category, with no notion of bijection available.

Self-check 3. Given two R-modules M and N, is there always an R-module homomorphism M → N?

The zero map respects addition (0 + 0 = 0) and scalars (r·0 = 0 by Proposition 8.9), so it is always available. For rings it is not: a ring homomorphism must send 1 to 1, which the zero map fails unless the target is trivial — and Example 4.25 exhibited two rings with no homomorphism between them. The missing third clause is exactly what makes the module category better connected. — Aluffi §8.2, Example 8.17, p. 159

Self-check 4. How much data determines an R-module homomorphism f : R → M?

f(r) = f(r·1) = r·f(1), so naming f(1) = m determines f completely; and conversely f(r) = rm is R-linear for any m. So homomorphisms R → M correspond exactly to elements of M. This is the first appearance of a pattern that runs through aa-18: a homomorphism out of a free module is determined by where the basis goes, and R is the free module on one generator. — Aluffi §8.2, Example 8.18, p. 159

Self-check 5. Is 2ℤ isomorphic to ℤ?

a ↦ 2a is a bijective ℤ-module homomorphism onto 2ℤ, so they are isomorphic as modules — as abelian groups. As rings they cannot be compared under this book's Definition 3.1, because 2ℤ has no multiplicative identity and is a rng. Being a proper subset is no obstacle to isomorphism for infinite objects. The moral: "isomorphic" is always relative to a category. — Aluffi §8.2, pp. 160–161; §3.1, Example 3.5, p. 42

  1. Definition 8.1 is the vector-space axioms with "field" weakened to "ring": an abelian group under +, plus an action of R satisfying 1·a = a, (rs)a = r(sa), and two distributivities. Instances: vector spaces (R a field), ideals (by absorption), R itself, R/I, and S for any ring homomorphism R → S. The ground ring is part of the data — ℂ has dimension 1, 2 or uncountable depending on it.
  2. ℤ-modules are abelian groups (Proposition 8.10, Definition 8.11): the action is forced to be repeated addition, and axioms (v)–(viii) then hold automatically. Every ring, every vector space, every ideal is an abelian group by forgetting structure. But ℤ is special, so abelian groups are a special case and should not calibrate your intuition.
  3. R-linear maps have two clauses, not three (Definition 8.14) — nothing plays the role of 1 ↦ 1. Consequences: multiplication by r is always a homomorphism of abelian groups, and is R-linear exactly when r is central — over a commutative R that is every r, but on the regular module f(sa) = rsa while sf(a) = sra, which differ for noncentral r, as Example 8.16 records; the zero map is always available, so Hom(M, N) is never empty; a map out of R is determined by the image of 1. Isomorphism is bijective homomorphism (Definition 8.20), and 2ℤ ≅ ℤ as modules while being a rng, not a ring.
The line to carry: chain groups are modules, not vector spaces. Over a field you may divide by a scalar and everything decomposes; over ℤ you may not, and what survives that failure is torsion. aa-20 is the theorem that says exactly how much survives.
