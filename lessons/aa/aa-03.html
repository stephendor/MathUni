Equivalence relations, quotients, and ℤ/nℤ (aa-03)

Take the number line and glue every multiple of 12 onto the same spot. Do it honestly — not "pretend they are equal", but build a new set whose points are whole infinite families of integers. What falls out is a clock face.

This is the single most reused construction in the rest of your degree. Quotient rings, quotient modules, quotient groups, and — three semesters from now — homology itself are all this move, performed on a bigger object. Today we perform it on ℤ, where you can see every piece. The one thing to guard against is the reflex that "reducing mod 12" turns an integer into a smaller integer. It does not. It turns an integer into a set.

Predict before we start. Aluffi's definition of congruence allows n = 0. How many elements does ℤ/0ℤ have?

Congruence mod 0 asks that b − a ∈ 0ℤ = {0}, i.e. a = b. So congruence mod 0 is plain equality, every class [a]₀ = {a} is a singleton, and ℤ/0ℤ is ℤ with each element wrapped in braces. Gluing nothing is a legitimate gluing. Keep this case in view: it is why Theorem 2.7 says "for all positive integers n". — Aluffi §2.2, Remark 2.8, p. 26

Why this matters for the mission: Your very first quotient — the construction homology is built from, rehearsed on integers.

Segment 1 · ~25 min

Equivalence relations and the quotient set

Aluffi treats this as a reminder rather than new material, and points you at Appendix A §A.8 if it is not fresh. Here is the machinery in the four bullets he uses, because every one of them gets used again today. — Aluffi §2.1, p. 22

Equivalence relation, class, quotient. A relation ∼ on a set A is an equivalence relation if it is reflexive (a ∼ a), symmetric (a ∼ b ⟹ b ∼ a) and transitive (a ∼ b and b ∼ c ⟹ a ∼ c). Given one, the equivalence class of a ∈ A is

[a] = { b ∈ A : a ∼ b },

and the quotient A/∼ is the set whose elements are these classes. The classes are pairwise disjoint and their union is all of A — they form a partition of A. — Aluffi §2.1, p. 22

The three axioms generalise properties of the relation =, which is the prototypical (and trivial) example. Two further facts, both of which we will lean on:

  • The projection π : A → A/∼, π(a) = [a], is surjective, and π(a) = π(b) ⟺ a ∼ b. — Aluffi §2.1, p. 22
  • That last property characterises the quotient: if f : A → B is any surjection with f(a) = f(b) ⟺ a ∼ b, then there is an induced function f̃ : A/∼ → B with f̃([a]) = f(a), and it is a bijection. — Aluffi §2.1, p. 23

The second bullet is the first "universal property" in the book, and it is worth naming the pattern now: a quotient is not characterised by what its elements are, but by which functions it accepts. Aluffi flags the connection to category theory and moves on; we will do the same, and meet it in earnest in aa-07.

Worked example — the induced function, and what "well defined" means. Let A = ℤ, let f : ℤ → {even, odd} record the parity of an integer, and let a ∼ b mean f(a) = f(b).

∼ is an equivalence relation — reflexive, symmetric and transitive because = is. There are two classes, and f̃ sends the class of 4 to "even".

Now the subtlety. To evaluate f̃ on a class you must first pick a representative: to compute f̃([4]) you may reach for 4, or for 10, or for −628. The definition f̃([a]) = f(a) is only a definition at all if every representative gives the same answer — and here it does, precisely because a ∼ b was defined as f(a) = f(b). Every "is this well defined?" question for the rest of the module has exactly this shape: does the recipe survive a change of representative?

Self-check 1. Which of these relations on ℤ is not transitive?

|a − b| ≤ 1 is reflexive and symmetric, but 0 ∼ 1 and 1 ∼ 2 while |0 − 2| = 2, so 0 ∼ 2 fails. This is the standard witness that the three axioms are independent — Problem 3(a) of your set asks you to build all three such witnesses. The other two relations are genuine equivalence relations (the second has three classes, the third has two).

Segment 2 · ~25 min

Congruence mod n

Write nℤ = { nk : k ∈ ℤ } = { …, −2n, −n, 0, n, 2n, … } for the set of multiples of n.

Definition 2.1 (congruence). Let n ≥ 0 be an integer and a, b ∈ ℤ. We say a is congruent to b modulo n, written a ≡ b mod n, if b − a ∈ nℤ. Equivalently, a ≡ b mod n ⟺ n ∣ (b − a). — Aluffi §2.2, Definition 2.1, p. 23

Remark 2.2. Negative moduli are not excluded for any deep reason — they are redundant, because nℤ = (−n)ℤ, so the relations for n and −n coincide and we may as well take n ≥ 0. And congruence modulo 0 is just equality, since 0ℤ = {0}. — Aluffi §2.2, Remark 2.2, p. 23

Congruence is an equivalence relation — transitivity, written out. Suppose a ≡ b mod n, so b − a = nk for some integer k, and b ≡ c mod n, so c − b = nℓ for some integer ℓ. Then

c − a = (c − b) + (b − a) = nℓ + nk = n(k + ℓ),

so c − a ∈ nℤ, i.e. a ≡ c mod n. ∎

Reflexivity (a − a = 0 = n·0) and symmetry (if b − a = nk then a − b = n(−k)) are the same one-line move, and are yours in the guided proof below. Note that all three arguments work verbatim for n = 0. — Aluffi §2.2, p. 23

Now the classes. For n ≥ 0 and a ∈ ℤ, write [a]n for the congruence class of a:

[a]n = { b ∈ ℤ : n divides b − a } = { a + nk : k ∈ ℤ },

also written a + nℤ. We call a a representative of [a]n. Because this is an equivalence relation and nothing more, we get for free — no proof needed — the identity Aluffi labels (2.1): — Aluffi §2.2, p. 24

(2.1)   [a]n = [b]n   ⟺   a ≡ b mod n. — Aluffi §2.2, p. 24
Example 2.3 (n = 2) and Example 2.4 (n = 3). For n = 2 there are two classes:

[0]₂ = {…, −6, −4, −2, 0, 2, 4, 6, …}    [1]₂ = {…, −5, −3, −1, 1, 3, 5, 7, …}

the even and the odd integers; in the other notation, the odd integers are 1 + 2ℤ, which is exactly "1 plus an even integer". For n = 3 there are three:

[0]₃ = {…, −6, −3, 0, 3, 6, …}   [1]₃ = {…, −5, −2, 1, 4, 7, …}   [2]₃ = {…, −4, −1, 2, 5, 8, …}

Each list is a partition of ℤ: every integer appears in exactly one class. Test yourself on −4 and 5. They are not congruent mod 2 and sit in different classes there; they are congruent mod 3, and by (2.1) that means [−4]₃ = [5]₃ = [2]₃ — a real equality of sets, not a resemblance. One subset of ℤ, three names. — Aluffi §2.2, Example 2.3 and Example 2.4, p. 24; discussion p. 25

Self-check 2. Is [2]₃ another name for the number 2?

[2]₃ = {…, −4, −1, 2, 5, 8, …}. Aluffi is emphatic here: 2 and 5 are different numbers, yet [2]₃ and [5]₃ are the same element of ℤ/3ℤ, because they are the same subset. Holding one object as both "a subset of ℤ" and "a point of a new set" is the whole conceptual cost of this lesson, and it is paid once. — Aluffi §2.2, p. 25

Guided proof (write it yourself)

Aluffi remarks in passing that for positive n, n ∣ (b − a) if and only if a and b leave the same remainder on division by n — and defers it to Exercise 1.8. Prove it. Let n > 0 and let a, b ∈ ℤ have remainders ra, rb under division by n. Show that a ≡ b mod n if and only if ra = rb. Use aa-01's Theorem 1.3 in both directions, and say explicitly which part of it — existence or uniqueness — each direction consumes.

Reveal model answer

By Theorem 1.3 write a = nqa + ra and b = nqb + rb with 0 ≤ ra, rb < n. Subtracting,

b − a = n(qb − qa) + (rb − ra).

(⟸) If ra = rb the last bracket vanishes, so b − a = n(qb − qa) ∈ nℤ, i.e. a ≡ b mod n. This direction uses only the existence half of Theorem 1.3.

(⟹) If a ≡ b mod n, then n ∣ (b − a), and since n also divides n(qb − qa), it divides the difference rb − ra. But both remainders lie in {0, …, n − 1}, so |rb − ra| ≤ n − 1 < n. A nonzero multiple of n has absolute value at least n (aa-01's Lemma 1.2), so rb − ra = 0. This direction is where uniqueness of the remainder does the work — equivalently, where the window 0 ≤ r < n is used. ∎

Grade yourself on the second direction. If your proof never used the size of the remainders, it is not finished: n ∣ (rb − ra) does not by itself say rb = ra.

Segment 3 · ~25 min

ℤ/nℤ, and exactly how big it is

Definition 2.5 (the quotient ℤ/nℤ). For any integer n ≥ 0, ℤ/nℤ denotes the set of congruence classes mod n in ℤ — the quotient of ℤ modulo nℤ, or "ℤ mod n". — Aluffi §2.2, Definition 2.5, p. 25

A notational warning worth repeating in your own notes: ℤn is a common alternative, and it is a pity, because ℤp already means the p-adic numbers, which are something else entirely. Aluffi uses ℤ/nℤ throughout, and so will we. — Aluffi §2.2, p. 25

And the conceptual warning, which is the one people actually trip on: resist with all your might the temptation to think of ℤ/nℤ as a subset of ℤ. Each element of ℤ/nℤ may be viewed as a subset of ℤ; the set of those elements is not itself sitting inside ℤ. The relationship between ℤ and ℤ/nℤ is real, but it runs through the projection π, not through inclusion — and it is taken up properly in Example 4.19. — Aluffi §2.2, p. 25

Lemma 2.6. Let n be a positive integer.

(i) If a ∈ ℤ and r is the remainder of a on division by n, then [a]n = [r]n.

(ii) The classes [0]n, [1]n, …, [n−1]n are all distinct.

— Aluffi §2.2, Lemma 2.6, p. 25
Proof. (i) If a = nq + r then a − r = nq ∈ nℤ, so a ≡ r mod n, and (2.1) upgrades that to [a]n = [r]n.

(ii) Suppose 0 ≤ r₁ < n and 0 ≤ r₂ < n with [r₁]n = [r₂]n; we show r₁ = r₂. From the bounds, 0 ≤ |r₂ − r₁| < n. From the equality of classes, n ∣ (r₂ − r₁), hence n ∣ |r₂ − r₁|. If |r₂ − r₁| ≠ 0 then Lemma 1.2 gives n ≤ |r₂ − r₁| < n, a contradiction. So |r₂ − r₁| = 0, i.e. r₁ = r₂. ∎ — Aluffi §2.2, p. 26

The two halves do different jobs and it is worth naming them: (i) says the list [0]n, …, [n−1]n is exhaustive, (ii) says it is irredundant. A count needs both.

Theorem 2.7. For all positive integers n, the set ℤ/nℤ consists of exactly n elements: [0]n, [1]n, …, [n−1]n. — Aluffi §2.2, Theorem 2.7, p. 26
Proof. Immediate from Lemma 2.6: by (i) every class equals one on the list, and by (ii) the entries of the list are pairwise different. ∎

But do not over-read the list. Aluffi labours the point and so will we: {[0]₅, [1]₅, [2]₅, [3]₅, [4]₅} is only one of infinitely many correct listings of ℤ/5ℤ. So is

[160]₅, [−324]₅, [17]₅, [48]₅, [−4329349871]₅.

Despite appearances that is the same list, item for item. The conventional choice of representatives is memorable; that is its entire advantage. At the extreme, ℤ/1ℤ has exactly one element, and there is no way whatsoever to tell [0]₁ from [1]₁. — Aluffi §2.2, p. 26

Remark 2.8 (the n = 0 case, as predicted). Congruence mod 0 is equality, so [a]₀ = {a} and ℤ/0ℤ is a copy of ℤ. So ℤ itself may be viewed as one of the quotients — the case n = 0 — and Theorem 2.7's restriction to positive n is exactly what keeps that case from contradicting it. — Aluffi §2.2, Remark 2.8, p. 26

Faded example — a map between two quotients. Consider the proposed rule π([a]₆) = [a]₃, from ℤ/6ℤ to ℤ/3ℤ.

To check it is well defined, take two names for the same input: [a]₆ = [b]₆, which by (2.1) means 6 ∣ (b − a). We need [a]₃ = [b]₃, i.e. ⟨your step: what divisibility statement?⟩.

And indeed 6 ∣ (b − a) forces it, because 3 ∣ 6 and divisibility is ⟨your step: which property of ∣ ?⟩. So the rule is well defined.

Now break it. Consider instead the rule ρ([a]₃) = [a]₆, going the other way. Take a = 0 and b = 3: these have the same class mod 3, since 3 ∣ 3. But [0]₆ and [3]₆ are ⟨your step: equal or different?⟩, because 6 ∤ 3. So ρ sends one input to two different outputs, and is not a function at all.

Read the asymmetry: the rule survives when the target modulus divides the source modulus. Problem 5 asks you to prove that this is exactly the condition, in both directions.

You try (solo). Decide, with proof, whether each rule is well defined. (a) f([a]n) = [a²]n, from ℤ/nℤ to ℤ/nℤ. (b) g([a]₄) = [3a]₄. (c) h([a]n) = a, from ℤ/nℤ to ℤ. In each case the whole question is: if [a]n = [b]n, does the recipe give the same answer for b as for a? Do (c) first — it is the one that fails, and the reason it fails is the reason ℤ/nℤ is not a subset of ℤ.

Self-check 3. In the proof of Lemma 2.6(ii), which hypothesis is doing the work?

n ∣ (r₂ − r₁) on its own says nothing — it holds for r₁ = 0, r₂ = n. What kills the nonzero case is the bound |r₂ − r₁| < n coming from both representatives sitting in [0, n), colliding with Lemma 1.2's "a nonzero multiple of n has absolute value at least n". Primality is irrelevant here, and disjointness is what (2.1) already encodes. — Aluffi §2.2, p. 26

Self-check 4. Which list is not a complete, irredundant listing of ℤ/4ℤ?

The third repeats itself: [4]₄ = [0]₄ by (2.1), since 4 ∣ 4. It is exhaustive but not irredundant, so it is a list of five names for four elements. The second is fine — reduce each representative mod 4 and you get 0, 1, 2, 3 in some order. This is Lemma 2.6's two halves used as a checklist. — Aluffi §2.2, Theorem 2.7, p. 26

Self-check 5. What must you check before defining an operation on ℤ/nℤ by a formula on representatives?

A class has infinitely many names, and a formula written in terms of a name defines a function on classes only if every name gives the same value. That is the entire content of "well defined", and it is what §2.3 has to verify before ℤ/nℤ can be given + and · at all — which is aa-04's first order of business. Commutativity and the behaviour at 0 are questions you can only ask after the operation exists. — Aluffi §2.1, p. 23

Then check yourself
  1. An equivalence relation partitions its set. Reflexive, symmetric, transitive ⟹ the classes [a] = {b : a ∼ b} are disjoint and cover A, and A/∼ is the set whose elements are those classes. The projection π(a) = [a] is surjective with π(a) = π(b) ⟺ a ∼ b, and that property pins A/∼ down up to bijection.
  2. Congruence mod n is such a relation (Definition 2.1: n ∣ b − a), for every n ≥ 0 — including n = 0, where it is equality. Its classes are [a]n = a + nℤ, and [a]n = [b]n ⟺ a ≡ b mod n, which is free from the general theory.
  3. ℤ/nℤ has exactly n elements for n > 0 (Theorem 2.7), because division with remainder makes the list [0]n, …, [n−1]n exhaustive (Lemma 2.6(i)) and the window 0 ≤ r < n makes it irredundant (Lemma 2.6(ii)). The list is one choice of representatives among infinitely many.
The load-bearing habit, not the theorem: a class has many names, so any rule written on names must be checked for independence of the name. That check is called well-definedness, and you will run it on every quotient for the rest of the degree.
