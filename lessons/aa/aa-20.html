Structure theorem: finitely generated modules over a PID (aa-20)

Aluffi calls it "probably one of the most important theorems in this text". Every finitely generated module over a Euclidean domain is a direct sum of cyclic pieces — and the pieces are uniquely determined.

Ten units of machinery converge here. aa-18 turned such a module into a matrix; aa-19 showed the matrix exists whenever the ring is Noetherian, and that over a field it reduces to a block of 1s. Today the reduction is pushed as far as it can go over a Euclidean domain: not to 1s, but to a diagonal d₁ ∣ d₂ ∣ ⋯ ∣ ds. Each di contributes one cyclic summand R/(di), each zero row contributes a free summand R, and that list is the module. This is the theorem a persistence barcode is an instance of — once specialised, as §9.6 and the mission note below spell out, to graded k[t]-modules and degree-preserving maps, which is what records an interval's birth time.

Predict before we start. Over ℤ, can every matrix be reduced by elementary operations to a diagonal of 1s and 0s, as over a field?

aa-19 located the failure precisely: scaling a row by the inverse of a nonzero entry needs that entry to be a unit, and over ℤ only ±1 qualify. A diagonal form does still exist — Lemma 9.38 — but the diagonal entries are elements d₁ ∣ d₂ ∣ ⋯ ∣ ds rather than 1s. Those surviving entries are exactly what becomes torsion. — Aluffi §9.5, Lemma 9.38, p. 193

Why this matters for the mission: This IS the barcode: persistence modules decompose into intervals by exactly this theorem.

Segment 1 · ~25 min

How far a matrix reduces over a Euclidean domain

Lemma 9.38. Let A be an m × n matrix over a Euclidean domain R. Then elementary operations transform A into a diagonal matrix with entries d₁, …, ds and zeroes elsewhere, where

d₁ ∣ d₂ ∣ ⋯ ∣ ds.

— Aluffi §9.5, Lemma 9.38, p. 193
The row step, and why it terminates. Take a single row a = (a₁, …, an), not all zero, and switch columns so a₁ ≠ 0. Over a field we would scale by a₁−1; here we cannot, so we divide with remainder instead. Let v be the Euclidean valuation (aa-12's Definition 6.24).

For each i ≥ 2 write ai = a₁qi + ri with ri = 0 or v(ri) < v(a₁), and add −qi times the first column to the ith. Every entry beyond the first is now a remainder ri.

If the row is now (d, 0, …, 0) — stop. Otherwise switch some nonzero remainder into the first position and repeat.

Why this halts: each time you go round, the new first entry has strictly smaller valuation, and valuations are nonnegative integers, so they cannot decrease forever. That is well-ordering, doing in aa-20 exactly what it did in aa-01. ∎ — Aluffi §9.5, pp. 193–194

From a row to the whole matrix — and the divisibility condition. Move a nonzero entry to (1,1); run a row step to clear the first row; run a column step to clear the first column — which may spoil the first row, so run the row step again, and so on. The (1,1) valuation strictly decreases each time round, so this too terminates, leaving

( d₁   0 ⋯ 0 / 0   ⋯ inner matrix ⋯ ),

and induction handles the inner matrix, giving d₂ ∣ d₃ ∣ ⋯ ∣ ds. — Aluffi §9.5, p. 194

But the lemma also demands d₁ ∣ d₂, and that is not yet established. If it fails, perform a row operation putting d₂ into the (1,2) position and start the whole reduction again. The valuation of the (1,1) entry drops again, so after finitely many restarts the divisibility condition holds too. ∎ — Aluffi §9.5, p. 195

Aluffi's own verdict on the argument — "I will grant you that this argument is dreadful" — comes with its defence: it is an actual procedure that can be carried out. More elegant proofs exist and are less concrete.

Faded example — Example 9.39, the algorithm run by hand. Start from

( −2   0   4 / −4   1   7 ).

A row step on the top row clears the last entry (4 = (−2)(−2) + 0), giving ( −2 0 0 / −4 1 −1 ). A column step clears the first column below the corner: ( −2 0 0 / 0 1 −1 ). Clearing the last entry of the second row gives ( −2 0 0 / 0 1 0 ).

Now check the lemma's condition: is −2 ∣ 1? ⟨your step: yes or no?⟩ — so we are not finished, and Aluffi performs the restart operation, putting a 1 into the (1,2) slot: ( −2 1 0 / 0 1 0 ).

Running the reduction again — a column operation, then a row step, then a column step — reaches ( 1 0 0 / 0 ⟨your step⟩ 0 ), and now the divisibility 1 ∣ 2 does hold. — Aluffi §9.5, Example 9.39, p. 195

This is aa-18's matrix with its rows swapped, and it lands on the same normal form — as it must, since equivalent matrices have isomorphic cokernels.

Self-check 1. Why does the row step of Lemma 9.38 terminate?

Each pass replaces the leading entry by a remainder of strictly smaller valuation, and a strictly decreasing sequence in ℤ≥0 must stop — well-ordering again. "Absolute value" is the valuation in the special case R = ℤ, not the general statement; over k[t] the valuation is the degree. And the number of columns is fixed, so it bounds nothing about how many passes occur. — Aluffi §9.5, p. 194

The classification

Theorem 9.40 (Classification of finitely generated modules over Euclidean domains). Let M be a finitely generated module over a Euclidean domain R. Then there are d₁, …, ds ∈ R with d₁ ∣ d₂ ∣ ⋯ ∣ ds and d₁ not a unit, and an integer r ≥ 0, such that

M ≅ R⊕r ⊕ R/(d₁) ⊕ R/(d₂) ⊕ ⋯ ⊕ R/(ds).

— Aluffi §9.5, Theorem 9.40, pp. 195–196

One condition to read in. The printed statement asks only that d₁ be a non-unit, and the list is allowed to be empty (s = 0) when M is free. But each di must also be nonzero, or the uniqueness of Remark 9.41 fails outright: R/(0) ≅ R, so M = R would have both the presentation r = 1, s = 0 and the presentation r = 0, s = 1, d₁ = 0 — the same module, two different lists, and a free summand miscounted as torsion. Zero is a non-unit, so "non-unit" alone does not exclude it. Read every di below as a nonzero non-unit.

Proof — every ingredient has already been proved. Euclidean domains are PIDs (aa-12's Theorem 6.26) and PIDs are Noetherian (Proposition 6.32), so M is finitely presented by aa-19's Theorem 9.29:

R⊕n —φ→ R⊕m → M → 0,

with φ given by a matrix. By Lemma 9.38 and aa-18's Corollary 9.26, we may replace that matrix by the diagonal form. Its image is

im φ = (d₁) ⊕ (d₂) ⊕ ⋯ ⊕ (ds) ⊕ 0 ⊕ ⋯ ⊕ 0 ⊆ R⊕m,

so the cokernel is R/(d₁) ⊕ ⋯ ⊕ R/(ds) ⊕ R ⊕ ⋯ ⊕ R — the last m − s factors untouched. Factors with di a unit are trivial and are discarded, which is why d₁ may be assumed a non-unit. ∎ — Aluffi §9.5, p. 196

Read the diagonal. Each entry does one of three things: a unit kills its factor entirely; a non-unit non-zero di leaves the torsion piece R/(di); and a missing entry — a zero row — leaves a free factor R. aa-19's Theorem 9.35 is the case where only the first and third occur, which is exactly what a field permits.

Remark 9.41 — it is a genuine classification. The rank r and the factors R/(di) are uniquely determined by M. Aluffi does not prove it but names the route: first show the free part R⊕r and the torsion part T = R/(d₁) ⊕ ⋯ ⊕ R/(ds) are each determined; then show (i) R⊕r₁ ≅ R⊕r₂ forces r₁ = r₂, which comes down to invertible matrices being square, and (ii) the torsion decomposition is unique, proved by extracting one factor at a time — the last ideal (ds) is the annihilator of the torsion part T — not of M. Take that distinction seriously: as soon as M has a free summand, Ann(M) = (0), since no nonzero r kills R. For M = R ⊕ R/(d) the annihilator is (0) while ds = d, so the route has to isolate T first and only then read (ds) = Ann(T). — Aluffi §9.5, Remark 9.41, p. 196

Remark 9.42. The theorem and its uniqueness hold over every PID, not merely Euclidean domains; the proof is harder because there is no valuation to descend on. — Aluffi §9.5, Remark 9.42, p. 196

Remark 9.43 — a theorem hidden inside the proof. Every submodule of a finitely generated free module over a Euclidean domain is itself free. This holds over any PID and not beyond: if an integral domain is not a PID then some ideal of it — a submodule of R — fails to be free. So "submodules of free are free" is another face of the PID condition. — Aluffi §9.5, Remark 9.43, p. 196

Drive the theorem below. Each matrix is reduced to its diagonal form, and the summands are drawn as bars: a bounded bar of length d for each torsion factor R/(d), an unbounded bar for each free factor R. The list of bars is the module.

Self-check 2. A matrix over ℤ reduces to the diagonal (1, 0, 6) as a map ℤ⊕3 → ℤ⊕3. What is the cokernel?

Read the diagonal entry by entry: 1 is a unit so ℤ/(1) = 0 and that factor vanishes; 0 gives ℤ/(0) ≅ ℤ, a free factor; 6 gives ℤ/6ℤ. The result is ℤ/6ℤ ⊕ ℤ. (Written in the normal form of Theorem 9.40 the zero entry is not listed among the di at all — it shows up as one of the m − s untouched factors.) — Aluffi §9.5, Theorem 9.40, p. 196

Self-check 3. Remark 9.43 says submodules of free modules are free over a PID. Why does this fail over ℤ[x]?

An ideal is a submodule of R viewed as a free module of rank 1. If it were free of rank 1 it would be principal, and free of rank ≥ 2 is impossible inside a domain — any two elements a, b satisfy the relation b·a − a·b = 0. So a non-principal ideal is a non-free submodule of a free module, and (2, x) ⊆ ℤ[x] is aa-11's example. ℤ[x] is a perfectly good domain; it just is not a PID. — Aluffi §9.5, Remark 9.43, p. 196

Segment 3 · ~25 min

Elementary divisors, and Cayley–Hamilton

The di of Theorem 9.40 are the invariant factors of M. A Euclidean domain is a UFD, so each di factors into irreducibles; and if d = q₁a₁⋯qrar with the qi distinct irreducibles, the Chinese Remainder Theorem (aa-10's Theorem 5.52) splits — Aluffi §9.6, p. 197; §5.6, Theorem 5.52, p. 97

R/(d) ≅ R/(q₁a₁) ⊕ ⋯ ⊕ R/(qrar).

The CRT gives a ring isomorphism, and a ring isomorphism between quotients of R is in particular an isomorphism of R-modules (aa-16's Example 8.35).

Corollary 9.44. Every finitely generated module over a Euclidean domain is isomorphic to a direct sum of cyclic modules R/(qa) with q irreducible and a ≥ 0 — the qa are its elementary divisors — and the decomposition is unique. — Aluffi §9.6, Corollary 9.44, p. 197

Quoted as printed, and incomplete as printed: every R/(qa) here is torsion, so no combination of them is the finitely generated module R. The free summand has to be carried across from Theorem 9.40 — see the paragraph immediately below the summary, which writes the corrected form out.

— Aluffi §9.6, Corollary 9.44, p. 197

So the R/(qa) are the atoms: every finitely generated module is a direct sum of them, "in the simplest possible way". Over more general rings the situation is far worse. — Aluffi §9.6, p. 197

Read the free part back in. Every R/(qa) with q irreducible is torsion, and R/(q⁰) = R/(1) = 0, so no combination of those atoms produces a free summand: M = R is finitely generated and torsion-free, and is not a direct sum of any of them. The elementary-divisor form is therefore R⊕r ⊕ (a sum of the R/(qa) with a ≥ 1), exactly parallel to the R⊕r in Theorem 9.40 — or, read the other way, the corollary and the "atoms" slogan apply as stated to finitely generated torsion modules. The free rank r is the piece the CRT refinement never touches.

The k[t] application — a linear transformation is a module. Let k be a field and V a k-vector space. Aluffi's observation: giving a linear transformation α : V → V is the same as giving V the structure of a k[t]-module extending the k-action.

One way: set t·v := α(v) and extend, so that for f(t) = a₀ + a₁t + ⋯ + antn,

f(t)·v = a₀v + a₁α(v) + a₂α²(v) + ⋯ + anαn(v).

The other way: given such a module structure, "multiplication by t" is a k-linear map V → V. In short, α acts as multiplication by t. — Aluffi §9.6, pp. 197–198

Now suppose V is finite-dimensional. Its k-generators generate it over k[t], so V is a finitely generated k[t]-module — and k[t] is a Euclidean domain (aa-13's Theorem 7.2). Theorem 9.40 applies:

V ≅ k[t]/(f₁(t)) ⊕ ⋯ ⊕ k[t]/(fs(t)),   f₁ ∣ ⋯ ∣ fs,

with no free part, because k[t] itself is infinite-dimensional over k while V is not. — Aluffi §9.6, p. 198

What the fi are. Chasing definitions identifies them with objects from ordinary linear algebra:

• the minimal polynomial of α is fs(t);

• the characteristic polynomial of α is f₁(t)⋯fs(t).

Since f₁ ∣ f₂ ∣ ⋯ ∣ fs, the minimal polynomial divides the characteristic polynomial — it is one of the factors of the product. That the minimal polynomial exists and is unique is itself an application: { f ∈ k[t] : f(α) = 0 } is an ideal of k[t], being the kernel of the evaluation homomorphism f ↦ f(α), and k[t] is a PID by aa-13's Corollary 7.7 — so that ideal is (g) for a single g, unique once taken monic. — Aluffi §7.2, Corollary 7.7, p. 134 — Aluffi §9.6, p. 198

And bases adapted to this decomposition are what "canonical forms" of a matrix are; the details belong to a more advanced text.

Theorem 9.45 (Cayley–Hamilton). Let α be a linear transformation of V with characteristic polynomial P(t). Then P(α) = 0. — Aluffi §9.6, Theorem 9.45, p. 199
Why it follows. The minimal polynomial fs annihilates α by definition, and fs divides P — so P annihilates α too. That is the whole argument, once Theorem 9.40 is available.

And it is not obvious. Aluffi warns against the fake proof "P(t) = det(tI − A), so P(A) = det(A − A) = det(0) = 0". Substituting a matrix for t in det(tI − A) does not give det of anything sensible: write out tI − A for a 3 × 3 matrix A and replace t by A, and you get an array some of whose entries are matrices and some are numbers. The identity is real; that derivation of it is not. — Aluffi §9.6, p. 199 and its footnote

Aluffi's closing comment on the whole chapter is worth keeping: a progression of comparatively simple steps has made an objectively difficult result straightforward. That is what the abstraction was for.

Guided proof (write it yourself)

Aluffi says of the k[t]-module construction that "it is easy to verify" — so verify it. Let V be a k-vector space and α : V → V a linear transformation. (a) Show that f(t)·v := a₀v + a₁α(v) + ⋯ + anαn(v) makes V a k[t]-module whose restriction to constants is the original k-action; you need at least axioms (v), (vi) and (viii) of Definition 8.1. (b) Show that if V is finite-dimensional over k then V is finitely generated over k[t]. (c) Explain why the decomposition of V by Theorem 9.40 has free rank 0.

Reveal model answer

(a) Axiom (v): the polynomial 1 has a₀ = 1 and no other terms, so 1·v = v. Axiom (viii): each αk is k-linear, so f(t)·(v + w) = Σakαk(v + w) = Σakαk(v) + Σakαk(w). Axiom (vii) is immediate from collecting coefficients. Axiom (vi), (fg)·v = f·(g·v), is enough to check on monomials f = ti, g = tj, where it reads αi+j(v) = αi(αj(v)) — true by definition of composition — and the general case follows by bilinearity. Restricting to constant polynomials gives λ·v = λv, the original action.

(b) If v₁, …, vd span V over k, they span it over k[t] as well: every k-combination is in particular a k[t]-combination, using only constant coefficients. So V = ⟨v₁, …, vd⟩ as a k[t]-module, and V is finitely generated over k[t].

(c) Theorem 9.40 writes V ≅ k[t]⊕r ⊕ (torsion). But k[t] is infinite-dimensional as a k-vector space — 1, t, t², … are k-linearly independent — so a nonzero free part would make V infinite-dimensional over k, contradicting the hypothesis. Hence r = 0, and V is all torsion:

V ≅ k[t]/(f₁) ⊕ ⋯ ⊕ k[t]/(fs). ∎

Grade yourself on (c). It is the step that converts a general classification into a statement about matrices, and the reason is a dimension count over k, not anything about α. Note also what (b) did not claim: V is finitely generated over k[t] by the same elements, but generally by fewer — a single vector often suffices, since t may be applied repeatedly.

Self-check 4. Why does the k[t]-module decomposition of a finite-dimensional V have no free summand?

A single free summand k[t] would already contain the k-linearly independent family 1, t, t², …, making V infinite-dimensional over k. So r = 0 and V is entirely torsion. k[t] is a Euclidean domain — that is what let Theorem 9.40 apply in the first place — and eigenvalues play no part in the argument. — Aluffi §9.6, p. 198

Self-check 5. Cayley–Hamilton says P(α) = 0 for the characteristic polynomial P. Which fact about the invariant factors delivers it?

fs annihilates α by definition of the minimal polynomial, and since f₁ ∣ ⋯ ∣ fs the product f₁⋯fs is a multiple of fs — so it annihilates α too. The det(0) argument is the fake proof Aluffi warns against in a footnote: substituting a matrix for t produces an array mixing matrices and scalars, not a determinant. And the fi are generally not irreducible; that is precisely what Corollary 9.44 refines. — Aluffi §9.6, Theorem 9.45, p. 199

  1. Lemma 9.38: over a Euclidean domain, elementary operations bring any matrix to a diagonal d₁ ∣ d₂ ∣ ⋯ ∣ ds. Division with remainder replaces the field's "scale by an inverse", and the procedure halts because the valuation of the leading entry strictly decreases — well-ordering, again. The divisibility condition requires restarting the whole reduction, which also terminates for the same reason.

Theorem 9.40: hence every finitely generated M over a Euclidean domain is R⊕r ⊕ R/(d₁) ⊕ ⋯ ⊕ R/(ds), with r and the di uniquely determined (Remark 9.41), and the same holds over any PID (Remark 9.42).   3. Two payoffs. The Chinese Remainder Theorem refines the invariant factors into elementary divisors R/(qa) with q irreducible (Corollary 9.44) — the atoms. And over k[t], a linear transformation α on a finite-dimensional V is a k[t]-module with α acting as t; the decomposition has no free part, its last invariant factor is the minimal polynomial, the product of all of them is the characteristic polynomial, and Cayley–Hamilton follows because the first divides the second.
And the mission strip, unpacked: a persistence module over k[t] is a finitely generated graded module over a Euclidean domain. Theorem 9.40 decomposes it into cyclic pieces; each piece is an interval; the list of intervals is the barcode. The theorem you just proved is the theorem that makes persistent homology a finite object.
