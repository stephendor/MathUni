Group actions (aa-24)

Groups do not sit still. A group is most useful when it is doing something to a set — permuting vertices, shuffling configurations, moving points of a space — and the doing is where the theorems hide.

The definition turns out to be something you already have. aa-21 established the principle: an action of a ring R on an abelian group M is a ring homomorphism R → End(M). Replace "ring" by "group" and "End" by the group of bijections, and an action of G on a set A is a group homomorphism G → SA. From that one identification come orbits, the partition they induce, the counting arguments of aa-28, and a theorem — Cayley's — saying every group whatsoever is a group of permutations.

Predict before we start. aa-21 defined a ring acting on a module as a ring homomorphism into End(M). What should an action of a group G on a set A be?

Aluffi's Remark 10.7 laid down the template: acting on an object means mapping into that object's automorphism group. For a bare set the automorphisms are all the bijections, so the automorphism group is SA and an action is a homomorphism G → SA. Definition 11.19 spells this out as a function ρ : G × A → A with two properties, and Proposition 11.20 proves the two descriptions are the same thing. An arbitrary function would not compose correctly, and G and A need not even have the same size. — Aluffi Underground §11.2, p. 236

Why this matters for the mission: Covering space theory (Semester 3) is a group acting on a space; deck groups are actions.

Segment 1 · ~25 min

Symmetric groups, and what an action is

Definition 11.17. The symmetric (or permutation) group on a set A, written SA, is the group of bijections A → A. — Aluffi Underground §11.2, Definition 11.17, p. 235

For a finite set a bijection is a scrambling — a permutation. With A = {1, 2, 3} there are 3! = 6 of them, and Aluffi lists all six; for A = {1, …, n} the group has n! elements and is written Sn. — Aluffi Underground §11.2, Example 11.18, p. 236

Why "symmetric"? A symmetry is a transformation preserving some salient feature — flipping an equilateral triangle about an axis, say. A set has no features to preserve, every element being like every other, so every bijection counts as a symmetry of it. Hence the name. These groups are a rich supply of examples, and far more representative of what groups look like than abelian ones. — Aluffi Underground §11.2, p. 236

Definition 11.19 (action). An action of a group G on a set A is a function ρ : G × A → A with, for all a ∈ A,

ρ(eG, a) = a   and   ρ(gh, a) = ρ(g, ρ(h, a)).

Writing ga for ρ(g, a), these read eGa = a and (gh)a = g(ha). — Aluffi Underground §11.2, Definition 11.19, p. 237
Proposition 11.20. Actions of G on A correspond exactly to group homomorphisms σ : G → SA, via σ(g)(a) = ρ(g, a). — Aluffi Underground §11.2, Proposition 11.20, p. 237
Proof of one direction. Given ρ, the formula defines a function σ(g) : A → A for each g. Then σ(eG)(a) = ρ(eG, a) = a, so σ(eG) = idA. And

σ(gh)(a) = ρ(gh, a) = ρ(g, ρ(h, a)) = σ(g)(σ(h)(a)) = (σ(g) ∘ σ(h))(a),

so σ(gh) = σ(g) ∘ σ(h). In particular σ(g) ∘ σ(g−1) = σ(eG) = idA, which shows each σ(g) really is a bijection — so σ lands in SA and preserves the operation. ∎ The converse is your guided proof. — Aluffi Underground §11.2, p. 237

Read the last step. Nothing in Definition 11.19 said the maps a ↦ ga were invertible; that came out of the two axioms, using the inverse in G. This is the same phenomenon as aa-23's guided proof, where φ(g−1) = φ(g)−1 also came free — group inverses keep doing work that has to be assumed elsewhere.

Carter says the same thing, and starts there. His Definition 9.1 is simply: G acts on a set S if there is a homomorphism φ : G → Perm(S), where Perm(S) is the group of permutations of S. His gloss on why it must be a homomorphism rather than a mere function: the interpretation of ab should be the action of a followed by the action of b, and φ(ab) = φ(a)φ(b) is exactly that demand. — Carter §9.1, Definition 9.1, p. 195

Self-check 1. Definition 11.19 does not require the map a ↦ ga to be a bijection. Why is it one anyway?

The two axioms give σ(g)σ(g−1) = σ(gg−1) = σ(e) = idA and likewise the other way, so a ↦ ga has a two-sided inverse, namely a ↦ g−1a. Finiteness is irrelevant — the argument works for any A. And the conclusion is not optional: it is what makes σ land in SA at all, which is the content of Proposition 11.20. — Aluffi Underground §11.2, Proposition 11.20, p. 237

Segment 2 · ~25 min

Orbits, transitivity, faithfulness

Faded example — Example 11.21: C₃ on the vertices of a triangle. Take A = {1, 2, 3} as the vertices of an equilateral triangle, and let C₃ = {e, g, g²} act by rotating clockwise, g being a 120° rotation.

Then e leaves the triangle alone, g turns it 120°, and g² turns it ⟨your step: how far?⟩. On vertices this is the homomorphism C₃ → S₃ given by

e ↦ (1↦1, 2↦2, 3↦3),   g ↦ (1↦2, 2↦3, 3↦1),   g² ↦ (1↦3, 2↦⟨your step⟩, 3↦2).

And the flip f about the axis through the centre and vertex 1 gives an action of C₂ = {e, f} with f ↦ (1↦1, 2↦3, 3↦2) — vertex 1 is ⟨your step: moved or fixed?⟩. — Aluffi Underground §11.2, Example 11.21, p. 238

Two groups, one set, two very different actions. The rotation moves every vertex; the flip pins one down.

Definition 11.22 (orbit). For G acting on A, the orbit of a ∈ A is { ga : g ∈ G } — the elements a can be sent to. The orbit is trivial if it is {a}, i.e. if a is a fixed point. — Aluffi Underground §11.2, Definition 11.22, p. 238

The orbits partition A. Aluffi records this in one sentence and flags where it goes: it "will lead to powerful counting principles down the road, such as the class equation" of aa-28. For the C₂-flip above the orbits are {1} and {2, 3}. — Aluffi Underground §11.2, Example 11.23, p. 239

Definition 11.24. The action is transitive if A is a single orbit — for all a, b there is g with b = ga. — Aluffi Underground §11.2, Definition 11.24, p. 239

Definition 11.26. The action is faithful if σ : G → SA is injective — equivalently, if every g ≠ e moves some element. It is free if every g ≠ e moves every element. — Aluffi Underground §11.2, Definition 11.26, p. 239

The C₃-rotation is transitive: any vertex reaches any other by turning the triangle. The C₂-flip is not — vertex 1 goes nowhere. And nothing in Definition 11.19 forces a non-identity element to move anything at all: the trivial action ga = a is legal for any G and A, and teaches nothing. Faithfulness is the condition ruling that out. — Aluffi Underground §11.2, Example 11.25 and the remark following, p. 239

Carter's picture of the same distinction. Carter draws an action as an action diagram: like a Cayley diagram, but of the set being acted on rather than of the group. For the rectangle puzzle, V₄ = ⟨h, v⟩ acts on the four configurations by φ(h) = "swap with the horizontal flip", φ(v) = "swap with the vertical flip" — and that action diagram is a Cayley diagram. — Carter §9.1, p. 195

Then he deliberately breaks it: define θ instead by θ(h) = the horizontal-flip permutation and θ(v) = the identity permutation. This is still a perfectly good action, but its diagram is not a Cayley diagram — there are too few arrows, and the non-identity element v is drawn as though it were e. Carter's point is that action diagrams are a strictly larger class than Cayley diagrams. — Carter §9.1, p. 196

In Aluffi's vocabulary, θ is exactly an action that is not faithful: v ≠ e lies in the kernel of θ. The two books are describing one phenomenon — Carter as a missing arrow in a picture, Aluffi as a non-injective σ.

Self-check 2. What is the difference between a faithful and a free action?

Free is strictly stronger, and implies faithful. The C₂-flip on {1, 2, 3} is faithful — f moves 2 and 3 — but not free, since it fixes vertex 1. Transitivity is a separate axis entirely: it is about whether the set is one orbit, not about which group elements do anything. The C₃-rotation happens to be transitive, faithful and free at once. — Aluffi Underground §11.2, Definition 11.26, p. 239

Self-check 3. What structure do the orbits of an action put on A?

"Lies in the same orbit as" is reflexive (via e), symmetric (via g−1) and transitive (via gh), so it is an equivalence relation and its classes partition A — aa-03's machinery, reused. That partition is what makes orbit-counting arguments possible, and Aluffi points forward to the class equation of aa-28 as the payoff. — Aluffi Underground §11.2, p. 239

Segment 3 · ~25 min

Cayley's theorem, and conjugation

Every group acts on itself. Take A = G and ρ(g, h) = gh. The two axioms of Definition 11.19 are immediate: eg = g because e is the identity, and (gh)k = g(hk) because the operation is associative. This is left-multiplication. — Aluffi Underground §11.2, p. 240

Lemma 11.28. The left-multiplication action of G on itself is free, hence faithful. — Aluffi Underground §11.2, Lemma 11.28, p. 240

Theorem 11.29 (Cayley's theorem). Every group G is isomorphic to a subgroup of a symmetric group SA — and one may take A = G. — Aluffi Underground §11.2, Theorem 11.29, p. 240

Both proofs, in full. Lemma 11.28: if g ≠ e then gh ≠ h for every h — which is aa-23's cancellation, one line. ∎

Theorem 11.29: the action is faithful, so σ : G → SG is injective; an injective homomorphism identifies G with its image, which is a subgroup of SG by aa-23's Example 11.9. ∎ — Aluffi Underground §11.2, p. 240

That is the whole thing. A theorem with a name, proved from cancellation and a definition — because the right definition was chosen first. Carter states the same result: every group can be embedded into some Sn, and he uses it to justify hunting for a set that any given group permutes. — Carter §9.1, p. 195

Example 11.30 — Cayley's theorem is the triangle picture, relabelled. Take Example 11.21's action of C₃ on the vertices, and rename them: 1 ↔ e, 2 ↔ g, 3 ↔ g². The same three pictures now read

g ↦ (e ↦ g, g ↦ g², g² ↦ e),

which is exactly left-multiplication by g. So the rotation action was the Cayley embedding all along, and it identifies C₃ with a subgroup of S{e, g, g²}. — Aluffi Underground §11.2, Example 11.30, p. 240

And the honest limitation. Cayley's theorem is conceptually important — complete knowledge of symmetric groups would be complete knowledge of all groups — but useless as a strategy. S₇₀ has 70! > 10¹⁰⁰ elements, "substantially more than the estimated number of elementary particles in the universe". Any classification must do something other than search inside symmetric groups. — Aluffi Underground §11.3, p. 241

A second action every group has: conjugation. Let G act on itself by g·a := gag−1. The orbits of this action have a name.

Definition 11.31. The conjugacy class of a ∈ G is its orbit under conjugation — the set of all conjugates gag−1. — Aluffi Underground §11.3, Definition 11.31, p. 241

Since orbits partition, the conjugacy classes partition G — and counting that partition is the class equation of aa-28. Note that in an abelian group gag−1 = a always, so every class is a single element: conjugation is interesting only because groups are not commutative.

The example to conjugate in is the dihedral group. Definition 11.32 writes D2n for the symmetries of a regular n-gon, so the square's group is D₈ with eight elements. (aa-23's warning stands: Carter and many others write D₄ for this group. This module follows Aluffi Underground.) — Aluffi Underground §11.3, Definition 11.32, p. 242

Guided proof (write it yourself)

Proposition 11.20 has two halves and Aluffi proves one, leaving the converse as Exercise 11.14. Supply it. Let σ : G → SA be a group homomorphism and define ρ(g, a) := σ(g)(a). Prove that ρ satisfies both conditions of Definition 11.19, saying at each step which property of σ you use. Then answer: where would the argument fail if σ were merely a function, not a homomorphism?

Reveal model answer

First condition. ρ(eG, a) = σ(eG)(a). By aa-23's Exercise 11.2 a group homomorphism sends the identity to the identity, so σ(eG) = idA, and ρ(eG, a) = a.

Second condition. For g, h ∈ G and a ∈ A,

ρ(gh, a) = σ(gh)(a) = (σ(g) ∘ σ(h))(a) = σ(g)(σ(h)(a)) = ρ(g, ρ(h, a)),

where the second equality is exactly the statement that σ preserves the operation — the group operation in SA being composition.

So ρ is an action, and taken with Aluffi's half the two notions correspond. ∎

Where a mere function fails. Both conditions. If σ is only a function, σ(e) need not be idA, so the first axiom can fail; and σ(gh) need not be σ(g) ∘ σ(h), so the second fails — meaning "do h, then do g" would not agree with "do gh". Carter puts the same point in words: the requirement that φ be a homomorphism is what makes the interpretation of a product be the two actions in succession.

Grade yourself on naming composition as the operation in SA. If your second step read σ(gh) = σ(g)σ(h) without saying that the product on the right is composition of bijections, the computation is not yet connected to Definition 11.19.

You try (solo). (a) Write out the action of D₈ on the four vertices of a square as a homomorphism D₈ → S₄, listing where each of the eight elements sends 1, 2, 3, 4. Is it faithful? Is it free? Is it transitive? (b) The same group also acts on the two diagonals of the square. Write that action as a homomorphism D₈ → S₂ and find its kernel — you should find four elements, so this action is not faithful. (c) Compare with Carter's θ: both are legitimate actions of the same group on different sets, and only one of them sees the whole group. (d) Finally, compute the conjugacy classes of S₃ using Definition 11.31, and check that they partition the six elements.

Self-check 4. Cayley's theorem embeds every group in a symmetric group. Why does that not classify all groups?

The embedding is injective — that is exactly what Lemma 11.28 provides. And the theorem holds for any group, with A = G. The obstruction is size: knowing that every group of order 70 sits inside S₇₀ is true and useless, since S₇₀ has more than 10¹⁰⁰ elements. Aluffi's conclusion is that classification must go beyond brute-force analysis of subgroups of symmetric groups. — Aluffi Underground §11.3, p. 241

Self-check 5. In an abelian group, what are the conjugacy classes?

If the group is commutative then gag−1 = agg−1 = a, so each element's conjugacy class is just itself. Conjugation carries information precisely to the extent that the group fails to be abelian — which is why aa-28's class equation is a genuinely non-abelian counting tool and has no content for the groups of aa-22. — Aluffi Underground §11.3, Definition 11.31, p. 241
Blank-page ending. Close the screen. Rebuild the three claims:
Then check yourself
  1. An action is a homomorphism into the symmetric group. Definition 11.19 lists two axioms — ea = a and (gh)a = g(ha) — and Proposition 11.20 shows these are exactly a group homomorphism σ : G → SA. Bijectivity of a ↦ ga is not assumed; it follows, using g−1. Carter's Definition 9.1 takes the homomorphism as the definition outright.
  2. Orbits partition the set. The orbit of a is {ga}; the action is transitive if there is one orbit, faithful if every non-identity element moves something, free if every non-identity element moves everything. Carter's non-faithful θ, which sends v to the identity permutation, is the same phenomenon as a non-injective σ — a missing arrow in the action diagram.
  3. Every group acts on itself. By left multiplication the action is free (Lemma 11.28, one line of cancellation), so σ : G → SG is injective and Cayley's theorem follows: every group is a subgroup of a symmetric group. Conceptually decisive, practically useless — 70! > 10¹⁰⁰. By conjugation, g·a = gag−1, the orbits are the conjugacy classes (Definition 11.31), which partition G and are all singletons exactly when G is abelian.
