Integers: well-ordering, induction, division (aa-01)

You have added and multiplied integers since before you could spell "integer". This lesson hands them back to you as strangers.

We are hunting for the single structural fact that makes ℤ behave the way it does — not addition, not multiplication, but one quiet statement about order: every nonempty collection of nonnegative integers has a smallest member. From that one fact we will re-derive induction (the domino trick turns out to be a theorem here, not an axiom) and prove that you can always divide, landing on a unique remainder. Rings, modules, and homology are all built on top of ℤ — today we set the first stone.

Predict before we start. The well-ordering principle says "every nonempty set of nonnegative integers has a least element." Does the same hold for the positive rationals ℚ>0?

No. Take the set of all positive rationals. If some q > 0 were least, then q/2 is still positive, still rational, and strictly smaller — contradiction. Well-ordering is a special feature of ℤ≥0, not a generic fact about ordered number systems. Hold that thought; it is the whole engine of this lesson. — Aluffi §1.1, p. 5

Why this matters for the mission: ℤ is the first ring, and the ground every chain complex is built over — homology with integer coefficients lives here, and "well-ordering ⟹ you can always divide" is the seed of every structure theorem downstream.

Segment 1 · ~25 min

The one special property of ℤ

Before the star of the show, one piece of vocabulary we will lean on twice.

Definition 1.1 (divides). Let a, b ∈ ℤ. We say b divides a (written b ∣ a) if there is an integer c such that a = bc. — Aluffi §1.1, Definition 1.1, p. 4

So 3 ∣ 18 (because 18 = 3·6, and 6 ∈ ℤ), but 2 ∤ 1 (the only c with 1 = 2c is ½, which is not an integer). The whole subtlety of ℤ lives in that insistence on "integer c". From it comes a small but load-bearing fact.

Lemma 1.2. If b ∣ a and a ≠ 0, then |b| ≤ |a|. — Aluffi §1.1, Lemma 1.2, p. 4
Proof of Lemma 1.2. By definition a = bc for some integer c. Since a ≠ 0, both b and c are nonzero. A nonzero integer has absolute value at least 1, so |c| ≥ 1. Then

|a| = |b|·|c| ≥ |b|·1 = |b|. ∎

Notice the step that uses "integer": |c| ≥ 1 is false for a nonzero rational (⅓ ≠ 0 but |⅓| < 1). We will re-use this lemma to pin down uniqueness in Segment 3 — flag it in your memory now.

Now the protagonist. ℤ carries the usual total order ≤ (given any two integers, one is ≤ the other). But ℤ≥0 = {0, 1, 2, 3, …} has a property the rationals and reals lack.

The Well-Ordering Principle. Every nonempty set of nonnegative integers contains a least element. — Aluffi §1.1, p. 5

Aluffi is candid about its status: if we built ℤ from scratch, well-ordering would be adopted as an axiom — there is no way to derive it from more primitive facts. It should still feel obvious ("among finitely-or-infinitely many bags of potatoes, some bag has the fewest"), but the previous panel's prediction shows it is genuinely special: the positive rationals form a nonempty set of "nonnegative rationals" with no least element. Well-ordering is what ℤ has and ℚ does not.

Worked example — well-ordering as an existence tool. Claim: every integer n ≥ 2 has a prime divisor.

Let S be the set of integers n ≥ 2 that have no prime divisor. We want S = ∅. Suppose not: then S is a nonempty set of nonnegative integers, so by well-ordering it has a least element m ≥ 2.

Now m divides itself, so m has some divisor > 1 (namely m). Is m prime? If m is prime, then m is a prime divisor of m — contradicting m ∈ S. So m is not prime: m = d·e with 1 < d < m. Then d ≥ 2 and d < m, so d ∉ S (m was least in S), meaning d has a prime divisor p. But p ∣ d and d ∣ m give p ∣ m, so p is a prime divisor of m — again contradicting m ∈ S.

Either way we contradict m ∈ S, so S = ∅. ∎   Pattern to keep: to prove "every … has a …", assume the set of counterexamples is nonempty, take its least element, and manufacture a smaller one.

Self-check 1. Which set is not well-ordered by ≤ (i.e. has a nonempty subset with no least element)?

The nonnegative rationals fail: the subset of strictly positive rationals has no least element (halve any candidate). Every nonempty set of nonnegative integers, by contrast, does have a least element — that is exactly the well-ordering principle. — Aluffi §1.1, p. 5

Segment 2 · ~25 min

Induction is a theorem here

You know induction: to prove a property P(n) for all n ≥ 0, prove (i) P(0), and (ii) P(n) ⟹ P(n+1) for every n ≥ 0. The intuition is dominoes — P(0) knocks P(1), which knocks P(2), "and so on forever." Aluffi's needle: "so on forever" is not mathematics. Well-ordering makes it rigorous.

Induction, from well-ordering. If (i) P(0) holds and (ii) P(n) ⟹ P(n+1) for all n ≥ 0, then P(n) holds for all n ≥ 0. — Aluffi §1.1, pp. 5–6
Proof. Let F = { n ∈ ℤ≥0 : P(n) is false }. We want F = ∅. Suppose instead F ≠ ∅. Then F is a nonempty set of nonnegative integers, so by well-ordering it has a least element ℓ — the least counterexample.

By (i), P(0) is true, so 0 ∉ F, hence ℓ > 0. Then n = ℓ − 1 is a nonnegative integer with n < ℓ. Because ℓ is the least element of F, this smaller n is not in F: P(ℓ − 1) is true. But (ii) says P(ℓ − 1) ⟹ P(ℓ), so P(ℓ) is true — i.e. ℓ ∉ F. That contradicts ℓ ∈ F.

The contradiction kills the assumption F ≠ ∅, so F = ∅: P(n) holds for every n ≥ 0. ∎

Read what happened: induction is just "there is no least counterexample," and that is well-ordering wearing a disguise. Every induction proof can be rewritten this way.

Scope note: the day-to-day mechanics of writing induction and strong induction (assuming P(0), …, P(n) to get P(n+1)) are drilled in pw-02; here we care about why the machine runs — well-ordering — and we will use it as a tool, sometimes directly, sometimes dressed as induction.

Worked example (ordinary induction). For all n ≥ 1,   1 + 2 + ⋯ + n = n(n+1)/2.

Base. n = 1: left side 1, right side 1·2/2 = 1. ✓

Step. Assume 1 + ⋯ + n = n(n+1)/2. Add (n+1) to both sides:
1 + ⋯ + n + (n+1) = n(n+1)/2 + (n+1) = (n+1)(n/2 + 1) = (n+1)(n+2)/2,
which is the formula with n replaced by n+1. By induction it holds for all n ≥ 1. ∎

Faded example — you fill the gaps. For all n ≥ 1,   1 + 3 + 5 + ⋯ + (2n − 1) = n². (The sum of the first n odd numbers.)

Base. n = 1: left side is 1, right side is ⟨your step: compute 1²⟩, and these agree. ✓

Step. Assume 1 + 3 + ⋯ + (2n − 1) = n². The next odd number is 2(n+1) − 1 = 2n + 1. Add it:
1 + 3 + ⋯ + (2n − 1) + (2n + 1) = n² + (2n + 1) = ⟨your step: factor this as a square⟩.
Since ⟨your step⟩ = (n+1)², the statement holds for n+1, and by induction for all n ≥ 1. ∎

You try (solo). Prove by induction that 2n ≥ n + 1 for all integers n ≥ 0. (Base n = 0: 2⁰ = 1 ≥ 1. For the step, from 2n ≥ n+1 show 2n+1 ≥ n+2 — double both sides, then check 2(n+1) ≥ n+2.) Write it out before revealing anything.

Self-check 2. In the well-ordering proof that induction works, what is ℓ?

ℓ is the least element of F = {n : P(n) false} — the "least counterexample." The whole proof is showing this least counterexample can't exist: ℓ − 1 satisfies P, and the inductive step (ii) then forces P(ℓ), contradiction. — Aluffi §1.1, p. 6

Segment 3 · ~25 min

Division with remainder — and why the remainder is unique

The first real dividend of well-ordering: in ℤ you can always divide, provided you allow a remainder — and there is exactly one honest way to do it.

Theorem 1.3 (Division with remainder). Let a, b ∈ ℤ with b ≠ 0. Then there exist a unique quotient q ∈ ℤ and a unique remainder r ∈ ℤ with

a = bq + r   and   0 ≤ r < |b|.

— Aluffi §1.2, Theorem 1.3, p. 6

Remark 1.4. Uniqueness is the whole point. You can write 13 = 4·4 − 3 = 4·3 + 1 = 4·2 + 5 = ⋯ in infinitely many ways; the theorem says exactly one of them puts the remainder in the window 0 ≤ r < 4 (namely 13 = 4·3 + 1). — Aluffi §1.2, p. 6

Proof — existence (via well-ordering). Assume b > 0 (if b < 0, run the argument with −b and flip the sign of q; |b| is unchanged). Consider

S = { a − bx : x ∈ ℤ, and a − bx ≥ 0 }.

S is nonempty: if a ≥ 0 take x = 0 to get a ≥ 0 ∈ S; if a < 0 take x = a to get a − ba = a(1 − b) ≥ 0 (since 1 − b ≤ 0). So S is a nonempty set of nonnegative integers, and by well-ordering it has a least element r = a − bq for some x = q. By construction a = bq + r and r ≥ 0.

Why is r < b? Suppose r ≥ b. Then r − b ≥ 0 and r − b = (a − bq) − b = a − b(q+1), so r − b ∈ S. But r − b < r, contradicting that r is the least element of S. Hence r < b = |b|. Existence done.

Proof — uniqueness (via Lemma 1.2). Suppose a = bq + r = bq′ + r′ with 0 ≤ r, r′ < b. Subtracting,

b(q − q′) = r′ − r.   (∗)

Both r, r′ lie in {0, …, b − 1}, so |r′ − r| ≤ b − 1 < |b|. But (∗) says b ∣ (r′ − r). If r′ − r ≠ 0, Lemma 1.2 forces |b| ≤ |r′ − r| — contradicting |r′ − r| < |b|. So r′ − r = 0, i.e. r′ = r; then b(q − q′) = 0 and b ≠ 0 give q′ = q. Unique. ∎

There is Lemma 1.2 earning its keep — uniqueness is nothing but "a nonzero multiple of b can't be smaller than |b|".

Watch existence happen: the picture below starts at a and slides by whole steps of b, and the well-ordering principle is exactly the guarantee that the sliding stops — at the least nonnegative point, which is r.

Worked numeric example. Divide a = −17 by b = 5. We need 0 ≤ r < 5. Slide down from... up to −17: −17 = 5·(−4) + 3, since 5·(−4) = −20 and −17 − (−20) = 3, and 0 ≤ 3 < 5. So q = −4, r = 3. (Note the naive "−17 = 5·(−3) − 2" is rejected: −2 is outside the window.)
Faded example. Divide a = 100 by b = 7.

The multiples of 7 near 100 are 7·14 = 98 and 7·15 = 105. The largest one not exceeding 100 is ⟨your step: which one?⟩, giving q = 14 and r = 100 − ⟨your step⟩ = ⟨your step⟩, with 0 ≤ r < 7. Check: 7·14 + r = 100.

Self-check 3. Dividing a = −17 by b = 5 with the theorem's rule (0 ≤ r < 5), the remainder r is:

r must satisfy 0 ≤ r < 5, which rules out −2. Since −17 = 5·(−4) + 3 and 0 ≤ 3 < 5, we get q = −4, r = 3. Remainders are always taken in [0, |b|), even for negative a. — Aluffi §1.2, Theorem 1.3, p. 6

Self-check 4. In the existence proof, which principle guarantees the set S = {a − bx ≥ 0} actually has a least element r?

S is a nonempty set of nonnegative integers, so well-ordering hands us its least element, which we name r. (Lemma 1.2 is used later, for uniqueness, not existence.) This is the same "take the least element" move as Segment 1's prime-divisor proof. — Aluffi §1.2, p. 7

Guided proof (write it yourself)

Use the well-ordering principle to prove: there is no integer n with 0 < n < 1. Draft your argument here, then reveal the model and compare — grade yourself on whether you (a) built the right set, (b) invoked well-ordering explicitly, (c) produced a genuinely smaller element.

Reveal model answer

Suppose for contradiction that S = { n ∈ ℤ : 0 < n < 1 } is nonempty. Every element of S is a positive integer, hence nonnegative, so S is a nonempty set of nonnegative integers. By the well-ordering principle, S has a least element m, with 0 < m < 1.

Since 0 < m < 1, multiplying the inequality m < 1 by the positive number m gives m² < m; and m² > 0. So 0 < m² < m < 1. Now m² is an integer (a product of the integer m with itself), and it satisfies 0 < m² < 1, so m² ∈ S. But m² < m contradicts m being the least element of S.

Therefore S is empty: no integer lies strictly between 0 and 1. ∎   (Same recipe as every proof today: nonempty set of nonnegatives → least element → build something smaller → contradiction.)

Then check yourself
  1. Well-ordering is the special fact about ℤ: every nonempty set of nonnegative integers has a least element (false for ℚ≥0). It is taken as an axiom.
  2. It implies induction: if P had any counterexample, well-ordering would hand us the least one ℓ; but P(ℓ−1) holds and the step forces P(ℓ) — no least counterexample can exist, so there are none.
  3. It implies division with remainder: the set {a − bx ≥ 0} is nonempty nonnegative, so it has a least element r = a − bq with 0 ≤ r < |b| (existence); and Lemma 1.2 — a nonzero multiple of b has absolute value ≥ |b| — squeezes r′ − r to 0 (uniqueness).
One fact about order, and out fall induction and division. That is the whole lesson.
