GCD, Bézout, and the Fundamental Theorem of Arithmetic (aa-02)

1 = 3·5 − 2·7. Fifteen minus fourteen. A child could check it; the question is why it was available.

It is available because 5 and 7 share no factor — and Bézout's theorem says that whenever two integers share nothing, some whole-number combination of them lands exactly on 1. Today the greatest common divisor stops being "the biggest number in both lists" and becomes something you can construct: it is the smallest positive quantity you can build out of a and b by adding multiples. From that one shift come the Euclidean algorithm, the proof that irreducible integers are prime, and unique factorisation itself.

Predict before we start. Aluffi defines gcd(a, b) without ever saying "largest". Under his definition, what is gcd(0, 0)?

Every integer divides 0, so every integer is a common divisor of 0 and 0 — and there is indeed no largest one. But the definition asks instead for a nonnegative d that every common divisor divides, and 0 is the only integer divisible by every integer. So gcd(0, 0) = 0, with no special case needed. Watch for this: the whole reason Aluffi phrases the second requirement with "divides" rather than "≤" is that divisibility survives into rings where there is no order at all. — Aluffi §1.3, Remark 1.7, p. 8

Why this matters for the mission: Unique factorisation is the template for every 'decompose into irreducibles' theorem ahead.

Segment 1 · ~25 min

The gcd, defined by divisibility — and Bézout

Definition 1.5 (greatest common divisor). Let a, b ∈ ℤ. A nonnegative integer d is the greatest common divisor of a and b, written gcd(a, b) or (a, b), if

(i) d ∣ a and d ∣ b;   and   (ii) if c ∣ a and c ∣ b, then c ∣ d.

— Aluffi §1.3, Definition 1.5, p. 7

Requirement (i) makes d a common divisor. Requirement (ii) is where the surprise lives: it does not say d is the biggest common divisor, it says every other common divisor goes into d. When a and b are not both 0 the two readings agree — by aa-01's Lemma 1.2, c ∣ d with d ≠ 0 forces |c| ≤ |d|, and d is nonnegative — so d really is the largest. But when they disagree, Aluffi's version is the one that keeps working. — Aluffi §1.3, p. 8

Example 1.6 — the slow way. To see gcd(30, −42) = 6, list the divisors of 30:

−30, −15, −10, −6, −5, −3, −2, −1, 1, 2, 3, 5, 6, 10, 15, 30

and the divisors of −42:

−42, −21, −14, −7, −6, −3, −2, −1, 1, 2, 3, 6, 7, 14, 21, 42

and take the largest integer occurring in both lists: 6. — Aluffi §1.3, Example 1.6, p. 8

Aluffi's own comment on this method: it is extremely inefficient, because listing divisors means factoring, and factoring a number a few thousand digits long may take longer than the age of the universe. Segment 2 replaces it with something fast.

Theorem 1.8 (Bézout). Let a, b be integers. Then d = gcd(a, b) is an integer linear combination of a and b: there exist integers m, n with d = ma + nb. In fact, if a and b are not both 0, then gcd(a, b) is the smallest positive linear combination of a and b. — Aluffi §1.3, Theorem 1.8, p. 8
Proof of Theorem 1.8. If a = b = 0 then gcd(a, b) = 0 = 1·0 + 1·0, a linear combination. So assume a, b are not both 0, and put

S = { ma + nb : m, n ∈ ℤ and ma + nb > 0 }.

S is nonempty: taking m = a and n = b gives a² + b² > 0. So S is a nonempty set of nonnegative integers, and well-ordering hands us its least element d = ma + nb. We show d = gcd(a, b) by checking the two requirements of Definition 1.5.

(i) d ∣ a. If a = 0 this is automatic. Otherwise divide with remainder (aa-01's Theorem 1.3): a = dq + r with 0 ≤ r < d. Then

r = a − dq = a − (ma + nb)q = a(1 − mq) + b(−nq),

so r is itself a linear combination of a and b. It cannot be positive: it is smaller than d, and d is the least positive one. With r ≥ 0 that forces r = 0, so a = dq and d ∣ a. The same argument with the roles swapped gives d ∣ b.

(ii) Let c ∣ a and c ∣ b, say a = uc and b = vc. Then d = ma + nb = m(uc) + n(vc) = (mu + nv)c, so c ∣ d. ∎

Notice what did the work: not arithmetic, but the same "least element of a set you build by hand" move as aa-01. Bézout is well-ordering applied to combinations rather than to remainders.

Three consequences, each one line from Bézout, and each one we spend the rest of the lesson cashing in.

Corollary 1.9. gcd(a, b) = 1 if and only if 1 can be written as a linear combination of a and b. — Aluffi §1.3, Corollary 1.9, p. 10

Definition 1.10. a and b are relatively prime if gcd(a, b) = 1. — Aluffi §1.3, Definition 1.10, p. 10

Corollary 1.11. If a ∣ bc and gcd(a, b) = 1, then a ∣ c. — Aluffi §1.3, Corollary 1.11, p. 10

Proof of Corollary 1.9. If gcd(a, b) = 1 then Theorem 1.8 writes 1 = ma + nb. Conversely, if 1 is some linear combination of a and b, then it is certainly the smallest positive one (nothing positive is smaller than 1), and Theorem 1.8 identifies the smallest positive combination as the gcd. So gcd(a, b) = 1. ∎

Proof of Corollary 1.11. By Theorem 1.8 write 1 = ma + nb, and multiply through by c:

c = (ma + nb)c = (mc)a + n(bc).

The first term is visibly a multiple of a. The second is too, because a ∣ bc by hypothesis: write bc = ra, and then n(bc) = (nr)a. So a divides the sum, which is c. ∎

Coprimality is used exactly once, at the very first step, and everything after is bookkeeping. That is a reliable sign of where a theorem's content sits.

Remark 1.12. The hypothesis gcd(a, b) = 1 cannot be dropped: 10 ∣ (6·5) = 30, yet 10 divides neither 6 nor 5. No contradiction — gcd(10, 6) = 2 ≠ 1, so there is no equation 10m + 6n = 1 to multiply by c. — Aluffi §1.3, Remark 1.12, p. 11

Self-check 1. Theorem 1.8 says gcd(a, b) is the smallest positive linear combination of a and b. Given that gcd(30, −42) = 6, which of these is impossible?

Every linear combination of 30 and −42 is a multiple of 6 — both numbers are, so any m·30 + n·(−42) is — and 3 is not a multiple of 6. 12 is fine (double a combination giving 6), and 6 itself is exactly what the theorem promises: 3·30 + 2·(−42) = 90 − 84 = 6. — Aluffi §1.3, Theorem 1.8, p. 9

Segment 2 · ~25 min

The Euclidean algorithm, forwards and backwards

Listing divisors is hopeless for large numbers. But dividing with remainder is instant — and one lemma turns repeated division into a gcd machine.

Lemma 1.15. Let a, b, q, r be integers with b ≠ 0 and a = bq + r. Then gcd(a, b) = gcd(b, r). — Aluffi §1.4, Lemma 1.15, p. 12
Proof (one direction; the other is your guided proof below). It is enough to show the pair (a, b) and the pair (b, r) have the same common divisors — then the gcds coincide, since the gcd of a pair is determined by the set of its common divisors.

Let c ∣ a and c ∣ b, say a = cs and b = ct. Then

r = a − bq = cs − ctq = c(s − tq),

so c ∣ r; and we already have c ∣ b. Hence every common divisor of a and b is a common divisor of b and r.

Theorem 1.14 (Euclidean algorithm). Let a, b be integers with b ≠ 0. Set r₋₂ = a and r₋₁ = b, and for i ≥ 0 let rᵢ be the remainder of dividing rᵢ₋₂ by rᵢ₋₁. Then there is an n with rₙ ≠ 0 and rₙ₊₁ = 0, and gcd(a, b) = rₙ — the last nonzero remainder. — Aluffi §1.3, Theorem 1.14, p. 11
Why Lemma 1.15 proves Theorem 1.14. The remainders strictly decrease and stay nonnegative, so one of them must eventually be 0 — the process terminates. Applying the lemma at every line,

gcd(a, b) = gcd(b, r₀) = gcd(r₀, r₁) = ⋯ = gcd(rₙ₋₁, rₙ) = gcd(rₙ, 0) = rₙ.

The last equality is the prediction gate's definition at work: gcd(rₙ, 0) = rₙ because rₙ divides both rₙ and 0, and any common divisor of them divides rₙ. ∎   No factorisation was performed anywhere. — Aluffi §1.4, p. 12

Geometrically the algorithm tiles an a × b rectangle with squares: cut off the largest square you can, then repeat on the strip that is left. The side of the last square is the gcd. Drive it below.

Example 1.13 — the algorithm on a = 30, b = −42.

30 = (−42)·0 + 30
−42 = 30·(−2) + 18
30 = 18·1 + 12
18 = 12·1 + 6
12 = 6·2 + 0

The last nonzero remainder is 6, and we found gcd(30, −42) = 6 by inspection in Segment 1. — Aluffi §1.3, Example 1.13, p. 11

Remark 1.16 (running it backwards). The algorithm also produces the Bézout coefficients: start at the line that produced the gcd and substitute the earlier remainders one at a time. — Aluffi §1.4, Remark 1.16, p. 12

Worked example — back-substitution for 30 and −42.

Second-to-last line: 6 = 18 − 12·1 = 18 − 12.

The line above gives 12 = 30 − 18, so   6 = 18 − (30 − 18) = 2·18 − 30.

The line above that gives 18 = −42 − 30·(−2), so

6 = 2·(−42 − 30·(−2)) − 30 = 3·30 + 2·(−42),

giving m = 3, n = 2. Check: 90 − 84 = 6. ✓ The discipline is never to multiply anything out: keep each line as a combination of the two numbers appearing on the previous line.

Faded example — do it for 1234 and 288.

Forward: 1234 = 288·4 + 82;   288 = 82·3 + 42;   82 = 42·1 + 40;   42 = 40·1 + 2;   40 = 2·20 + 0. So gcd(1234, 288) = ⟨your step: read off the last nonzero remainder⟩.

Backward, starting from the line that produced it: 2 = 42 − 40.

The line above gives 40 = 82 − 42, so 2 = 42 − (82 − 42) = ⟨your step: collect the 42s⟩·42 − 82.

The line above that gives 42 = 288 − 3·82, so 2 = 2(288 − 3·82) − 82 = 2·288 − ⟨your step⟩·82.

Finally 82 = 1234 − 4·288, so 2 = 2·288 − 7(1234 − 4·288) = ⟨your step⟩·1234 + ⟨your step⟩·288. Check against −8638 + 8640 = 2.

You try (solo). Run the Euclidean algorithm on 803 and 154, then back-substitute to get Bézout coefficients. Two sanity checks before you start: the answer divides both numbers, and 154 = 2·7·11 — so the gcd is one of 1, 2, 7, 11, 14, 22, 77, 154. Write out every division line; the back-substitution is only as reliable as the forward record.

Self-check 2. Why does the Euclidean algorithm always stop?

Division with remainder forces 0 ≤ rᵢ < rᵢ₋₁, so the remainders form a strictly decreasing sequence of nonnegative integers — which cannot go on forever. (Well-ordering again, in yet another disguise: an infinite strictly decreasing sequence of nonnegative integers would be a nonempty set with no least element.) Divisor-counting is exactly what the algorithm avoids doing. — Aluffi §1.3, Theorem 1.14, p. 11

Guided proof (write it yourself)

Aluffi leaves half of Lemma 1.15 to you — literally: "The reader should work this out." Do it. Show that if c is a common divisor of b and r, then c is a common divisor of a and b, where a = bq + r. Then say in one sentence why the two halves together give gcd(a, b) = gcd(b, r).

Reveal model answer

Suppose c ∣ b and c ∣ r, say b = ct and r = cu for integers t, u. Then

a = bq + r = (ct)q + cu = c(tq + u),

so c ∣ a; and c ∣ b was a hypothesis. Hence c is a common divisor of a and b.

Together with the direction proved in the body, the pairs (a, b) and (b, r) have exactly the same set of common divisors. The gcd of a pair is determined by that set — it is the nonnegative member of the set that every member divides — so gcd(a, b) = gcd(b, r). ∎

Grade yourself on one thing: did you substitute into a = bq + r, or did you try to derive this from the direction already proved? The two directions are genuinely separate computations; neither follows from the other.

Segment 3 · ~25 min

Irreducible, prime, and unique factorisation

Addition needs one brick: every integer is built from 1. Multiplication needs infinitely many — and Aluffi is careful to give them two names, because in general rings the two names come apart.

Definition 1.17 (irreducible). An integer p is irreducible if p ≠ ±1 and the only divisors of p are ±1 and ±p. An integer ≠ 0, ≠ ±1 is reducible (or composite) if it is not irreducible. Note that 0 and ±1 are neither. — Aluffi §1.4, Definition 1.17, p. 13
Definition 1.19 (prime). An integer p is prime if p ≠ ±1 and whenever p divides a product bc of two integers, p divides b or p divides c. — Aluffi §1.4, Definition 1.19, p. 14

Irreducibility is about factorisations: p cannot be broken up. Primality is about products: p cannot hide inside one. They are different sentences about different things. Two warnings from the text, both easy to trip on. First, 10 is not prime — 10 ∣ 30 = 6·5 while 10 divides neither 6 nor 5. Second, and unusually, 0 is prime under Definition 1.19; most books exclude it, and Aluffi keeps it deliberately, to line up with the language of prime ideals in §6.1. That is why Theorem 1.21 below carries the hypothesis p ≠ 0. — Aluffi §1.4, p. 14

Lemma 1.18. If p is irreducible and b is not a multiple of p, then gcd(p, b) = 1. — Aluffi §1.4, Lemma 1.18, p. 13
Proof. Let c be a common divisor of p and b. Since c ∣ p and p is irreducible, c is ±1 or ±p. But c ∣ b, and p ∤ b, so c ≠ ±p. Hence c = ±1. This applies in particular to c = gcd(p, b), which is nonnegative, so gcd(p, b) = 1. ∎

Combine with Corollary 1.9: for an irreducible p and any b it does not divide, there are integers m, n with mp + nb = 1. That is not obvious by inspection, and it is the engine of everything below.

Theorem 1.21. Let p ∈ ℤ with p ≠ 0. Then p is prime if and only if p is irreducible. — Aluffi §1.4, Theorem 1.21, p. 14
Proof. If p = ±1 then p is neither prime nor irreducible, so the claim holds in that case; assume p ≠ 0, ±1.

Prime ⟹ irreducible. Let d ∣ p, say p = dq. Then p ∣ dq (as dq = 1·p), and p prime gives p ∣ d or p ∣ q. If p ∣ d, then with d ∣ p, aa-01's Lemma 1.2 gives |d| ≤ |p| and |p| ≤ |d|, so d = ±p. If instead p ∣ q, write q = ep; then p = dq = dep, so p(de − 1) = 0, and p ≠ 0 forces de = 1, i.e. d ∣ 1, i.e. d = ±1. So the only divisors of p are ±1, ±p.

Irreducible ⟹ prime. Suppose p ∣ bc. If p ∣ b we are done, so assume p ∤ b. Lemma 1.18 gives gcd(p, b) = 1, and Corollary 1.11 turns p ∣ bc into p ∣ c. ∎

Read the asymmetry. The first direction used nothing but divisibility. The second reached back through Corollary 1.11 to Bézout — that is, to well-ordering. Aluffi's whole reason for keeping two words is that the second direction is the one that fails in general rings (§6.2): nonzero primes are always irreducible in a domain, but irreducibles need not be prime. ℤ is special, and Theorem 1.21 is where the specialness is spent.

Theorem 1.22 (Fundamental Theorem of Arithmetic). Every integer n ≠ 0, ≠ ±1 is a product of finitely many irreducible integers, n = q₁⋯q_r. Further this factorisation is unique: if n = q₁⋯q_r = p₁⋯p_s with all qᵢ, pⱼ irreducible, then s = r and, after reordering the factors, p₁ = ±q₁, …, p_r = ±q_r. — Aluffi §1.4, Theorem 1.22, p. 15
Proof — existence (well-ordering and Definition 1.17 only). Signs can be absorbed into the factors, so take n > 1, and let S be the set of integers n > 1 with no factorisation into irreducibles. If S ≠ ∅ it has a least element n. Then n is not itself irreducible, so n = ab with a and b different from ±1, ±n; taking both positive, 1 < a < n and 1 < b < n (Lemma 1.2 again). Both are below the minimum of S, so both factor into irreducibles, and concatenating those factorisations factors n — contradicting n ∈ S. So S = ∅.

Uniqueness (needs Theorem 1.21). Let T be the set of n > 1 with a non-unique factorisation; if T ≠ ∅ take its least element n and write n = q₁⋯q_r = p₁⋯p_s, all factors positive irreducibles. Then p₁ divides q₁⋯q_r; p₁ is irreducible, hence prime by Theorem 1.21, hence divides some qᵢ — reorder so that it divides q₁. But q₁ is irreducible and p₁ ≠ ±1, so p₁ = ±q₁, and both being positive, p₁ = q₁. Cancel it: q₂⋯q_r = p₂⋯p_s. That number is n/q₁ < n, so its factorisation is unique, forcing r − 1 = s − 1 and the remaining factors to match up to order. Contradiction. ∎

The line to remember: existence never mentions primality; uniqueness cannot be proved without it. In a setting where irreducible does not imply prime, you keep existence and lose uniqueness — which is precisely what Problem 6 makes you build. — Aluffi §1.4, pp. 16–17

Once factorisation is unique, every positive integer is a list of exponents: n = 2^ν₂ · 3^ν₃ · 5^ν₅ ⋯ with only finitely many νᵢ nonzero, and the list is determined by n. Divisibility then becomes a comparison of lists: c ∣ n exactly when every exponent of c is ≤ the corresponding exponent of n. — Aluffi §1.4, p. 18

Proposition 1.25. Write nonzero a = ±2^α₂3^α₃5^α₅⋯ and b = ±2^β₂3^β₃5^β₅⋯. Then gcd(a, b) = 2^δ₂3^δ₃5^δ₅⋯ where δᵢ = min(αᵢ, βᵢ) for every i. — Aluffi §1.4, Proposition 1.25, p. 18
Proof. A positive c = 2^γ₂3^γ₃⋯ is a common divisor of a and b exactly when γᵢ ≤ αᵢ and γᵢ ≤ βᵢ for all i, i.e. exactly when γᵢ ≤ min(αᵢ, βᵢ) = δᵢ for all i — which says precisely that c ∣ d, where d = 2^δ₂3^δ₃⋯. Taking c = d shows d is itself a common divisor (requirement (i) of Definition 1.5); the same display shows every common divisor divides d (requirement (ii)). ∎

Example 1.26. 30 = 2·3·5 and −42 = −2·3·7, so taking minima exponent by exponent, gcd(30, −42) = 2·3 = 6 — the third time today we have reached 6, by a third method. Taking maxima instead gives lcm(30, −42) = 2·3·5·7 = 210. — Aluffi §1.4, Example 1.26, p. 19

And a warning Aluffi repeats: this is a beautiful formula and a terrible algorithm. It needs the factorisations, which is the expensive part; the Euclidean algorithm needs none.

Self-check 3. Which half of the Fundamental Theorem of Arithmetic uses Theorem 1.21 (irreducible ⟺ prime)?

Existence runs on well-ordering plus Definition 1.17: a least non-factorable n splits as ab with both factors smaller, and both factor. Nowhere does it ask whether a divisor is prime. Uniqueness is where p₁ ∣ q₁⋯q_r has to become p₁ ∣ qᵢ for one single i — and that step is the definition of prime, reached from irreducibility by Theorem 1.21. — Aluffi §1.4, p. 17

Self-check 4. In the set S = {1, 5, 9, 13, 17, …} of positive integers of the form 4k + 1 (closed under multiplication), 9 and 21 and 49 have no divisors inside S other than 1 and themselves, and 441 = 9·49 = 21·21. What does this show?

S inherits well-ordering from ℤ, so the existence argument still runs — every element of S above 1 is a product of S-irreducibles. What S lacks is Theorem 1.21: 9 is S-irreducible but not S-prime, since 9 ∣ 21·21 while 9 ∤ 21. And Theorem 1.21 came from Bézout, which S has no version of, since S is not closed under subtraction. This is Problem 6, and it is the cleanest demonstration that "irreducible = prime" is a theorem about ℤ, not a definition. — Aluffi §1.4, p. 15

Self-check 5. Under Definition 1.19 as Aluffi writes it, is 0 prime?

0 ≠ ±1, and if 0 ∣ bc then bc = 0, so b = 0 or c = 0, i.e. 0 ∣ b or 0 ∣ c. The condition holds. Aluffi flags this as a deliberate, nonstandard choice made to align with prime ideals in §6.1 — which is also why Theorem 1.21 has to say p ≠ 0: 0 is prime but is not irreducible, since it has divisors other than ±1 and ±0. — Aluffi §1.4, Definition 1.19, p. 14

Then check yourself
  1. Bézout (Theorem 1.8): gcd(a, b) is the smallest positive integer of the form ma + nb. Proved by well-ordering on the set of positive combinations. This turns the gcd from something you find into something you build.
  2. Theorem 1.21: for p ≠ 0, irreducible ⟺ prime. The irreducible-implies-prime direction runs Lemma 1.18 → Corollary 1.11 → Bézout; the other direction is pure divisibility. Only the second generalises to arbitrary rings.
  3. FTA (Theorem 1.22): existence of a factorisation into irreducibles needs only well-ordering and Definition 1.17; uniqueness needs Theorem 1.21, hence needs Bézout. Remove Bézout — as in the 4k+1 numbers — and you keep existence and lose uniqueness.
