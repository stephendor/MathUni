Compactness (top-08)

Every open cover has a finite subcover — the property that tames the infinite, now off the real line. It reads like a technical convenience and it is not: it is what turns "for each point there is a δ" into "there is a δ that works for every point". Two theorems calculus assumed without saying so, the extreme value theorem and uniform continuity, are that conversion carried out, and both fail on (0,1) for exactly the same reason.

Predict before we start. The set {1/n : n ∈ ℤ₊} sits inside ℝ. Predict whether it is compact, and whether adding the single point 0 changes the answer.

Adding one point does it. Without 0, the sets (1/(n+1), 2/n) cover the set and no finite subfamily reaches the small terms. With 0 present, any open cover has a member U containing 0, and U being open already swallows every 1/n beyond some index — so finitely many more finish the job. That is Munkres's Example 2 against Example 4, printed 164, and the whole subject in miniature: compactness is what a limit point forces.

Why this matters for the mission: TDA's theory lives on compact spaces; filtrations of compact data are where the theorems hold.

"Compact data" is true of every point cloud and tells you nothing.

Munkres's Example 3, printed 164: "Any space X containing only finitely many points is necessarily compact, because in this case every open covering of X is finite." A point cloud is a finite set. So a point cloud is compact — and the argument never looked at a distance, exactly as top-06's argument that its topology is discrete never looked at a distance. Both facts are true, trivial and uninformative, and for the same reason: finiteness settles them before the geometry is consulted.

So the strip's phrase "filtrations of compact data" names the wrong object. What the theorems of TDA require to be compact is not the finite sample. It is the underlying space being sampled — the manifold or compact set the data is drawn from — or the parameter interval along which the filtration runs. Neither is the point cloud, and neither is established anywhere in §26 or §27.

And there is no TDA here. §§26–27 contain no filtration, no persistence and no data. What they do supply is the property that later stability arguments consume: Lemma 27.5 and Theorem 27.6, where compactness converts a point-by-point δ into a single δ good everywhere. That conversion is the shape every uniform bound in the mission has.
Segment 1 · ~25 min

Covers, and what a limit point forces

Definitions (Munkres, printed 164). A collection 𝒜 of subsets of a space X is said to cover X, or to be a covering of X, if the union of the elements of 𝒜 is equal to X. It is called an open covering of X if its elements are open subsets of X.

A space X is said to be compact if every open covering 𝒜 of X contains a finite subcollection that also covers X.
Worked example — Examples 2 and 4 side by side.

(0,1] is not compact (Example 4, printed 164). The collection 𝒜 = {(1/n, 1) : n ∈ ℤ₊} is an open covering: every x with 0 < x < 1 has 1/n < x for large n. Any finite subfamily has a largest index N, so its union is (1/N, 1), which misses every point of (0, 1/N]. No finite subcover exists. Munkres notes the same argument disposes of (0,1).

{0} ∪ {1/n} is compact (Example 2, printed 164). Let 𝒜 be an open cover and pick U ∈ 𝒜 containing 0. Because U is open there is ε > 0 with (−ε, ε) ∩ X ⊂ U; by the Archimedean property there is N with 1/N < ε, and then every 1/n with n ≥ N lies in U. So the points of X outside U are among 1, 1/2, …, 1/(N−1) — finitely many. Choose one member of 𝒜 for each, add U, and you have a finite subcover. ∎

The difference is one point. {1/n} alone is not compact — it is (0,1]'s failure in miniature. Adjoin its limit point and it becomes compact. Compactness is not about being small or bounded; it is about whether the space contains the points its own covers are aiming at.
Lemma 26.1 (printed 164). Let Y be a subspace of X. Then Y is compact if and only if every covering of Y by sets open in X contains a finite subcollection covering Y.

Theorem 26.2 (printed 165). Every closed subspace of a compact space is compact.

Theorem 26.3 (printed 165). Every compact subspace of a Hausdorff space is closed.

Theorem 26.5 (printed 166). The image of a compact space under a continuous map is compact. This is the exact analogue of top-07's Theorem 23.5, which said the same for connectedness; both are proved by pulling a structure on the image back through f⁻¹.

Theorem 26.6 (printed 167). Let f : X → Y be a bijective continuous function. If X is compact and Y is Hausdorff, then f is a homeomorphism.

Theorems 26.2 and 26.3 are near-converses with different hypotheses, and the asymmetry is worth noticing: "closed ⇒ compact" needs the ambient space compact, "compact ⇒ closed" needs it Hausdorff. Neither hypothesis can be dropped. And Theorem 26.6 is the pair of them put to work — it is the standard tool for promoting a continuous bijection to a homeomorphism, and it explains top-04's Example 6 exactly: F : [0,1) → S¹ fails it because [0,1) is not compact, not because anything is wrong with F.

Self-check 1. Which hypothesis of Theorem 26.6 does F : [0,1) → S¹ fail?

[0,1) is not compact: the covering {[0, 1 − 1/n)} has no finite subcover, by the same argument as Example 4. S¹ is Hausdorff, being a subspace of ℝ² (Theorem 17.11), and F is a continuous bijection. So Theorem 26.6 is inapplicable, and top-04 found by hand that its conclusion is false.

Products, tubes, and closed sets that refuse to be empty

Theorem 26.7 (printed 167). The product of finitely many compact spaces is compact.

Lemma 26.8, the tube lemma (printed 168). Consider the product space X × Y, where Y is compact. If N is an open set of X × Y containing the slice x₀ × Y of X × Y, then N contains some tube W × Y about x₀ × Y, where W is a neighbourhood of x₀ in X.

Theorem 26.9 (printed 170). Let X be a topological space. Then X is compact if and only if for every collection 𝒞 of closed sets in X having the finite intersection property, the intersection ⋂_{C ∈ 𝒞} C of all the elements of 𝒞 is non-empty.

A collection has the finite intersection property if every finite subcollection has non-empty intersection (printed 169). Theorem 26.9 is the definition of compactness with every set complemented: covers become collections of closed sets with empty intersection, and finite subcovers become finite subcollections with empty intersection. De Morgan does the whole translation, and the value of having both forms is that some arguments name open sets naturally and others name closed ones.

Faded example — the tube lemma, and where compactness is spent. Let N be open in X × Y containing x₀ × Y, with Y compact.

For each y ∈ Y pick a basis element U_y × V_y with (x₀, y) ∈ U_y × V_y ⊂ N. The sets V_y cover Y.

⟨your step: apply compactness of Y to extract finitely many V_{y₁},…,V_{y_n} covering Y, and define W = U_{y₁} ∩ ⋯ ∩ U_{y_n}. Say why W is open — which axiom of top-01, and why the finiteness of the subcover is what makes it applicable.⟩

⟨your step: show W × Y ⊂ N. Take (x,y) with x ∈ W; find the i with y ∈ V_{y_i}, and check that (x,y) ∈ U_{y_i} × V_{y_i}.⟩

Without compactness it fails. Take Y = ℝ and N = {(x,y) : |x|·(1 + y²) < 1}. The slice 0 × ℝ lies in N, but for any neighbourhood W of 0 there is a small non-zero x ∈ W, and then (x, y) ∉ N once |y| is large enough. No tube fits.
Guided proof. Prove Theorem 26.9 in the direction that is usually the useful one: if X is compact and 𝒞 is a collection of closed sets with the finite intersection property, then ⋂𝒞 ≠ ∅.

Argue by contradiction and name the De Morgan step explicitly.
Model answer Suppose ⋂_{C ∈ 𝒞} C = ∅. Put 𝒜 = {X − C : C ∈ 𝒞}. Each X − C is open, since each C is closed. By De Morgan,
⋃_{C ∈ 𝒞} (X − C) = X − ⋂_{C ∈ 𝒞} C = X − ∅ = X,
so 𝒜 is an open covering of X.

Since X is compact, finitely many members cover X, say X = (X − C₁) ∪ ⋯ ∪ (X − C_n). Applying De Morgan again,
∅ = X − ⋃_{i}(X − C_i) = C₁ ∩ ⋯ ∩ C_n.

So the finite subcollection {C₁, …, C_n} of 𝒞 has empty intersection — contradicting the finite intersection property. Hence ⋂𝒞 ≠ ∅. ∎

The immediate corollary. A decreasing sequence C₁ ⊃ C₂ ⊃ ⋯ of non-empty closed subsets of a compact space has non-empty intersection: any finite subcollection has intersection equal to its smallest member, which is non-empty, so the finite intersection property holds. In ℝ this fails — take C_n = [n, ∞) — and the failure is exactly the failure of compactness.

Self-check 2. Where is compactness of Y used in the tube lemma?

The finite subcover is what makes W = U_{y₁} ∩ ⋯ ∩ U_{y_n} a finite intersection of open sets, hence open by top-01's axiom (3). An infinite intersection would not be open, and the argument would collapse — and the lemma really does fail, as N = {(x,y) : |x|(1+y²) < 1} over Y = ℝ shows.

Segment 3 · ~25 min

The real line, and the two theorems calculus assumed

Theorem 27.1 (printed 172). Let X be a simply ordered set having the least upper bound property. In the order topology, each closed interval in X is compact.

Corollary 27.2 (printed 173). Every closed interval in ℝ is compact.

Theorem 27.3 (printed 173). A subspace A of ℝⁿ is compact if and only if it is closed and is bounded in the euclidean metric d or the square metric ρ.

Theorem 27.4, the extreme value theorem (printed 174). Let f : X → Y be continuous, where Y is an ordered set in the order topology. If X is compact, then there exist points c and d in X such that f(c) ≤ f(x) ≤ f(d) for every x ∈ X.

Theorem 27.3 is the Heine–Borel statement, and it is worth seeing which pieces it consumes. Compact ⇒ closed is Theorem 26.3, using that ℝⁿ is Hausdorff; compact ⇒ bounded comes from covering A by balls. Closed and bounded ⇒ compact puts A inside a cube [−M,M]ⁿ, compact by Corollary 27.2 and Theorem 26.7, and then Theorem 26.2 finishes. That either metric may be used is top-06's Theorem 20.3.

Theorem 27.4 and top-07's Theorem 24.3 are the matched pair of the two chapters. The intermediate value theorem is powered by connectedness of the domain; the extreme value theorem by compactness. Both fail on (0,1): f(x) = 1/x is continuous and unbounded there, so no maximum exists; and on the disconnected domain (0,1) ∪ (2,3) the map f(x) = x omits the value 1.5 while taking values on both sides of it.

Definitions (Munkres, printed 175–176). For a non-empty A ⊂ (X,d), the distance from x to A is d(x,A) = inf{d(x,a) : a ∈ A}.

f : (X,d_X) → (Y,d_Y) is uniformly continuous if given ε > 0 there is δ > 0 such that for every pair of points x₀, x₁ of X, d_X(x₀,x₁) < δ ⟹ d_Y(f(x₀), f(x₁)) < ε.
Lemma 27.5, the Lebesgue number lemma (printed 175). Let 𝒜 be an open covering of the metric space (X,d). If X is compact, there is a δ > 0 such that for each subset of X having diameter less than δ, there exists an element of 𝒜 containing it.

Theorem 27.6, the uniform continuity theorem (printed 176). Let f : X → Y be a continuous map of the compact metric space (X,d_X) to the metric space (Y,d_Y). Then f is uniformly continuous.

Theorem 27.7 (printed 176). Let X be a non-empty compact Hausdorff space. If X has no isolated points, then X is uncountable.

Corollary 27.8 (printed 177). Every closed interval in ℝ is uncountable.
Worked example — what compactness actually buys, in one sentence. Compare the two definitions written out with their quantifiers in order.

Continuous (Theorem 21.1, top-06): for every x, for every ε > 0, there exists δ > 0 such that d_X(x,y) < δ ⟹ d_Y(f(x),f(y)) < ε.
Uniformly continuous: for every ε > 0, there exists δ > 0 such that for every pair x₀, x₁, d_X(x₀,x₁) < δ ⟹ d_Y(f(x₀),f(x₁)) < ε.

The only change is that ∃δ has moved to the left of ∀x. In the first, δ may shrink as x moves; in the second one δ must serve the whole space. Theorem 27.6 says compactness licenses the move, and Lemma 27.5 is how — the Lebesgue number is precisely a δ that works everywhere at once, extracted from a cover by a finite subcover.

Why it fails without compactness. f(x) = 1/x on (0,1) is continuous: for each x a δ exists. But as x → 0 the admissible δ shrinks to nothing, and no single δ serves. That is the same failure as Example 4's, seen through a different window.

And this is the shape the mission cares about. Every uniform bound in stability theory — sup-norm control, a single ε governing an entire diagram — is a quantifier in this position. Compactness is the hypothesis that puts it there.

Munkres defines an isolated point of X as a point x with {x} open (printed 176). Note in passing what that makes of a point cloud, whose topology top-06 showed is discrete: every point is isolated, so Theorem 27.7 says nothing about it — correctly, since a point cloud is countable.

Self-check 3. Which quantifier moves when "continuous" becomes "uniformly continuous"?

∃δ moves left of ∀x, so one δ must serve every point rather than being chosen per point. Nothing is deleted — the second definition still quantifies over all pairs x₀, x₁, but after δ has been fixed. That single reordering is what Theorem 27.6 buys with compactness, via the Lebesgue number of Lemma 27.5.

Self-check 4. Is a point cloud compact?

Yes, by Munkres's Example 3: every open covering of a finite space is finite. The fact is true and useless, since it never consults a distance — the same shape as top-06's finding that a point cloud's metric topology is discrete. The second and fourth options describe Theorem 27.3, which is about subspaces of ℝⁿ in general and is not what settles the finite case. The third is wrong: a finite discrete space is compact; an infinite one is not.

Self-check 5. Is compactness a homotopy invariant?

No. ℝ deformation retracts onto {0}, so ℝ and a one-point space are homotopy equivalent; a point is compact and ℝ is not. Compactness is a topological property in Munkres's sense (§18, printed 105) — it is stated purely in open sets, so homeomorphisms preserve it — but topological properties need not survive the coarser relation, which is precisely top-04's mission bound seen from the other side.

Check against this 1. Compactness is what the space's own limit points force. {1/n} is not compact and {0} ∪ {1/n} is; (0,1] is not and [0,1] is. Nothing about size or boundedness is doing the work — it is whether a cover aiming at a point finds that point present. Take finiteness away and each argument fails at exactly that line.
