Categories and morphisms (cat-01)

Aluffi opens by quoting Norman Steenrod's name for this material: abstract nonsense. He accepts the label. Categories are about structure and not meaning — about "things, and things that go from things to things" without being explicit about what the things are. The discipline that buys is severe and it starts immediately: in a general category, objects have no elements. You cannot say a morphism is injective, because there is nothing to be injective on. Everything you want to say has to be said with arrows, and §4 shows that when you do say it with arrows, some of what you believed turns out to be false.

Predict before we start. In Set, a function is a bijection exactly when it is both injective and surjective. §4 defines monomorphism and epimorphism so that in Set they mean exactly injective and surjective. Predict: in an arbitrary category, is a morphism that is both a monomorphism and an epimorphism necessarily an isomorphism?

No. In the category built from ≤ on ℤ there is at most one morphism between any two objects, so the cancellation conditions defining mono and epi are satisfied vacuously by every morphism — while the only isomorphisms are the identities. That is Example 4.10 against Example 4.5, and it is the sharpest thing in the unit. Aluffi's comment is that this property is "a special feature of Set", not a general fact.

Why this matters for the mission: Persistence lives in a category — objects are homology groups, arrows are the maps a filtration induces.

What this unit's sources do and do not establish. The mission strip is quoted verbatim, as the rubric requires. Aluffi §I.3–I.4 contains no persistence, no homology and no filtration, so every clause of the strip is a forward pointer. What the unit supplies is the definition against which those clauses would have to be checked, and one piece of the check is genuinely available now.

Functors are not in this unit's sources at all. Aluffi says so in a footnote on p. 18: "we will not consider functors until later chapters: our first formal encounter with functors will be in Chapter VIII." Chapter VIII is cat-03's resource, not this unit's. That matters because the strip's picture — a family of homology groups with the maps between them — is the image of a functor, and the fact that such an image is closed under composition and contains the identities is a consequence of functoriality, which nothing here may use. at1-10 did establish that Hn is a functor, from Hatcher §2.3, so the claim is established somewhere in the programme; it is not established here, and this lesson does not lean on it.

One clause can be sharpened now, and in a direction the strip does not anticipate. The index of a filtration is a set of parameter values with an order, and Aluffi's Example 3.3 turns exactly that into a category — but it requires only that the relation be reflexive and transitive. Antisymmetry is not assumed, so the index of a filtration need not be a partially ordered set; a preorder is enough. at1-10, following Hatcher, used a poset. Aluffi's version is strictly more general, and Segment 3 shows what antisymmetry would have added: nothing about the arrows, and everything about whether distinct objects can be isomorphic.

Also not established: that the strip's description defines a category. "Objects are homology groups, arrows are the maps a filtration induces" is a proposal, and Definition 3.1 is the list of things a proposal must satisfy — identities, composition, associativity, units, and the disjointness clause that people forget. Checking it is cat-03's work, because the check runs through functoriality. This unit's contribution is the checklist, not the verdict.

Segment 1 · ~25 min

The definition, and the clause everyone skips

Before the definition, one honest difficulty. Aluffi writes that the objects form a class, not a set, and explains why: we want a category of sets, and there is no set of all sets — that is what Russell's paradox tells us. A class is the technical device for collections too big to be sets. He then defuses it: nothing in the book depends on the distinction, and in many examples the collection genuinely is a set, in which case the category is called small. Take the word "class" as a promise that the difficulty has been dealt with elsewhere.

Definition 3.1. A category C consists of a class Obj(C) of objects, and for every two objects A, B a set HomC(A, B) of morphisms, such that: — Aluffi §I.3, p. 19

· for every object A there is at least one morphism 1A ∈ HomC(A, A), the identity on A;
· morphisms compose: for every triple A, B, C there is a function HomC(A, B) × HomC(B, C) → HomC(A, C), sending (f, g) to gf;
· composition is associative: (hg)f = h(gf);
· identities are identities for composition: f1A = f and 1Bf = f for all f ∈ HomC(A, B);
· and the sets HomC(A, B) and HomC(C, D) are disjoint unless A = C and B = D.

Aluffi's advice for remembering all this is to think of sets and functions, and his prototype is exactly that: objects are sets, morphisms are functions. But he also makes a remark worth taking seriously — that 90% of the definition goes into the properties of the morphisms, and that "it is fair to say that the morphisms are the important constituents of a category". The objects are nearly placeholders. Every axiom above is about arrows.

The disjointness clause is not bookkeeping. It says a morphism remembers its source and its target: the same f cannot live in two different Hom-sets. Aluffi notes this holds for ordinary set-functions, where "source and target are part of the datum of a set-function" — a point that usually goes unnoticed because we never write a function without knowing where it goes. Drop the clause and composition breaks: gf would no longer be determined by f and g, because f alone would not say which Hom-set it came from, and the composition function is indexed by the triple (A, B, C). Problem 1(c) asks you to build the ambiguity explicitly.

Two pieces of vocabulary come straight out of the definition. A morphism from A to itself is an endomorphism, and HomC(A, A) is written EndC(A). One of the axioms makes it a pointed set, since 1A lives in it; and composition is an operation on it, because the composite of two endomorphisms of A is again one. Notation relaxes too: drop the subscript C when the category is understood, write f : A → B, and draw diagrams. A diagram commutes when all ways of traversing it compose to the same morphism.

Self-check 1. Why does Definition 3.1 say the objects form a class but the morphisms between any two objects form a set?

Russell. The motivating example is Set itself, whose objects are all sets, and there is no set of all sets. Hom(A, B) for fixed A and B is a different matter — for sets it is a set of functions, and it is part of the definition that it always be a set. A category whose object class is a set is called small; Examples 3.3 and 3.4 are both small, which is why they feel comfortable.

Segment 2 · ~25 min

Categories that are not sets and functions

Example 3.2 is Set, and Aluffi says that if it is not crystal clear the reader should stop and go no further. Example 3.3 is where the subject actually starts, because in it the morphisms are not functions and nothing is applied to anything.

Example 3.3. Let S be a set and ∼ a relation on S that is reflexive and transitive. Then: objects are the elements of S; and for a, b ∈ S, Hom(a, b) is the one-element set {(a, b)} if a ∼ b, and ∅ otherwise. — Aluffi §I.3, pp. 20–21

Reflexivity supplies the identities: a ∼ a gives 1a = (a, a). Transitivity supplies composition: a ∼ b and b ∼ c give a ∼ c. Associativity and the unit laws are automatic, because there is at most one morphism in any Hom-set and so any two parallel morphisms are equal.

Aluffi's own comment: "unlike in Set there are very few morphisms: at most one for any pair of objects, and no morphisms at all between 'unrelated' objects." Note what is not required — antisymmetry. The relation need only be a preorder. Take S = ℤ with ≤ and you get a partial order; take a relation where a ∼ b and b ∼ a can both hold with a ≠ b, and you get a category in which two distinct objects have arrows both ways. Segment 3 says exactly what that difference amounts to.

Worked, then fading: Example 3.4, the power set. — Aluffi §I.3, p. 22

Let S be a set. Define Ŝ by: Obj(Ŝ) = 𝒫(S), the power set; and for A, B ⊆ S, let HomŜ(A, B) be the one-element set {(A, B)} if A ⊆ B, and ∅ otherwise.

A note on that wording. Aluffi writes "let HomŜ(A, B) be the pair (A, B)", but Definition 3.1 requires HomŜ(A, B) to be a set, and the pair is the morphism, not the Hom-set. The singleton reading is forced. He is careful about exactly this two pages earlier in Example 3.3, where he writes "the set consisting of the element (a, b)"; the slip is local to Example 3.4 and the correction is this lesson's.

The identity 1A is the pair (A, A), which exists because A ⊆ A, and is the only morphism A → A. Composition is stringing inclusions: given A → B and B → C we have A ⊆ B and B ⊆ C, hence A ⊆ C and a morphism A → C.

Now check the rest. Associativity holds because ⟨ what is true of any two morphisms with the same source and target here? ⟩. The unit laws hold for the same reason. Disjointness holds because a morphism is literally the pair (A, B), so it ⟨ … ⟩.

Aluffi's footnote says Ŝ is really an instance of Example 3.3. It is: take the set to be ⟨ … ⟩ and the reflexive transitive relation to be ⟨ … ⟩. That is his Exercise 3.5.

He adds that examples in this style, with more sophisticated structures — "such as the family of open subsets of a topological space" — are hugely important in algebraic geometry.

Example 3.5 is the construction to sit with, because variations of it recur throughout the subject. Fix a category C and an object A. The slice category CA has as its objects all morphisms f : Z → A, for every object Z of C — drawn as arrows pointing down into A. Aluffi then stops and invites the reader to work out the morphisms independently, remarking that "there really is only one sensible way" to do it. There is: a morphism from f : Z → A to g : W → A is a morphism σ : Z → W making the triangle over A commute, that is, gσ = f.

Example 3.6 makes it concrete with C the ≤-on-ℤ category and A = 3: objects of C3 are the pairs (n, 3) with n ≤ 3. Example 3.7 flips the arrows to get coslice categories, and Example 3.8 takes C = Set with A a singleton — whose objects are sets with a chosen element, that is, pointed sets, and whose morphisms are the functions preserving the chosen point.

Self-check 2. In Example 3.3, why is associativity automatic?

Uniqueness of parallel morphisms. Both (hg)f and h(gf) are morphisms from the source of f to the target of h. Transitivity is what guarantees they exist; the fact that Hom-sets have at most one element is what makes them equal. Distinguishing existence from uniqueness here is the whole verification, and the same observation makes every mono and epi check in Segment 3 collapse.

Segment 3 · ~30 min

Morphisms, and where set intuition fails

Aluffi opens §4 with the methodological point: we would like to single out kinds of morphisms the way we single out injective, surjective and bijective functions, but "defining qualities of morphisms by their actions on 'elements' is not an option in the general setting, because objects of an arbitrary category do not (in general) have 'elements'." So every definition below is a statement about composition only.

Definition 4.1. A morphism f ∈ HomC(A, B) is an isomorphism if it has a two-sided inverse under composition: some g ∈ HomC(B, A) with gf = 1A and fg = 1B. — Aluffi §I.4, p. 27

Proposition 4.2. The inverse of an isomorphism is unique. — Aluffi §I.4, p. 28

Proof. If g1 and g2 both invert f, compose f on the left by one and on the right by the other, then apply associativity: g1 = g11B = g1(fg2) = (g1f)g2 = 1Ag2 = g2. ∎

Aluffi points out that the argument proves more than it states: if f has a left-inverse g1 and a right-inverse g2, then f is an isomorphism and g1 = g2. Since the inverse is unique, writing f−1 is unambiguous.

Proposition 4.3 collects the consequences: each 1A is an isomorphism and is its own inverse; if f is an isomorphism then so is f−1, with (f−1)−1 = f; and a composite of isomorphisms is an isomorphism, with (gf)−1 = f−1g−1. Aluffi flags the reversal explicitly. Two objects are isomorphic, written A ≅ B, when an isomorphism between them exists, and the three parts of Proposition 4.3 are precisely reflexivity, symmetry and transitivity of that relation.

One consequence deserves its own line. An automorphism of A is an isomorphism A → A, and AutC(A) is the set of them. Composition is associative on it, 1A is in it, it is closed under composition, and every element has an inverse in it. So AutC(A) is a group — for every object of every category. Aluffi's next line is "We will soon devote all our attention to groups!"

Definition 4.7. f ∈ HomC(A, B) is a monomorphism if for all objects Z and all α′, α″ ∈ HomC(Z, A), fα′ = fα″ implies α′ = α″.

Definition 4.8. f is an epimorphism if for all objects Z and all β′, β″ ∈ HomC(B, Z), β′f = β″f implies β′ = β″. — Aluffi §I.4, p. 29

Cancellation on the left, cancellation on the right. Example 4.9 records that in Set these are exactly the injections and the surjections, so the definitions do generalise what they were built to generalise. And that success is the trap.

Guided proof. Let C be the category built from ≤ on ℤ, as in Example 3.3. Prove that every morphism of C is both a monomorphism and an epimorphism, and that the only isomorphisms of C are the identities. Conclude that "monomorphism and epimorphism together imply isomorphism" is false. Write your argument before revealing the model answer.

Reveal the model answer

Every morphism is a monomorphism. Let f : a → b and suppose α′, α″ : z → a satisfy fα′ = fα″. Both α′ and α″ lie in Hom(z, a), which has at most one element. So α′ = α″, and the implication holds. Note that f played no part in the argument: the condition is satisfied vacuously.

Every morphism is an epimorphism. The same argument with the arrows reversed: β′, β″ ∈ Hom(b, z) and that Hom-set has at most one element.

The only isomorphisms are the identities. Suppose f : a → b is an isomorphism, so there is g : b → a. Then a ≤ b and b ≤ a, hence a = b by antisymmetry of ≤. So an isomorphism goes from an object to itself; and Hom(a, a) contains only 1a. That is Example 4.5.

Conclusion. C has non-identity morphisms — 2 → 5, for instance. Each is both a monomorphism and an epimorphism and is not an isomorphism. So the implication fails. ∎

What to notice. The two halves fail for opposite reasons. Mono and epi hold for too few morphisms in the Hom-sets, making the conditions empty; iso fails because there are too few morphisms to build an inverse. Aluffi's comment is that the coincidence in Set "is a special feature of Set, and we should not expect it to hold automatically in every category". He names Ring as a respectable category where it also fails, and says it does hold in every abelian category — with the sting that Set is not one.

And notice where antisymmetry entered. Only in the third paragraph, and nowhere else. The mono and epi arguments never used it. That is the whole difference between a preorder and a poset, seen categorically.

The picture is the whole counterexample. Every arrow in it is a monomorphism and an epimorphism. Only the loops are isomorphisms.

You try. Example 4.6 defines a groupoid: a category in which every morphism is an isomorphism. Aluffi says the reader already knows many examples. Find two. Then decide, for a relation ∼ that is reflexive and transitive, exactly which extra property makes Example 3.3's category a groupoid — this is his Exercise 4.2 — and check your answer against the ≤-on-ℤ case, where the answer had better be that it is not a groupoid.

Then the harder half: at1-10 built a category from a partially ordered set and Aluffi builds one from a preorder. Using the guided proof, say in one sentence what antisymmetry contributes, phrased entirely in the language of this unit — no mention of ≤.

Self-check 3. In the ≤-on-ℤ category, why do the definitions of monomorphism and epimorphism hold vacuously?

At most one element per Hom-set. Both cancellation conditions say "if two parallel morphisms become equal after composing with f, they were equal" — and here any two parallel morphisms are equal to begin with, so there is nothing to prove and nothing being said about f. The first option is true of the category but is not the reason: even between related objects there is only one arrow, and that is what does the work.

Self-check 4. Aluffi proves AutC(A) is a group for every object A of every category C. What does that tell you about where groups come from?

They fall out of the axioms. No structure is added: associativity is a category axiom, 1A is a category axiom, closure and inverses come from Proposition 4.3. So "the symmetries of an object" is not a notion one has to define separately for each kind of object — it is a consequence of being in a category at all. The first option is a genuine theorem in some settings but is not what has been proved here, and Aluffi does not claim it.

Self-check 5. Which of these is Aluffi's stated reason for defining monomorphism by cancellation instead of by injectivity?

No elements. Aluffi says it directly in the opening paragraph of §4, and adds that this is why §§2.4–2.6 spent time analysing injectivity from several viewpoints: the element-free viewpoints are the ones that transfer. The last option is the opposite of the truth — Example 4.9 says mono and injective coincide in Set exactly, which is what makes the definition a reasonable generalisation in the first place.

Reveal the skeleton

1. A category is objects, Hom-sets and composition, and nearly all of it is about arrows. Definition 3.1: a class of objects, a set Hom(A, B) for each pair, identities, composition, associativity, unit laws, and disjointness of Hom-sets — the last saying that a morphism remembers its source and target, without which composition is not well defined. Objects form a class rather than a set because there is no set of all sets; a category whose objects do form a set is small. End(A) is a pointed set closed under composition.

2. The important examples are not sets with functions. Example 3.3 turns any reflexive transitive relation into a category: morphisms are bare pairs, Hom-sets have at most one element, reflexivity gives identities and transitivity gives composition, and associativity is free because parallel morphisms coincide. Antisymmetry is not assumed. Example 3.4 is the power set under inclusion, an instance of 3.3. Example 3.5 builds slice categories, whose objects are arrows into a fixed A and whose morphisms are commuting triangles — with Example 3.8 giving pointed sets as a special case.

3. Arrow-only definitions generalise the set notions and then break the relations between them. Isomorphism is a two-sided inverse; the inverse is unique by a five-step computation using only associativity and the unit laws; Aut(A) is therefore a group, for every object of every category. Mono and epi are left and right cancellation, and in Set they are exactly injective and surjective. But in the ≤-on-ℤ category every morphism is both, vacuously, while the only isomorphisms are the identities. Mono plus epi does not give iso — a special feature of Set, failing also in Ring, holding in abelian categories, of which Set is not one.
