Zigzag and levelset zigzag persistence (tda2-01)

Filtrations only ever add. What if the arrows were allowed to point both ways — spaces that grow and shrink?

You have a data set too large to build a Vietoris–Rips complex on. So you subsample, twice, and compute the homology of each sample. Both report one hole. Excellent — except that this tells you almost nothing, because the two computations were run on different complexes and there is no map between them. Is it the same hole? Or does the true data have many holes, each sample finding a different one?

Ghrist's fix is to stop comparing answers and start building a diagram. Interleave the two samples with a complex containing both, and you get a sequence of spaces whose arrows alternate in direction. The homology of that sequence is worth more than the sequence of homologies — but only if such a thing still has a barcode.

Prediction gate — commit before reading on. The one-parameter structure theorem of tda1-04 decomposed a persistence module into intervals by reading it as a graded module over 𝐤[t]. Predict what happens to that argument when some arrows point backwards.

Correct, and it is worth being precise about the loss. The whole force of the one-parameter theorem came from the module being a sequence of maps all pointing the same way, which is what let "advance one step" be multiplication by t. Reverse a single arrow and there is no such action, so the structure theorem is simply unavailable — not weakened, unavailable. Remarkably the conclusion survives anyway, for an entirely different reason: Gabriel's classification of representations of An quivers. That substitution of one theorem for another, with the same conclusion, is the content of Segment 1.

Why this matters for the mission: A zigzag module is a representation of an A_n quiver with arbitrary arrow directions, and by Gabriel's theorem it still decomposes into intervals — so a barcode survives even though tda1-04's monotone filtration does not. This is what lets persistence handle time-varying and sliced data.

Zigzag filtrations and the quiver that saves them

Zigzag filtration. A zigzag filtration 𝓕 of a complex K (space 𝕋) is a diagram

𝓕 : X0 ↔ X1 ↔ ⋯ ↔ Xn−1 ↔ Xn,

where each Xi is a subcomplex Ki ⊆ K (or subspace 𝕋i ⊆ 𝕋), and each Xi ↔ Xi+1 is either a forward inclusion Xi ↪ Xi+1 or a backward inclusion Xi ↩ Xi+1. — Dey & Wang §4.3, p. 125

Reverse arrows can be read as simplex deletions: the complex is now permitted to grow and shrink as the index advances. Taking p-th homology with coefficients in a field 𝐤 — ℤ2 throughout Dey and Wang — gives the zigzag persistence module

Hp𝓕 : Hp(X0)  φ0↔  Hp(X1)  φ1↔  ⋯,

a vector space at each node and a linear map on each arrow, pointing whichever way its inclusion does. Dey and Wang are careful to say that it is not obvious a priori that such a module admits barcodes — the existence of which is essential before persistence pairs or an algorithm can even be defined.

Definition 4.10 (quiver). A quiver Q = (N, E) is a directed graph, finite or infinite. A representation 𝕍(Q) of Q assigns a vector space Vi to every node Ni and a linear map vij : Vi → Vj to every directed edge (Ni, Nj). A zigzag persistence module is the special case in which the graph is finite and linear shaped — also known as An type — where every node has at most two directed edges incident to it. — Dey & Wang §4.3, Definition 4.10, pp. 126–127

Definition 4.11 (interval module). An interval module 𝓘[b,d], also called an interval or a bar, over an index set 0, 1, …, n with field 𝐤 is a sequence of vector spaces 𝓘[b,d] : I0 ↔ I1 ↔ ⋯ ↔ In where Ik = 𝐤 for b ≤ k ≤ d and 0 otherwise, the maps 𝐤 ← 𝐤 and 𝐤 → 𝐤 being identities. — Dey & Wang §4.3, Definition 4.11, p. 126

Theorem 4.10. Every quiver representation 𝕍(Q) for an An-type quiver Q has an interval decomposition, that is 𝕍(Q) ≅ ⊕i 𝓘[bi,di]. Furthermore this decomposition is unique up to isomorphism and permutation of the intervals. — Dey & Wang §4.3, Theorem 4.10, p. 127

Since the underlying graph of a zigzag persistence module is of An type, we get Hp𝓕 ≅ ⊕i 𝓘[bi,di], and that decomposition is the barcode. Ghrist tells the same story from the representation-theoretic side: Gabriel's classification theorem for quivers of type A reveals that the Structure Theorem classifies indecomposables of any linear sequence in which each node is an 𝔽-vector space and each arrow a linear transformation going either left or right. An indecomposable interval is, as before, a sequence of copies of 𝔽 with identity maps, respecting the arrow directions. In classical persistence all arrows go right; in consistency tests they alternate.

Remark 4.2 — the bars have changed shape. Unlike the bars defined in Chapter 3 for non-zigzag filtrations, an interval module here is non-zero on the closed index range b ≤ k ≤ d. So a zigzag bar [b, d] is closed at both ends: index d is the last index at which the class is present, not the first at which it is absent. — Dey & Wang §4.3, Remark 4.2, p. 127

Worked example 1: reading the barcode

Example. For Dey's Figure 4.4 filtration with H1 bars [0,4], [1,1], [3,4], [4,4], compute dim H1(Ki) at each index.

The counting rule. Theorem 4.10 gives H1𝓕 ≅ ⊕i𝓘[bi,di], and an interval module contributes exactly one dimension at index k when bi ≤ k ≤ di and none otherwise. So the dimension at index k is the number of bars whose closed range contains k.

index kbars containing kdim H1(Kk)
0[0,4]1
1[0,4], [1,1]2
2[0,4]1
3[0,4], [3,4]2
4[0,4], [3,4], [4,4]3

What the bar [0,4] means and the dimensions do not. Reading only the sequence 1, 2, 1, 2, 3 you would know how many one-dimensional holes are present at each stage and nothing more. The bar [0,4] says something the sequence cannot: that a single class is carried across every map of the diagram. That is exactly Ghrist's consistency question — a long bar means a homological feature is sampled consistently over the sequence — and it is why the homology of a sequence is worth more than a sequence of homologies.

Worked example 2 (faded): a bar of length one. The bar [1,1] occupies a single index. What must be happening at the two arrows on either side of index 1?

At the left end. The class is present at index 1 but the bar does not extend to index 0. If the arrow between them points forward, K0 ↪ K1, then the class is not in the image of φ0 — it is ⟨your step: born how?⟩. If instead the arrow points backward, K0 ↩ K1, then the class exists at index 1 without coming from index 0, which happens because ⟨your step: what has been removed?⟩.

At the right end. Symmetrically: a forward arrow out of index 1 kills the class by sending it to zero, while a backward arrow out of index 1 means the class is simply not in the image coming from index 2.

The moral. In a monotone filtration each endpoint has exactly one explanation. In a zigzag each endpoint has two, decided by the direction of the adjoining arrow — which is precisely why the bookkeeping in Segment 2 needs four kinds of endpoint rather than one.

Gap solutions: the class is newly born at index 1, by the addition of simplices; and in the backward case, simplices present in K0 have been deleted, and their removal has opened up a cycle that was previously filled.

Definition 4.12 (representative cycles). For a zigzag filtration 𝓕 and an interval [b,d] in Dgmp(𝓕), a set of representative p-cycles is an indexed set {ci ⊆ Ki : i ∈ [b,d]} of p-cycles whose classes are carried to one another across the interval, and which genuinely begin and end there — for b > 0, [cb] is not in the image of φb−1 when that arrow points into index b, and symmetrically at the right endpoint. — Dey & Wang §4.3, Definition 4.12, p. 128

Theorem 4.11. Let 𝓕 : K0 ↔ ⋯ ↔ Kn be a zigzag filtration with Hp(K0) = 0 and A an index set. Then Hp𝓕 is equal to — not merely isomorphic to — a direct sum of interval submodules ⊕α∈A𝓘[bα,dα] if and only if each 𝓘[bα,dα] is induced by a set of representative p-cycles for [bα, dα], where Dgmp(𝓕) = {[bα, dα]}. — Dey & Wang §4.3, Theorem 4.11, p. 129

The single word being upgraded is "isomorphic". Theorem 4.10 supplies an abstract decomposition; Theorem 4.11 says exactly when the decomposition can be realised on the nose, by actual cycles sitting in the actual complexes — and the answer is: precisely when representative cycles exist. That matters in practice for the same reason it mattered in at2-08: only a concrete representative can be localised, drawn, or fed to anything downstream.

Self-check 1. Why is a zigzag persistence module a quiver representation of An type?

An type is a condition on the shape of the graph, not on the directions of its arrows or the size of its spaces — that is exactly why it covers the zigzag case. The second option describes ordinary persistence, a special case. Theorem 4.10 is explicitly noted not to require finite-dimensionality, so the third is not the criterion either.

Self-check 2. A zigzag bar is written [b, d] with both ends closed. What is present at index d?

Remark 4.2 flags this precisely because it differs from the ordinary convention. The interval module is 𝐤 for b ≤ k ≤ d inclusive, so the class lives at index d and is gone by d + 1. Carrying the Chapter 3 half-open reading across is the standard off-by-one error here, and it shifts every death by one index.

Levelset zigzag: slicing instead of accumulating

Now specialise to a function. Standard persistence filters by growing sublevel sets; levelset zigzag persistence replaces the sublevel sets by levelsets and interval sets, with the maps from each levelset into its two adjacent interval sets giving the alternating arrows. For a real value s and an interval I ⊆ ℝ, write X=s for the levelset f−1(s) and XI for the interval set f−1(I).

Definition 4.14 (critical and regular values). An open interval I ⊆ ℝ is a regular interval if there exist a space Y and a homeomorphism Φ : Y × I → XI with f ∘ Φ the projection onto I, and with Φ extending to a continuous Φ̃ : Y × Ĩ → XĨ on the closure. f is of Morse type if each levelset X=s has finitely generated homology groups and there are finitely many critical values a0 = −∞ < a1 < ⋯ < an < an+1 = +∞. — Dey & Wang §4.5, Definition 4.14, p. 138

The point of "regular" is that over such an interval the space is a product: nothing happens topologically as the value varies. All the change is concentrated at the finitely many critical values, which is what makes a finite diagram sufficient.

Definition 4.15 (compatible complex). A complex K is compatible with the levelsets of a PL-function f : |K| → ℝ if for every simplex σ of K, the function values of points in |σ| contain at most one critical value of f. Given a PL-function on K, one can always make K compatible by barycentric subdivision. — Dey & Wang §4.5, Definition 4.15, pp. 140–141

Proposition 4.14. Let K be compatible with the levelsets of f and let X = |K|. Then X(ai,aj) deformation retracts to |K(i,j)| for any two critical values ai < aj. Therefore the zigzag modules induced by the space and the simplicial levelset zigzag filtrations are isomorphic. — Dey & Wang §4.5, Proposition 4.14, p. 141

This is the licence to compute. The space-level object is not finite; the simplicial one is, and Proposition 4.14 says they carry the same module, so the barcode computed from the finite object is a statement about the space.

Worked example 3: what the levelset barcode recovers

Example. Compare the sublevel-set barcode of tda1-08 with the levelset zigzag barcode.

Step 1 — the sublevel-set side. With si ∈ (ai, ai+1) a regular value, set X[0,i] = f−1[s0, si] = f−1(−∞, si], giving the sublevel-set diagram 𝓧 : X[0,0] → X[0,1] → ⋯ → X[0,n], which for a PL-function converts to the simplicial filtration 𝓚 with K[0,i] = {σ ∈ K : f(σ) ≤ ai}.

Step 2 — its bars have one shape. Every bar is [ai, aj): closed on the left because the class exists at K[0,i], open on the right because it does not exist at K[0,j]. There are two kinds — those with j ≤ n, bounded on the right, and those of the form [ai, ∞) = [ai, an+1), which are the infinite bars of tda1-05. The infinite ones correspond to the essential classes, since Hp(K) ≅ ⊕i[ai, ∞).

Step 3 — the correspondence. Writing 𝓚 for the sublevel-set filtration and 𝓚′ for the levelset one, Theorem 4.15 states that for every p ≥ 0:

(a) for j ≠ n + 1, [ai, aj) is a bar of Dgmp(𝓚) if and only if it is a bar of Dgmp(𝓚′);
(b) [ai, an+1) is a bar of Dgmp(𝓚) if and only if either [ai, aj] is a closed-closed bar of Dgmp(𝓚′) for some aj > ai, or (aj, ai) is an open-open bar of Dgmp−1(𝓚′) for some aj < ai.

Step 4 — read it. The finite bars transfer unchanged: nothing is lost. The infinite bars are the interesting case — an essential class, which the sublevel-set barcode could only record as "never dies", reappears in the levelset barcode as a finite object, either a closed-closed bar in the same degree or an open-open bar one degree down. Infinite information has been traded for finite information, which is the practical gain of the levelset construction.

Why four endpoint types. A monotone filtration offers exactly one reason for a bar to end: the class dies going forward. A zigzag offers two at each end, decided by the direction of the adjoining arrow — the class fails to come from the previous term, or fails to map into the next. Closed and open at each end gives four combinations, which is precisely the vocabulary Theorem 4.15 needs.

Worked example 4 (faded): making a complex compatible. Let f be a PL-function on K with critical values a1 < a2, and suppose some simplex σ has function values on |σ| spanning both.

The problem. Definition 4.15 requires each simplex to see at most ⟨your step: how many critical values?⟩, and σ violates it.

The repair. Barycentric subdivision replaces σ by smaller simplices. Iterating it makes the simplices as small as required, and since the critical values are ⟨your step: what property of the critical set makes this work?⟩, eventually no simplex spans two of them.

What is then licensed. With K compatible, Proposition 4.14 applies: the interval sets deformation retract onto the corresponding subcomplexes, and the space-level and simplicial zigzag modules are isomorphic. Only then may the finite computation be read as a statement about |K|.

Gap solutions: at most one critical value; and the critical values are finite in number and separated, so there is a positive minimum gap between consecutive ones.

Self-check 3. What does Proposition 4.14 actually license?

The proposition is a bridge between a computable object and an uncomputable one: the interval sets deformation retract onto subcomplexes, so the induced zigzag modules agree. Without it, a barcode computed simplicially would be a fact about a triangulation rather than about the space. Morse type is a hypothesis assumed earlier, in Definition 4.14, not a conclusion; and nothing here claims the barcode is a complete invariant.

Self-check 4. An essential class has an infinite sublevel-set bar [ai, ∞). What happens to it in the levelset barcode?

Theorem 4.15(b) is exactly this statement, and the degree shift in the second alternative is the surprising part. Nothing is lost — the theorem is an "if and only if" in both clauses, so the two barcodes determine each other — but the essential classes are re-encoded as finite bars, which is why levelset zigzag is attractive for functions whose sublevel-set barcode is dominated by infinite bars.

Self-check 5. Why does the levelset barcode need four endpoint types where the sublevel-set barcode needs one?

The vocabulary is forced by the diagram, not by the geometry. In a monotone filtration the only way a bar can end is by the class dying under a forward map, so one convention — closed on the left, open on the right — suffices. Reverse some arrows and each endpoint admits two readings, exactly as worked example 2 spelled out for the bar [1,1].

Guided proof

Prompt. Let 𝕍 be a zigzag persistence module over indices 0, …, n, and suppose 𝕍 ≅ ⊕i∈A𝓘[bi,di] by Theorem 4.10. Prove that dim Vk equals the number of indices i ∈ A with bi ≤ k ≤ di, and deduce that the barcode determines the dimension sequence but that the dimension sequence does not determine the barcode. For the second part, exhibit two zigzag modules over indices 0, 1, 2 with the same dimensions at every index but different barcodes.

Hint: for the counterexample, think about a class that survives all the way across versus two classes each surviving part of the way.

Click to reveal model answer

Model answer, first part. An isomorphism of zigzag modules is in particular an isomorphism of vector spaces at each index, so dim Vk = dim (⊕i∈A𝓘[bi,di])k. Dimension is additive over direct sums, so this is Σi∈A dim (𝓘[bi,di])k. By Definition 4.11 each summand contributes dim 𝐤 = 1 when bi ≤ k ≤ di and dim 0 = 0 otherwise. Hence the sum counts exactly the intervals whose closed range contains k. ∎

Second part. The first part shows the barcode determines every dim Vk, so the map from barcodes to dimension sequences is well defined. It is not injective. Over indices 0, 1, 2, take

𝕍 = 𝓘[0,2]   and   𝕎 = 𝓘[0,1] ⊕ 𝓘[2,2].

Counting intervals containing each index: 𝕍 has dimensions 1, 1, 1 and 𝕎 has dimensions 1, 1, 1. The barcodes {[0,2]} and {[0,1], [2,2]} are different multisets, so by the uniqueness clause of Theorem 4.10 the two modules are not isomorphic. ∎

What the counterexample is really saying. 𝕍 has a single class carried across every map; 𝕎 has one class that dies and another, unrelated, that appears. No amount of dimension counting can tell them apart, because dimension is computed index by index and the difference lives in the maps. This is Ghrist's consistency question in its smallest possible form: both diagrams report "one hole throughout", and only one of them means it.
