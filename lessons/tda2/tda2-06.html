Reeb graphs and their distances (tda2-06)

Stand a doughnut on its end and slice it horizontally. Squash each slice to a point and watch a solid become a wire.

Almost every horizontal cut of the standing torus is one circle or two, depending on whether the knife is inside the hole. Collapse each circle to a single point and the whole surface shrinks to a loop of wire whose shape records exactly where the cuts split and rejoined. That wire is the Reeb graph, and it is a quotient in the sense of top-12 — you are dividing X by the relation "lies in the same connected component of the same level set".

What makes this more than a picture is the arithmetic. The torus has β1 = 2. The wire is a single loop. Something was lost and something was kept, and Dey and Wang say precisely which is which.

Prediction gate — commit before reading on. Let X be a torus and f the height function with X standing on end, so that β1(X) = 2. Predict β1 of the Reeb graph Rf.

Correct, and the halving is Theorem 7.3(a): for a Morse function on a connected compact orientable 2-manifold, β1(Rf) = β1(X)/2. The reason a loop can die is that some loops of X lie inside level sets — the meridian circle of the standing torus is a single contour, and a contour is collapsed to a point by construction. The reason a loop can live is that the other generator climbs through the level sets and cannot be collapsed. Segment 3 turns that intuition into the horizontal/vertical decomposition and Theorem 7.4, which explains the factor of two rather than merely reporting it.

Why this matters for the mission: The Reeb graph is the quotient of X by the relation "lies in the same connected component of a level set of f" — top-12's quotient topology applied to a scalar field. It retains branching information that tda1-08's sublevel-set barcode discards, and it carries its own interleaving and functional-distortion distances.

Segment 1 · ~25 min

The quotient, and reading the graph it produces

Definition 7.1 (Reeb graph). Define an equivalence relation ∼ on X by asserting x ∼ y if and only if (i) f(x) = f(y) = α and (ii) x and y belong to the same connected component of the levelset f−1(α). Let [x] denote the equivalence class to which a point x ∈ X belongs. The Reeb graph Rf of f : X → ℝ is the quotient space X/∼, that is, the set of equivalence classes equipped with the quotient topology. Let Φ : X → Rf, x ↦ [x], denote the quotient map. — Dey & Wang §7.1, Definition 7.1, pp. 208–209

Each connected component of a levelset is called a contour, and the quotient collapses every contour to a single point. Two structures come with it for free. First, since f is constant on each contour, it descends: define f̃ : Rf → ℝ by f̃(z) = f(x) for any pre-image x ∈ Φ−1(z). Any two pre-images of z are equivalent, and clause (i) of ∼ says equivalent points share an f-value, so the choice of x does not matter. Dey and Wang usually drop the tilde and write f(z), keeping f̃ only to stress the change of domain.

Second — and this is the hypothesis the word "graph" is resting on — Definition 7.1 by itself does not produce a graph. Quotient a pathological X by a pathological relation and you get a pathological space. So from here on Dey and Wang tacitly assume f is levelset tame: (i) each levelset f−1(a) has finitely many components, each of them path connected; and (ii) f is of Morse type, in the sense of Definition 4.14, which tda2-01 stated in full. Morse functions on a compact smooth manifold and PL-functions on finite simplicial complexes are both levelset tame, and under the hypothesis Rf is a finite one-dimensional regular CW complex.

Visual: the sweep, and the wire it leaves behind

The picture is Dey and Wang's Figure 7.2 in miniature, and it also fixes the vocabulary. Treat Rf as a graph (V, E) with f̃ monotone along each edge — if monotonicity fails somewhere along a 1-cell, insert a node there, and tameness guarantees only finitely many such insertions are needed. Then for a node x, let the up-degree (resp. down-degree) be the number of incident edges with higher (resp. lower) f̃-value than x. A node is regular when both are 1, and critical otherwise: a minimum when the down-degree is 0, a maximum when the up-degree is 0, a down-fork when the down-degree exceeds 1, an up-fork when the up-degree exceeds 1. Criticality can be mixed — down-degree 0 with up-degree 2 is both a minimum and an up-fork.

Monotonicity at the regular points has a consequence worth pausing on: the Reeb graph together with its function is completely described, up to homeomorphisms preserving the function, by the function values at the critical points. Along an arc of regular points f̃ climbs without turning, so a function-preserving homeomorphism may reparametrise that arc however it likes; nothing there is data. All the information sits at the forks and the extrema — which is exactly why sweeping X in increasing f and recording where components appear, vanish, merge and split reconstructs the whole object.

Definition 7.2 (merge tree; split tree). Define x ∼M y if and only if f(x) = f(y) = a and x is connected to y within the sublevel set f−1((−∞, a]). Then the quotient space TM = X/∼M is the merge tree with respect to f. Alternatively, if we define x ∼S y if and only if f(x) = f(y) = a and x is connected to y within the superlevel set f−1([a, +∞)), then the quotient space TS = X/∼S is the split tree with respect to f. — Dey & Wang §7.1, Definition 7.2, p. 211

Same recipe, different set to be connected in: levelset for the Reeb graph, sublevel set for the merge tree, superlevel set for the split tree. For levelset tame f both TM and TS are finite trees. A loop-free Reeb graph is called a contour tree, and when Rf is loop-free it is uniquely decided by, and computable from, the merge and split trees of f. Finally, run Definition 7.1 with a map f : X → Z into a general metric space instead of ℝ and the quotient is called the Reeb space — the object §9.3 works with, and the one tda2-07 will meet under the name mapper.

Self-check 1. Why does f̃(z) = f(x) for x ∈ Φ−1(z) define a function at all?

Well-definedness is exactly clause (i): x ∼ y already requires f(x) = f(y). Clause (ii) does something else — it decides how many points of Rf sit over a given value. The second option is false in the strongest way: Φ collapses each contour, so it is as far from injective on a contour as a map can be. The third is false too — a class is a whole contour, which is generally not a point; it is a point of the quotient, which is not the same thing.

Self-check 2. A node of a Reeb graph has down-degree 2 and up-degree 2. How is it classified?

Regular means both degrees equal 1, not merely equal to each other. Down-degree 2 exceeds 1 and up-degree 2 exceeds 1, so the node is a down-fork and an up-fork at once. Dey and Wang say explicitly that a critical point can be degenerate, carrying more than one type of criticality, and give down-degree 0 with up-degree 2 — a minimum that is also an up-fork — as the example. There is no precedence rule.

Segment 2 · ~25 min

Computing it, and where the log factor comes from

Take K a simplicial complex and f : |K| → ℝ piecewise linear. Since Rf depends only on the connectivity of each levelset, for a generic f — no two vertices sharing a function value — the Reeb graph depends only on the 2-skeleton of K. So assume K = (V, E, T) is a simplicial 2-complex with m = nv + ne + nt simplices in all.

The levelset f−1(a) meets edges of E in points and triangles of T in segments, so it is itself a graph: the pre-image graph Ga = (Wa, Fa), where each vertex of Wa corresponds to an edge of E cut by the levelset, and each edge of Fa joins two of them and corresponds to a pair of edges of E adjoining a triangle of T. Connected components of Ga correspond to connected components of f−1(a), and Φ sends each to one point of Rf — so maintaining the components of Ga is literally maintaining the points of the Reeb graph. Because f is piecewise linear, the combinatorial structure of Ga can change only as the sweep passes a vertex v ∈ V, and then only simplices incident to v are involved: O(sv) insertions and deletions, where sv counts the simplices incident on v.

Definition 7.3 (augmented Reeb graph). Given a PL-function f : |K| → ℝ defined on a simplicial complex K = (V, E, T), let Rf be its Reeb graph and Φf : |K| → Rf(K) be the associated quotient map. The augmented Reeb graph of f, denoted R̂f, is obtained by inserting each point in Φf(V) := {Φf(v) | v ∈ V} as graph nodes to Rf (if it is not already in). — Dey & Wang §7.2, Definition 7.3, p. 212

For a PL-function every critical point of Rf is necessarily the image of some vertex of K, so the critical points already form a subset of Φf(V); augmentation adds the remaining images as degree-two nodes. Nothing topological changes — you are subdividing arcs — but the algorithms find it convenient to carry a node for every input vertex.

Theorem 7.1. Given a PL-function f : |K| → ℝ, let m denote the total number of simplices in the 2-skeleton of K. One can compute the (augmented) Reeb graph Rf of f in O(m log m) time. — Dey & Wang §7.2.1, Theorem 7.1, p. 217

The algorithm is REEB-SWEEPALG: sort V by f-value, and for each v in turn collect the components of the pre-image graph in the lower star, update the pre-image graph, collect the components in the upper star, and attach arcs in R accordingly. The whole cost is O(m) operations on a data structure that must maintain connectivity of Ga under insertions and deletions. Dynamic connectivity under deletions is the expensive half of that problem in general — and the following is where the log factor is actually won.

Worked example 1: why deletions are free here

The set-up. Dey and Wang observe that this is an offline dynamic connectivity problem: every insertion and deletion is known in advance, because the sweep order is known in advance. They exploit it by giving each pre-image edge a weight — the time, that is the f-value, at which it will be deleted from Ga — and maintaining a maximum spanning forest under those weights. Their claim is that a deleted tree edge then never requires the search for a replacement edge that makes deletion costly: it simply breaks its tree.

Step 1 — state what has to be shown. Deleting a non-tree edge is free. The expensive case is deleting an edge e = (u, v) of the maximum spanning forest, because u and v may still be connected by some other path, in which case a replacement must be found. So the claim to establish is: at the moment e is deleted, no such path survives.

Step 2 — the lemma that does it. Dey and Wang assert the consequence rather than deriving it, so we supply the standard exchange argument, stated as Lemma A below.

Lemma A (cycle property, maximum-weight version). Let G be a weighted graph and C a cycle in G on which some edge e has strictly smaller weight than every other edge of C. Then e lies in no maximum spanning forest of G.

Proof. Suppose e = (u, v) belongs to a maximum spanning forest F. Removing e splits its tree in two; let S be the vertex set of the part containing u, so that v ∉ S. The path C − e runs from u ∈ S to v ∉ S, so some edge g of it has exactly one endpoint in S. Adding g to F − e joins S to a different component of F − e and so creates no cycle: F − e + g is acyclic, spans the same vertices and has the same number of edges as F, hence is again a spanning forest. Its total weight exceeds that of F, since w(g) > w(e) by hypothesis. That contradicts maximality of F. ∎

Step 3 — apply it. Suppose, at the moment e is deleted, that u and v were still joined by a path P in Ga. Every edge g of P is still alive at that moment, so g is deleted no earlier than e — and since the offline schedule is a sequence of operations, reading the weight off an edge's position in that sequence rather than off the raw f-value makes the comparison strict, w(g) > w(e), even when several pre-image edges leave at one vertex. Then e is the strict minimum on the cycle e + P, so by Lemma A e cannot belong to a maximum spanning forest — contradicting the assumption that e was a tree edge. Hence no replacement path exists, and the deletion merely breaks the tree.

Step 4 — read off the bound. With replacement searches eliminated, a standard dynamic tree structure — Dey and Wang name link-cut trees — maintains the maximum spanning forest in O(log m) amortised time per find, insert or delete. The sweep performs O(m) such operations and the initial sort costs O(n log n). Total: O(m log m), which is Theorem 7.1.

Step 5 — what the argument needed. Only one thing, and it is worth naming: the weights had to be the deletion times, and those are knowable only because the problem is offline. Run the same sweep with adversarially arriving updates and the weighting is unavailable, the cycle argument evaporates, and one is back to general dynamic connectivity.

Theorem 7.2. Given a PL-function f : |K| → ℝ defined on a simplicial 2-complex K with m simplices, one can compute the (augmented) Reeb graph in O(m log m) expected time. — Dey & Wang §7.2.2, Theorem 7.2, p. 220

The randomised algorithm REEB-RANDOMALG reaches the same bound by a different route: rather than sweeping, it models the quotient map directly. Take a random permutation of V; for i = 1 to nv, collapse the contour of fi−1 passing through vi and let fi be the induced PL-function on the collapsed complex Ki. The collapse is performed triangle by triangle on those triangles having vi as mid-vertex — the vertex whose height ranks second of the three — splitting neighbouring triangles as needed, until none is left.

Two things are then true. First, the output is a graph: no vertex of Knv is the mid-vertex of a triangle, and under the standing genericity assumption a triangle's three vertices have distinct heights and so it always has a mid-vertex, so there are no triangles left at all, and the complex is a simplicial 1-complex — the augmented Reeb graph by construction. Second, the cost for v is proportional to the number of triangles the contour through v meets, which in the worst case is nt, giving a worst-case O(nvnt) that Dey and Wang say is tight. Randomising the order defeats the worst case: an input triangle is split O(log nv) times in expectation — the argument is in the spirit of the path length in a randomly built binary search tree — so each collapse costs O(log m) expected time and the total is O(m log m) in expectation.

Self-check 3. Which feature of the Reeb-graph sweep licenses the maximum-spanning-forest weighting in Worked example 1?

The weights are the deletion times, so knowing them in advance is precisely what makes the scheme definable — that is Dey and Wang's own emphasis on the offline character. Planarity plays no role in the argument. The third option describes a genuine special case they mention in the notes — for a triangulated 2-manifold the pre-image graph is a collection of disjoint loops at a generic value, which is how the earlier O(m log m) algorithm for surfaces worked — but §7.2.1's algorithm is stated for a general simplicial complex and does not assume it.

Segment 3 · ~25 min

What survives the collapse, and how far apart two graphs are

Homology of a graph is nontrivial only in dimensions 0 and 1, so for a Reeb graph there is exactly one question in each: how many components, and how many independent loops.

Fact 7.1. For a tame function f : X → ℝ, β0(X) = β0(Rf) and β1(X) ≥ β1(Rf). — Dey & Wang §7.2.3, Fact 7.1, p. 220

The β0 equality holds because Rf is the quotient X/∼ and each equivalence class is itself connected, being a component of a levelset — collapsing connected sets cannot merge or create components. The β1 inequality can be proved directly, and it is also a byproduct of Theorem 7.4 combined with Fact 7.2 below; the guided proof asks you to run that deduction. One consequence Dey and Wang draw immediately: if X is simply connected then Rf is loop-free.

Theorem 7.3. Let f : X → ℝ be a Morse function defined on a connected and compact 2-manifold. Then (a) if X is orientable, β1(Rf) = β1(X)/2; and (b) if X is non-orientable, β1(Rf) ≤ β1(X)/2. — Dey & Wang §7.2.3, Theorem 7.3, p. 220

That is the prediction gate settled: the standing torus has β1(X) = 2 and an orientable X, so its Reeb graph has β1 = 1, exactly the loop in the canvas. Note how much more Theorem 7.3 assumes than Fact 7.1 — Morse rather than merely tame, and a connected compact 2-manifold rather than an arbitrary triangulable space — and note what it buys: an exact count instead of a bound. The next construction explains the halving instead of merely recording it.

Horizontal and vertical homology. Write X=a := f−1(a). A class h ∈ Hp(X) is horizontal if there is a finite set of values {ai}i∈A such that h has a pre-image under the inclusion-induced map Hp(⋃i∈A X=ai) → Hp(X). The horizontal classes form a subgroup H̄p(X) — the trivial class is horizontal and a sum of horizontal classes is horizontal — the horizontal homology group of X with respect to f. The vertical homology group is the quotient

Ȟp(X) := Hp(X) / H̄p(X).

— Dey & Wang §7.2.3, pp. 220–221

Fact 7.2. By definition, rank(Hp(X)) = rank(H̄p(X)) + rank(Ȟp(X)). — Dey & Wang §7.2.3, Fact 7.2, p. 221

The words are chosen for the picture in which f is height: a horizontal class can be represented inside finitely many level sets, so it lies flat; a vertical class cannot, so it must climb. The meridian of the standing torus is horizontal — it is a contour — and the longitude is not. Collapsing contours is precisely killing the horizontal part, and the theorem says that is all it kills.

Theorem 7.4. Given a levelset tame function f : X → ℝ, let Φ̌ : Ȟ1(X) → H1(Rf(X)) be the homomorphism induced by the surjection Φ : X → Rf(X). Then the map Φ̌ is an isomorphism. Furthermore, for any vertical homology class h ∈ Ȟ1(X), we have that height(h) = height(Φ̌(h)). — Dey & Wang §7.2.3, Theorem 7.4, p. 222

Two remarks on the statement. Φ∗ sends H̄1(X) to 0, so it descends to the quotient; and the target needs no quotient of its own because H̄1(Rf(X)) = 0 — levelset tameness makes every levelset of the Reeb graph a finite set of disjoint points, and a finite point set supports no nonzero 1-cycle. The height clause is the quantitative half: the height of a class h is the infimum of heights of closed intervals I whose interval set XI already contains a cycle of h, and the collapse changes none of it.

Proposition 7.5. One has Dgm0(fX) = Dgm0(fR) where the diagrams are for the zeroth levelset zigzag persistence. — Dey & Wang §7.2.3, Proposition 7.5, p. 223

This is tda2-01's levelset zigzag reappearing as a computational shortcut. The proof is a ladder between the two levelset zigzag modules whose vertical maps are isomorphisms, because Xij and Rij = Xij/∼ have the same number of components; the horizontal maps are induced by inclusions, every square commutes, so the modules are isomorphic. The payoff is stated plainly by Dey and Wang: processing the underlying space of a simplicial complex is much harder than processing a graph, so compute the Reeb graph first and read the zeroth diagram off it.

What the mission strip claims, and what §7.1–7.3 establish. The strip says the Reeb graph "retains branching information that tda1-08's sublevel-set barcode discards". What this unit's sources actually license is narrower and worth stating exactly. Dey and Wang open the chapter by contrasting the two summaries in kind — persistence produces barcodes as a simplified signature of the function, whereas the Reeb graph is a one-dimensional skeleton representing a simplification of the domain with the function taken into account, and "the summarizations produced by the two differ in a fundamental way". The branching is then made explicit as the up-fork and down-fork classification of §7.1, and Proposition 7.5 gives the determination in one direction: the graph is enough to recover the zeroth levelset zigzag diagram. What is not proved anywhere in §7.1–7.3 is a converse — no theorem here says a barcode fails to determine the graph — and the sublevel-set barcode itself belongs to tda1-08's sources, not to Dey's Chapter 7; the sublevel-set object appearing here is the merge tree of Definition 7.2. Fact 7.1 also records loss in the other direction: β1(X) ≥ β1(Rf), so the graph is not a complete invariant of X either.

Distances: two of them, and they agree up to a constant

Rename Rf as 𝔽 with function f, and let 𝔾 with g be a second Reeb graph; both are finite simplicial 1-complexes with the function strictly monotone on each edge. If they were "the same" there would be a function-preserving isomorphism. Both distances measure deviation from that, differently.

Definition 7.4 (ε-smoothing). Given a Reeb graph (𝔽, f), its ε-smoothing, denoted Sε(𝔽, f), is the Reeb graph of the function fε : 𝔽ε → ℝ where fε(x, t) = f(x) + t for x ∈ 𝔽 and t ∈ [−ε, ε], with 𝔽ε := 𝔽 × [−ε, ε]. In other words Sε(𝔽, f) = 𝔽ε/∼fε, where x ∼fε y if and only if x, y ∈ 𝔽ε are from the same contour of fε. — Dey & Wang §7.3.1, Definition 7.4, p. 224

Smoothing thickens the graph by ε in the function direction and then takes the Reeb graph again; the quotiented inclusion ι(x) = [x, 0] embeds the original into it. The two limits are what motivate the definition. For ε large enough, Sε(A, fa) is a single segment with monotone function values, whatever A was — so interleaved maps always exist for large ε and the infimum below is over a nonempty set. At ε = 0 the conditions force ψ = φ−1, an honest function-preserving isomorphism.

Definition 7.5 (Reeb graph interleaving). A pair of continuous maps φ : (𝔽, f) → Sε(𝔾, g) and ψ : (𝔾, g) → Sε(𝔽, f) are ε-interleaved if (i) both of them are function-preserving, and (ii) the diagram built from ι, ιε, φε and ψε commutes. — Dey & Wang §7.3.1, Definition 7.5, p. 225

Definition 7.6 (interleaving distance). dI(𝔽, 𝔾) = inf{ε | there exists a pair of ε-interleaved maps between (𝔽, f) and (𝔾, g)}. — Dey & Wang §7.3.1, Definition 7.6, p. 226

The commutativity splits into two halves that mirror the rectangular and triangular commutativity of persistence-module interleaving in Definition 3.16, and tda1-06's interleaving distance is the same idea one category over. Rectangular commutativity is the easy half — Dey and Wang say it is easy to verify — and it constrains φ alone, or ψ alone. The triangular half is the key technicality, because it is the only place where φ and ψ interact: it is what says going out by φ and back by ψ returns you to where you started, up to a shift of 2ε.

Definition 7.7 (function-induced metric). Given a path π from u to v in a Reeb graph (A, fa), the height of π is height(π) = maxx∈π fa(x) − minx∈π fa(x). Let Π(u, v) denote the set of all paths between u, v ∈ A. The function-induced metric dfa : A × A → ℝ induced by fa is dfa(u, v) = minπ∈Π(u,v) height(π). — Dey & Wang §7.3.2, Definition 7.7, p. 226

Equivalently, dfa(u, v) is the minimum length of a closed interval I ⊂ ℝ such that u and v lie in the same path component of fa−1(I). For a finite Reeb graph it is a proper metric, so (A, dfa) is a metric space — and once a Reeb graph is a metric space, the Gromov–Hausdorff machinery becomes available.

Definition 7.8 (functional distortion distance). Given Reeb graphs (𝔽, f) and (𝔾, g) and continuous maps Φ : 𝔽 → 𝔾 and Ψ : 𝔾 → 𝔽, set C(Φ, Ψ) = {(x, y) ∈ 𝔽 × 𝔾 | Φ(x) = y, or x = Ψ(y)} and D(Φ, Ψ) = sup(x,y),(x′,y′)∈C(Φ,Ψ) ½|df(x, x′) − dg(y, y′)|. Then

dFD(𝔽, 𝔾) = infΦ,Ψ max{ D(Φ, Ψ), ‖f − g∘Φ‖∞, ‖g − f∘Ψ‖∞ }.

— Dey & Wang §7.3.2, Definition 7.8, p. 227

Note that Φ and Ψ are not required to preserve function values here; the two sup-norm terms are what bound the discrepancy instead. Drop those two terms and drop the continuity requirement on Φ and Ψ, and what remains is exactly the Gromov–Hausdorff distance between the metric spaces (𝔽, df) and (𝔾, dg). Definition 7.8 is that distance, function-adapted.

Worked example 2 (faded): reading β1 of the standing torus twice. X is a torus, f the height function with X standing on end, so β1(X) = 2 with generators the meridian (a single level circle) and the longitude (which climbs).

Route one — the theorem. X is a connected compact orientable 2-manifold and f is Morse, so Theorem 7.3(a) applies and gives β1(Rf) = ⟨your step: what number?⟩.

Route two — the decomposition, run as a bound. The meridian is a whole level circle, so taking the single value a at which it sits exhibits its class in the image of H1(X=a) → H1(X): its class is ⟨your step: horizontal or vertical?⟩, and it is nonzero, so rank(H̄1(X)) ≥ 1. Fact 7.2 then gives rank(Ȟ1(X)) = 2 − rank(H̄1(X)) ≤ 1, and Theorem 7.4, being an isomorphism, transports that to β1(Rf) = rank(Ȟ1(X)) ≤ ⟨your step: what bound?⟩.

The two routes together. Route one gives the exact value 1 and route two gives the upper bound 1, so the bound is attained and, reading Fact 7.2 backwards, rank(H̄1(X)) = 1 exactly. That is more than either route alone: it says which generator died and why — the horizontal one, because a contour is collapsed to a point by construction — and it identifies the surviving loop in the canvas as the image of the longitude, the generator that climbs through the level sets and so cannot be horizontal.

Gap solutions: β1(Rf) = 2/2 = 1; the meridian's class is horizontal; and the bound is β1(Rf) ≤ 1.

Theorem 7.6 (bi-Lipschitz equivalence). One has dFD ≤ 3dI ≤ 3dFD. — Dey & Wang §7.3.2, Theorem 7.6, p. 227

Definition 7.9 (stable distance). Given f, g : X → ℝ, let (𝔽, f̃) and (𝔾, g̃) be the Reeb graphs of f and g respectively. A Reeb graph distance dR is stable if dR((𝔽, f̃), (𝔾, g̃)) ≤ ‖f − g‖∞. — Dey & Wang §7.3.2, Definition 7.9, pp. 227–228

Theorem 7.7. One has db(Dgm0(f), Dgm0(g)) ≤ 2dI(𝔽, 𝔾) ≤ 2dFD(𝔽, 𝔾). — Dey & Wang §7.3.2, Theorem 7.7, p. 228

Definition 7.10 (universal Reeb graph distance). A Reeb graph distance dU is universal if and only if (i) dU is stable, and (ii) for any other stable Reeb graph distance dS, we have dS ≤ dU. — Dey & Wang §7.3, Definition 7.10, p. 228

Universality picks out the most discriminative distance among the stable ones — the one that separates whatever any stable distance can separate. Neither dI nor dFD is universal. For Reeb graphs of PL-functions on compact triangulable spaces a universal distance does exist, constructed by pulling back to a common space, and two edit-like universal distances have been proposed; whether dI is within a constant factor of it is open. Dey and Wang also note that for merge trees specifically, dI and dFD are not merely equivalent but equal.

The pattern to carry out of this unit. Every distance in §7.3 is defined by an infimum over maps and none of them is computable in practice: apart from the bottleneck distance db, computing any of these is at least as hard as graph isomorphism, and even for merge trees the interleaving distance is NP-hard, though a fixed-parameter tractable algorithm exists in that case. What survives contact with a dataset is the chain db ≤ 2dI ≤ 2dFD of Theorem 7.7, whose left-hand end is computable — and by Proposition 7.5 computable on the graphs themselves. So the honest report is a lower bound, labelled as one, together with the stability guarantee of Definition 7.9: perturb the field by δ in sup-norm and either distance moves by at most δ.

Self-check 4. Why is no quotient needed on the target of Φ̌ in Theorem 7.4?

The quotient by the horizontal subgroup is invisible on the target precisely because that subgroup is trivial there, and it is trivial for the stated reason. The second option is false as an argument, whatever one thinks of free groups. The third confuses surjectivity with the vanishing of a subgroup: Φ being surjective is what gives a map at all, but it says nothing about H̄1 of the target.

Self-check 5. In Definition 7.8, why are the two sup-norm terms there?

Dey and Wang say it directly: the maps need not preserve function values, and the terms ‖f − g∘Φ‖∞ and ‖g − f∘Ψ‖∞ bound the difference. Symmetry comes from taking both directions in C(Φ, Ψ) and in the max, not from these terms specifically. Continuity is imposed separately as a hypothesis on Φ and Ψ; dropping it, along with the two terms, is what returns you to Gromov–Hausdorff.

Self-check 6. Two Reeb graphs are known to satisfy dI = 0.4. What may be asserted about dFD?

Theorem 7.6 is dFD ≤ 3dI ≤ 3dFD. The first inequality gives dFD ≤ 3(0.4) = 1.2. The second, after cancelling the 3, is dI ≤ dFD, so dFD ≥ 0.4 — note that this half is an honest comparison, not a factor-3 one. Bi-Lipschitz equivalence bounds a ratio; it does not assert equality. Equality is what Dey and Wang note separately for the special case of merge trees, which is exactly why the third option inverts the truth: the general bound is the theorem, the merge-tree equality is the special case.

Guided proof

Prompt. Prove the two halves of Fact 7.1 that the chapter leaves to the reader. (1) Show β0(X) = β0(Rf). (2) Show H̄1(Rf(X)) = 0 for levelset tame f. (3) Deduce β1(X) ≥ β1(Rf) from Theorem 7.4 together with Fact 7.2, and say exactly when the inequality is strict.

Hint: for (1), the load-bearing observation is that each equivalence class is a component of a levelset and is therefore connected — so ∼ never relates points lying in different components of X.

Click to reveal model answer

(1) The component count. Write X = ⨆i Xi as the disjoint union of its connected components. Each equivalence class of ∼ is a connected component of some levelset, hence a connected subset of X, hence entirely contained in a single Xi; so ∼ never relates a point of Xi to a point of Xj for i ≠ j. Consequently Rf = X/∼ is the disjoint union of the quotients Xi/∼, and these are open and closed in Rf because their preimages under Φ are. Each Xi/∼ is the continuous image of the connected space Xi under Φ, hence connected. So the components of Rf are exactly the Xi/∼, one for each component of X, and β0(X) = β0(Rf). ∎

(2) No horizontal 1-classes upstairs. Let h ∈ H̄1(Rf(X)), so there is a finite set of values {ai}i∈A with h in the image of the inclusion-induced map H1(⋃i∈A (Rf)=ai) → H1(Rf). By levelset tameness each levelset f−1(ai) of X has finitely many components, and each is collapsed by Φ to one point, so the levelset (Rf)=ai is a finite set of points. A finite union of finite point sets is a finite discrete space, whose first homology is 0. So h lies in the image of the zero group, that is h = 0, and H̄1(Rf(X)) = 0. ∎

(3) The inequality. Theorem 7.4 says Φ̌ : Ȟ1(X) → H1(Rf(X)) is an isomorphism, so rank(Ȟ1(X)) = rank(H1(Rf)) = β1(Rf). Fact 7.2 with p = 1 gives

β1(X) = rank(H1(X)) = rank(H̄1(X)) + rank(Ȟ1(X)) = rank(H̄1(X)) + β1(Rf).

Ranks are non-negative, so β1(X) ≥ β1(Rf), and the inequality is strict exactly when rank(H̄1(X)) > 0 — that is, exactly when X carries a nonzero horizontal 1-class, a cycle representable inside finitely many level sets. Note also the special case Dey and Wang record: if X is simply connected then H1(X) = 0, so β1(Rf) = 0 and Rf is loop-free. ∎

What this does and does not license. The computation identifies the defect β1(X) − β1(Rf) exactly, as the rank of the horizontal subgroup — that is more than the inequality alone says, and it is what makes Theorem 7.3(a)'s factor of two intelligible rather than magical: on a connected compact orientable 2-manifold carrying a Morse function, the horizontal and vertical parts have equal rank, since β1(Rf) = β1(X)/2 forces rank(H̄1(X)) = β1(X) − β1(X)/2 = rank(Ȟ1(X)). It licenses nothing about Hp for p > 1, where the Reeb graph has nothing to say at all, since a graph has no homology above dimension one — the loss Dey and Wang acknowledge in the chapter's opening paragraph.
