Cardinality and Cantor's diagonal (an-02)

Some infinities are bigger than others — provably.

ℕ, ℤ, and ℚ all feel like they ought to have different "sizes" — ℤ contains negative numbers ℕ doesn't have, and ℚ is packed absurdly densely compared to either. Yet all three turn out to be exactly the same size, in the only sense of "size" that survives contact with infinity: you can list each of them off, one at a time, without ever running out of natural numbers to use as list-tags. ℝ cannot be listed this way. Not "hasn't been listed yet" — cannot, ever, no matter how clever the listing scheme. Georg Cantor proved this in 1891 with an argument so short it fits in half a page, and so slippery that it convinced almost nobody at first.

Why this matters for the mission: Countability arguments recur in measure-free TDA foundations.

Segment 1 · ~25 min

1-1 correspondence, and why ℚ is no bigger than ℕ

How do you compare the sizes of two infinite sets, when "count them and compare the counts" is not an option? Cantor's answer starts from how you'd settle it for finite sets without counting at all — Abbott's example: is the set of Snow White's seven dwarfs smaller than the nine-seat US Supreme Court? You don't need the numbers 7 and 9; you just try to seat every dwarf on the bench and see whether chairs are left empty. — Abbott §1.4, p. 22

Definition 1.4.6. A function f: A → B is one-to-one (1–1) if a₁ ≠ a₂ in A implies f(a₁) ≠ f(a₂) in B. It is onto if, given any b ∈ B, there exists a ∈ A with f(a) = b. — Abbott §1.4, p. 23

A function that is both 1–1 and onto is a 1-1 correspondence (a bijection): nobody in B is left unmatched (onto), and nobody in B is double-matched (1–1). This is precisely "seating every judge at exactly one position, with no chairs empty."

Definition 1.4.7. Two sets A and B have the same cardinality if there exists f: A → B that is 1–1 and onto. We write A ∼ B. — Abbott §1.4, p. 23

This definition doesn't care that one set might look "obviously smaller" — proper-subset intuition, trained on finite sets, actively misleads you here. Watch: let E = {2, 4, 6, …} be the even naturals, a proper subset of ℕ missing infinitely many elements. Yet f(n) = 2n is a 1–1, onto map ℕ → E. So ℕ ∼ E, full stop — "half as many" is not a notion cardinality respects. — Abbott §1.4, Example 1.4.8, p. 23

Definition 1.4.10. A set A is countable if ℕ ∼ A. An infinite set that is not countable is called uncountable. — Abbott §1.4, p. 24

"Countable" just means: the elements can be arranged into a single infinite list, tagged 1st, 2nd, 3rd, …, with every element eventually appearing. Now for the result that should feel surprising: ℚ, despite being packed infinitely densely into every interval of ℝ (between any two rationals there's another), is exactly the same size as ℕ.

Theorem 1.4.11(i). The set ℚ is countable. — Abbott §1.4, p. 24

Worked example — Theorem 1.4.11(i), the listing strategy (fully worked). Show ℚ ∼ ℕ.

Proof idea. Group the rationals into finite "shells" by the sum of numerator and denominator (in lowest terms, allowing negative numerators). For each n ∈ ℕ, let

 An = {±p/q : p, q ∈ ℕ in lowest terms, p + q = n}.

So A₁ = {0/1}, A₂ = {1/1, −1/1}, A₃ = {1/2, −1/2, 2/1, −2/1}, A₄ = {1/3, −1/3, 3/1, −3/1}, and so on. Crucial observation: every An is finite (only finitely many ways to split n into p + q with both positive), and every rational number lands in exactly one shell (its own reduced p + q value picks the shell uniquely). Listing the shells one after another — all of A₁, then all of A₂, then all of A₃, … — produces one infinite list containing every rational exactly once. That list is the required bijection with ℕ. ∎

— Abbott §1.4, Theorem 1.4.11(i), pp. 24–26

The trick generalises: any infinite set you can chop into an infinite sequence of finite pieces, each piece exhausting a "layer," is countable — you just concatenate the layers into one list. Abbott uses precisely this move again to show ℤ ∼ ℕ (zig-zag: 0, 1, −1, 2, −2, 3, −3, …) and that finite unions of countable sets stay countable. — Abbott §1.4, Example 1.4.8(ii), p. 23–24

You try (solo). ℤ is countable via the zig-zag map f(n) = (n−1)/2 if n is odd, −n/2 if n is even. Verify f is 1–1 by checking a handful of small inputs land on distinct integers, and describe in one sentence why the zig-zag pattern guarantees every integer eventually gets hit (i.e. why f is onto). — cf. Abbott §1.4, Example 1.4.8(ii), p. 23

Self-check 1. ℕ ∼ E (the even naturals) even though E ⊊ ℕ. What does this tell you about the phrase "proper subset" when applied to infinite sets?

This is exactly the point Abbott flags: intuition trained on finite sets ("a proper subset must be strictly smaller") simply fails for infinite sets. Cardinality, defined via bijection, is the correct — if initially counterintuitive — replacement. (Abbott §1.4, p. 23)

Self-check 2. In the shell-listing proof that ℚ is countable, why does it matter that each shell An is finite?

If some shell A_n were infinite, "list all of A_n, then move on to A_{n+1}" would never actually reach A_{n+1} — you'd never finish the first infinite shell. Finiteness of each layer is exactly what makes the concatenation into one ℕ-indexed list legal.

Segment 2 · ~25 min

The diagonal argument, staged as an adversarial game

Cantor first proved ℝ is uncountable in 1874 using nested intervals. In 1891 he found a second proof — shorter, and in Abbott's words "startling in its simplicity." — Abbott §1.5, p. 29 Think of it as a game with an opponent who claims to have listed every real number in (0, 1).

Theorem 1.5.1. The open interval (0, 1) is uncountable. — Abbott §1.5, p. 29

The setup — your opponent's move. Your opponent hands you a function f: ℕ → (0, 1) and insists it's 1–1 and onto — every real number between 0 and 1 appears somewhere in the list f(1), f(2), f(3), … Write each entry out in decimals:

f(1) = .a11a12a13a14 …
f(2) = .a21a22a23a24 …
f(3) = .a31a32a33a34 …
⋮

Your move — build the adversary number. You are going to construct one specific real number x ∈ (0, 1) guaranteed to be missing from this list, using only the diagonal entries a11, a22, a33, … — one digit from each row, always at that row's own position.

"Now for the pearl of the argument. Define a real number x ∈ (0, 1) with the decimal expansion x = .b₁b₂b₃b₄… using the rule bn = 2 if ann ≠ 2, and bn = 3 if ann = 2." — Abbott §1.5, p. 30

Every digit of x is deliberately chosen to disagree with the diagonal entry it's built from. That's the whole trick, and it's worth sitting with why it's devastating.

Watch the diagonal walk

Here is a concrete instance of the array, with the diagonal digits picked out and the adversary number's digits built directly from them.

In this instance, a₁₁ = 3 ≠ 2, so b₁ = 2. a₂₂ = 2, so b₂ = 3. a₃₃ = 2, so b₃ = 3. a₄₄ = 9 ≠ 2, so b₄ = 2. a₅₅ = 7 ≠ 2, so b₅ = 2. The result, x = .23322…, is guaranteed by construction to differ from f(1) in its 1st digit, from f(2) in its 2nd digit, from f(3) in its 3rd digit, and so on forever — one deliberate disagreement per row, forever out of reach.

The checkmate. x is a genuine element of (0, 1) — it has a perfectly good decimal expansion. But it cannot equal f(1) (they disagree at digit 1), cannot equal f(2) (disagree at digit 2), and in general cannot equal f(n) for any n ∈ ℕ (they disagree at digit n, by construction). So x is missing from a list that was assumed to contain every real number in (0,1). Contradiction. No such onto function f exists; (0, 1) is uncountable. ∎ — Abbott §1.5, Theorem 1.5.1 and Exercise 1.5.2, pp. 30–31

Notice the shape of the game: your opponent moves first and commits to an entire infinite list; you move second, and your one move (reading the diagonal, flipping each digit) defeats every possible list they could have chosen, not just this particular one. That's what makes it a proof and not a lucky counterexample.

Faded example — adapting the argument (your turn to fill the gaps). Let S be the set of all infinite sequences of 0's and 1's, e.g. (1,0,1,0,1,0,…) ∈ S. Show S is uncountable.

Proof. Suppose for contradiction that S is countable, so there is a list g(1), g(2), g(3), … containing every sequence in S. Write g(m) = (am1, am2, am3, …) where each amn ∈ {0, 1}.

Build the adversary sequence b = (b₁, b₂, b₃, …) by the rule ⟨your step: define bn in terms of the diagonal entry ann — the natural choice here has only two options to flip between, unlike the ten-digit case⟩.

By construction, b differs from g(n) in position n, for ⟨your step: state the quantifier — for which values of n does this disagreement hold?⟩. So b cannot equal g(n) for any n, meaning ⟨your step: name the contradiction with the assumption that g's list was exhaustive⟩. Therefore S is uncountable. ∎

— Abbott §1.5, Exercise 1.5.4, p. 31

One honest wrinkle, worth naming rather than hiding: a handful of real numbers have two decimal representations (0.5 = 0.4999…), which could in principle let two different rows secretly represent the same real. Abbott flags this exact objection as an exercise — Abbott §1.5, Exercise 1.5.3(b), p. 31 — the fix is to choose the digits 2 and 3 specifically (never 0 or 9) so the constructed x never falls into a repeating-9s ambiguity. The argument survives; it just needs that one small piece of housekeeping to be fully airtight.

Cantor didn't stop at ℝ. His general theorem says no set can be put in 1–1 correspondence with its own power set — so there is always a strictly bigger infinity waiting above whatever you've got:

Theorem 1.5.2 (Cantor's Theorem). Given any set A, there does not exist a function f: A → P(A) that is onto. — Abbott §1.5, p. 32

The proof is the same diagonal trick wearing a different costume: build B = {a ∈ A : a ∉ f(a)}, then ask whether the element a′ with f(a′) = B belongs to B or not — either answer contradicts itself. — Abbott §1.5, p. 32 The upshot, per Abbott's Epilogue: card ℕ < card ℝ < card P(ℝ) < card P(P(ℝ)) < ⋯, an endless tower of ever-larger infinities, with ℵ₀ (aleph-naught) the name for the smallest one and c for the cardinality of the continuum. — Abbott §1.6, pp. 33–34

Self-check 3. In the diagonal argument, why is it essential that bn is defined to disagree specifically with ann (the n-th digit of the n-th listed number), rather than, say, always looking at an1 (the first digit of every row)?

If you fixed on a_n1 for every n, your adversary number would only need to disagree in its first digit — trivially achievable, but it would only rule out numbers whose first digit matches, not guarantee disagreement with every f(n) individually. Walking the diagonal is precisely what supplies one dedicated disagreement slot per row.

Self-check 4. Which of these best explains why the diagonal argument shows (0,1) is a strictly "bigger" infinity than ℕ, rather than merely a different-looking infinite set?

The proof is a genuine impossibility result: it starts by assuming an arbitrary onto function f exists (not a specific flawed attempt) and derives a contradiction that holds regardless of which f was chosen. That universality is exactly what upgrades "this listing missed some numbers" into "no listing ever could work."
