Open and closed sets in ℝ (an-07)

The vocabulary the whole of topology is built from.

Everything so far has been about sequences: objects with an index, a tail, and a limit. This unit changes the subject to sets, and defines four words — open, limit point, closed, closure — out of nothing but the ε-neighbourhood an-03 already introduced.

The definitions look modest and the payoff is not. Semester 2 opens by taking Definition 3.2.1's conclusion — that a collection of sets is closed under arbitrary unions and finite intersections — and promoting it to an axiom, at which point ℝ disappears and topology begins. What you meet here is that axiom's original instance, with proofs you can still see the ε in.

Prediction gate — commit before reading on. Suppose each set in a collection is open. (i) Must the union of the whole collection be open, however many sets it contains? (ii) Must the intersection be open, however many sets it contains?

Unions are unconditional; intersections are not. The intervals On = (−1/n, 1/n) are each open, and every one of them contains 0, but their intersection over all n ∈ ℕ is exactly {0} — a set containing no interval at all, and so not open. Theorem 3.2.3 states the asymmetry, and the canvas below is this counterexample.

Why this matters for the mission: Direct on-ramp to Semester 2's point-set topology.

Segment 1 · ~20 min

Open sets, and an asymmetry worth remembering

The primitive is an-03's ε-neighbourhood Vε(a) = {x ∈ ℝ : |x − a| < ε}, which is just the open interval (a − ε, a + ε). Every definition in this unit is built from it. — Abbott §3.2, p. 78

Definition 3.2.1. A set O ⊆ ℝ is open if for every a ∈ O there exists an ε-neighbourhood Vε(a) ⊆ O. — Abbott §3.2, Definition 3.2.1, p. 78

Read the quantifiers before anything else: for every point, there exists a radius. The radius is allowed to depend on the point, and in every interesting example it does — near the edge of an interval you must take a smaller one. A set is open when no point of it sits on an edge of it.

Two examples are worth having permanently. ℝ itself is open, since any ε will do for any point; and ∅ is open, because the definition asks something of every element and there are none to ask it of. That second one is a piece of logic rather than geometry, and Abbott flags it as such. — Abbott §3.2, Example 3.2.2, p. 78

Theorem 3.2.3. (i) The union of an arbitrary collection of open sets is open. (ii) The intersection of a finite collection of open sets is open. — Abbott §3.2, Theorem 3.2.3, p. 79

Worked example — why (ii) says "finite" (faded). — Abbott §3.2, p. 79

For (i), let a lie in the union. Then a lies in some member Oλ′ of the collection, which is open, so some Vε(a) ⊆ Oλ′ ⊆ the union. One member did all the work, and how many others there are never entered the argument.

For (ii), let a lie in O₁ ∩ ⋯ ∩ ON. Each Ok supplies its own radius εk with Vεk(a) ⊆ Ok, and we need one radius that works for all of them at once. Take ε = ⟨your step: which combination of the εk?⟩. Then Vε(a) ⊆ Vεk(a) ⊆ Ok for every k, so Vε(a) is inside the intersection. ∎

Gap solution: ε = min{ε₁, …, εN}. This is where finiteness is spent: a finite set of positive numbers has a smallest element, and it is positive. An infinite set of positive numbers need have neither.

Interactive visual: an intersection that loses its interior

Each blue band is the open interval (−1/n, 1/n). Every one of them contains 0 together with room on both sides. The green marker is the intersection of the first n of them, which is the smallest band so far — still an interval, still open. Taken over all n, nothing is left but the single point 0.

Each finite stage is open and the limit is not, which is the sharpest way to see that "open" is not a property preserved by limits of sets. Abbott turns the point into Exercise 3.2.1, which asks you to locate the exact line of the proof where finiteness was used — the answer is in the gap solution above. — Abbott §3.2, Exercise 3.2.1, p. 82

Self-check 1. Is the interval [0, 1] open?

Definition 3.2.1 demands a neighbourhood at every point of the set, and 0 is a point of the set. Any Vε(0) = (−ε, ε) contains −ε/2, which is not in [0, 1]. A single failing point is enough; the definition is not about most points.

Segment 2 · ~25 min

Limit points and closed sets

Definition 3.2.4. A point x is a limit point of a set A if every ε-neighbourhood Vε(x) of x intersects A in some point other than x itself. — Abbott §3.2, Definition 3.2.4, p. 79

The clause "other than x" is the whole definition. Without it every point of every set would qualify, since a neighbourhood of x always meets A at x when x ∈ A. With it, being a limit point says that A crowds up against x — and notably x need not belong to A at all.

Theorem 3.2.5. A point x is a limit point of A if and only if x = lim an for some sequence (an) contained in A with an ≠ x for all n. — Abbott §3.2, Theorem 3.2.5, p. 79

This is the bridge between the two halves of the course, and it is why the vocabulary is worth the trouble: a statement about neighbourhoods becomes a statement about sequences, so every theorem from Chapter 2 is available. The forward proof takes ε = 1/n in turn and picks a point of A from each neighbourhood; the reverse reads the definition of convergence back.

Definition 3.2.6. A point a ∈ A is an isolated point of A if it is not a limit point of A. — Abbott §3.2, Definition 3.2.6, p. 80

Definition 3.2.7. A set F ⊆ ℝ is closed if it contains its limit points. — Abbott §3.2, Definition 3.2.7, p. 80

Abbott's gloss is the one to carry: elsewhere in mathematics "closed" means an operation does not take you out of the set — closed under addition, closed under scalar multiplication. Here the operation is taking limits. A closed set is one you cannot escape by converging.

Theorem 3.2.8. A set F ⊆ ℝ is closed if and only if every Cauchy sequence contained in F has a limit that is also an element of F. — Abbott §3.2, Theorem 3.2.8, p. 80

Abbott sets the proof as Exercise 3.2.6 and it is the Guided Proof below. Note which hypothesis is used where: an-05's Cauchy Criterion supplies the limit in ℝ, and closedness is exactly the extra fact that the limit lands back in F. That division of labour is the definition of a complete subspace, and an-14 will state it in those words. — Abbott §2.6, Theorem 2.6.4, p. 59

Worked example — a set all of whose points are isolated, with a limit point outside it (fully worked). Let A = {1/n : n ∈ ℕ}. — Abbott §3.2, Example 3.2.9, p. 80

Every point of A is isolated. Given 1/n ∈ A, take ε = 1/n − 1/(n+1), the distance to the nearest smaller element. Then Vε(1/n) ∩ A = {1/n}, so the neighbourhood meets A in no point other than 1/n itself, and Definition 3.2.4 fails.

Yet 0 is a limit point of A: any Vε(0) contains 1/n for every n > 1/ε, and those points are in A and differ from 0. So A has exactly one limit point, and it is not in A — hence A is not closed.

What the example separates. "Every point isolated" and "no limit points" are different statements: the first is about points of A, the second about points of ℝ. Conflating them is the standard error here, and this set is the standing witness against it.

Theorem 3.2.10 (Density of ℚ in ℝ). Given any y ∈ ℝ, there exists a sequence of rational numbers that converges to y. — Abbott §3.2, Theorem 3.2.10, p. 81

an-01's density property said that between any two reals there is a rational; combining it with Theorem 3.2.5 says every real is a limit point of ℚ. So the set of limit points of ℚ is all of ℝ, and ℚ is very far from closed. The same argument works for the irrationals, which is worth noticing: two disjoint sets can both be dense. — Abbott §1.4, Theorem 1.4.3, p. 20

Self-check 2. Is a finite set closed?

Given a finite set A and any x ∈ ℝ, let ε be smaller than the distance from x to the nearest point of A other than x; then Vε(x) meets A in no point other than possibly x. So there are no limit points and Definition 3.2.7 is satisfied with nothing to check. Vacuous satisfaction is real satisfaction.

Self-check 3. A set is not open. Does it follow that it is closed?

The words are not opposites, and the vocabulary is at its most misleading here. [0, 1) is not open because of the point 0, and not closed because 1 is a limit point it does not contain. Meanwhile ℝ and ∅ are both open and closed. Theorem 3.2.13 gives the correct relationship, and it is about complements, not about negation.

Segment 3 · ~20 min

Closure, complements, and the symmetry that appears

Definition 3.2.11. Given A ⊆ ℝ, let L be the set of all limit points of A. The closure of A is A‾ = A ∪ L. — Abbott §3.2, Definition 3.2.11, p. 81

Theorem 3.2.12. For any A ⊆ ℝ, the closure A‾ is a closed set, and it is the smallest closed set containing A. — Abbott §3.2, Theorem 3.2.12, p. 81

Two clauses, doing different jobs. That A‾ is closed is the non-obvious half — adding the limit points might have created new ones, and the proof is that it does not. That it is smallest makes the closure canonical: it is not merely a closed set around A but the intersection of all of them. Worked examples: {1/n}‾ = {1/n} ∪ {0}, (a, b)‾ = [a, b], and ℚ‾ = ℝ. — Abbott §3.2, p. 81

Theorem 3.2.13. A set O is open if and only if Oc is closed; a set F is closed if and only if Fc is open. — Abbott §3.2, Theorem 3.2.13, p. 82

Here is the correct relationship between the two words, and it explains the earlier asymmetry rather than removing it. Complementation turns unions into intersections, so a statement about arbitrary unions of open sets becomes a statement about arbitrary intersections of closed sets.

Theorem 3.2.14. (i) The union of a finite collection of closed sets is closed. (ii) The intersection of an arbitrary collection of closed sets is closed. — Abbott §3.2, Theorem 3.2.14, p. 82

The proof is Theorem 3.2.3 read through Theorem 3.2.13 using De Morgan's Laws, which Abbott sets as Exercise 3.2.10. Every "arbitrary" in one theorem has become a "finite" in the other and vice versa, and no new mathematics was needed to get it — which is the first appearance in this course of a duality that Semester 2 uses constantly. — Abbott §3.2, Exercise 3.2.10, p. 83

Self-check 4. Take the closure of the closure: is A‾‾ larger than A‾?

This is the first clause of Theorem 3.2.12 doing visible work. If closure could keep growing, the operation would be far less useful; the content of "the closure is closed" is exactly that the process stops after one step.

Self-check 5. Which of these is the reason Semester 2 can define a topology without mentioning ℝ?

Definition 3.2.1 needs a distance to say what Vε(a) is; Theorem 3.2.3's conclusion does not mention distance at all. Promoting the conclusion to a definition is the whole move, and it is why an-14's metric spaces sit between this unit and Semester 2 rather than after them.

You try (solo). Give an example of an infinite collection of nested open sets O₁ ⊇ O₂ ⊇ O₃ ⊇ ⋯ whose intersection is closed and nonempty. — Abbott §3.2, Exercise 3.2.1, p. 82

Guided proof practice

Prompt: Prove Theorem 3.2.8: a set F ⊆ ℝ is closed if and only if every Cauchy sequence contained in F has a limit that is also an element of F. Hint: both directions go through Theorem 3.2.5, which converts between limit points and sequences. In one direction you are handed a Cauchy sequence and must produce a limit point; in the other you are handed a limit point and must produce a sequence. Watch the clause an ≠ x — it is needed in one direction and is a nuisance in the other. — Abbott §3.2, Exercise 3.2.6, p. 83

Click to reveal model answer

Model answer. (⇒) Assume F is closed and let (xn) be a Cauchy sequence with every xn ∈ F. By an-05's Cauchy Criterion the sequence converges to some x ∈ ℝ. If xn = x for some n, then x ∈ F immediately. Otherwise xn ≠ x for every n, and Theorem 3.2.5 makes x a limit point of F; since F is closed, x ∈ F.

(⇐) Assume every Cauchy sequence in F has its limit in F, and let x be a limit point of F. By Theorem 3.2.5 there is a sequence (xn) in F with xn ≠ x and xn → x. A convergent sequence is Cauchy by an-05's Theorem 2.6.2, so the hypothesis applies and gives x ∈ F. Hence F contains its limit points and is closed by Definition 3.2.7. ∎

The case split is not padding. Theorem 3.2.5 characterises limit points using sequences that avoid x, and a Cauchy sequence in F is under no obligation to avoid anything — the constant sequence x, x, x, … is Cauchy. Without the split, the forward direction would be applying Theorem 3.2.5 to a sequence that does not satisfy its hypothesis. Notice also where completeness entered: only once, in the forward direction, to produce a limit at all.
