Metric spaces bridge (an-14)

Everything you just proved for ℝ, replayed on any set with a distance.

Look back at what the last eleven units actually used. Convergence needed |xn − x| to be small; the Cauchy condition needed |xn − xm| to be small; open, closed, compact and continuous were all written in ε-neighbourhoods. Almost nothing needed x to be a number.

Replace |x − y| by a function d(x, y) with three properties and every one of those definitions survives verbatim. Most of the theorems survive too — but not all, and the ones that break are the ones that used the order of ℝ or its completeness. Sorting the survivors from the casualties is this unit, and it is also the reason the mission's objects can be studied at all: a point cloud, a space of persistence diagrams, and a space of functions are all metric spaces and none of them is ℝ.

Prediction gate — commit before reading on. an-08 proved that a subset of ℝ is compact if and only if it is closed and bounded. In a general metric space (X, d): (i) must a compact set be closed and bounded? (ii) must a closed bounded set be compact?

The proofs that compact implies closed and bounded used only sequences and distances, so they transfer. The converse used Bolzano–Weierstrass, which used the Axiom of Completeness, which is a statement about the order of ℝ — and a general metric space has no order. The discrete metric gives the counterexample in Segment 2: an infinite set in which every subset is closed and the whole space is bounded, and almost nothing is compact.

Why this matters for the mission: Point clouds, diagram space, bottleneck distance: all metric spaces.

Segment 1 · ~25 min

Three axioms, and everything written again

Definition 8.2.1. Given a set X, a function d : X × X → ℝ is a metric if for all x, y, z ∈ X: (i) d(x, y) ≥ 0, with equality if and only if x = y; (ii) d(x, y) = d(y, x); (iii) d(x, y) ≤ d(x, z) + d(z, y). A metric space is a set together with a metric on it. — Abbott §8.2, Definition 8.2.1, p. 222

Lindström states the same three conditions and names them: positivity, symmetry, and the triangle inequality. He also notes that symmetry is a genuine assumption rather than a fact about distance — measure d(x, y) by how long it takes to walk from x to y and the axiom fails. What is being defined is a useful class of distance functions, not distance itself. — Lindström §3.1, Definition 3.1.1, printed 44

Now the translation table. In each case the ℝ definition is recovered by taking d(x, y) = |x − y|, and nothing else about ℝ appears.

Definition 8.2.2. (xn) converges to x if for all ε > 0 there is N ∈ ℕ with d(xn, x) < ε whenever n ≥ N. — Abbott §8.2, Definition 8.2.2, p. 223

Definition 8.2.3. (xn) is a Cauchy sequence if for all ε > 0 there is N ∈ ℕ with d(xm, xn) < ε whenever m, n ≥ N. — Abbott §8.2, Definition 8.2.3, p. 223

Definition 8.2.4. (X, d) is complete if every Cauchy sequence in X converges to an element of X. — Abbott §8.2, Definition 8.2.4, p. 223

That is the pay-off an-05 promised. Of the five equivalent descriptions of completeness in ℝ, four mentioned order or suprema and could not be written here at all; the Cauchy criterion mentioned only distances, so it survives — and it survives by being promoted from a theorem to a definition. In ℝ, "every Cauchy sequence converges" is proved; in a metric space it is the property being named. — Lindström §3.4, Definition 3.4.1, printed 59

Definition 8.2.6. The ε-neighbourhood of x is Vε(x) = {y ∈ X : d(x, y) < ε}. — Abbott §8.2, Definition 8.2.6, p. 224

Definition 8.2.7. K ⊆ X is compact if every sequence in K has a subsequence converging to a limit in K. — Abbott §8.2, Definition 8.2.7, p. 224

Once the neighbourhood is defined, an-07's Definition 3.2.1 for open sets, Definition 3.2.4 for limit points and Definition 3.2.7 for closed sets can be copied out word for word, and Abbott does exactly that for closure and interior in Definition 8.2.8. Which is the point of the unit: the vocabulary was never about ℝ. — Abbott §8.2, Definition 8.2.8, p. 225

Interactive visual: the same set, four different distances

Each panel shows the unit ball {y : d(0, y) < 1} for a different metric on ℝ². The Euclidean, taxicab and maximum metrics give different shapes but the same open sets, so they define the same convergence and the same continuous functions. The discrete metric — distance 1 between any two distinct points — is a genuine metric whose unit ball is a single point, and it breaks Heine–Borel.

Self-check 1. Is d(x, y) = (x − y)² a metric on ℝ?

Two axioms hold and the third does not: d(0, 2) = 4 while d(0, 1) + d(1, 2) = 1 + 1 = 2. Checking all three axioms rather than the two easy ones is the routine discipline here, and the triangle inequality is nearly always the one that fails.

Self-check 2. In an-13, uniform convergence of fn to f meant sup|fn − f| → 0. What is that, in this unit's language?

Functions become points of a space and the sup-norm becomes the distance between them, at which point Definition 8.2.2 is exactly Definition 6.2.3. This is not a re-labelling exercise: once uniform convergence is convergence in a metric space, an-13's Cauchy criterion for uniform convergence becomes the statement that this space is complete, and that is the theorem the mission's stability results are built on.

Read the word bounded in that answer as load-bearing rather than decorative. Uniform convergence itself asks nothing about boundedness — on ℝ, fn(x) = x + 1/n converges uniformly to f(x) = x, and not one of those functions is a point of the space just named. What sup|f − g| actually needs is not that each function be bounded but that their difference be, since otherwise the supremum is infinite and d is not a metric. The exact statement is therefore: uniform convergence to f is ordinary metric convergence within the set of functions lying at finite sup-distance from f. Restricting to bounded functions is the standard way to secure that, and it is the case the rest of this unit works in — the ℝ example above simply lives in a different such set, the one centred on the identity.

Segment 2 · ~25 min

What survives, and what does not

Every proof in an-03 through an-13 that used only distances transfers unchanged. Limits are unique; convergent sequences are Cauchy; a convergent sequence is bounded; compact sets are closed and bounded; continuous images of compact sets are compact; a continuous function on a compact set is uniformly continuous. Lindström proves these in the general setting and the arguments are the ones you have already read. — Lindström §3.4, Proposition 3.4.2, printed 59

Three things do not transfer, and they fail in two quite different ways. Keeping those apart is the point of this segment: a statement that cannot be written and a statement that is written and false are not the same loss, and they are not repaired by the same move.

The Axiom of Completeness has no statement. "Bounded above" needs an order, and a metric space has none. So the Monotone Convergence Theorem and the Nested Interval Property cannot even be written down, let alone proved — "monotone" and "interval" are both order words, and nothing in (X, d) supplies them. Only the Cauchy criterion survives, and — as Segment 1 said — it survives as a definition rather than a theorem.

Bolzano–Weierstrass is a different case: it is perfectly expressible, and it is false. "Every bounded sequence has a convergent subsequence" uses only words this lesson has already defined — bounded is Lindström's Definition 3.5.3, that there is M with d(a, b) ≤ M throughout the set, and a convergent subsequence needs nothing but the metric. — Lindström §3.5, Definition 3.5.3, printed 63 So it can be stated in any metric space, and it is simply not true in all of them: the discrete metric in the next paragraph is the counterexample, and it is Lindström's own. — Lindström §3.5, Corollary 3.5.5, printed 64

What happens to a true theorem that becomes a false statement is worth watching, because it is not deletion. Lindström takes Bolzano–Weierstrass's conclusion and promotes it to a definition: a set is compact when every sequence in it has a subsequence converging inside it. — Lindström §3.5, Definition 3.5.2, printed 63 What was a theorem about ℝ becomes the definition of a class of spaces. In ℝn that class is exactly the closed bounded sets, which is Corollary 3.5.5 and is Heine–Borel again; in a general metric space it is strictly smaller, which is what the next paragraph shows. Extra hypotheses — compactness itself, or completeness together with total boundedness — are what buy the conclusion back.

Heine–Borel fails. Take any infinite set X with the discrete metric: d(x, y) = 1 for x ≠ y. Every subset is both open and closed, since V1/2(x) = {x}; the whole space is bounded, since all distances are at most 1; and X is not compact, because a sequence of distinct points has no convergent subsequence — no two of its terms are ever within 1/2 of each other. Closed and bounded, and not compact. — Abbott §8.2, p. 224

Completeness is a property of the metric, not of the set. Lindström makes the point with the space of continuous functions on [a, b] under three different metrics, of which some are complete and some are not, on the same underlying set. In ℝ we could speak of "the" completeness of the reals because there was one distance in play; here the distance is part of the data. — Lindström §3.4, Definition 3.4.3, printed 60

Worked example — the discrete metric, in full (faded). Let X be any infinite set and d(x, y) = 0 if x = y and 1 otherwise. — Abbott §8.2, Exercise 8.2.1, p. 222

The three axioms hold: positivity and symmetry by inspection, and the triangle inequality because the right-hand side d(x, z) + d(z, y) is 0 only when z equals both x and y, in which case the left-hand side is 0 too.

Which sequences converge? If xn → x, then taking ε = 1/2 gives N with d(xn, x) < 1/2 for n ≥ N, and the only distance below 1/2 is 0. So ⟨your step: what must the sequence do?⟩. The same computation shows the Cauchy sequences are the same sequences, so (X, d) is complete.

And X is closed in itself and bounded by 1, while a sequence of distinct points has no convergent subsequence — every subsequence still consists of distinct points. So X is a complete, closed, bounded, non-compact space. ∎

Gap solution: the sequence must be eventually constant, equal to x from index N onwards. Note what this example separates: complete and bounded do not give compact, though in ℝ closed and bounded did.

Theorem 3.6.4 (Lindström). A subset K of a metric space is compact if and only if it has the open covering property: every open covering of K has a finite subcovering. — Lindström §3.6, Theorem 3.6.4, printed 70

This is the survivor among an-08's three characterisations, and it is worth seeing which one made it. "Closed and bounded" failed. "Every sequence has a convergent subsequence" survives as the definition. And the open-cover property remains equivalent to it — in a metric space, though not in a general topological space, where the two come apart and the cover version is the one kept. an-08 predicted this: the cover formulation was the one that mentioned no distance. — Lindström §3.6, Definition 3.6.1, printed 69

Where the mission's objects live

Three metric spaces carry the whole of topological data analysis, and none of them is ℝ.

A point cloud is a finite subset of ℝn with the Euclidean metric — or, increasingly often, a finite set with an abstract distance matrix and no ambient space at all. Finite metric spaces are automatically compact and complete, which is why the algorithms terminate.

The space of continuous functions on a compact set, with d(f, g) = sup|f − g|, is where an-13 was really working. Filtration functions live here, and this space is complete — which is Abbott's setting for the Baire Category Theorem and, in a different direction, the reason limits of filtrations behave. — Abbott §8.2, Theorem 8.2.10, p. 226

The space of persistence diagrams with the bottleneck distance is a metric space in exactly the sense of Definition 8.2.1, and the stability theorem is the statement that the map from filtration functions to diagrams is continuous in the sense of Definition 8.2.5 — indeed 1-Lipschitz. Both sides of that statement are metric spaces built in this unit's language, and neither is a subset of the real line. That is the whole reason Semester 1 ends here.

Self-check 3. In a metric space, is every compact set closed?

Take a sequence in K converging to some x ∈ X. Compactness gives a subsequence converging to a point of K; the subsequence also converges to x; limits are unique; so x ∈ K. Every step is a distance argument. The direction that fails is the converse, which is why the gate had two halves.

Self-check 4. ℚ with d(x, y) = |x − y| is a metric space. Is it complete?

Completeness is not inherited by subspaces; only closed subspaces of a complete space are complete, which is an-07's Theorem 3.2.8 read in this language. ℚ is not closed in ℝ, and the same example that motivated the Axiom of Completeness in an-01 is the counterexample here.

Self-check 5. Which of an-08's three characterisations of compactness is the one that generalises furthest?

Closed and bounded fails already for metric spaces. The sequential form survives here and comes apart from the cover form in general topological spaces, where sequences are too weak a tool. The cover form survives everywhere, because it mentions only open sets — which is what an-08 flagged and an-07 explained.

Hint: for the triangle inequality, apply the one-dimensional triangle inequality in each coordinate and add. For completeness, show that a sequence is Cauchy in this metric exactly when both coordinate sequences are Cauchy in ℝ.

Guided proof practice

Prompt: Prove that in any metric space, a compact set is closed and bounded — and then explain precisely where the converse breaks. Hint: for closedness, take a sequence in K converging in X and use compactness on it. For boundedness, argue by contradiction as an-08 did, choosing points at ever greater distance from a fixed point. For the converse, do not look for a repair: name the step of an-08's proof that has no counterpart here. — Lindström §3.5, Definition 3.5.2, printed 63

Click to reveal model answer

Model answer. Closed. Let x ∈ X be the limit of a sequence (xn) in K. By compactness there is a subsequence converging to some y ∈ K. That subsequence also converges to x, since a subsequence of a convergent sequence has the parent's limit — an-04's Theorem 2.5.2, whose proof used only the index inequality nk ≥ k and the definition of convergence, both available here. Limits in a metric space are unique, because if x ≠ y then d(x, y) > 0 and no tail can be within d(x, y)/2 of both. Hence x = y ∈ K.

Bounded. Suppose not, and fix any p ∈ X. For each n choose xn ∈ K with d(p, xn) > n. Compactness gives a convergent subsequence, and a convergent sequence is bounded — the same ε = 1 argument as an-03's Theorem 2.3.2, with |·| replaced by d(p, ·) — contradicting d(p, xnk) > nk ≥ k.

Where the converse dies. an-08 proved closed and bounded implies compact by invoking Bolzano–Weierstrass, and Bolzano–Weierstrass was proved by bisecting an interval — a construction that needs the order of ℝ to say what "half" means, and the Axiom of Completeness to say the nested intervals meet. Neither is available. And the failure is not a gap in the argument but a genuine one: the discrete metric on an infinite set is closed, bounded, complete, and not compact. ∎

The habit worth keeping. For each earlier theorem, ask what its proof consumed. If the answer is only distances, it transfers; if it is order or suprema, it does not. That question — not the theorem list — is what this unit is for.
