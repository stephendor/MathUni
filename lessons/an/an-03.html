Sequences and limits (an-03)

Make "gets close to" bulletproof against every adversary.

When calculus was first invented by Newton and Leibniz, people talked informally about quantities "getting infinitely close" to a limit. But in 1734, Bishop Berkeley famously mocked these vague notions as "the ghosts of departed quantities." For over a century, calculus worked in practice, but lacked rigorous foundations whenever subtle infinite operations clashed.

The solution — constructed by Augustin-Louis Cauchy and Karl Weierstrass — was to replace hand-waving with a game against an adversary. You claim a sequence approaches a limit L. The adversary challenges you with a challenge tolerance ε > 0, no matter how tiny. Your job is to produce a threshold index N after which every single term in the sequence sits within distance ε of L. If you can win for any ε > 0, the limit is proven.

Prediction Gate: Consider the sequence an = (−1)n. An adversary challenges you with ε = 0.5, asking if the sequence stays within 0.5 of L = 0 after some threshold N. What happens?

Correct! Distance |(−1)n − 0| = 1 is always strictly greater than ε = 0.5. The terms never enter the ε-neighborhood V0.5(0), so no threshold N exists.

The ε-N Adversarial Game and Topological Neighborhoods

We begin by formalising what a sequence actually is in standard mathematical language.

Definition 2.2.1. A sequence is a function whose domain is ℕ. — Abbott §2.2, p. 38

Given a function f : ℕ → ℝ, we write an = f(n) for the n-th term. We denote the infinite sequence by (an)n=1∞ or simply (an). What happens at the start of a sequence (the first 10, or 10,000 terms) does not affect convergence; analysis is entirely concerned with the infinite "tail" of the sequence.

Definition 2.2.3 (Convergence of a Sequence). A sequence (an) converges to a real number a if, for every positive number ε > 0, there exists a natural number N ∈ ℕ such that whenever n ≥ N it follows that |an − a| < ε. — Abbott §2.2, p. 39

We write lim an = a or (an) → a.

To understand the geometry behind |an − a| < ε, we define an open interval around a of radius ε:

Definition 2.2.4. Given a ∈ ℝ and ε > 0, the set Vε(a) = {x ∈ ℝ : |x − a| < ε} = (a − ε, a + ε) is called the ε-neighborhood of a. — Abbott §2.2, p. 39

This allows us to restate convergence in purely topological terms — a bridge directly to metric spaces and point-set topology:

Definition 2.2.3B (Convergence of a Sequence: Topological Version). A sequence (an) converges to a if, given any ε-neighborhood Vε(a), there exists a point in the sequence after which all terms are in Vε(a). In other words, every ε-neighborhood contains all but a finite number of terms of (an). — Abbott §2.2, p. 39

Definition 2.2.8. A sequence that does not converge to any real number is said to diverge. — Abbott §2.2, p. 43

Worked Example 1: Formal ε-N Proof

Example. Prove using Definition 2.2.3 that lim 3n+12n+5 = 32. — Abbott §2.2, p. 41

Scratchwork (done before writing proof): We want |an − L| < ε, i.e.,

|an − L| = | 3n+12n+5 − 32 | = | 6n+2 − 6n − 154n+10 | = 134n+10 < ε.

Since 4n+10 > 4n, we have 134n+10 < 134n. Setting 134n < ε gives n > 134ε.

Formal Proof: Let ε > 0 be arbitrary. Choose N ∈ ℕ such that N > 134ε.
Let n ≥ N. Then n > 134ε ⇒ 134n < ε.
Thus, | 3n+12n+5 − 32 | = 134n+10 < 134n < ε.
By Definition 2.2.3, lim 3n+12n+5 = 32. ∎

Worked Example 2 (Faded). Prove lim 1√n = 0. — Abbott §2.2, Example 2.2.5, p. 40

Proof: Let ε > 0 be arbitrary. We need | 1√n − 0 | = 1√n < ε, which is equivalent to n > 1ε².
Choose N ∈ ℕ satisfying N > ⟨your step: expression in ε⟩.
Then for any n ≥ N, we have n > 1ε² ⇒ 1√n < ε, so | 1√n − 0 | < ε. ∎

Self-check 1. What happens to the threshold N in Definition 2.2.3 when the adversary chooses a smaller value of ε > 0?

Smaller ε defines a narrower target band Vε(a). Sequence terms take longer to enter and stay inside this narrower band, so N typically gets larger as ε → 0.

Self-check 2. Rephrasing Definition 2.2.3B topologically, a sequence (an) → a if and only if every ε-neighborhood Vε(a) contains:

"Infinitely many terms" is not enough — the sequence 1, 0, 1, 0, 1, 0… visits V0.1(1) infinitely often, but infinitely many terms (0) stay outside. Convergence requires that all but finitely many terms lie inside Vε(a).

Boundedness, Algebraic Limit Theorem, and Order Limit Theorem

Now that we have a rigorous definition of convergence, we use it to establish fundamental structural properties of convergent sequences.

Definition 2.3.1. A sequence (xn) is bounded if there exists a real number M > 0 such that |xn| ≤ M for all n ∈ ℕ. — Abbott §2.3, p. 44

Theorem 2.3.2. Every convergent sequence is bounded. — Abbott §2.3, p. 44

Proof: Assume (xn) → L. Setting ε = 1 in Definition 2.2.3, there exists N ∈ ℕ such that for all n ≥ N, |xn − L| < 1. By the triangle inequality,

|xn| = |xn − L + L| ≤ |xn − L| + |L| < |L| + 1   for all n ≥ N.

To handle the finite number of terms before N, set M = max{|x₁|, |x₂|, …, |xN−1|, |L| + 1}. Then |xn| ≤ M for all n ∈ ℕ, so (xn) is bounded. ∎

Intermediate Building Block Lemmas

Before proving the full limit theorems, we state two intermediate lemmas that arise repeatedly in problem set proofs.

Lemma 2.3.A (Constant Sequence). The constant sequence an = c for all n ∈ ℕ converges to c. — Abbott §2.3, Exercise 2.3.1, p. 49

Proof: For any ε > 0, pick N = 1. Then for n ≥ 1, |an − c| = |c − c| = 0 < ε. ∎

Lemma 2.3.B (Triangle Inequality Split). For any two sequences (an) → a and (bn) → b, the termwise distance satisfies |(an + bn) − (a + b)| ≤ |an − a| + |bn − b|. — Abbott §2.3, p. 46

Theorem 2.3.3 (Algebraic Limit Theorem). Let lim an = a and lim bn = b. Then: — Abbott §2.3, pp. 45–48

  1. lim (c an) = c a for all c ∈ ℝ;
  2. lim (an + bn) = a + b;
  3. lim (an bn) = a b;
  4. lim (an / bn) = a / b, provided b ≠ 0 and bn ≠ 0 for all n.

Proof of (ii) Sum Rule: Let ε > 0. Since (an) → a, choose N₁ so n ≥ N₁ ⇒ |an − a| < ε2. Since (bn) → b, choose N₂ so n ≥ N₂ ⇒ |bn − b| < ε2. Set N = max{N₁, N₂}. For any n ≥ N, applying Lemma 2.3.B yields:

|(an + bn) − (a + b)| ≤ |an − a| + |bn − b| < ε2 + ε2 = ε. ∎

Theorem 2.3.4 (Order Limit Theorem). Assume lim an = a and lim bn = b. — Abbott §2.3, pp. 48–49

  1. If an ≥ 0 for all n ∈ ℕ, then a ≥ 0.
  2. If an ≤ bn for all n ∈ ℕ, then a ≤ b.
  3. If c ≤ bn for all n ∈ ℕ, then c ≤ b; if an ≤ c for all n ∈ ℕ, then a ≤ c.

Proof of (i): By contradiction: assume a < 0. Pick ε₀ = |a| = −a > 0. Since (an) → a, there exists N such that |aN − a| < −a. This implies aN − a < −a ⇒ aN < 0, contradicting aN ≥ 0. Thus a ≥ 0. ∎

Self-check 3. Why can't we prove that an unbounded sequence is convergent?

By contrapositive of Theorem 2.3.2 (Convergent ⇒ Bounded), if a sequence is unbounded, it cannot converge!

Self-check 4. If an > 0 for all n ∈ ℕ, does Theorem 2.3.4 guarantee that a = lim an > 0 strictly?

Consider an = 1n. Every term is strictly positive (1n > 0), but lim (1n) = 0, which is not strictly positive. Order limit theorems preserve non-strict inequalities (≥), not strict ones (>).

Prompt: Prove that if (an) → a and (bn) → b with an ≤ bn for all n ∈ ℕ, then a ≤ b (Theorem 2.3.4 part ii). Hint: Define dn = bn − an ≥ 0 and use Theorem 2.3.3(ii) alongside Theorem 2.3.4(i).

Model Answer: Define the sequence dn = bn − an. Since an ≤ bn for all n, we have dn ≥ 0 for all n ∈ ℕ. By the Algebraic Limit Theorem (Theorem 2.3.3 part ii), (dn) = (bn − an) → b − a. Now apply Theorem 2.3.4 part (i) to the non-negative sequence (dn): since dn ≥ 0 for all n, its limit must be non-negative, so b − a ≥ 0 ⇒ a ≤ b. ∎
