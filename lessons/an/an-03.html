Sequences and limits (an-03)

Make "gets close to" bulletproof against every adversary.

When calculus was first invented by Newton and Leibniz, people talked informally about quantities "getting infinitely close" to a limit. But in 1734, Bishop Berkeley famously mocked these vague notions as "the ghosts of departed quantities." For over a century, calculus worked in practice, but lacked rigorous foundations whenever subtle infinite operations clashed.

The solution — constructed by Augustin-Louis Cauchy and Karl Weierstrass — was to replace hand-waving with a game against an adversary. You claim a sequence approaches a limit $L$. The adversary challenges you with a challenge tolerance $\epsilon > 0$, no matter how tiny. Your job is to produce a threshold index $N$ after which every single term in the sequence sits within distance $\epsilon$ of $L$. If you can win for any $\epsilon > 0$, the limit is proven.

Prediction Gate: Consider the sequence $a_n = (-1)^n$. An adversary challenges you with $\epsilon = 0.5$, asking if the sequence stays within $0.5$ of $L=0$ after some threshold $N$. What happens?

Correct! Distance $|(-1)^n - 0| = 1$ is always strictly greater than $\epsilon = 0.5$. The terms never enter the $\epsilon$-neighborhood $V_{0.5}(0)$, so no threshold $N$ exists.

The $\epsilon$-$N$ Adversarial Game and Topological Neighborhoods

We begin by formalising what a sequence actually is in standard mathematical language.

Definition 2.2.1. A sequence is a function whose domain is $\mathbb{N}$. — Abbott §2.2, p. 38

Given a function $f : \mathbb{N} \to \mathbb{R}$, we write $a_n = f(n)$ for the $n$-th term. We denote the infinite sequence by $(a_n)_{n=1}^\infty$ or simply $(a_n)$. What happens at the start of a sequence (the first 10, or 10,000 terms) does not affect convergence; analysis is entirely concerned with the infinite "tail" of the sequence.

Definition 2.2.3 (Convergence of a Sequence). A sequence $(a_n)$ converges to a real number $a$ if, for every positive number $\epsilon > 0$, there exists a natural number $N \in \mathbb{N}$ such that whenever $n \geq N$ it follows that $|a_n - a| < \epsilon$. — Abbott §2.2, p. 39

We write $\lim a_n = a$ or $(a_n) \to a$.

To understand the geometry behind $|a_n - a| < \epsilon$, we define an open interval around $a$ of radius $\epsilon$:

Definition 2.2.4. Given $a \in \mathbb{R}$ and $\epsilon > 0$, the set $V_\epsilon(a) = \{x \in \mathbb{R} : |x - a| < \epsilon\} = (a - \epsilon, a + \epsilon)$ is called the $\epsilon$-neighborhood of $a$. — Abbott §2.2, p. 39

This allows us to restate convergence in purely topological terms — a bridge directly to metric spaces and point-set topology:

Definition 2.2.3B (Convergence of a Sequence: Topological Version). A sequence $(a_n)$ converges to $a$ if, given any $\epsilon$-neighborhood $V_\epsilon(a)$, there exists a point in the sequence after which all terms are in $V_\epsilon(a)$. In other words, every $\epsilon$-neighborhood contains all but a finite number of terms of $(a_n)$. — Abbott §2.2, p. 39

Definition 2.2.8. A sequence that does not converge to any real number is said to diverge. — Abbott §2.2, p. 43

Worked Example 1: Formal $\epsilon$-$N$ Proof

Example. Prove using Definition 2.2.3 that $\lim_{n\to\infty} \frac{3n+1}{2n+5} = \frac{3}{2}$. — Abbott §2.2, p. 41

Scratchwork (done before writing proof): We want $|a_n - L| < \epsilon$, i.e.,

$$\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \left|\frac{2(3n+1) - 3(2n+5)}{2(2n+5)}\right| = \left|\frac{-13}{4n+10}\right| = \frac{13}{4n+10} < \epsilon.$$

Since $4n+10 > 4n$, we have $\frac{13}{4n+10} < \frac{13}{4n}$. Setting $\frac{13}{4n} < \epsilon$ gives $n > \frac{13}{4\epsilon}$.

Formal Proof: Let $\epsilon > 0$ be arbitrary. Choose $N \in \mathbb{N}$ such that $N > \frac{13}{4\epsilon}$.
Let $n \geq N$. Then $n > \frac{13}{4\epsilon} \implies \frac{13}{4n} < \epsilon$.
Thus, $\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \frac{13}{4n+10} < \frac{13}{4n} < \epsilon$.
By Definition 2.2.3, $\lim_{n\to\infty} \frac{3n+1}{2n+5} = \frac{3}{2}$. $\blacksquare$

Worked Example 2 (Faded). Prove $\lim_{n\to\infty} \frac{1}{\sqrt{n}} = 0$. — Abbott §2.2, Example 2.2.5, p. 40

Proof: Let $\epsilon > 0$ be arbitrary. We need $\left|\frac{1}{\sqrt{n}} - 0\right| = \frac{1}{\sqrt{n}} < \epsilon$, which is equivalent to $n > \frac{1}{\epsilon^2}$.
Choose $N \in \mathbb{N}$ satisfying $N > \langle\text{your step: expression in } \epsilon\rangle$.
Then for any $n \geq N$, we have $n > \frac{1}{\epsilon^2} \implies \frac{1}{\sqrt{n}} < \epsilon$, so $\left|\frac{1}{\sqrt{n}} - 0\right| < \epsilon$. $\blacksquare$

Gap solution: $N > 1/\epsilon^2$.

Self-check 1. What happens to the threshold $N$ in Definition 2.2.3 when the adversary chooses a smaller value of $\epsilon > 0$?

Smaller $\epsilon$ defines a narrower target band $V_\epsilon(a)$. Sequence terms take longer to enter and stay inside this narrower band, so $N$ typically gets larger as $\epsilon \to 0$.

Self-check 2. Rephrasing Definition 2.2.3B topologically, a sequence $(a_n) \to a$ if and only if every $\epsilon$-neighborhood $V_\epsilon(a)$ contains:

"Infinitely many terms" is not enough — the sequence $1, 0, 1, 0, 1, 0\dots$ visits $V_{0.1}(1)$ infinitely often, but infinitely many terms ($0$) stay outside. Convergence requires that all but finitely many terms lie inside $V_\epsilon(a)$.

Boundedness, Algebraic Limit Theorem, and Order Limit Theorem

Now that we have a rigorous definition of convergence, we use it to establish fundamental structural properties of convergent sequences.

Definition 2.3.1. A sequence $(x_n)$ is bounded if there exists a real number $M > 0$ such that $|x_n| \leq M$ for all $n \in \mathbb{N}$. — Abbott §2.3, p. 44

Theorem 2.3.2. Every convergent sequence is bounded. — Abbott §2.3, p. 44

Proof: Assume $(x_n) \to L$. Setting $\epsilon = 1$ in Definition 2.2.3, there exists $N \in \mathbb{N}$ such that for all $n \geq N$, $|x_n - L| < 1$. By the triangle inequality,

$$|x_n| = |x_n - L + L| \leq |x_n - L| + |L| < |L| + 1 \quad \text{for all } n \geq N.$$

To handle the finite number of terms before $N$, set $M = \max\{|x_1|, |x_2|, \dots, |x_{N-1}|, |L| + 1\}$. Then $|x_n| \leq M$ for all $n \in \mathbb{N}$, so $(x_n)$ is bounded. $\blacksquare$

Intermediate Building Block Lemmas

Before proving the full limit theorems, we state two intermediate lemmas that arise repeatedly in problem set proofs.

Lemma 2.3.A (Constant Sequence). The constant sequence $a_n = c$ for all $n \in \mathbb{N}$ converges to $c$. — Abbott §2.3, Exercise 2.3.1, p. 49

Proof: For any $\epsilon > 0$, pick $N = 1$. Then for $n \geq 1$, $|a_n - c| = |c - c| = 0 < \epsilon$. $\blacksquare$

Lemma 2.3.B (Triangle Inequality Split). For any two sequences $(a_n) \to a$ and $(b_n) \to b$, the termwise distance satisfies $|(a_n + b_n) - (a + b)| \leq |a_n - a| + |b_n - b|$. — Abbott §2.3, p. 46

Theorem 2.3.3 (Algebraic Limit Theorem). Let $\lim a_n = a$ and $\lim b_n = b$. Then: — Abbott §2.3, pp. 45–48

  1. $\lim (c a_n) = c a$ for all $c \in \mathbb{R}$;
  2. $\lim (a_n + b_n) = a + b$;
  3. $\lim (a_n b_n) = a b$;
  4. $\lim (a_n / b_n) = a / b$, provided $b \neq 0$ and $b_n \neq 0$ for all $n$.

Proof of (ii) Sum Rule: Let $\epsilon > 0$. Since $(a_n) \to a$, choose $N_1$ so $n \geq N_1 \implies |a_n - a| < \epsilon/2$. Since $(b_n) \to b$, choose $N_2$ so $n \geq N_2 \implies |b_n - b| < \epsilon/2$. Set $N = \max\{N_1, N_2\}$. For any $n \geq N$, applying Lemma 2.3.B yields:

$$|(a_n + b_n) - (a + b)| \leq |a_n - a| + |b_n - b| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon. \quad \blacksquare$$

Theorem 2.3.4 (Order Limit Theorem). Assume $\lim a_n = a$ and $\lim b_n = b$. — Abbott §2.3, pp. 48–49

  1. If $a_n \geq 0$ for all $n \in \mathbb{N}$, then $a \geq 0$.
  2. If $a_n \leq b_n$ for all $n \in \mathbb{N}$, then $a \leq b$.
  3. If $c \leq b_n$ for all $n \in \mathbb{N}$, then $c \leq b$; if $a_n \leq c$ for all $n \in \mathbb{N}$, then $a \leq c$.

Proof of (i): By contradiction: assume $a < 0$. Pick $\epsilon_0 = |a| = -a > 0$. Since $(a_n) \to a$, there exists $N$ such that $|a_N - a| < -a$. This implies $a_N - a < -a \implies a_N < 0$, contradicting $a_N \geq 0$. Thus $a \geq 0$. $\blacksquare$

Self-check 3. Why can't we prove that an unbounded sequence is convergent?

By contrapositive of Theorem 2.3.2 (Convergent $\implies$ Bounded), if a sequence is unbounded, it cannot converge!

Self-check 4. If $a_n > 0$ for all $n \in \mathbb{N}$, does Theorem 2.3.4 guarantee that $a = \lim a_n > 0$ strictly?

Consider $a_n = 1/n$. Every term is strictly positive ($1/n > 0$), but $\lim (1/n) = 0$, which is not strictly positive. Order limit theorems preserve non-strict inequalities ($\geq$), not strict ones ($>$).

Model Answer: Define the sequence $d_n = b_n - a_n$. Since $a_n \leq b_n$ for all $n$, we have $d_n \geq 0$ for all $n \in \mathbb{N}$. By the Algebraic Limit Theorem (Theorem 2.3.3 part ii), $(d_n) = (b_n - a_n) \to b - a$. Now apply Theorem 2.3.4 part (i) to the non-negative sequence $(d_n)$: since $d_n \geq 0$ for all $n$, its limit must be non-negative, so $b - a \geq 0 \implies a \leq b$. $\blacksquare$
