Connectedness and the Cantor set (an-09)

A set with zero length and uncountably many points.

Remove the middle third of [0, 1], then the middle third of each piece that remains, and repeat for ever. What is left has total length 0 — the removed pieces sum to exactly 1 — and yet it has as many points as ℝ itself, contains no interval whatsoever, and is compact.

The Cantor set is the standing counterexample of this chapter: it separates properties that intuition bundles together. Alongside it this unit takes up connectedness, the last of the topological vocabulary, and the one that becomes the mission's zeroth Betti number.

Prediction gate — commit before reading on. Let C be the Cantor set: everything left in [0, 1] after removing middle thirds for ever. (i) Is C countable? (ii) Does C contain an interval (a, b) with a < b?

Uncountable and empty of intervals at once. The endpoints of the removed intervals are a countable set and they are not all of C: every sequence of zeros and ones names a point of C, and an-02 proved the set of such sequences uncountable. Meanwhile C ⊆ Cn, a union of intervals of length 3−n, so no interval of positive length fits inside. Uncountability and containing an interval are unrelated, and this set is what proves it.

Why this matters for the mission: Connected components are H0 — the first Betti story.

Segment 1 · ~25 min

The Cantor set, and perfect sets

The construction: C₀ = [0, 1]; C₁ = C₀ with the open middle third (1/3, 2/3) removed; C₂ removes the open middle third of each of the two pieces of C₁; and so on. Each Cn is a union of 2n closed intervals of length 1/3n, and C is the intersection of all of them. — Abbott §3.1, p. 75

Three properties follow almost immediately from earlier units, and it is worth naming which unit pays for each. C is closed, being an intersection of closed sets by an-07's Theorem 3.2.14. It is bounded, sitting inside [0, 1]. So it is compact by an-08's Theorem 3.3.4 — a compact set containing no interval, which is exactly the warning an-08 attached to closed intervals as an archetype. — Abbott §3.3, Theorem 3.3.4, p. 84

Interactive visual: the construction, and what it leaves

Each row is a stage Cn. The total length shown at each stage is (2/3)n, which tends to 0; the number of intervals is 2n, which does not. The two numbers moving in opposite directions is the whole paradox.

The uncountability argument is worth carrying in full, because it is short. Each point of C is located by an infinite list of choices — at each stage, left piece or right piece — and every such list locates a point. So the points of C correspond exactly to the sequences of zeros and ones, and an-02 proved that set uncountable. The endpoints of the removed intervals form only a countable part of C; the rest is invisible to the construction's own bookkeeping. — Abbott §3.1, p. 77

Definition 3.4.1. A set P ⊆ ℝ is perfect if it is closed and contains no isolated points. — Abbott §3.4, Definition 3.4.1, p. 89

Theorem 3.4.2. The Cantor set is perfect. — Abbott §3.4, Theorem 3.4.2, p. 89

Closedness is the intersection argument above. That no point is isolated takes an idea: given x ∈ C, at each stage x lies in one of the 2n intervals of Cn, and that interval has two endpoints, both in C. Take the one different from x. Those points converge to x, since they are within 3−n, and they differ from x, so an-07's Definition 3.2.4 is satisfied. — Abbott §3.4, p. 90

Theorem 3.4.3. A nonempty perfect set is uncountable. — Abbott §3.4, Theorem 3.4.3, p. 90

This gives a second and more structural proof that C is uncountable, and its method is worth more than its statement. Suppose P = {x₁, x₂, x₃, …} listed every element. Build nested closed intervals In with xn ∉ In+1 and each In ∩ P nonempty — possible precisely because no point of P is isolated, so there is always another point of P nearby to build the next interval around. — Abbott §3.4, p. 91

Then Kn = In ∩ P is compact and nonempty and nested, so an-08's Theorem 3.3.5 puts a point in every one of them; that point is in P and is excluded from the list by construction. The contradiction is Cantor's diagonal argument from an-02 with an interval in place of a digit. — Abbott §3.3, Theorem 3.3.5, p. 85

Self-check 1. The endpoints of the removed intervals — 0, 1, 1/3, 2/3, 1/9, … — all belong to C. Do they exhaust it?

The endpoints form a countable set: finitely many appear at each stage, and a countable union of finite sets is countable. Since C is uncountable, uncountably many of its points are never named as endpoints. The point 1/4 is one such: it survives every stage and is not an endpoint of any removed interval.

Self-check 2. Is the closed interval [0, 1] perfect?

Definition 3.4.1 asks for closed and no isolated points, and nothing else. Endpoints are not isolated: every neighbourhood of 0 contains points of [0, 1] other than 0. So Theorem 3.4.3 also reproves that [0, 1] is uncountable — the same theorem covering a set with interior and one without.

Segment 2 · ~25 min

Connectedness, and what a component is

Definition 3.4.4. Two nonempty sets A, B ⊆ ℝ are separated if A‾ ∩ B and A ∩ B‾ are both empty. A set E is disconnected if it can be written as E = A ∪ B with A and B separated, and connected otherwise. — Abbott §3.4, Definition 3.4.4, p. 91

Separated is a stronger demand than disjoint, and the difference is the point. (1, 2) and (2, 5) are separated: neither contains a limit point of the other, so there is space between them even though they share the limit point 2. But (1, 2] and (2, 5) are disjoint and not separated, because 2 belongs to the first and is a limit point of the second. Splitting an interval always leaves the two halves touching somewhere. — Abbott §3.4, p. 91

Theorem 3.4.6. E ⊆ ℝ is connected if and only if, for all nonempty disjoint A and B with E = A ∪ B, there always exists a convergent sequence (xn) → x with (xn) contained in one of A, B and x an element of the other. — Abbott §3.4, Theorem 3.4.6, p. 92

This is an-07's Theorem 3.2.5 applied to Definition 3.4.4: "contains a limit point of the other" becomes "there is a sequence in one converging into the other". However you cut a connected set in two, the cut cannot be clean.

Theorem 3.4.7. E ⊆ ℝ is connected if and only if whenever a < c < b with a, b ∈ E, it follows that c ∈ E. — Abbott §3.4, Theorem 3.4.7, p. 92

Worked example — the forward direction (faded). Assume E is connected, let a, b ∈ E with a < c < b, and suppose for contradiction that c ∉ E. — Abbott §3.4, p. 92

Split E at the missing point: A = (−∞, c) ∩ E and B = (c, ∞) ∩ E. Neither is empty, since a ∈ A and b ∈ B. Neither contains a limit point of the other, because any such limit point would have to be ⟨your step: which single number?⟩, which is in neither set.

And E = A ∪ B, because the only element of E that could be missing from the union is c, and c ∉ E by assumption. So E is disconnected, contradicting the hypothesis. Hence c ∈ E. ∎

Gap solution: c itself. A limit point of A is at most c and a limit point of B is at least c, so the only candidate for a shared boundary is c — and removing it is what let the split be clean.

So in ℝ the connected sets are exactly the intervals, unbounded ones included. That makes connectedness look like a small idea; it is not. Abbott notes that the concept earns its keep in the plane and higher dimensions, and the reason is that "no gaps in the ordering" is available only on a line while "cannot be split cleanly" makes sense anywhere. — Abbott §3.4, p. 92

For the mission, this is the first Betti number. A space breaks up into maximal connected pieces — its components — and counting them is counting zero-dimensional holes, the rank of H₀. When a filtration is built over a point cloud, the components merge as the radius grows, and the bars of the zeroth persistence diagram record exactly when two pieces that were separated in the sense of Definition 3.4.4 stop being so. Everything later in the mission is this idea in one dimension up.

Self-check 3. Is the Cantor set connected?

The first removal took out (1/3, 2/3), so 1/2 ∉ C while 0, 1 ∈ C. In fact C is totally disconnected: its only connected subsets are single points, since any two distinct points of C have a removed interval between them. Compactness and connectedness are independent properties, and C is the example that shows it.

Self-check 4. Are the sets ℚ and its complement, the irrationals, separated in the sense of Definition 3.4.4?

an-07's Theorem 3.2.10 gives ℚ‾ = ℝ, so ℚ‾ ∩ (irrationals) is the whole set of irrationals, not empty. Disjoint is easy; separated is hard. And it must be hard, or Theorem 3.4.7 would be false — ℝ = ℚ ∪ (irrationals) is a partition into two disjoint nonempty pieces, and ℝ is connected.

Self-check 5. A set has two connected components. What does that say about the zeroth Betti number of the space it models?

Counting components is the zero-dimensional case of counting holes, and the mission's persistence bars in dimension 0 record when components merge as a filtration grows. The vocabulary of Definition 3.4.4 is what makes "component" a definition rather than a picture.

Guided proof practice

Prompt: Prove Theorem 3.4.6: E is connected if and only if, for every partition of E into nonempty disjoint A and B, some sequence in one of them converges to a point of the other. Hint: both directions are the contrapositive of Definition 3.4.4 read through an-07's Theorem 3.2.5. Work out first what "A‾ ∩ B is nonempty" says in the language of sequences, and mind the clause an ≠ x in that theorem. — Abbott §3.4, Exercise 3.4.6, p. 93

Click to reveal model answer

Model answer. Both directions rest on one translation. For disjoint A and B, the set A‾ ∩ B is nonempty exactly when some x ∈ B lies in A‾ = A ∪ L(A); since A and B are disjoint, x ∉ A, so x is a limit point of A. By an-07's Theorem 3.2.5 that is the same as saying some sequence in A, avoiding x, converges to x ∈ B — and it avoids x automatically, because it lies in A and x does not.

(⇒) Assume E is connected and let E = A ∪ B with A, B nonempty and disjoint. If no sequence of the stated kind existed, then by the translation both A‾ ∩ B and A ∩ B‾ would be empty, making A and B separated and E disconnected — a contradiction.

(⇐) Assume the sequence condition holds for every such partition, and suppose E were disconnected, say E = A ∪ B with A, B separated. Separated sets are in particular disjoint and nonempty, so the hypothesis gives a sequence in one converging to a point of the other; by the translation, that makes one of A‾ ∩ B, A ∩ B‾ nonempty, contradicting separation. So E is connected. ∎

Why the awkward clause is free here. Theorem 3.2.5 characterises limit points using sequences that avoid the point, which was a real nuisance in an-08's guided proof. Here disjointness supplies it at no cost: a sequence in A can never equal a point of B. Recognising when a hypothesis is automatically satisfied is as useful as knowing when it must be checked.
