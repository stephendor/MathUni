Functional limits and continuity (an-10)

Continuity recast: preimages of open sets are open. Remember pw-03?

The ε-N game of an-03 had a challenger who names a tolerance and a responder who names an index. For functions the responder names a radius instead: given ε around the target value, produce a δ around the input point. Same game, one letter changed.

What makes this unit matter is that the game has an equivalent form with no ε and no δ in it at all — continuity says the preimage of every open set is open. That version mentions only the vocabulary of an-07, and it is the version that becomes the definition when Semester 2 removes the real line from underneath.

Prediction gate — commit before reading on. Consider g(x) = x sin(1/x) for x ≠ 0 and g(0) = 0. The factor sin(1/x) oscillates without limit as x → 0. (i) Does limx→0 sin(1/x) exist? (ii) Is g continuous at 0?

The limit in (i) fails: take xn = 1/(nπ) and yn = 1/(2nπ + π/2), both tending to 0, along which sin(1/x) is constantly 0 and constantly 1. Yet |g(x) − g(0)| = |x sin(1/x)| ≤ |x|, so δ = ε answers every challenge and g is continuous at 0. The bounded factor is multiplied by something going to zero, and a product can indeed be tamer than its factors.

Why this matters for the mission: This definition, verbatim, is the one topology keeps.

Segment 1 · ~25 min

Functional limits, and the bridge back to sequences

Definition 4.2.1. Let f : A → ℝ and let c be a limit point of A. Then limx→c f(x) = L means: for all ε > 0 there exists δ > 0 such that whenever 0 < |x − c| < δ and x ∈ A, it follows that |f(x) − L| < ε. — Abbott §4.2, Definition 4.2.1, p. 104

Three details in that statement are load-bearing and easy to read past. c must be a limit point of A — an-07's Definition 3.2.4 — because otherwise there are no nearby points of the domain to test and every L would qualify. The strict inequality 0 < |x − c| excludes x = c, so the value f(c) is irrelevant and may not even exist. And δ depends on ε, never the reverse. — Abbott §4.2, p. 104

Theorem 4.2.3 (Sequential Criterion for Functional Limits). For f : A → ℝ and c a limit point of A, the following are equivalent: (i) limx→c f(x) = L; (ii) for every sequence (xn) ⊆ A with xn ≠ c and (xn) → c, it follows that f(xn) → L. — Abbott §4.2, Theorem 4.2.3, p. 106

This is the second bridge of the course, and it pays the same dividend an-07's Theorem 3.2.5 did: once functional limits are sequential limits in disguise, everything proved in Chapter 2 applies without reproof. Abbott takes the two immediate corollaries in that spirit rather than reproving them. — Abbott §4.2, Corollary 4.2.4, p. 106

Corollary 4.2.5 (Divergence Criterion for Functional Limits). If two sequences (xn) and (yn) in A, both converging to c with terms different from c, produce image sequences f(xn) and f(yn) with different limits, then limx→c f(x) does not exist. — Abbott §4.2, Corollary 4.2.5, p. 107

That is the tool the prediction gate used, and it is the standard way to prove a limit fails: exhibiting two routes to c with different destinations. Abbott's own instance is sin(1/x) at the origin. — Abbott §4.2, Example 4.2.6, p. 107

Self-check 1. Why does Definition 4.2.1 require c to be a limit point of the domain?

If c is isolated in A, some Vδ(c) contains no point of A other than c, so the hypothesis "0 < |x − c| < δ and x ∈ A" is never satisfied and the implication holds for every L at once. The first option is precisely what the definition does not require, which is the difference from continuity.

Self-check 2. In the ε-δ definition, may δ depend on c?

The quantifiers run: fix c, then for all ε, there exists δ. So δ is allowed to shrink as c moves, and for most functions it must. Forbidding that dependence gives a strictly stronger property — uniform continuity, which an-11 takes up, and where the whole content is that one quantifier moved.

Segment 2 · ~25 min

Continuity, four ways

Definition 4.3.1. A function f : A → ℝ is continuous at c ∈ A if for all ε > 0 there exists δ > 0 such that whenever |x − c| < δ and x ∈ A, it follows that |f(x) − f(c)| < ε. If this holds at every point of A, then f is continuous on A. — Abbott §4.3, Definition 4.3.1, p. 109

Set this beside Definition 4.2.1 and two things have changed. The target L has become the value f(c), so c must now be in the domain; and the exclusion 0 < |x − c| has been dropped, which costs nothing since x = c gives |f(c) − f(c)| = 0 < ε. Continuity at c is "the limit exists and equals the value", with a small caveat: at an isolated point of A the definition is satisfied automatically while the functional limit is not defined at all. — Abbott §4.3, p. 109

Theorem 4.3.2 (Characterisations of Continuity). Let f : A → ℝ and c ∈ A. The following are equivalent: (i) the ε-δ condition of Definition 4.3.1; (ii) if c is a limit point of A, then limx→c f(x) = f(c); (iii) for every Vε(f(c)) there is Vδ(c) with f(Vδ(c) ∩ A) ⊆ Vε(f(c)); (iv) for every sequence (xn) → c in A, it follows that f(xn) → f(c). — Abbott §4.3, Theorem 4.3.2, p. 109

Abbott warns that the length of the list is deceiving. Statements (i), (ii) and (iii) are the same sentence in three notations. Statement (iv) is different in kind, and it is the one that does most of the work — usually to prove a function is not continuous, by exhibiting one bad sequence. — Abbott §4.3, p. 110

Corollary 4.3.3 (Criterion for Discontinuity). If there is a sequence (xn) ⊆ A with (xn) → c but f(xn) not converging to f(c), then f is not continuous at c. — Abbott §4.3, Corollary 4.3.3, p. 110

Interactive visual: the challenge and the response

The horizontal band is the challenge Vε(f(c)); the vertical band is the response Vδ(c). Continuity at c means: whatever height the horizontal band is given, some width of vertical band keeps the graph inside it. Watch δ shrink as ε does — and watch how much faster it must shrink where the graph is steep.

The picture makes one thing plain that the symbols hide: δ depends on c as well as on ε. At c = 0.75 the graph is steeper and the same ε buys a much narrower δ than at c = 0.25. Whether a single δ can be made to serve every c at once is a different question, and an-11's answer to it is the difference between continuity and uniform continuity.

Worked example — the greatest integer function (faded). Let h(x) = ⟦x⟧ be the largest integer not exceeding x. — Abbott §4.3, Example 4.3.7, p. 111

At an integer m, take xn = m − 1/n. Then (xn) → m, while h(xn) = m − 1 for every n, so h(xn) → m − 1 ≠ m = h(m). By ⟨your step: which result?⟩, h is not continuous at m.

At a non-integer c, with n < c < n + 1, take δ = min{c − n, (n + 1) − c}. Then h(x) = h(c) for every x ∈ Vδ(c), so |h(x) − h(c)| = 0 < ε whatever ε is. ∎ — Abbott §4.3, p. 112

Gap solution: Corollary 4.3.3. Note the oddity of the second half, which Abbott points out: δ does not depend on ε at all here. Usually smaller ε forces smaller δ; on a locally constant function one δ answers every challenge.

Theorem 4.3.4 (Algebraic Continuity Theorem). If f and g are continuous at c, then so are kf for k ∈ ℝ, f + g, fg, and f/g provided g(c) ≠ 0. — Abbott §4.3, Theorem 4.3.4, p. 110

Theorem 4.3.9 (Composition of Continuous Functions). If f : A → ℝ is continuous at c ∈ A and g : B → ℝ is continuous at f(c) ∈ B, with f(A) ⊆ B, then g ∘ f is continuous at c. — Abbott §4.3, Theorem 4.3.9, p. 112

Both are proved by quoting Theorem 4.3.2(iv) and then an-03's Algebraic Limit Theorem, which is the dividend the sequential characterisation was set up to pay. With the constant and identity functions continuous, every polynomial follows, and every rational function away from its zeros. — Abbott §4.3, p. 111

The version with no ε in it

The hook promised a formulation in the vocabulary of an-07, and here it is: for g defined on all of ℝ, writing g−1(A) = {x ∈ ℝ : g(x) ∈ A}, the function g is continuous if and only if g−1(O) is open whenever O ⊆ ℝ is open. Abbott sets it as an exercise, in the section an-11 covers rather than this one. — Abbott §4.4, Exercise 4.4.11, p. 120

Why it is the same statement: Theorem 4.3.2(iii) says every ε-neighbourhood of g(c) pulls back to contain a δ-neighbourhood of c. An open set is exactly a set containing a neighbourhood of each of its points, so "every neighbourhood of the image pulls back to a neighbourhood" and "every open set pulls back to an open set" are the same demand, made point by point in one case and all at once in the other.

And why it matters more than the others: it mentions no distance, no ε, no sequence — only open sets, whose behaviour an-07's Theorem 3.2.3 showed can be axiomatised on its own. In Semester 2 this becomes the definition of a continuous map, and Definition 4.3.1 becomes a theorem about one particular kind of space. That is the sense in which this unit's definition is the one topology keeps.

Self-check 3. The preimage characterisation says preimages of open sets are open. Are images of open sets open under a continuous function?

A constant function is continuous and maps (0, 1) to {k}, which is not open. Nor does the third option rescue it: f(x) = x² maps (−1, 1) to [0, 1), which is not open either. Preimage and image behave quite differently, and the correct statements about images are an-11's business: continuous images of compact sets are compact, and of connected sets are connected.

Self-check 4. A function f has limx→2 f(x) = 5 and f(2) = 7. Is f continuous at 2?

Theorem 4.3.2(ii) is an equation, not an existence claim. A removable discontinuity is exactly this situation, and it is why Definition 4.2.1 excludes x = c: the limit is deliberately blind to the value, so that the two can be compared.

Self-check 5. To prove a function is discontinuous at c, which characterisation is usually easiest?

Negating the ε-δ statement requires producing an ε that defeats every δ, which is a statement about infinitely many candidates. Corollary 4.3.3 needs a single sequence. That asymmetry is why Abbott says (iv) is qualitatively different from the first three.

You try (solo). Prove the Squeeze Theorem for functional limits: if f(x) ≤ g(x) ≤ h(x) on a common domain A, and limx→c f(x) = limx→c h(x) = L at a limit point c of A, then limx→c g(x) = L. — Abbott §4.2, Exercise 4.2.9, p. 109

Hint: do not repeat the ε-δ argument from scratch. Use Theorem 4.2.3 to turn all three hypotheses into statements about sequences, and quote an-03's version of the same result.

Guided proof practice

Prompt: Prove the forward direction of Theorem 4.2.3: if limx→c f(x) = L, and (xn) is any sequence in A with xn ≠ c and (xn) → c, then f(xn) → L. Hint: you are given a δ that governs points and must produce an N that governs indices. The sequence hypothesis converts one into the other — apply it with δ in the role of the tolerance. — Abbott §4.2, Theorem 4.2.3, p. 106

Click to reveal model answer

Model answer. Let ε > 0. By Definition 4.2.1 there is δ > 0 such that every x ∈ A with 0 < |x − c| < δ satisfies |f(x) − L| < ε.

Now apply the definition of convergence to (xn) → c, using the positive number δ as its tolerance: there is N ∈ ℕ such that n ≥ N implies |xn − c| < δ. Since xn ≠ c by hypothesis, we in fact have 0 < |xn − c| < δ, and every xn lies in A.

So for n ≥ N the point xn meets the condition governed by δ, giving |f(xn) − L| < ε. Since ε was arbitrary, f(xn) → L by an-03's Definition 2.2.3. ∎

The move worth naming. The proof feeds δ — a number produced as a response in one definition — in as the challenge in another. That is the standard way two ε-style definitions are chained, and it is exactly why the hypothesis xn ≠ c appears in the statement: without it the sequence could sit at c, where Definition 4.2.1 says nothing at all.
