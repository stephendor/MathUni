The derivative and the Mean Value Theorem (an-12)

MVT: the theorem that quietly proves half of calculus.

The derivative is not a new kind of limit. It is an-10's functional limit applied to one particular quotient, which means every theorem of the last two units is available and nothing has to be rebuilt. What is new is what the derivative knows about the function it came from.

One theorem carries almost all of that knowledge. The Mean Value Theorem says a chord's slope is attained somewhere by the tangent, which sounds like a picture and behaves like a lever: it is what proves that a zero derivative means a constant function, what makes L'Hospital's rule true, and what licenses differentiating a series term by term. It is also, in an-13 and beyond, the step where an inequality about derivatives becomes an inequality about values.

Prediction gate — commit before reading on. an-11 showed that a function with the intermediate value property need not be continuous, and promised a reason. (i) If f is differentiable on [a, b], must f′ be continuous? (ii) Must f′ take every value between f′(a) and f′(b)?

Derivatives can be genuinely discontinuous — g(x) = x² sin(1/x) with g(0) = 0 is differentiable everywhere and g′ jumps around wildly near 0. Yet every derivative has the intermediate value property, which is Darboux's Theorem below. So the class of derivatives sits strictly between the continuous functions and the arbitrary ones, and that is exactly why an-11's converse to the Intermediate Value Theorem needed a hypothesis.

Why this matters for the mission: Morse-theoretic TDA needs derivatives treated honestly.

Segment 1 · ~25 min

The derivative as a functional limit

Definition 5.2.1. Let g : A → ℝ be defined on an interval A, and let c ∈ A. The derivative of g at c is g′(c) = limx→c (g(x) − g(c))/(x − c), provided the limit exists. — Abbott §5.2, Definition 5.2.1, p. 132

Two features of that sentence are choices, not conventions. The domain is an interval — a connected set, in an-09's vocabulary — because a rate of change wants the variable to move without jumping. And the difference quotient is undefined at x = c, which is exactly why an-10's Definition 4.2.1 excluded that point: the derivative would be unstatable otherwise. — Abbott §5.2, p. 132

Theorem 5.2.3. If g is differentiable at c, then g is continuous at c. — Abbott §5.2, Theorem 5.2.3, p. 132

The proof is one line of algebra plus an-03's Algebraic Limit Theorem: g(x) − g(c) is the difference quotient times (x − c), a quantity with a limit times one going to 0. The converse fails at every corner — |x| at 0 is continuous with no derivative — so differentiability is strictly stronger. — Abbott §5.2, Example 5.2.2, p. 132

Theorem 5.2.4. If f and g are differentiable at c, then so are f + g, kf, fg and, when g(c) ≠ 0, f/g, with the familiar formulas — in particular (fg)′(c) = f′(c)g(c) + f(c)g′(c). — Abbott §5.2, Theorem 5.2.4, p. 133

Theorem 5.2.5 (Chain Rule). If g is differentiable at c and f is differentiable at g(c), then f ∘ g is differentiable at c with (f ∘ g)′(c) = f′(g(c))g′(c). — Abbott §5.2, Theorem 5.2.5, p. 134

These are the rules from calculus, now with proofs. The product rule's proof is the add-and-subtract move that has appeared in every unit since an-05: insert f(x)g(c) into the numerator and split. The Chain Rule needs more care than the naive cancellation suggests, because the inner difference g(x) − g(c) may be zero for x arbitrarily close to c — a detail this unit's problem set takes up.

Theorem 5.2.6 (Interior Extremum Theorem). Let f be differentiable on (a, b). If f attains a maximum or minimum value at c ∈ (a, b), then f′(c) = 0. — Abbott §5.2, Theorem 5.2.6, p. 135

Worked example — the proof of the Interior Extremum Theorem (faded). — Abbott §5.2, p. 135

Because c lies in the open interval, there is room on both sides: choose sequences (xn) → c and (yn) → c with xn < c < yn for every n.

Suppose f(c) is a maximum. Then f(yn) − f(c) ≤ 0 while yn − c > 0, so each quotient is ≤ 0 and ⟨your step: which theorem passes that to the limit?⟩ gives f′(c) ≤ 0.

On the other side f(xn) − f(c) ≤ 0 and xn − c < 0, so each quotient is ≥ 0 and the same theorem gives f′(c) ≥ 0. Both hold, so f′(c) = 0. ∎

Gap solution: an-03's Order Limit Theorem, Theorem 2.3.4. Note where "open interval" was spent: at an endpoint only one of the two sequences exists, and the conclusion genuinely fails — f(x) = x on [0, 1] has a maximum at 1 with f′(1) = 1.

Theorem 5.2.7 (Darboux's Theorem). If f is differentiable on [a, b] and α satisfies f′(a) < α < f′(b), then there exists c ∈ (a, b) with f′(c) = α. — Abbott §5.2, Theorem 5.2.7, p. 136

Abbott's reduction is the elegant part: set g(x) = f(x) − αx, so that g′ = f′ − α and the hypothesis becomes g′(a) < 0 < g′(b). Now a minimum of g on [a, b] exists by an-11's Extreme Value Theorem, and the sign conditions place it in the interior rather than at an endpoint, so Theorem 5.2.6 finishes. This answers the gate: every derivative has an-11's intermediate value property, whether or not it is continuous. — Abbott §4.5, Definition 4.5.3, p. 124

Self-check 1. Definition 5.2.1 insists the domain be an interval. Would "every point is a limit point of the domain" do instead?

Two different requirements sit here, and they are worth not merging.

The definition needs only that c be a limit point of the domain, which is an-10's Definition 4.2.1: without it there is nothing to take a limit along. And that much is satisfied by plenty of non-intervals — on (0, 1) ∪ (2, 3) every point is a limit point, and the difference quotient makes perfect sense at every one of them.

What the interval buys is connectedness, and Abbott says so in the sentence before the definition: we want the independent variable to move about a connected domain. — Abbott §5.2, p. 132

Everything downstream turns on that, not on limit points. Take f = 0 on (0, 1) and f = 1 on (2, 3). It is differentiable at every point of its domain with f′ ≡ 0, and it is not constant — so the Mean Value Theorem's corollary fails outright, and Darboux's theorem with it, because there is no point between two given points at which anything could be found. An interval is what guarantees the "between" these theorems quantify over. That is an-09's word, used for an-09's reason.

Self-check 2. f is continuous on [0, 1] and attains its maximum at c = 1. Does the Interior Extremum Theorem give f′(1) = 0?

f(x) = x is differentiable on [0, 1] with maximum at 1 and f′(1) = 1. At an endpoint only one of the two approach directions is available, so only one of the two inequalities in the proof survives. This is why Rolle's Theorem asks for differentiability on the open interval and continuity on the closed one.

Segment 2 · ~25 min

The Mean Value Theorem, and what it is for

Theorem 5.3.1 (Rolle's Theorem). Let f be continuous on [a, b] and differentiable on (a, b). If f(a) = f(b), then there exists c ∈ (a, b) with f′(c) = 0. — Abbott §5.3, Theorem 5.3.1, p. 138

Two earlier theorems and nothing else. an-11's Extreme Value Theorem gives a maximum and a minimum on the compact [a, b]; if both are attained at endpoints then f(a) = f(b) forces f to be constant and any interior point serves; otherwise an extremum is interior and Theorem 5.2.6 applies. The two hypotheses split cleanly — continuity on the closed interval is what Extreme Value needs, differentiability on the open one is what Interior Extremum needs. — Abbott §4.4, Theorem 4.4.3, p. 115

Theorem 5.3.2 (Mean Value Theorem). If f is continuous on [a, b] and differentiable on (a, b), then there exists c ∈ (a, b) with f′(c) = (f(b) − f(a))/(b − a). — Abbott §5.3, Theorem 5.3.2, p. 138

Rolle's Theorem is the case f(a) = f(b), and the general case reduces to it by subtracting the chord: apply Rolle to d(x) = f(x) − L(x), where L is the line through the two endpoints. Tilting the picture until the chord is horizontal is the whole proof, and the same trick appeared in Darboux's Theorem as subtracting αx.

Interactive visual: the chord and the tangent

The blue curve is a function on [0, 1]; the grey line is the chord from (0, f(0)) to (1, f(1)). The green line is the tangent at the point c the Mean Value Theorem promises — found here by scanning for equal slopes. As the right endpoint moves, the chord tilts and c moves with it; the two lines stay parallel throughout, because that is what the theorem says.

Now the payoff. The Mean Value Theorem is almost never used for its own statement; it is used to convert a fact about f′ into a fact about f, which no other tool in the course can do.

Corollary 5.3.3. If g is differentiable on an interval A with g′(x) = 0 for all x ∈ A, then g is constant on A. — Abbott §5.3, Corollary 5.3.3, p. 140

Corollary 5.3.4. If f′ = g′ on an interval A, then f = g + k for some constant k. — Abbott §5.3, Corollary 5.3.4, p. 140

The first is three lines: for x < y in A, the Mean Value Theorem on [x, y] gives g(y) − g(x) = g′(c)(y − x) = 0. The second follows by applying the first to f − g. Every "+ C" ever written in an integration problem is Corollary 5.3.4, and the reason it needs A to be an interval is that on a disconnected domain the constants may differ on different pieces.

Theorem 5.3.5 (Generalised Mean Value Theorem). If f and g are continuous on [a, b] and differentiable on (a, b), then there exists c ∈ (a, b) with [f(b) − f(a)]g′(c) = [g(b) − g(a)]f′(c). — Abbott §5.3, Theorem 5.3.5, p. 140

Taking g(x) = x recovers Theorem 5.3.2, and the general form is what L'Hospital's rule actually needs. Abbott states the 0/0 case as Theorem 5.3.6 and the ∞/∞ case as Theorem 5.3.8, and both are consequences rather than separate ideas. — Abbott §5.3, Theorem 5.3.6, p. 141

Self-check 3. g′(x) = 0 for every x in the domain A = (0, 1) ∪ (2, 3). Must g be constant on A?

Corollary 5.3.3 asks for an interval. Take g = 0 on (0, 1) and g = 1 on (2, 3): differentiable with zero derivative throughout, and not constant. The Mean Value Theorem needs the two points joined by an interval inside the domain, and on a disconnected set there is no such interval to apply it to.

Self-check 4. A function is differentiable on ℝ. Is its derivative necessarily Riemann integrable, or at least continuous?

Theorem 5.2.3 says a differentiable function is continuous, not that its derivative is. The gate's example x² sin(1/x) has a derivative that is discontinuous at 0. Darboux's Theorem constrains the damage: a jump discontinuity would skip values, and derivatives cannot skip values.

Self-check 5. Which hypothesis of the Mean Value Theorem does f(x) = |x| on [−1, 1] violate?

The chord from (−1, 1) to (1, 1) has slope 0, and f′ is −1 on the left and +1 on the right and undefined at 0, so no c works. The function is continuous everywhere, which is why the failure has to be located precisely: one point of non-differentiability inside the open interval is enough to break the conclusion.

You try (solo). A function is Lipschitz on A if there is M > 0 with |(f(x) − f(y))/(x − y)| ≤ M for all x ≠ y in A. Show that if f is differentiable on [a, b] and f′ is continuous on [a, b], then f is Lipschitz there. — Abbott §5.3, Exercise 5.3.1, p. 143

Hint: the Mean Value Theorem turns the quotient into a value of f′, and an-11’s Extreme Value Theorem bounds those values because [a, b] is compact. Notice which hypothesis each half of the argument uses.

Guided proof practice

Prompt: Prove the Mean Value Theorem from Rolle's Theorem. Hint: Rolle applies only when the two endpoint values agree. You cannot change f, but you can subtract something from it whose derivative you know exactly and which agrees with f at both endpoints. Write down that something before doing any calculus, then check both hypotheses of Rolle for the difference. — Abbott §5.3, Theorem 5.3.2, p. 138

Click to reveal model answer

Model answer. Let L be the line through (a, f(a)) and (b, f(b)):

L(x) = f(a) + f(b) − f(a)b − a(x − a),

and set d(x) = f(x) − L(x). Then d is continuous on [a, b] and differentiable on (a, b), being a difference of two such functions by Theorem 5.2.4; and d(a) = 0 = d(b) by construction.

Rolle's Theorem therefore supplies c ∈ (a, b) with d′(c) = 0. Since L is linear with slope (f(b) − f(a))/(b − a), we have d′(x) = f′(x) − (f(b) − f(a))/(b − a), and setting this to zero at c gives the statement. ∎

The move, named. Subtracting a function whose behaviour is completely known, in order to normalise the hypothesis of a theorem you already have, is the same manoeuvre as Darboux's g(x) = f(x) − αx and as Corollary 5.3.4's h = f − g. Three of this unit's proofs are the same idea, and recognising it is worth more than remembering any of them.
