Uniform convergence (an-13)

When limits of nice functions go wrong — and the fix.

Every function gn(x) = xn on [0, 1] is a polynomial: continuous, differentiable, as well behaved as a function can be. Their limit is 0 on [0, 1) and 1 at x = 1 — a step function. Continuity did not survive the limit.

The diagnosis is a quantifier. Pointwise convergence lets the threshold N depend on the point, so different parts of the domain arrive at different speeds and the limit can tear. Demanding one N for the whole domain at once repairs it, and the same move — moving a quantifier to make a response uniform over the domain — is the one an-11 made for continuity. In the mission's language, that uniform bound is the sup-norm, and it is the metric the stability theorem is stated in.

Prediction gate — commit before reading on. Let fn be continuous on a set A and suppose fn(x) → f(x) for every x ∈ A. (i) Must f be continuous? (ii) Must it be, if in addition a single threshold N can be chosen that works for every x ∈ A at once?

xn on [0, 1] settles (i): every term is continuous and the limit is not. The repair in (ii) is Definition 6.2.3, and the theorem that it works is Theorem 6.2.6. Notice how little was changed — the same ε, the same N, the same inequality, with only the order of two quantifiers exchanged.

Why this matters for the mission: Uniform (sup-norm) bounds are the language of the stability theorem.

Segment 1 · ~25 min

Two ways for a sequence of functions to converge

Definition 6.2.1. For each n ∈ ℕ let fn be a function on A ⊆ ℝ. The sequence (fn) converges pointwise on A to f : A → ℝ if, for every x ∈ A, the sequence of real numbers fn(x) converges to f(x). — Abbott §6.2, Definition 6.2.1, p. 154

Read as an ε-N statement this says: for every ε > 0 and every x ∈ A, there exists N — possibly depending on x — with |fn(x) − f(x)| < ε for n ≥ N. Abbott restates it in exactly that form, side by side with the uniform version, so the single difference is visible. — Abbott §6.2, p. 158

Two examples do all the work. fn(x) = (x² + nx)/n converges pointwise to f(x) = x on ℝ, since x²/n → 0 for each fixed x. And gn(x) = xn on [0, 1] converges pointwise to the function that is 0 on [0, 1) and 1 at 1 — every term continuous, the limit not. — Abbott §6.2, Example 6.2.2, pp. 154, 155

Definition 6.2.3. (fn) converges uniformly on A to f if, for every ε > 0, there exists N ∈ ℕ such that |fn(x) − f(x)| < ε whenever n ≥ N and x ∈ A. — Abbott §6.2, Definition 6.2.3, p. 157

The letters are identical; the placement of "x ∈ A" is not. In Definition 6.2.1 the point is chosen before N; in Definition 6.2.3 it is chosen after. Abbott points at the parallel with an-11's uniform continuity, and it is exact: in both cases "uniformly" means the response to ε can be chosen once for the whole domain. — Abbott §6.2, p. 158

Interactive visual: a band around the limit

The dashed grey lines are the band of width ε around the limit function. Uniform convergence means: from some index onwards, the whole graph of fn lies inside that band. Watch xn on [0, 1], whose graphs always escape the band near x = 1 however large n is, against 1/(n(1 + x²)), whose graphs eventually fit entirely.

Worked example — one sequence of each kind (faded). — Abbott §6.2, Example 6.2.4, p. 158

Uniform. Let gn(x) = 1/(n(1 + x²)) on ℝ, with pointwise limit g = 0. Since 1/(1 + x²) ≤ 1 for every x, we have |gn(x) − 0| ≤ 1/n, a bound with no x in it. Given ε > 0, take ⟨your step: which N?⟩ and the same N answers every point.

Not uniform. Let gn(x) = xn on [0, 1). The pointwise limit is 0. Take ε = 1/2. For any proposed N, the point x = (1/2)1/N lies in [0, 1) and has xN = 1/2, which is not less than ε. So no single N works for every point, though for each fixed x some N does. ∎

Gap solution: N > 1/ε. The whole difference between the two halves is whether the bound on |fn(x) − f(x)| still mentions x.

That last remark is the working test, and it is worth stating as a rule: bound |fn(x) − f(x)| by something depending on n alone and you have uniform convergence; if every bound you can find still involves x, look for a point that defeats each N in turn.

Self-check 1. Does uniform convergence imply pointwise convergence?

Uniform convergence is strictly stronger: it is the same statement with the choice of N restricted. So the uniform limit, when it exists, is the pointwise limit — which is why one first computes the pointwise limit and then asks whether the convergence to it is uniform. There is never a separate candidate to find.

Self-check 2. On [0, 1/2] rather than [0, 1], is xn → 0 uniform?

Uniform convergence, like uniform continuity, is a property of a sequence on a domain. The failure on [0, 1] happened entirely near x = 1; remove a neighbourhood of that point and the bound (1/2)n works everywhere at once. Exactly the same phenomenon as an-11's x² on ℝ versus on [−10, 10].

Segment 2 · ~25 min

What uniform convergence buys, and why the proof needed it

Theorem 6.2.5 (Cauchy Criterion for Uniform Convergence). (fn) converges uniformly on A if and only if for every ε > 0 there exists N ∈ ℕ such that |fn(x) − fm(x)| < ε for all m, n ≥ N and all x ∈ A. — Abbott §6.2, Theorem 6.2.5, p. 160

This is an-05's Cauchy Criterion one level up, and it earns its place for the same reason: it decides uniform convergence without requiring the limit function to be known in advance. Abbott sets the proof as Exercise 6.2.6, and it runs by applying the numerical criterion at each fixed x to get the limit, then checking that the resulting convergence is uniform. — Abbott §2.6, Theorem 2.6.4, p. 59

Theorem 6.2.6 (Continuous Limit Theorem). If (fn) converges uniformly on A to f, and each fn is continuous at c ∈ A, then f is continuous at c. — Abbott §6.2, Theorem 6.2.6, p. 160

The proof is the ε/3 argument, and it is one of the few proofs in this course where reading the failed attempt first is worth more than reading the successful one. Abbott gives both. — Abbott §6.2, p. 157

The estimate is forced: |f(x) − f(c)| is split into |f(x) − fN(x)| + |fN(x) − fN(c)| + |fN(c) − f(c)|, with the middle term handled by continuity of fN and the outer two by convergence. Under pointwise convergence the third term is fine — c is fixed, so choose N for it — but the first is not. It must hold for every x in a neighbourhood of c, and that neighbourhood's size δ depends on N, which was chosen before δ existed. You cannot go back and pick a larger N, because δ would change with it. — Abbott §6.2, p. 157

Uniform convergence dissolves the circularity at a stroke: the N works for all x at once, so it can be chosen first and δ afterwards. The hypothesis is not merely sufficient — it was reverse-engineered from precisely this obstruction, which is why Definition 6.2.3 looks the way it does.

For the mission, the same object appears with a different name. Uniform convergence says supx∈A|fn(x) − f(x)| → 0, and that supremum is the sup-norm distance between two functions. The stability theorem for persistence diagrams is an inequality in exactly this metric: perturb a filtration function by at most ε in sup-norm and its diagram moves by at most ε in bottleneck distance. The reason the theory is stated with sup-norms rather than pointwise closeness is the reason this unit exists.

Self-check 3. The limit of continuous functions xn on [0, 1] is discontinuous. Does that contradict Theorem 6.2.6?

Each xn is a polynomial and continuous everywhere, so the third option is wrong. The theorem's hypothesis is uniform convergence, and the faded example showed it fails here. Notice the logical direction this gives you: since the limit is discontinuous and every term is continuous, the convergence cannot be uniform — the theorem used contrapositively is often the quickest disproof.

Self-check 4. Where exactly does the ε/3 proof break down under pointwise convergence?

The middle term is fine: fN is continuous by hypothesis. The triangle inequality is unconditional. The failure is that N would have to be chosen after δ, and δ is chosen after N — a circular dependency that uniform convergence removes by making N independent of the point.

Self-check 5. Which earlier definition has the same relationship to its non-uniform version as Definition 6.2.3 has to Definition 6.2.1?

In both cases the response to ε — a δ there, an N here — is required to work simultaneously at every point of the domain, rather than being chosen after the point. That is what the adverb "uniformly" means throughout analysis, and recognising the pattern is more useful than either definition on its own.

You try (solo). Decide whether hn(x) = x/(1 + nx²) converges uniformly on ℝ, and prove your answer. — Abbott §6.2, Exercise 6.2.4, p. 161

Hint: find the pointwise limit first, then try to bound |hn(x)| by something free of x. Calculus on the function x ↦ x/(1 + nx²), using an-12's Interior Extremum Theorem, will tell you the largest value it takes.

Guided proof practice

Prompt: Prove Theorem 6.2.6: a uniform limit of functions continuous at c is continuous at c. Hint: the quantity to estimate is |f(x) − f(c)|, and you have information about fn rather than f. Insert a single well-chosen fN twice, so that three terms appear. Then decide, deliberately, in which order N and δ must be chosen, and say what would go wrong in the other order. — Abbott §6.2, Theorem 6.2.6, p. 160

Click to reveal model answer

Model answer. Fix c ∈ A and let ε > 0. By uniform convergence choose N ∈ ℕ such that |fN(x) − f(x)| < ε/3 for every x ∈ A.

With N now fixed, fN is continuous at c, so there is δ > 0 with |fN(x) − fN(c)| < ε/3 whenever |x − c| < δ and x ∈ A.

For such x, insert and remove fN twice:

|f(x) − f(c)| ≤ |f(x) − fN(x)| + |fN(x) − fN(c)| + |fN(c) − f(c)| < ε/3 + ε/3 + ε/3 = ε.

So f is continuous at c by an-10's Definition 4.3.1. ∎

The order is the proof. N is chosen first, before δ exists, and that is legitimate only because uniform convergence lets N be chosen without reference to any point. Under pointwise convergence the first term would need an N depending on x, and the values of x in question are the ones within δ of c — but δ is not available until N has been fixed. Writing the two choices in the wrong order produces a proof that looks complete and is circular, which is why Abbott shows the failed attempt before the successful one.
