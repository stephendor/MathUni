Continuity on compact sets; IVT and EVT (an-11)

Why continuous images of compact sets can't misbehave.

an-10 gave you continuity and warned that images are less well behaved than preimages: a continuous function can send an open set to a set that is not open, and a closed set to one that is not closed. This unit finds the two properties that are preserved, and they are the two an-08 and an-09 spent their time on.

The consequences are the theorems everyone remembers from calculus, now with hypotheses that can be checked. A continuous function on a compact set attains its maximum; a continuous function on an interval takes every intermediate value. Both are corollaries of one preservation statement each, and the hypotheses are exactly what the counterexamples require.

Prediction gate — commit before reading on. Recall that continuity at each point allows δ to depend on the point as well as on ε; uniform continuity demands one δ that works at every point of the domain at once. (i) Is g(x) = x² uniformly continuous on ℝ? (ii) Is it uniformly continuous on [−10, 10]?

On ℝ, take xn = n and yn = n + 1/n. Then |xn − yn| → 0 while |xn² − yn²| = 2 + 1/n² stays above 2, so no single δ can serve. On [−10, 10] the estimate |x² − y²| = |x − y||x + y| ≤ 20|x − y| gives δ = ε/20 for every point at once. The difference is the domain, not the function — and Theorem 4.4.8 will show that compactness of the domain is what makes the difference disappear.

Why this matters for the mission: Filtration functions on compact spaces attain their bounds.

Segment 1 · ~25 min

What a continuous function does to a compact set

Start with what fails, since it explains the shape of what follows. If f(x) = x² and A = (−1, 1), then f(A) = [0, 1), so open sets need not map to open sets. If g(x) = 1/(1 + x²) and A = [0, ∞), then g(A) = (0, 1], so closed sets need not map to closed sets — and note the counterexample needed an unbounded closed set. — Abbott §4.4, p. 115

Theorem 4.4.2 (Preservation of Compact Sets). Let f : A → ℝ be continuous on A. If K ⊆ A is compact, then f(K) is compact. — Abbott §4.4, Theorem 4.4.2, p. 115

The proof is a paragraph and every step has been prepared. Take a sequence (yn) in f(K); each yn = f(xn) for some xn ∈ K. Compactness of K gives a subsequence (xnk) → x ∈ K; continuity in the form of an-10's Theorem 4.3.2(iv) gives f(xnk) → f(x); and f(x) ∈ f(K). So an arbitrary sequence in f(K) has a subsequence converging inside f(K), which is an-08's Definition 3.3.1. — Abbott §3.3, Definition 3.3.1, p. 84

Theorem 4.4.3 (Extreme Value Theorem). If f : K → ℝ is continuous on a compact set K, then f attains a maximum and a minimum: there exist x₀, x₁ ∈ K with f(x₀) ≤ f(x) ≤ f(x₁) for all x ∈ K. — Abbott §4.4, Theorem 4.4.3, p. 115

Abbott leaves this as Exercise 4.4.3, and once Theorem 4.4.2 is in hand it is three lines: f(K) is compact, so it is closed and bounded, so it has a supremum which — being a closed set's supremum — belongs to it, and anything in f(K) is a value of f. Every word of that sentence is an earlier unit. — Abbott §4.4, Exercise 4.4.3, p. 119

It is worth saying plainly why this is the theorem the mission needs. A filtration function on a point cloud is continuous on a compact set, and the Extreme Value Theorem is what guarantees the filtration has a largest and smallest value that are actually attained — so the barcode has finite endpoints rather than suprema that are approached and never reached.

Definition 4.4.5. A function f : A → ℝ is uniformly continuous on A if for every ε > 0 there exists a δ > 0 such that |x − y| < δ implies |f(x) − f(y)| < ε. — Abbott §4.4, Definition 4.4.5, p. 116

Compare with an-10's Definition 4.3.1 and exactly one thing has moved: there, the point c was fixed before ε was chosen, so δ could depend on both; here x and y are quantified after δ, so δ may depend only on ε. Uniform continuity is also a property of a domain, never of a point — the prediction gate's function is the same function in both halves. — Abbott §4.4, p. 117

Theorem 4.4.6 (Sequential Criterion for Nonuniform Continuity). f fails to be uniformly continuous on A if there exist ε₀ > 0 and two sequences (xn), (yn) in A with |xn − yn| → 0 and |f(xn) − f(yn)| ≥ ε₀. — Abbott §4.4, Theorem 4.4.6, p. 117

This is the tool the prediction gate used, and Abbott's other instance is worth having: h(x) = sin(1/x) on (0, 1), with xn = 1/(π/2 + 2nπ) and yn = 1/(3π/2 + 2nπ), where the inputs close up and the outputs stay 2 apart. Note the domain is bounded here — so boundedness alone is not what buys uniform continuity. — Abbott §4.4, p. 118

Theorem 4.4.8. A function that is continuous on a compact set K is uniformly continuous on K. — Abbott §4.4, Theorem 4.4.8, p. 118

Worked example — the proof of Theorem 4.4.8 (faded). — Abbott §4.4, p. 118

Suppose f is continuous on the compact K but not uniformly continuous. Theorem 4.4.6 gives ε₀ > 0 and sequences (xn), (yn) in K with |xn − yn| → 0 and |f(xn) − f(yn)| ≥ ε₀ for every n.

Because K is compact, ⟨your step: what does that give you about (xn)?⟩, say (xnk) → x ∈ K. Since |xn − yn| → 0, the matching terms (ynk) converge to the same x, by an-03's Algebraic Limit Theorem applied to ynk = xnk + (ynk − xnk).

Continuity at x now gives f(xnk) → f(x) and f(ynk) → f(x), so their difference tends to 0 — contradicting that it stays at least ε₀. ∎

Gap solution: a subsequence of (xn) converging to a point of K, by Definition 3.3.1. Note that both sequences are forced to the same limit, which is what makes the two image sequences collide.

Self-check 1. Is 1/x uniformly continuous on (0, 1)?

|xn − yn| = 1/(n(n+1)) → 0 while |f(xn) − f(yn)| = |n − (n+1)| = 1, so Theorem 4.4.6 applies with ε₀ = 1. The third option is the trap: (0, 1) is bounded but not closed, so it is not compact, and Theorem 4.4.8 does not apply.

Segment 2 · ~25 min

What a continuous function does to a connected set

Theorem 4.5.1 (Intermediate Value Theorem). If f : [a, b] → ℝ is continuous and L satisfies f(a) < L < f(b) or f(a) > L > f(b), then there exists c ∈ (a, b) with f(c) = L. — Abbott §4.5, Theorem 4.5.1, p. 120

Theorem 4.5.2 (Preservation of Connectedness). Let f : A → ℝ be continuous. If E ⊆ A is connected, then f(E) is connected. — Abbott §4.5, Theorem 4.5.2, p. 121

The second implies the first, and seeing that is the point of the section. [a, b] is connected by an-09's Theorem 3.4.7, so f([a, b]) is connected, so — by that same theorem read the other way — f([a, b]) contains every point between any two of its points. It contains f(a) and f(b), hence L, hence L = f(c) for some c. — Abbott §3.4, Theorem 3.4.7, p. 92

Theorem 4.5.2's own proof runs through an-09's Theorem 3.4.6: split f(E) into two nonempty disjoint pieces, pull the split back to E, use connectedness of E to get a sequence in one piece converging into the other, and push it forward with continuity. Every step is a theorem from an-09 or an-10 with nothing new added, which is the sense in which the whole chapter has been preparation. — Abbott §3.4, Theorem 3.4.6, p. 92

Interactive visual: both theorems, and the hypotheses that carry them

The blue curve is continuous on [0, 1]; the amber one has a jump. The dashed line is a target value L strictly between the two endpoint values. The continuous curve is forced to cross it; the discontinuous one steps over it. The bars on the left edge mark each function's largest and smallest value, with a dot on the curve at the point where it occurs. Both functions attain both — and that is the point worth pausing on. Blue attains them because Theorem 4.4.2 says a continuous function on a compact set must; amber attains them with nothing guaranteeing it, since it is not continuous. The Extreme Value Theorem is a promise, not a description, and a function that keeps the promise without meeting the hypothesis has not refuted anything.

The sentence under the picture is the one to take away. Discontinuous functions sometimes hit intermediate values; the theorem is that continuous ones always do. A theorem whose conclusion occasionally holds without its hypothesis is not thereby weaker — it is a guarantee, and the counterexample shows the guarantee is not free.

Definition 4.5.3. A function f has the intermediate value property on [a, b] if for every L strictly between f(a) and f(b) there is c ∈ (a, b) with f(c) = L. — Abbott §4.5, Definition 4.5.3, p. 124

Giving the conclusion its own name invites the obvious question: does the intermediate value property imply continuity? It does not, and an-12's Darboux Theorem produces the counterexamples — every derivative has this property, and derivatives need not be continuous. So the converse fails for an interesting reason rather than a cheap one. — Abbott §4.5, p. 124

Self-check 2. f is continuous on (0, 1]. Must it attain a maximum?

Theorem 4.4.3 needs K compact, and (0, 1] is bounded but not closed. The third option also fails: f(x) = x on (0, 1) is bounded and continuous with supremum 1, which it never attains. Boundedness of the function is not enough; attainment is what compactness buys.

Self-check 3. Does the Intermediate Value Theorem hold for continuous functions on ℚ ∩ [0, 2]?

an-09's Theorem 3.4.7 makes connectedness in ℝ the statement that no point between two members is missing, and ℚ ∩ [0, 2] fails that at every irrational. The theorem is about connectedness, connectedness is about completeness, and this is the same gap that made an-01's √2 argument necessary in the first place.

Self-check 4. Which single hypothesis does the Extreme Value Theorem share with Theorem 4.4.8?

Both theorems take a continuous function on a compact set and conclude something that fails on non-compact domains — attainment of extrema in one case, a uniform δ in the other. Neither needs the domain to be an interval, which is why they apply to the Cantor set as readily as to [0, 1].

Self-check 5. A continuous function maps a compact set to a compact set and a connected set to a connected set. What does it map an open set to?

Openness is preserved by preimages, as an-10's topological characterisation says, and by images not at all. Keeping straight which direction each property travels in is most of what this section is for.

You try (solo). Prove the Extreme Value Theorem from Theorem 4.4.2 rather than from scratch. — Abbott §4.4, Exercise 4.4.3, p. 119

Hint: f(K) is compact, hence closed and bounded, so it has a supremum. The only thing to prove is that a nonempty closed bounded set contains its supremum — and an-07's Exercise 3.2.11 already says the supremum is in the closure.

Guided proof practice

Prompt: Prove Theorem 4.4.2: the continuous image of a compact set is compact. Hint: start from an arbitrary sequence in f(K) and work backwards to K. Every term of that sequence is a value, so it has at least one preimage in K — say why you may choose one. Then use compactness of K and the sequential characterisation of continuity in turn. — Abbott §4.4, Theorem 4.4.2, p. 115

Click to reveal model answer

Model answer. Let (yn) be an arbitrary sequence in f(K). By definition of the image, for each n there is at least one point xn ∈ K with f(xn) = yn; fix one such choice for each n.

Since K is compact, an-08's Definition 3.3.1 gives a subsequence (xnk) converging to some x ∈ K. Because f is continuous at x ∈ K, an-10's Theorem 4.3.2(iv) gives f(xnk) → f(x); that is, (ynk) → f(x).

Finally f(x) ∈ f(K) since x ∈ K. So the arbitrary sequence (yn) has a subsequence converging to a point of f(K), and f(K) is compact. ∎

Two remarks. The proof never mentions closed, bounded, or ε — it is pure Definition 3.3.1, which is why the sequential form of compactness was worth keeping alongside Heine–Borel. And the phrase "fix one such choice" is the only step with any logical weight: the preimage of yn may contain many points, and a choice is being made for every n at once. At this level that passes without comment, but it is worth noticing that a choice was made rather than a formula given.
