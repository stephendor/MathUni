Compactness and Heine–Borel (an-08)

The property that makes infinite behave like finite.

A finite set has properties an infinite one has no right to: every sequence in it repeats a value infinitely often, every cover of it by anything at all has a finite subcover, every continuous function on it attains a maximum. Compactness is the exact hypothesis that buys those properties back for infinite sets.

The remarkable thing about ℝ is that the hypothesis has three completely different-looking descriptions — one about sequences, one about closedness and boundedness, one about covers — and they are the same condition. That is the Heine–Borel Theorem, and the third description is the one that survives when ℝ is left behind.

Prediction gate — commit before reading on. A collection of open sets whose union contains a set A is called an open cover of A. (i) Must every open cover of the open interval (0, 1) contain finitely many sets that already cover (0, 1)? (ii) Must every open cover of the closed interval [0, 1] contain such a finite subcollection?

The intervals Ox = (x/2, 1) for x ∈ (0, 1) cover (0, 1), because every point is above half of itself. But any finite subcollection has a smallest left endpoint, and everything below that endpoint is uncovered — so no finite subcover exists. Add the endpoints and the situation reverses completely. Both facts are drawn in the canvas in Segment 2, and the difference between them is Theorem 3.3.8.

Why this matters for the mission: Compact metric spaces are where TDA's theory lives.

Segment 1 · ~25 min

Compactness by sequences, and what it forces

Definition 3.3.1. A set K ⊆ ℝ is compact if every sequence in K has a subsequence that converges to a limit that is also in K. — Abbott §3.3, Definition 3.3.1, p. 84

Two demands, and it is worth separating them, because they are met by two different earlier theorems. A convergent subsequence must exist: that is an-04's Bolzano–Weierstrass Theorem and it needs boundedness. Its limit must be in K: that is an-07's Definition 3.2.7 and it needs closedness. The whole of Heine–Borel is the observation that these two are not merely sufficient but necessary.

Worked example — closed intervals are compact (fully worked). Let (an) be any sequence contained in [c, d]. — Abbott §3.3, Example 3.3.2, p. 84

The sequence is bounded, since every term lies between c and d, so an-04's Theorem 2.5.5 supplies a convergent subsequence (ank) → x. And [c, d] is a closed set, so it contains its limit points and x ∈ [c, d]. Both clauses of Definition 3.3.1 are met. ∎ — Abbott §2.5, Theorem 2.5.5, p. 56

Read the proof as a list of hypotheses consumed. Boundedness was spent on Bolzano–Weierstrass and closedness on the limit. Nothing else about intervals was used at any point — which is the clue that "closed interval" is the wrong archetype and "closed and bounded" is the right one.

Definition 3.3.3. A set A ⊆ ℝ is bounded if there exists M > 0 such that |a| ≤ M for all a ∈ A. — Abbott §3.3, Definition 3.3.3, p. 84

Theorem 3.3.4 (Heine–Borel Theorem). A set K ⊆ ℝ is compact if and only if it is closed and bounded. — Abbott §3.3, Theorem 3.3.4, p. 84

Worked example — compact forces bounded (faded). — Abbott §3.3, p. 85

Suppose K is compact but not bounded. Unboundedness means no M works, so for each n ∈ ℕ there is a point xn ∈ K with |xn| > n. That is a sequence in K, so compactness hands back a convergent subsequence (xnk).

But the terms of that subsequence satisfy |xnk| > nk ≥ k, so the subsequence is unbounded — and an-03's ⟨your step: which theorem?⟩ says a convergent sequence cannot be. Contradiction, so K is bounded. ∎

Gap solution: Theorem 2.3.2, every convergent sequence is bounded. Note also where an-04's index fact nk ≥ k earned its keep — without it the subsequence's terms carry no bound at all.

The other half of the forward direction is shorter: if x is the limit of a sequence in K, compactness gives a convergent subsequence, an-04's Theorem 2.5.2 says it converges to the same x, and Definition 3.3.1 puts that limit in K. So K contains its limit points. Abbott leaves the converse — closed and bounded implies compact — as Exercise 3.3.2, and it is the Guided Proof below. — Abbott §3.3, p. 85

Abbott adds a warning worth repeating: closed intervals are a misleading archetype. The Cantor set of an-09 is compact and contains no interval at all. What compactness controls is not shape but the two properties above. — Abbott §3.3, Exercise 3.3.3, p. 88

Theorem 3.3.5 (Nested Compact Set Property). If K₁ ⊇ K₂ ⊇ K₃ ⊇ ⋯ is a nested sequence of nonempty compact sets, then the intersection of all of them is not empty. — Abbott §3.3, Theorem 3.3.5, p. 85

This is an-01's Nested Interval Property with "closed interval" weakened to "compact set", and the proof shows why that weakening is free: pick a point from each Kn, note the resulting sequence lies in K₁, extract a convergent subsequence, and observe that its limit lies in every Kn because from index n onwards the whole tail does.

Self-check 1. Is the set ℕ = {1, 2, 3, …} compact?

The sequence xn = n has no convergent subsequence at all, since every subsequence is unbounded. The third option is a real trap: some sequences in ℕ do have constant subsequences, but Definition 3.3.1 quantifies over every sequence.

Self-check 2. Is the set {1/n : n ∈ ℕ} compact?

an-07's worked example established that 0 is the only limit point and is not in the set. Concretely, the sequence 1, 1/2, 1/3, … lies in the set, converges to 0, and every subsequence also converges to 0 — which is not in the set, so Definition 3.3.1 fails. Adding the single point 0 makes it compact.

Segment 2 · ~25 min

Open covers, and the description that outlives ℝ

Definition 3.3.6. An open cover for A ⊆ ℝ is a possibly infinite collection of open sets whose union contains A. Given an open cover, a finite subcover is a finite subcollection of those same sets whose union still contains A. — Abbott §3.3, Definition 3.3.6, p. 86

Note what a finite subcover is not: it is not permission to choose new smaller sets, and it is not a claim that some clever cover is finite. The sets must come from the cover you were handed, and the claim must hold for every cover — which is what makes it a strong hypothesis and an awkward one to verify directly.

Interactive visual: a cover with no finite subcover, and the repair

The bands are the sets Ox = (x/2, 1) for various x. Together they cover (0, 1). The marker below shows the union of the finitely many bands drawn so far — always an interval (x′/2, 1) that misses everything to the left of x′/2. Toggle to the closed interval and two extra sets finish the job at once, one at each endpoint. Both are needed: every band is (x/2, 1), which omits the point 1 exactly as it omits 0, so this family is a cover of the open interval and does not cover [0, 1] until both ends are patched. The right-hand endpoint is the one that gets forgotten, because the bands all visibly run towards it.

Formally: given any finite subcollection Ox₁, …, Oxn, let x′ = min{x₁, …, xn}. The union of those sets is exactly (x′/2, 1), which omits every point of (0, 1) at or below x′/2 — and there are such points, since x′/2 > 0. The minimum over a finite set is doing the work again, and it is doing it in the opposite direction from an-07's Theorem 3.2.3. — Abbott §3.3, Example 3.3.7, p. 86

Theorem 3.3.8. For K ⊆ ℝ the following are equivalent: (i) K is compact; (ii) K is closed and bounded; (iii) every open cover for K has a finite subcover. — Abbott §3.3, Theorem 3.3.8, p. 87

The equivalence of (i) and (ii) is Theorem 3.3.4, so the work is in (iii). That (iii) implies bounded is quick and worth having in mind, because it shows the technique: cover K by the neighbourhoods V₁(x) for x ∈ K, take a finite subcover, and note that a finite union of bounded sets is bounded. — Abbott §3.3, p. 87

That (iii) implies closed is more delicate and is the argument to study. Suppose y is a limit of a sequence in K but y ∉ K. Every x ∈ K is then a positive distance from y, so the intervals of radius |x − y|/2 around each x ∈ K form an open cover — one built to keep y out with room to spare. A finite subcover has a smallest such radius, and that leaves a neighbourhood of y disjoint from all of them, contradicting that points of K come arbitrarily close to y. — Abbott §3.3, p. 87

Why does this description matter more than the other two? Because of what it does not mention. Sequences need a notion of convergence and boundedness needs a distance; "every open cover has a finite subcover" mentions only open sets, which is precisely the structure an-07's Theorem 3.2.3 showed can be axiomatised without a metric. In Semester 2 this becomes the definition of compactness, and Definitions 3.3.1 and 3.3.3 become theorems that hold in some spaces and fail in others.

Self-check 3. Does the collection {(−1, 1)} — a single open set — form an open cover of [0, 1]?

Definition 3.3.6 asks only that the union contain the set; the collection may be finite, the sets may overlap freely, and they may spill outside. What Theorem 3.3.8(iii) claims is that whatever cover you are given — including deliberately awkward infinite ones — a finite subcollection suffices.

Self-check 4. Where exactly does Example 3.3.7's cover fail to be a cover of [0, 1]?

Both endpoints are missing, and the second one is the one that gets forgotten. Every Ox has left endpoint x/2 > 0, so 0 is in none of them — that much is obvious from the picture. But (x/2, 1) is open at its right end too, so 1 is in none of them either, however close the bands appear to come. "Reaches up to 1" and "contains 1" are different claims, and an open interval never makes the second one. Repairing this cover into a cover of [0, 1] therefore takes two extra sets, not one.

Self-check 5. A set is compact. Is every subset of it compact?

Boundedness is inherited by subsets; closedness is not. So the correct statement is that a closed subset of a compact set is compact — and by Theorem 3.3.4 that is the same as saying a closed subset of a closed bounded set is closed and bounded.

You try (solo). Prove that if K is compact and F is closed, then K ∩ F is compact, in two ways: once from Definition 3.3.1, and once from Theorem 3.3.4. — Abbott §3.3, Exercise 3.3.4, p. 88

Hint: the second proof is two lines and uses an-07's Theorem 3.2.14. Do it first, then write the sequence proof and notice which parts of it are doing the same work.

Guided proof practice

Prompt: Prove the converse half of Theorem 3.3.4: if K ⊆ ℝ is closed and bounded, then K is compact. Hint: you must start from an arbitrary sequence in K and produce a convergent subsequence with its limit in K. You have exactly two hypotheses; each buys exactly one of those two requirements, and an-04 supplies the machinery for the first. — Abbott §3.3, Exercise 3.3.2, p. 88

Click to reveal model answer

Model answer. Let (xn) be an arbitrary sequence with every xn ∈ K. Because K is bounded, there is M > 0 with |a| ≤ M for all a ∈ K, so in particular |xn| ≤ M for every n and the sequence is bounded in the sense of an-03's Definition 2.3.1.

By an-04's Bolzano–Weierstrass Theorem there is a convergent subsequence (xnk) → x for some x ∈ ℝ. It remains to show x ∈ K. The terms xnk all lie in K, and they converge to x, so an-07's Theorem 3.2.8 applies: a convergent sequence is Cauchy, and a Cauchy sequence in a closed set has its limit in that set. Hence x ∈ K, both requirements of Definition 3.3.1 are met, and K is compact. ∎

Note the one subtlety. Concluding x ∈ K directly from Definition 3.2.7 requires x to be a limit point of K, and a limit point needs a sequence avoiding x — which a subsequence of an arbitrary sequence is under no obligation to do. Routing through Theorem 3.2.8 sidesteps that case split, which is exactly why an-07 proved it. Alternatively, split into the case where xnk = x for some k, where x ∈ K at once, and the case where it never does.
