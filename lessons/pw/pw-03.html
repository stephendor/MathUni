Sets, functions, images and preimages, done rigorously (pw-03)

Here is a fact that catches nearly everyone the first time they meet it: if f is a function and A, B are subsets of its domain, you would expect f(A ∩ B) to equal f(A) ∩ f(B) — after all, f just relabels elements, so surely intersecting first or relabelling first shouldn't matter. It does. Take f: ℝ → ℝ, f(x) = x², with A = [−2, 0] and B = [0, 2]. Then A ∩ B = {0}, so f(A ∩ B) = {0} — a single point. But f(A) = [0, 4] and f(B) = [0, 4] too, so f(A) ∩ f(B) = [0, 4] — an entire interval. The two sides aren't even close. Somewhere between "intersect the inputs" and "intersect the outputs", information got lost — and pinning down exactly what got lost, and why the same trick doesn't lose anything when you go the other way (preimages, not images), is the whole of today's lesson.

Prediction Gate: Before you read on, commit to an answer. The counterexample above killed the equality f(A ∩ B) = f(A) ∩ f(B). What about the one-way inclusion f(A ∩ B) ⊆ f(A) ∩ f(B)?

Always true — and Segment 1 proves it as Lemma 1, using nothing about f beyond the definition of image. Note which direction survived: the hook's example has the left side smaller ({0} inside [0,4]), so "the two sides differ" rules out equality without ruling out containment. Segment 3 then pins down the exact hypothesis that upgrades the inclusion to equality.

Why this matters for the mission: Continuity in topology is defined entirely via preimages.

Not images — and by the end of today you'll see in your bones why that is the only sane choice. The asymmetry the hook just exposed is the whole reason topology picks the direction it does.

Segment 1 · ~25 min

Images of unions and intersections

Fix a function f : A → B. For a subset X ⊆ A, the image of X collects every output you can reach by feeding in something from X:

Definition (Image). Let f : A → B and X ⊆ A. The image of X is

f(X) = { y ∈ B : y = f(x) for some x ∈ X }.

Cummings, Proofs, Ch. 8 "Functions", p. 280.

The hook already showed f(A ∩ B) can be a strict subset of f(A) ∩ f(B). What's still true is the inclusion — and that's worth nailing down as a lemma, because the problem sets for this unit will lean on it.

Lemma 1 (Images and intersections). For any f : A → B and C, D ⊆ A,

f(C ∩ D) ⊆ f(C) ∩ f(D).

Proof. Let y ∈ f(C ∩ D). By definition of image, y = f(x) for some x ∈ C ∩ D. Since x ∈ C ∩ D, we have x ∈ C, so y = f(x) ∈ f(C). Likewise x ∈ D, so y ∈ f(D). Hence y ∈ f(C) ∩ f(D). As y was arbitrary, f(C ∩ D) ⊆ f(C) ∩ f(D). ∎

Notice exactly where the proof stalls if you try to run it backwards. Given y ∈ f(C) ∩ f(D), you know y = f(x₁) for some x₁ ∈ C and y = f(x₂) for some x₂ ∈ D — but nothing forces x₁ and x₂ to be the same point. In the hook's example, y = 4 ∈ f(A) ∩ f(B) comes from x₁ = −2 ∈ A and x₂ = 2 ∈ B — two different preimages, neither of which lies in A ∩ B = {0}. That mismatch is the entire mechanism behind the failure of equality.

Worked example. Let f : ℤ → ℤ, f(n) = n², C = {−3, −2, −1}, D = {1, 2, 3}.

C ∩ D = ∅, so f(C ∩ D) = f(∅) = ∅.

f(C) = {9, 4, 1}, f(D) = {1, 4, 9}, so f(C) ∩ f(D) = {1, 4, 9}.

Indeed ∅ ⊆ {1,4,9} (Lemma 1 holds) and the inclusion is strict — a clean second illustration that equality is the exception, not the rule.

The union case is different in kind — and this is the fact worth remembering, because it tells you unions are "safe" under images in a way intersections are not.

Lemma 2 (Images and unions). For any f : A → B and C, D ⊆ A,

f(C ∪ D) = f(C) ∪ f(D).

Proof. (⊆) Let y ∈ f(C ∪ D). Then y = f(x) for some x ∈ C ∪ D, so x ∈ C or x ∈ D. If x ∈ C then y ∈ f(C); if x ∈ D then y ∈ f(D). Either way y ∈ f(C) ∪ f(D).

(⊇) Let y ∈ f(C) ∪ f(D). Then y ∈ f(C) or y ∈ f(D). Say y ∈ f(C): then y = f(x) for some x ∈ C ⊆ C ∪ D, so y ∈ f(C ∪ D). The case y ∈ f(D) is identical. Combining both directions, f(C ∪ D) = f(C) ∪ f(D). ∎

Why does union survive but intersection doesn't? Existential quantifiers ("some x") play nicely with "or" — an x witnessing membership in C or D is still just one x — but they don't play nicely with "and", because "and" over the image side needs a single shared witness, and images only ever promise you separate witnesses. Keep that asymmetry in your head; it resurfaces in a moment as the entire reason preimages behave better.

Faded example. Let f : ℝ → ℝ, f(x) = x², C = [1, 3], D = [−2, −1].

C ∪ D = [−2,−1] ∪ [1,3]. Applying f pointwise: ⟨your step — compute f(C∪D) directly⟩.

f(C) = [1, 9] and f(D) = ⟨your step⟩, so f(C) ∪ f(D) = ⟨your step⟩.

Check the two answers agree, as Lemma 2 guarantees they must.

You try. Let f : ℤ → ℤ, f(n) = |n|, C = {−5,−4,−3}, D = {3,4,5}. Compute f(C ∩ D) and f(C) ∩ f(D) separately, and confirm Lemma 1's inclusion (strict or not?).

Self-check 1. Is f(A ∩ B) ⊆ f(A) ∩ f(B) a theorem for every function f and every A, B?

Lemma 1's proof used nothing about f beyond the definition of image — no injectivity, no surjectivity. The inclusion is unconditional; it's the reverse inclusion (equality) that needs an extra hypothesis, which segment 3 pins down exactly.

Self-check 2. Which best explains why f(C ∪ D) = f(C) ∪ f(D) but f(C ∩ D) can be a strict subset of f(C) ∩ f(D)?

Size isn't the mechanism — the mechanism is witnesses. "Or" is satisfied by a single x; "and" on the output side can be satisfied by two different x's, one in C and one in D, neither of which need lie in C∩D.

Segment 2 · ~20 min

Preimages: the cleaner half of the story

Now run the machinery backwards. Instead of pushing a subset of the domain forward, pull a subset of the codomain back.

Definition (Preimage / inverse image). Let f : A → B and Y ⊆ B. The inverse image of Y is

f⁻¹(Y) = { x ∈ A : f(x) ∈ Y }.

Cummings, Proofs, Ch. 8 "Functions", p. 280. (This uses the symbol f⁻¹ purely as notation for a set-building operation — it exists whether or not f itself is invertible.)

That last parenthetical matters: f⁻¹(Y) is defined for any function f, invertible or not. It just names "everything that lands in Y". And because membership in f⁻¹(Y) is phrased as a condition on a single point x (namely "f(x) ∈ Y"), rather than as an existential search for some witness, preimages inherit set-operation laws perfectly — no witness-mismatch problem at all.

Lemma 3 (Preimages commute with ∩, ∪, and complement). Let f : A → B and E, F ⊆ B. Then

(i) f⁻¹(E ∩ F) = f⁻¹(E) ∩ f⁻¹(F)    (ii) f⁻¹(E ∪ F) = f⁻¹(E) ∪ f⁻¹(F)    (iii) f⁻¹(Eᶜ) = (f⁻¹(E))ᶜ

Proof of (i). For any x ∈ A:

x ∈ f⁻¹(E ∩ F)  ⟺  f(x) ∈ E ∩ F  ⟺  f(x) ∈ E and f(x) ∈ F  ⟺  x ∈ f⁻¹(E) and x ∈ f⁻¹(F)  ⟺  x ∈ f⁻¹(E) ∩ f⁻¹(F).

Every step is a biconditional (⟺), not just an inclusion, so the two sets have exactly the same elements. ∎

Compare that to Lemma 1's proof: there we only ever got a one-way implication ("y ∈ f(C∩D) ⟹ y ∈ f(C)∩f(D)"), because the definition of image involves an existential ("some x"). The preimage definition involves no existential at all — it's a direct test on x — so "and" on the Y-side converts losslessly into "and" on the x-side. That's the precise sense in which preimages are the "cleaner" operation the hook promised, and exactly why continuity in topology (mission link) is phrased with preimages: you get honest equalities to build a theory on, not one-way inclusions you have to patch with extra hypotheses.

Faded example — proof of (ii). For any x ∈ A:

x ∈ f⁻¹(E ∪ F)  ⟺  f(x) ∈ E ∪ F  ⟺  ⟨your step — unpack "f(x) ∈ E ∪ F" using the definition of union⟩  ⟺  x ∈ f⁻¹(E) or x ∈ f⁻¹(F)  ⟺  ⟨your step — name the final set⟩.

You try. Prove part (iii): f⁻¹(Eᶜ) = (f⁻¹(E))ᶜ, where complements are taken in B and A respectively. (Hint: run the same biconditional chain, unpacking "f(x) ∉ E" at the middle step.)

Worked example (concrete check). Let f : ℝ → ℝ, f(x) = x², E = [1, 4], F = [4, 9].

E ∩ F = {4}, so f⁻¹(E ∩ F) = f⁻¹({4}) = {−2, 2}.

f⁻¹(E) = [−2,−1] ∪ [1,2], f⁻¹(F) = [−3,−2] ∪ [2,3]. Their intersection is {−2} ∪ {2} = {−2, 2} — exactly matching f⁻¹(E∩F), as Lemma 3(i) guarantees, no strictness anywhere.

Self-check 3. Why does Lemma 3(i) give an equality (⟺ throughout) while Lemma 1 only gave an inclusion?

The definition f⁻¹(Y) = {x : f(x) ∈ Y} tests each x directly against a condition, so logical connectives (and/or/not) on the Y-side translate word-for-word to the x-side. Images instead package an existential quantifier, which only distributes cleanly over "or", not "and".

Self-check 4. f : ℝ → ℝ, f(x)=x². Is f⁻¹((−∞,0)) equal to ∅?

f⁻¹(Y) = {x : f(x) ∈ Y}. Since x² is never negative, no x satisfies f(x) ∈ (−∞,0), so the preimage is the empty set — a perfectly legal, well-defined answer.

Segment 3 · ~20 min

Injective and surjective, seen through images and preimages

Recall the two definitions this unit's arrows-and-dots pictures were building towards.

Definition 8.3 (Injective). f : A → B is injective if f(a₁) = f(a₂) implies a₁ = a₂.
Definition 8.5 (Surjective). f : A → B is surjective if for every b ∈ B there exists a ∈ A with f(a) = b.
Definition 8.7 (Bijective). f is bijective if it is both.

Cummings, Proofs, Ch. 8 "Functions", pp. 251–253.

Segment 1 left a loose thread: Lemma 1 only gave f(C∩D) ⊆ f(C)∩f(D). The missing reverse inclusion turns out to be exactly injectivity — not an approximation of it, the precise characterisation.

Lemma 4 (Injectivity closes the intersection gap). If f : A → B is injective, then for all C, D ⊆ A, f(C ∩ D) = f(C) ∩ f(D).

Proof. By Lemma 1, f(C∩D) ⊆ f(C)∩f(D) always holds, so it suffices to prove the reverse inclusion. Let y ∈ f(C) ∩ f(D). Then y ∈ f(C), so y = f(x₁) for some x₁ ∈ C; and y ∈ f(D), so y = f(x₂) for some x₂ ∈ D. Now f(x₁) = y = f(x₂), and since f is injective, x₁ = x₂. Call this common point x: then x ∈ C and x ∈ D, so x ∈ C ∩ D, and y = f(x) ∈ f(C ∩ D). Hence f(C) ∩ f(D) ⊆ f(C ∩ D), and combined with Lemma 1, equality follows. ∎

This is precisely the missing ingredient from the hook: x² failed because it isn't injective on [−2,2] — the two witnesses x₁=−2, x₂=2 genuinely differ, and injectivity is exactly the hypothesis that rules that out.

A second characterisation runs through preimages rather than images, and it's the one the guided proof below asks you to establish yourself.

Lemma 5 (Surjectivity and preimages). f : A → B is surjective if and only if f(f⁻¹(Y)) = Y for every Y ⊆ B.

Proof sketch. The inclusion f(f⁻¹(Y)) ⊆ Y holds unconditionally: any element of f(f⁻¹(Y)) is f(x) for some x with f(x) ∈ Y, so it lies in Y. The reverse inclusion Y ⊆ f(f⁻¹(Y)) asks: for every y ∈ Y, is there some x with f(x) = y? That is exactly the surjectivity condition applied to the point y. So the reverse inclusion holds for every Y precisely when f is surjective. ∎ (Compare Cummings Exercise 8.30(c)–(d), which frames these as two separate conjectures — the lesson here is that combining "always true" with "true iff surjective" is what produces the full iff.)

Self-check 5. f : ℤ → ℤ, f(n) = 2n. Is f(f⁻¹({4,5,6})) = {4,5,6}?

f is not surjective (odd numbers are never hit), so Lemma 5's equality can fail. Concretely f⁻¹({4,5,6}) = {2,3} and f({2,3}) = {4,6} ≠ {4,5,6} — the missing 5 is exactly the non-surjectivity showing up.

Self-check 6. Let f : A → B be injective and C, D ⊆ A with C ∩ D = ∅. What can you say about f(C) and f(D)?

By Lemma 4, injectivity gives f(C∩D) = f(C)∩f(D). Since C∩D = ∅, f(C∩D) = f(∅) = ∅, so f(C)∩f(D) = ∅ as well. Without injectivity this can fail — that's exactly the hook's counterexample.

Guided proof. Prove: f : A → B is injective if and only if X = f⁻¹(f(X)) for every X ⊆ A.

(Hint: split into the inclusion that's always true, and the inclusion that needs injectivity — the same strategy Lemma 4 and Lemma 5 both used.)

Reveal model answer

(⊆, always true). Let x ∈ X. Then f(x) ∈ f(X) by definition of image, so x ∈ f⁻¹(f(X)) by definition of preimage. This holds for any f, injective or not: X ⊆ f⁻¹(f(X)) always.

(⟸ f injective ⟹ f⁻¹(f(X)) ⊆ X). Suppose f is injective and let a ∈ f⁻¹(f(X)). Then f(a) ∈ f(X), so f(a) = f(x) for some x ∈ X. By injectivity, a = x, so a ∈ X. Hence f⁻¹(f(X)) ⊆ X, and combined with the always-true inclusion, X = f⁻¹(f(X)).

(⟹ the equality forces injectivity). Suppose X = f⁻¹(f(X)) holds for every X ⊆ A. Suppose f(a₁) = f(a₂); we must show a₁ = a₂. Let X = {a₁}. Then f(X) = {f(a₁)}, and by hypothesis f⁻¹(f(X)) = X = {a₁}. But f(a₂) = f(a₁) ∈ f(X), so a₂ ∈ f⁻¹(f(X)) = {a₁}, forcing a₂ = a₁. Hence f is injective. ∎

  1. What does the hook's counterexample show, and what's the one-sentence reason it happens (witnesses)?

Reveal the skeleton to check against

(1) f(C∩D) can be a strict subset of f(C)∩f(D) because an element of f(C)∩f(D) may come from two different points, one in C and one in D, that don't have to lie in C∩D. (2) Union survives (f(C∪D)=f(C)∪f(D)) because "or" distributes cleanly over an existential witness; intersection needs f injective to force the two witnesses to coincide (Lemma 4). (3) Preimage membership is a direct pointwise test ("f(x)∈Y"), not an existential search, so logical connectives on the Y-side translate word-for-word to the x-side — no witness-matching problem ever arises (Lemma 3). (4) f injective ⟺ X=f⁻¹(f(X)) for every X⊆A (Lemma 4/guided proof); f surjective ⟺ Y=f(f⁻¹(Y)) for every Y⊆B (Lemma 5).
