Epsilon-delta craft (pw-04)

Every epsilon proof is the same two-player game, and once you see it as a game the notation stops being decoration. Your opponent moves first. They name a tolerance ε > 0 — as small and as spiteful as they like — and they are allowed to see the claim you are defending but not your reply in advance. You move second. You must produce a threshold: an N beyond which the sequence stays inside the tolerance, or a δ-window around the input inside which the function stays inside it. You win if you have a reply for every opening move. You lose if there is even one ε for which you have nothing.

That is the whole content of "∀ε > 0 ∃N" — and it explains the thing that makes these proofs feel backwards when you first write one. The order the quantifiers are written in is the order of play, so your δ is allowed to depend on ε (you moved second, you saw their move) but their ε may never depend on your δ. Every classic epsilon-proof error is the same error: playing out of turn.

Prediction Gate: Before you read on, commit. Someone reverses the quantifiers and defines: "(xₙ) verconges to x if there exists ε > 0 such that for all N ∈ ℕ and for all n ≥ N, |xₙ − x| < ε." Which sequences verconge to 0?

Every bounded sequence. The opponent no longer chooses; you choose one ε and it must work for all N — so pick ε larger than the bound and take N = 1. The sequence 1, 0, 1, 0, … verconges to 0 and diverges. Segment 1 works this through; it is Abbott's Exercise 2.2.2, and it is the sharpest single test of whether you have read a quantifier or just recognised its shape.

Why this matters for the mission: Stability of persistence diagrams is an epsilon statement.

Read that mission line again once you have finished Segment 1. The stability theorem says the bottleneck distance between two diagrams is at most the sup-distance between the functions that produced them — which is exactly this game: name a tolerance on the OUTPUT — how far apart you are willing to let the two diagrams be — and the theorem answers with a tolerance on the input, namely that the functions agree to within that same amount. Output first, input second, as always: ε is the tolerance you are held to and δ is what you are allowed to demand in return. It is this game played once, at the level of an entire pipeline.

Segment 1 · ~25 min

The order of play

Here is the definition you met in an-03, written the way Abbott writes it.

Definition (Convergence of a sequence). A sequence (aₙ) converges to a real number a if, for every positive number ε, there exists an N ∈ ℕ such that whenever n ≥ N it follows that |aₙ − a| < ε.

Abbott, Understanding Analysis, Definition 2.2.3, p. 39.

Cummings states the same definition with "n > N" where Abbott writes "n ≥ N". Nothing depends on this: a threshold that works from N onwards works from N+1 onwards, and conversely. It is worth noticing anyway, because it is the kind of difference that makes two textbooks look like they disagree when they do not — and because in a written proof you must be consistent with whichever one you have stated.

Now the reversal. Abbott sets it as an exercise and gives the fake notion a fake name, which is a good habit: an object with a name is easier to reason about than "the wrong definition".

The vercongence test. Say (xₙ) verconges to x if there exists ε > 0 such that for all N ∈ ℕ and for all n ≥ N, |xₙ − x| < ε.

Abbott writes the last clause as "n ≥ N implies |xₙ − x| < ε", leaving n to be read as universally quantified — as does his Definition 2.2.3, and as does almost every textbook. The convention is standard and harmless in print. It is written out here because this is the one unit whose subject is reading quantifiers exactly, and a free variable in a definition of a property of sequences is precisely the thing we are asking you to notice elsewhere.

Claim. (xₙ) verconges to x if and only if (xₙ) is bounded.

Proof. (⇒) Suppose ε works. Taking N = 1, every term satisfies |xₙ − x| < ε, so every xₙ lies in (x − ε, x + ε) and the sequence is bounded.

(⇐) Suppose |xₙ| ≤ M for all n. Take ε = M + |x| + 1. Then |xₙ − x| ≤ |xₙ| + |x| ≤ M + |x| < ε for every n, so this single ε works for every N. ∎

Cf. Abbott, Understanding Analysis, Exercise 2.2.2, p. 43.

So vercongence is not a weaker form of convergence, or a stronger one — it is boundedness, wearing convergence's clothes. The sequence 1, 0, 1, 0, 1, 0, … verconges to 0, to 1, and to 1000, and converges to nothing. Swapping two quantifiers did not blur the definition; it replaced it with a different one entirely.

Worked example — reading the game off the symbols. Prove that (1/n) converges to 0.

Their move. Let ε > 0 be arbitrary. We know nothing about it except that it is positive; in particular we may not assume it is small.

Our move. Choose N to be any natural number with N > 1/ε. (Such an N exists by the Archimedean property, which is an-01's result — say so in a written proof rather than assuming it.)

The verification. For any n ≥ N we have n > 1/ε, hence 1/n < ε, hence |1/n − 0| = 1/n < ε. ∎

Notice that N was written down after ε and mentions it. That is not a stylistic accident — it is the proof recording who moved when.

You try. Write out, in the same three beats, a proof that the constant sequence aₙ = 7 converges to 7. Where does your N mention ε? What does it mean that it does not have to?

Self-check 1. In "for every ε > 0 there exists N", which quantity is allowed to depend on which?

Reading order is dependency order: ε is fixed before N is chosen, so N may be built out of ε — and almost always is. A proof whose N does not mention ε is not automatically wrong (the constant sequence is the standard case), but it is worth a second look.

Self-check 2. A student writes: "Let N = 100. Then for all ε > 0 and all n ≥ N, |1/n| < ε." What has gone wrong?

This is vercongence again, in disguise. Take ε = 1/1000: the claim asserts 1/n < 1/1000 for all n ≥ 100, and n = 100 already breaks it. The fix is not a bigger constant — no constant works — but making N a function of ε.

Self-check 3. To prove a sequence does not converge to a, what must you exhibit?

Negating ∀ε ∃N P gives ∃ε ∀N ¬P: the roles swap and you become the first player. You name the ε — one is enough — and must then defeat every N your opponent offers. For 1, 0, 1, 0, … against the target 0, ε = 1/2 does it: whatever N is given, some later term equals 1.

Segment 2 · ~25 min

Scratch work is not the proof

Move from sequences to functions. The game is identical; only the shape of your reply changes, from a threshold N to a window δ.

Definition (Functional limit). Let f : A → ℝ and let c be a limit point of A. Then limx→c f(x) = L if for all ε > 0 there exists some δ > 0 such that for every x ∈ A with 0 < |x − c| < δ, we have |f(x) − L| < ε.

Cummings, Real Analysis, Definition 6.8, p. 226.

The "0 < " on the left is doing real work: it excludes x = c itself, which is why a limit can exist at a point where the function is undefined, and why c is required to be a limit point of A rather than merely a member of it.

Now the craft. An ε–δ proof is written in the opposite order from the order in which it is discovered, and the discipline of keeping those two orders separate is most of what this lesson is teaching. Cummings marks the two phases explicitly, and we adopt his labels.

Worked example. Let f(x) = 5x + 2. Prove limx→3 f(x) = 17.

Scratch Work (discovered backwards, and not part of the proof). Assume the conclusion and unwind it until only |x − 3| is left on one side:

|5x + 2 − 17| < ε  ⟺  |5x − 15| < ε  ⟺  5|x − 3| < ε  ⟺  |x − 3| < ε/5.

The last line is a constraint on the one quantity we control, so it tells us what to choose: δ = ε/5.

Proof (written forwards). Let ε > 0. Let δ = ε/5 > 0. Then for any x with 0 < |x − 3| < δ,

|f(x) − 17| = |5x − 15| = 5|x − 3| < 5δ = 5 · ε/5 = ε. ∎

Cummings, Real Analysis, Example 6.9, p. 231.

Compare the two halves. The scratch work runs from the goal to the choice and is full of "⟺"; the proof runs from the choice to the goal and is a chain of "=" and one "<". If you hand in the scratch work you have written something true and it is still not a proof, because it assumes what was to be shown. If you hand in only the proof, δ = ε/5 appears out of nowhere and the reader cannot tell whether you found it or guessed it. Working mathematicians do the first in private and publish the second — and the reason the choice looks unmotivated in every textbook is that the motivation was deliberately deleted.

Faded example. Let f : ℝ \ {2} → ℝ with f(x) = (3x² − 12)/(x − 2). Prove limx→2 f(x) = 12.

Scratch Work. For x ≠ 2, factor the numerator: 3x² − 12 = 3(x − 2)(x + 2), so f(x) = ⟨your step — simplify⟩.

Then |f(x) − 12| = ⟨your step — write it in terms of |x − 2|⟩ < ε forces |x − 2| < ⟨your step⟩, so take δ = ⟨your step⟩.

Proof. Let ε > 0 and let δ be your choice. For any x with 0 < |x − 2| < δ, run the computation forwards and finish at ε. Note where the hypothesis x ≠ 2 was used — and that it is available precisely because of the 0 < in the definition.

Cummings, Real Analysis, Example 6.10, p. 232.

Self-check 4. Why is scratch work not a proof, even when every line of it is true?

Direction is the whole issue. Scratch work starts from |f(x) − L| < ε, which is what you are trying to establish. When every step happens to be a biconditional you could reverse it and get a proof — but that is a fact you must check and state, not assume, and the moment one step is a one-way inequality (Segment 3) the reversal fails outright.

Self-check 5. In Definition 6.8, what does the condition 0 < |x − c| exclude, and why?

The faded example is exactly this: f is undefined at 2, and the limit at 2 is nevertheless 12. A limit is a statement about the punctured neighbourhood of c, never about c itself. This is the one clause that separates Definition 6.8 from the definition of continuity in Segment 3.

Segment 3 · ~20 min

When one δ is not enough: bounding the other factor

Every example so far was linear after simplification, so |f(x) − L| came out as a constant times |x − c| and δ was that constant divided into ε. Non-linear functions do not cooperate, and the standard repair is the one move in this lesson worth memorising.

Worked example. Prove limx→3 x² = 9.

Scratch Work. |x² − 9| = |x − 3| · |x + 3|. The first factor is ours to shrink; the second is not, and it is not bounded by any constant over all of ℝ. But we do not need it to be: δ is ours, so we may first insist δ ≤ 1, which confines x to (2, 4) and hence |x + 3| < 7. On that confined region |x² − 9| < 7|x − 3|, and 7|x − 3| < ε as soon as |x − 3| < ε/7.

Two constraints on δ, so take the smaller: δ = min(1, ε/7).

Proof. Let ε > 0 and put δ = min(1, ε/7) > 0. Suppose 0 < |x − 3| < δ. Since δ ≤ 1 we have 2 < x < 4, so |x + 3| < 7. Since δ ≤ ε/7,

|x² − 9| = |x − 3| · |x + 3| < δ · 7 ≤ (ε/7) · 7 = ε. ∎

Note what changed: the scratch work now contains a one-way "<", not a chain of "⟺", so it could not have been reversed into a proof by itself. The bound |x + 3| < 7 had to be established in the proof, from δ ≤ 1, before it could be used.

The pattern generalises. When |f(x) − L| factors as |x − c| · (something), bound the something on a fixed small window around c, then take δ to be the minimum of that window's radius and ε divided by the bound. The min is not a trick; it is what "both constraints must hold" looks like when written as a single number.

Definition (Continuity at a point). A function f : A → ℝ is continuous at c ∈ A if for all ε > 0 there exists some δ > 0 such that for all x ∈ A with |x − c| < δ we have |f(x) − f(c)| < ε.

Cummings, Real Analysis, Definition 6.16, p. 238.

Set L = f(c) in Definition 6.8 and, at a point c that is a limit point of A, the two are the same sentence but for the missing 0 < — which is dropped here because x = c gives |f(c) − f(c)| = 0 < ε and so costs nothing. So continuity is not a new game: it is the limit game with the answer pinned in advance to the value the function actually takes.

The qualification is not pedantry, and Cummings states it himself on p. 238. Definition 6.8 requires c to be a limit point of A and Definition 6.16 does not, so the two definitions do not even have the same domain of application. At an isolated point of A the limit is simply undefined while continuity holds vacuously: on A = {0} every function is continuous at 0, because some δ small enough to admit no x other than 0 itself always exists, and the only x in range gives |f(0) − f(0)| = 0. Cummings puts it as "if it's not [a limit point], then observe that f is guaranteed to be continuous at c."

Self-check 6. Why is δ = min(1, ε/7) used rather than δ = ε/7 alone?

The two constraints are independent: δ ≤ 1 buys the bound on the second factor, δ ≤ ε/7 buys the ε. Dropping the first leaves |x + 3| unbounded, and for large ε the choice δ = ε/7 would admit x far from 3, where 7 is no longer a bound. "Smaller is safer" is the right instinct but the wrong reason — δ ≤ 1 has to be there for the inequality to be true, not for comfort.

Self-check 7. A proof of limx→c f(x) = L opens "Let δ = 0.01. Given any ε > 0 …". What is wrong before any computation happens?

Same error as self-check 2, one level along. Order of introduction is order of dependency: writing δ first claims a single window that works for every tolerance, which is a far stronger — and usually false — statement. You can diagnose it without reading another line.

Guided proof. Prove that f(x) = 1/x is continuous at c = 2, directly from the definition.

(Hint: |1/x − 1/2| = |x − 2| / (2|x|), so you need a lower bound on |x| to get an upper bound on the quotient. Confine x first, exactly as in the worked example — and notice that this time the confinement also keeps you away from the point where f blows up.)

Reveal model answer

Scratch Work. |1/x − 1/2| = |2 − x| / (2|x|) = |x − 2| / (2|x|). Insisting δ ≤ 1 confines x to (1, 3), so |x| > 1 and hence 1/(2|x|) < 1/2. On that region |1/x − 1/2| ≤ |x − 2| / 2, which is below ε once |x − 2| < 2ε. Two constraints, so δ = min(1, 2ε).

Proof. Let ε > 0 and put δ = min(1, 2ε) > 0. Suppose |x − 2| < δ. Since δ ≤ 1 we have 1 < x < 3, so x ≠ 0 (the expression is defined) and |x| > 1. Therefore

|1/x − 1/2| = |x − 2| / (2|x|) ≤ |x − 2| / 2 < δ/2 ≤ (2ε)/2 = ε. ∎

Note the ≤ in the first step, where you might have written <. Continuity admits x = c — Definition 6.16 has no 0 < clause — and at x = 2 both sides of that step are 0, so a strict inequality there would assert 0 < 0 and the proof would be false at exactly the point continuity is about. Bound the other factor non-strictly and let the strict step be |x − 2| < δ, which holds at x = 2 because δ > 0. A limit proof does not face this, since 0 < |x − c| excludes the centre.

Two more things to notice. The confinement δ ≤ 1 did double duty: it bounded the second factor and kept x in the domain, which a proof about 1/x owes the reader. And δ = min(1, 2ε) grows with ε rather than shrinking — nothing requires δ to be small, only to exist.

The picture the notation is describing

The ε–δ condition is a statement about two boxes. The opponent draws a horizontal band of half-height ε around L. You must draw a vertical strip of half-width δ around c such that the graph, inside your strip, never leaves their band. A narrower band forces a narrower strip; the claim is that you can always answer.

Shrink the band and the same strip will generally no longer do: the curve leaves through the top or bottom before it leaves through the side. Answering every band is the content of the definition, and it is why δ is normally written as a formula in ε rather than as a number.

Normally, not always. A constant function stays inside any band whatever strip you draw, so δ = 1 answers every ε at once and is a perfectly valid choice — as is any fixed δ for a function that is constant near c. The rule is not "δ must mention ε"; it is that δ may depend on ε, and for a non-constant function it generally has to. A proof whose δ does not mention ε is worth a second look and is not thereby wrong: check whether the function earns it. This is the same point self-check 1 makes about the constant sequence, one level along.

Exit Ritual: Blank-Page Reconstruction

Close your eyes, or look at the ceiling, and reconstruct the shape of this lesson from nothing:

  1. State the ε–N definition of convergence and the ε–δ definition of a functional limit, and say which quantity may depend on which in each.
  2. What does reversing the two quantifiers in the ε–N definition turn convergence into? Give a sequence that satisfies the reversed version and not the real one.
  3. Why is scratch work not a proof, and what has to be true of the scratch work before it can be reversed into one?
  4. State the min-trick in one sentence, and say what each of the two constraints on δ is buying.
  5. What is the one clause of difference between the definition of a functional limit and the definition of continuity at a point, why does dropping it cost nothing — and at which points do the two definitions fail to line up at all?
Reveal the skeleton to check against

(1) ∀ε > 0 ∃N with n ≥ N ⟹ |aₙ − a| < ε; ∀ε > 0 ∃δ > 0 with 0 < |x − c| < δ ⟹ |f(x) − L| < ε. In both, the second-named quantity may depend on the first-named one and never the reverse. (2) Into boundedness — 1, 0, 1, 0, … verconges to 0 and diverges. (3) Because it assumes the conclusion; it reverses only if every step is a biconditional, which fails as soon as a one-way bound like |x + 3| < 7 is used. (4) δ = min(window, ε/bound): the window confines x so the other factor is bounded at all, the second constraint converts that bound into ε. (5) The 0 < , dropped because x = c gives |f(c) − f(c)| = 0 < ε. They line up only at limit points of A: Definition 6.8 requires c to be one and Definition 6.16 does not, so at an isolated point the limit is undefined while continuity holds vacuously.
