Groups: definition and first properties (gt-02)

Four axioms that generate a universe.

Four short lines — a closure clause you don't even need to say out loud, one about grouping, one demanding a do-nothing element exists, one demanding every move has an undo — and from those four lines mathematicians have derived everything from the impossibility of trisecting an angle with a straightedge to the periodic table's structure to why a Rubik's Cube always has a solution. You met three of those four ideas already in gt-01, discovered by playing with a rectangle. Today they get names, symbols, and — for the first time — a proof standing behind them instead of a demonstration with paper.

Why this matters for the mission: H1 is a group before it's anything else.

Segment 1 · ~25 min

The formal definition, matched against what you already found

Aluffi's official definition trades "actions on a rectangle" for "a set with an operation" — the same content, now stripped of any particular physical costume:

Definition 11.1. A 'group' (G, ·) consists of a set G along with a binary operation · on G such that

(i) ∀ g,h,k ∈ G: (g·h)·k = g·(h·k)  [associativity]

(ii) ∃ eG ∈ G ∀ g ∈ G: g·eG = eG·g = g  [identity]

(iii) ∀ g ∈ G ∃ h ∈ G: g·h = h·g = eG  [inverse]

— Aluffi, Underground, Definition 11.1, pp. 229–230

Notice what is quietly built into this definition before the numbered list even starts: writing "g·h" as an element of G already presumes closure — the result of combining two elements of G is itself required to lie in G. Aluffi folds closure into the phrase "a binary operation on G" rather than listing it as a fourth numbered axiom. — Aluffi, Definition 11.1, p. 229 This is exactly Carter's Rule 1.8 in disguise: "any sequence of consecutive actions is also an action" is precisely the demand that combining moves never escapes the group.

Lay the two treatments side by side and the translation is almost mechanical:

Axiom (i) — associativity

One genuinely new idea appears here that gt-01 never had to name: associativity, axiom (i). Carter's rectangle never forced you to notice it, because every rectangle move happened to commute with every other, and there were only four configurations to juggle — parenthesising three flips in a row never seemed to matter. But associativity is doing real work in the background: it is what guarantees that "flip horizontal, then (flip vertical, then rotate)" and "(flip horizontal, then flip vertical), then rotate" are the same instruction, so that a "sequence of moves" is unambiguous without you having to specify where the invisible brackets go.

First examples: numbers, clocks, rectangles

Three examples, escalating in abstraction, all satisfying Definition 11.1:

Example A — (ℤ, +). The integers under ordinary addition. Associativity: (a+b)+c = a+(b+c) is ordinary arithmetic. Identity: e = 0, since a+0 = 0+a = a. Inverse of a: the element −a, since a+(−a) = 0. All three axioms hold, so (ℤ, +) is a group — in fact Aluffi notes it is commutative (a+b = b+a always), which earns it the extra name abelian. — Aluffi, §11.1, p. 231

Example B — (ℤ/nℤ, +). The integers mod n, where [a]n + [b]n := [a+b]n. — Aluffi, Definition 2.10, p. 26 This is a group for every n ≥ 0: identity [0]n, inverse of [a]n is [−a]n, and associativity is inherited from ℤ because the operation was defined in terms of ordinary addition (Aluffi's Claim 2.12 confirms the operation doesn't even depend on which representative of the class you pick — a subtlety worth taking seriously, since not every naive attempt at defining arithmetic on equivalence classes survives it; Aluffi's Example 2.11 shows one that doesn't). — Aluffi, Claim 2.12 and Example 2.11, pp. 26–27 ℤ/4ℤ, with elements {[0],[1],[2],[3]}, is our running example for Segment 2.

Example C — the rectangle's symmetries. gt-01's four rectangle configurations, with "do one flip then another" as the operation. You already verified informally that this satisfies Carter's Rules 1.5–1.8; under Aluffi's Definition 11.1 the identity is the solved state, and every element is its own inverse (flip-then-flip-again undoes itself). This group has a name too: it is (abstractly) the Klein four-group, usually written V or V4. Segment 2's self-check compares it directly against ℤ/4ℤ.

Self-check 1. In Definition 11.1, which single word or phrase is doing the job that Carter's Rule 1.8 ("any sequence of consecutive actions is also an action") did informally in gt-01?

Saying · is "a binary operation on G" already means g·h always lands back inside G for every g, h in G — this is closure, Carter's Rule 1.8 in symbolic form (Aluffi, Definition 11.1, p. 229).

Self-check 2. Which of gt-01's four informal rules has no numbered counterpart in Definition 11.1 at all, because gt-01's example was too simple to expose it?

Every one of Carter's rules maps onto some part of Definition 11.1 (Rule 1.5 corresponds to "a set G", Rule 1.6 to inverses, Rule 1.7 is just what it means for · to be a function, Rule 1.8 to closure) — but the formal definition additionally demands associativity by name, a fact the four-element rectangle group was too small and too well-behaved to force into view.

Uniqueness of identity and inverses; the order of an element

Definition 11.1 only demands that some identity and some inverse exist. It is worth asking: could a group secretly have two different identity elements, or could one element have two genuinely different inverses? Aluffi disposes of both worries immediately after the definition, calling them "basic but useful observations." — Aluffi, §11.1, p. 230

Theorem (uniqueness of the identity) — fully worked. If e1 and e2 both satisfy axiom (ii) for the same group G, then e1 = e2.

Proof. Since e1 satisfies axiom (ii), it acts as an identity when combined with any element of G — in particular when combined with e2:

 e1·e2 = e2  (taking g = e2 in axiom (ii) for e1).

But equally, since e2 satisfies axiom (ii), it acts as an identity when combined with e1:

 e1·e2 = e1  (taking g = e1 in axiom (ii) for e2).

The left-hand sides of both displayed equations are the same expression, e1·e2, so the right-hand sides must be equal too: e1 = e2. ∎

— cf. Aluffi, §11.1, p. 230 (stated as a bullet observation; proof expanded here in full)

This is why we are entitled to speak of the identity of a group, write it as e (dropping the subscript), and — as Aluffi remarks — sometimes even write it as 1, though e is the more common convention. — Aluffi, §11.1, p. 230

Theorem (uniqueness of inverses) — your turn to fill the gaps. If h1 and h2 both satisfy axiom (iii) for the same element g ∈ G (that is, both are inverses of g), then h1 = h2.

Proof. Consider the element h1·g·h2, and bracket it two different ways.

Bracketing on the left: (h1·g)·h2 = ⟨your step: what does axiom (iii) say h₁·g equals?⟩ · h2 = ⟨your step: simplify using axiom (ii)⟩.

Bracketing on the right: h1·(g·h2) = h1· ⟨your step: what does axiom (iii) say g·h₂ equals?⟩ = ⟨your step: simplify using axiom (ii)⟩.

These two bracketings compute the same element of G, by ⟨your step: name the axiom that lets you re-bracket freely⟩. Therefore the two simplified results must be equal: ⟨your step: state the conclusion, h₁ = h₂⟩. ∎

— cf. Aluffi, §11.1, p. 230 (stated as a bullet observation; faded proof here follows the standard "sandwich" strategy)

Because the inverse of g is unique, we are entitled to give it a single name, g−1, and it follows immediately that (g−1)−1 = g — undoing the undo gets you back to where you started. — Aluffi, §11.1, p. 230 Aluffi also records that cancellation holds in any group: if g1h = g2h, multiplying both sides on the right by h−1 gives g1 = g2. — Aluffi, §11.1, p. 230

The order of an element

Every element g of a group generates its own miniature cyclic group, ⟨g⟩ = {gi : i ∈ ℤ}, consisting of all its powers. — Aluffi, §11.1, p. 233 (Remark 11.12) How large that miniature group is has a name:

Definition 10.12. Let G be a group, and let g ∈ G. The 'order' of g, denoted |g|, is the order (cardinality) of the cyclic group ⟨g⟩ ⊆ G generated by g. — Aluffi, Definition 10.12, p. 261

In ℤ/4ℤ: the element [1]4 generates the whole group ([1],[2]=[1]+[1],[3],[0]), so |[1]4| = 4. But [2]4 generates only {[2],[0]} — adding [2] to itself gives [0] — so |[2]4| = 2. In the rectangle's Klein four-group, every non-identity element (horizontal flip, vertical flip, the 180° rotation) has order exactly 2, since each is its own inverse: doing it twice returns you to the identity, and no smaller repetition does. This numerical fingerprint — one element of order 4 versus every non-identity element of order 2 — is exactly what distinguishes the two groups below, even though both have four elements.

Both tables show the identity down the diagonal marked in green, but in different patterns: in ℤ/4ℤ the green cell for [1]+[1]+[1]+[1] only reappears after four steps ([1] has order 4), while in V₄ every non-identity element squares directly to e (order 2 each). Same size, different internal "clockwork" — the tables are not relabellings of each other.

Self-check 4. Which axiom of Definition 11.1 is responsible for every row and every column of a Cayley table containing each group element exactly once (so no repeats within a row)?

If some element x appeared twice in row g (say g·h₁ = g·h₂ = x with h₁ ≠ h₂), multiplying both sides on the left by g⁻¹ — which axiom (iii) guarantees exists — forces h₁ = h₂, a contradiction. This "no repeats" property (sometimes called the Latin square property) is a direct consequence of invertibility, not a special feature of these two groups.
