Uniform convergence of derivatives and integrals (an2-05)

Abbott does something in this chapter that textbooks almost never do: he writes out a proof that does not work, lets it break, and shows you the fracture. He attempts to prove that a pointwise limit of continuous functions is continuous, gets two of three terms under control, and then stops — "the value of n depends on the point x". The repair is not a cleverer argument. It is moving one quantifier, and the whole of this unit is what that single move does and does not buy you.

Predict before we start. Suppose fₙ → f uniformly on [0, 1] and every fₙ is differentiable. Which of these is guaranteed?

Nothing. Two separate failures are on record and this unit uses both. Abbott's Example 6.2.2(iii) has differentiable hₙ(x) = x1+1/(2n−1) converging uniformly on [−1, 1] to |x|, which is not differentiable at 0 — so the second option is out. Lindström's Example 3 has sin(nx)/n → 0 uniformly, with a limit that is differentiable, while the derivatives cos(nx) fail to converge anywhere useful — so the first and fourth are out. Uniform convergence is a statement about values. Derivatives are about slopes, and the figure in Segment 3 shows a family squeezed into a strip of width 2/n whose steepest slope is 1 for every n.

Why this matters for the mission: Sup-norm (uniform) control is the exact language the persistence stability theorem is written in.

The strip is true, and unusually literal — so the work is saying what follows from it, which is less than it sounds.

The identification is exact. tda1-07 states stability as Oudot's Corollary 3.6: for 𝔮-tame f and g on the same space X, db(dgm(f), dgm(g)) ≤ ‖f − g‖∞. That sup norm is an2-01's sup metric d₁ on C(X), and by Lindström's Proposition 4.2.3 below, smallness in it is uniform convergence. The strip's "exact language" is not a metaphor: the hypothesis of the stability theorem is a statement in the metric space an2-01 built, and this unit is what that metric space controls.

And what it controls is a specific list. Sup-norm closeness transfers continuity (Theorem 6.2.6) and the value of an integral (Lindström's Proposition 4.3.1). It does not transfer differentiability, and it does not transfer the value of a derivative — Segment 3's figure is the counterexample. So a hypothesis of the form ‖f − g‖∞ ≤ ε licenses nothing whatever about gradients of filter functions, and any claim that needs one has smuggled in a second hypothesis nobody assumed.

A parallel, offered as a parallel. tda1-07's own audit found that db(X, Y) ≤ ε controls the longest bar and controls neither a count above a threshold nor the total persistence. That has the same shape as this unit's transfer table — a bound in one metric controls exactly the functionals Lipschitz for that metric — but it is an analogy and not a deduction. db lives on multisets in the plane and ‖·‖∞ on functions, and Corollary 3.6 is a one-way inequality between them. Nothing here transports a result from either side to the other.
Segment 1 · 25 min

One quantifier, and a proof written to fail

Definition 6.2.1 / Definition 4.2.1 — pointwise. fₙ → f pointwise on A if for each x and each ε > 0 there is N with |fₙ(x) − f(x)| < ε for n ≥ N.

Definition 6.2.3 / Definition 4.2.2 — uniform. fₙ → f uniformly on A if for each ε > 0 there is N such that for n ≥ N, |fₙ(x) − f(x)| < ε for all x ∈ A.

Abbott at printed 154 and 157; Lindström at printed 81. Two books, two wordings, one difference — where "for all x" sits relative to "there is N". Lindström's gloss: "the N in the last sentence of the definition depends on x — we may need a much larger N for some x's than for others."

Abbott makes the gap numerical before he makes it formal. For gₙ(x) = xⁿ on [0, 1] — Example 6.2.2(ii), printed 154–155, getting within 1/3 of the limit needs n ≥ 2 at x = 1/2, and n ≥ 11 at x = 9/10. At x = 0.99 it needs n ≥ 110, and as x → 1⁻ the requirement runs off to infinity. There is no largest N, which is precisely why no single N exists.

Worked — the proof that does not work, and exactly where. Abbott, printed 156–157.

Claim (false): a pointwise limit of continuous functions is continuous. Fix c and ε > 0. By the triangle inequality — Abbott: "we should really call this the quadrilateral inequality" —

|f(x) − f(c)| ≤ (I) |f(x) − fₙ(x)| + (II) |fₙ(x) − fₙ(c)| + (III) |fₙ(c) − f(c)|.

(III) is fine. c is fixed, so pointwise convergence at that one point gives an N with (III) < ε/3.

(II) is fine. N is now chosen, and f_N is continuous at c, so there is a δ > 0 with (II) < ε/3 whenever |x − c| < δ.

(I) is not fine, and the reason is an ordering. We need |f_N(x) − f(x)| < ε/3 for all x within δ of c. But x was not fixed — it ranges over an interval that only came into existence at the previous step, after N was spent. Abbott: "The values of x depend on δ, which depends on the choice of N. Thus, we cannot go back and simply choose a different N."

What the repair is. Not a better argument — the same argument. Definition 6.2.3 supplies an N that works at every x simultaneously, so the N chosen for (III) also serves (I). Nothing else in the proof changes, which is the cleanest available demonstration that the distinction is about quantifier order and nothing more.
Theorem 6.2.6 (printed 160) / Lindström's Proposition 4.2.4 (printed 83). A uniform limit of continuous functions is continuous. Both proved, by the same ε/3 argument; Lindström names the technique, calling such arguments "ε/3-arguments" and adding that "it's quite instructive to take a closer look at the proof to see where it fails for pointwise convergence".

Lindström's Proposition 4.2.3 (printed 81). fₙ → f uniformly if and only if sup{d_Y(fₙ(x), f(x)) : x ∈ X} → 0. Proved. Lindström flags a subtlety inside: "note that we may have unstrict inequality ≤ for the supremum although we have strict inequality < for each x ∈ X" — the same phenomenon that put a ≤ into an2-02's Proposition 3.7.2 — there it was Lemma 3.7.9's proof producing a limit of strict inequalities, here it is a supremum of them.

Theorem 6.2.5 (printed 160). Cauchy criterion: (fₙ) converges uniformly on A if and only if for every ε there is N with |fₙ(x) − f_m(x)| < ε for all m, n ≥ N and all x ∈ A. Stated; proof set as Exercise 6.2.6.

Lindström's Proposition 4.2.3 is the sentence that connects this unit to the previous four. The supremum in it is an2-01's sup metric d₁ on C[a, b]. So uniform convergence is convergence in d₁, by Lemma 3.2.2; "uniformly Cauchy" is Definition 3.4.1 in that metric; and Theorem 6.2.5 asserting that the two coincide is exactly the statement that the space is complete — which is an2-08's Lindström's Theorem 4.6.4. Three units' worth of machinery turns out to have been about this one notion all along.

Self-check 1. In the doomed proof, which term fails, and why?

(I). Term (III) is evaluated at the single fixed point c, where pointwise convergence is exactly enough. Term (II) is continuity of one function, which holds by hypothesis and delivers δ. Term (I) needs the same N to work at every x in (c − δ, c + δ), and pointwise convergence gives an N per point with no bound across them — Abbott's numbers for xⁿ show the N required growing without limit as x → 1⁻. The fourth option is wrong in a way worth noticing: two of the three terms are perfectly controlled, and a proof that fails at one step is not a proof that fails everywhere.

Self-check 2. Lindström's Proposition 4.2.3 identifies uniform convergence with convergence in which metric space?

The sup metric. an2-01 proved d₁ is a metric and worked its triangle inequality; an2-02 recorded Lindström's Example 2, that of the three metrics on C[a,b] only d₁ is complete; Lindström's Theorem 4.6.4 supplies that completeness at printed 102. The integral metric d₂ induces a genuinely different notion of convergence, and the tents of Segment 2 separate all three: they converge to 0 pointwise, but d₁(fₙ, 0) = n → ∞ and d₂(fₙ, 0) = ½ for every n, since every tent has area exactly ½. So they converge in neither metric, and their integrals do not converge to the integral of the limit. Pointwise convergence is the odd one out here — it is the one with no metric on C[a,b] behind it.

Segment 2 · 25 min

Integration: uniform convergence is enough

Lindström opens §4.3 with the two questions plainly — printed 86: "Assume that we have a sequence of functions {fₙ} converging to a limit function f. If we integrate the functions fₙ, will the integrals converge to the integral of f? And if we differentiate the fₙ's, will the derivatives converge to f′?" The answers are yes-with-a-hypothesis and no, and the asymmetry is the subject of this unit's second half.

Lindström's Proposition 4.3.1 (printed 87). If continuous fₙ → f uniformly on [a, b], then Fₙ(x) = ∫ₐˣ fₙ converges uniformly to F(x) = ∫ₐˣ f. Proved.

Lindström's Corollary 4.3.2 (printed 87). The same with an arbitrary lower limit x₀ ∈ [a, b]. Proved, by splitting the integral.

Lindström's Corollary 4.3.3 (printed 88). A uniformly convergent series of continuous functions may be integrated term by term. Proved, from 4.3.2 applied to the partial sums.

Lindström's Proposition 4.3.1's proof is three lines and it is worth watching the ε move. Uniform convergence gives N with |f(t) − fₙ(t)| < ε/(b − a) for every t, and then

|F(x) − Fₙ(x)| ≤ ∫ₐˣ |f(t) − fₙ(t)| dt ≤ ∫ₐᵇ ε/(b − a) dt = ε,

with a bound independent of x, so the convergence is uniform. The interval had to be bounded twice over: once to divide by b − a at all, and once to replace the upper limit x by b. On [0, ∞) neither step is available and the proposition is false.

Lindström attaches a warning to Lindström's Corollary 4.3.3 that is worth keeping — printed 88: "This formula may look obvious, but it does not in general hold for series that only converge pointwise. As we shall see many times later in the book, interchanging integrals and infinite sums is quite a tricky business."

Faded — the tent, and why pointwise is not enough. Lindström's Example 1 to §4.3, printed 86–87.

Let fₙ : [0, 1] → ℝ be 0 outside [0, 1/n] and rise linearly to height n at 1/(2n), returning to 0 at 1/n. Each fₙ is continuous.

For any fixed x > 0, once n > 1/x the point x is outside the support, so fₙ(x) = 0; and fₙ(0) = 0 for every n. So fₙ → 0 pointwise on [0, 1].

⟨your step: compute ∫₀¹ fₙ as the area of a triangle with base 1/n and height n, observe that it does not depend on n, and conclude that ∫₀¹ fₙ does not converge to ∫₀¹ 0. Then use Lindström's Proposition 4.2.3 to show the convergence is not uniform, by computing one supremum — and say how badly it fails, since the number you get does not merely fail to tend to 0.⟩

The two failures, side by side. Left: the tents of Lindström's Example 1, drawn for n = 2, 3, 4. Every one has area exactly ½ — base 1/n, height n — so the integrals are constant while the functions tend pointwise to 0. Pointwise convergence loses the integral because the discrepancy can be enormous on a set that is shrinking fast enough. Right: sin(nx)/n for n = 4, 8, 16, with the strip |y| ≤ 1/16 marked. These converge uniformly to 0, since the sup distance is exactly 1/n — and every one of them leaves the origin along the dashed line y = x, because the derivative at 0 is cos 0 = 1 whatever n is. Uniform convergence loses the derivative because squeezing a graph vertically says nothing about its slope; these compensate by oscillating faster.

Self-check 3. Why does Lindström's Proposition 4.3.1 need a bounded interval?

The ε/(b − a). Uniform closeness gives a bound on the integrand, and turning that into a bound on the integral costs a factor equal to the length of the interval — which must be finite for the trade to be worth anything. On [0, ∞), take fₙ equal to 1/n on [0, n], falling linearly to 0 across [n, n + 1], and 0 beyond — continuous, as Lindström's Proposition 4.3.1 requires of its functions, so the witness actually tests the hypothesis under discussion. Then sup|fₙ| = 1/n → 0, so fₙ → 0 uniformly, while ∫₀∞ fₙ = 1 + 1/(2n) → 1, not 0. (The lazy version of this witness, 1/n on [0, n] and 0 after, has a jump at x = n and so is not continuous; it would refute nothing, because Lindström's Proposition 4.3.1 never claimed it.) The first option names a true fact that is not the reason; the fourth confuses integrability with the estimate.

Segment 3 · 30 min

Differentiation: uniform convergence is not enough, and two books pay differently

Lindström is blunt about the asymmetry — printed 89: differentiation "is a much trickier business than integration as integration often helps to smoothen functions while differentiation tends to make them more irregular". His Example 3 is the figure's right-hand panel: {sin(nx)/n} converges uniformly to 0 and {cos nx} does not converge at all. His explanation is exactly what the panel draws — "although they live in an increasingly narrower strip around the x-axis, they are all equally steep at their steepest".

Abbott's Example 6.2.2(iii) is the other failure: hₙ(x) = x1+1/(2n−1) on [−1, 1] converges to |x|. Every hₙ is differentiable and the limit is not, so there is nothing for the derivatives to converge to. Two genuinely distinct ways for the question to have no answer, and both are excluded by hypothesising convergence of the derivatives rather than of the functions.

Theorem 6.3.1 (Abbott, printed 164). If fₙ → f pointwise on [a, b], each fₙ differentiable, and (fₙ′) → g uniformly, then f is differentiable and f′ = g. Proved, by splitting the difference quotient into three and applying the Mean Value Theorem to f_m − fₙ.

Theorem 6.3.2 (printed 166). If (fₙ′) converges uniformly and fₙ(x₀) converges at one point x₀, then (fₙ) converges uniformly. Stated; proof set as Exercise 6.3.5.

Theorem 6.3.3 (printed 166). The two combined: uniform convergence of the derivatives plus convergence at one point gives uniform convergence of the functions, differentiability of the limit, and f′ = g.

Abbott is candid that the hypothesis looks circular — "This may sound as though we are assuming what it is we would like to prove, and there is some validity to this complaint. The more hypotheses a proposition has, the more difficult it is to apply." And the single point in Theorem 6.3.2 is not a technicality: "Two functions with the same derivative may differ by a constant." Take fₙ ≡ n; the derivatives converge uniformly to 0 and the functions converge nowhere.

Lindström's Proposition 4.3.5 (Lindström, printed 90). Let {fₙ} be differentiable on [a, b], with continuous derivatives fₙ′ converging uniformly to g, and suppose {fₙ(x₀)} converges for some x₀. Then {fₙ} converges uniformly to a differentiable f with f′ = g. Proved — and the proof is three lines: "The proposition is just Lindström's Corollary 4.3.2 in a convenient disguise."

Lindström's Corollary 4.3.6 (printed 90). The series form: term-by-term differentiation, under the same conditions. Stated, with "Proof. Left to the reader."

Start: Lindström calls his own result one that "may look ugly and unsatisfactory, but it gives us the information we shall need". Take that seriously — the question is not which statement is better but what each purchase costs.
Reveal the model answer

The proof. The fₙ′ are continuous and converge uniformly to g, so Lindström's Corollary 4.3.2 applies to them: ∫x₀x fₙ′(t) dt converges uniformly to ∫x₀x g(t) dt. By the Fundamental Theorem of Calculus the left side is fₙ(x) − fₙ(x₀), so

fₙ(x) − fₙ(x₀) → ∫x₀x g(t) dt uniformly on [a, b].

Since fₙ(x₀) → b for some real b, the functions fₙ converge uniformly to f(x) = b + ∫x₀x g(t) dt. By the Fundamental Theorem of Calculus again, f′ = g. ∎

The extra hypothesis, and where it was spent — twice. Continuity of the derivatives. First, Lindström's Corollary 4.3.2 is stated for continuous functions, so without it the very first line is unavailable. Second, the closing appeal to the Fundamental Theorem needs the integrand g continuous — which is free here, by Lindström's Proposition 4.2.4, precisely because the fₙ′ were continuous and converged uniformly. Remove the hypothesis and both ends of the argument fail.

Is it a corollary of Theorem 6.3.3? Yes. Lindström's hypotheses are Abbott's plus continuity of the fₙ′, so every situation Lindström's Proposition 4.3.5 covers is one Theorem 6.3.3 already covers, with the same conclusion. Abbott's is the stronger theorem.

So what did Lindström buy? Not generality — proof length, and reuse. His argument spends only machinery he has already built two pages earlier, where Abbott's needs the Mean Value Theorem applied to f_m − fₙ and the Cauchy criterion for uniform convergence. And he needs the result for §4.4's power series, where the derivatives are polynomials and continuity is free, so the extra hypothesis costs him nothing at the point of use. "Shorter proof" and "weaker theorem" are one fact seen from two sides; a book that says so out loud is doing the reader a favour, and Lindström says so.

Self-check 4. "fₙ → f uniformly and each fₙ is smooth, so f′ is the limit of fₙ′." What is wrong?

The hypothesis is attached to the wrong sequence. sin(nx)/n is smooth — infinitely differentiable — converges uniformly to 0, and its derivatives cos(nx) converge nowhere; boundedness of the interval is irrelevant, since the failure already happens on [0, 1]. Self-check 6. Four uniformity conditions have now appeared. Match each to what its single δ, N or K must not depend on.

Definition 4.1.1 asks one δ for all points; Definition 4.1.3 asks one δ for all points and all members of the family, which is why an2-03's Arzelà–Ascoli needed it; Definition 4.2.2 asks one N for all points; and an2-04's uniform Lipschitz condition asks one K for all times t, with the Lipschitz estimate itself in the space variable.
