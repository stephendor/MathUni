Metric-space topology, deepened (an2-01)

Three conditions on a two-variable function, and every argument you know about sequences and continuity in ℝ runs again — on the plane, on messages, on functions, on sets. Lindström opens the chapter with the complaint that motivates it: it "becomes quite boring to perform almost the same arguments over and over again in new settings", and asks whether the results can be proved "once and for all". The answer is yes, and the price is exactly three conditions.

Predict before we start. Of the three conditions on a distance — that it is zero only between equal points, that it is symmetric, and that going direct beats going via a third point — which one do you expect to be the one that fails most often when someone proposes a "distance" that turns out not to be one?

The first, and almost always the half that says d(x,y) = 0 forces x = y. You will run seven candidates through the checklist in Problem 1 and find that not one of them fails symmetry or the triangle inequality. The triangle inequality is the one that is hardest to prove when it holds; condition (i) is the one that is most often false. Those are different questions, and confusing them is how a proposed distance gets called a metric on the strength of the difficult verification while the easy one was never run. It is also, as the last segment shows, exactly what happens to the distance between persistence diagrams.

Why this matters for the mission: The space of persistence diagrams is a metric space; fluency here is fluency there.

The strip is quoted exactly, and its first clause is false as it stands. This unit's sources contain no persistence diagram — Lindström is a real-analysis text and Abbott's §8.2 is about metric spaces and the Baire category theorem. So nothing here can confirm or deny the first clause on its own evidence. But the corpus has already settled it downstream, and the answer is no: tda1-06 reads Oudot at his printed 51, where the bottleneck distance "is an extended pseudometric … It is not a true distance though", with two distinct diagrams exhibited at distance zero. The claim becomes true only after the class of diagrams is restricted — to locally finite multisets off the diagonal, which is what tda1-06 establishes, and which tda1-05 gets from Oudot's Theorem 1.13, the result that every 𝔮-tame module has a diagram in that class.

So read the strip as a promise about the second clause. Fluency here really is fluency there, and the specific form it takes is that you will be able to run the three conditions as a checklist on a proposed distance and find which one breaks. tda1-05 has already committed you to doing exactly that: its Problem 5(c) says "take an2-01's axioms for a metric space and apply them as a checklist". This unit supplies that checklist, and the last segment shows that the checklist returns a failure on the headline application — which is the reason it is worth having rather than a reason to distrust it.
Segment 1 · 25 min

Three conditions, and the seven candidates that test them

Two books state the same definition on this page, and it is worth having both because they are worded differently and you will need both wordings.

Definition 3.1.1 (Lindström, printed 44). A metric space (X, d) consists of a nonempty set X and a function d : X × X → [0, ∞) such that:

(i) (Positivity) For all x, y ∈ X, d(x, y) ≥ 0, with equality if and only if x = y.
(ii) (Symmetry) For all x, y ∈ X, d(x, y) = d(y, x).
(iii) (Triangle Inequality) For all x, y, z ∈ X, d(x, y) ≤ d(x, z) + d(z, y).

A function d satisfying (i)–(iii) is called a metric on X.

Definition 8.2.1 (Abbott, printed 222). Given a set X, a function d : X × X → R is a metric on X if for all x, y ∈ X: (i) d(x, y) ≥ 0 with d(x, y) = 0 if and only if x = y; (ii) d(x, y) = d(y, x); and (iii) for all z ∈ X, d(x, y) ≤ d(x, z) + d(z, y).

The same three conditions. Lindström names them, which is why this unit's checklist uses his names; Abbott numbers them, which is why the problem set quotes his numbering when it runs his exercises. One real difference: Lindström builds non-negativity into the codomain [0, ∞), Abbott into condition (i). That difference is invisible until something takes the value ∞, and then it decides which condition gets the blame — the last segment turns on this.

Notice how little has been assumed. There is no addition on X, no ordering, no dimension, no smoothness — X is a bare set. Everything the theory proves will therefore hold for every example at once, which is Lindström's stated reason for the chapter. Here is the variety he offers, and it is worth reading as a range rather than a list — Examples 1–7, printed 44–47.

  • ℝ with d(x, y) = |x − y|, and ℝⁿ with the Euclidean distance. Both triangle inequalities are inherited from the ones you already have for numbers and vectors.
  • The Manhattan metric on ℝ², |x₁ − y₁| + |x₂ − y₂| — a genuinely different metric on the same set as the Euclidean one.
  • The Hamming metric on messages of fixed length K: the number of positions at which two messages differ. The set is finite, there is no geometry at all, and it is used to measure transmission corruption.
  • Metrics on functions: on the continuous functions [a, b] → ℝ, the sup metric d₁(f, g) = sup{|f(x) − g(x)|}, the integral metric d₂(f, g) = ∫|f − g|, and d₃ with the square-integral. Lindström's comment is the one to keep: having several metrics "doesn't mean that one of them is 'right' and the others 'wrong', but that they are useful for different purposes".
  • The discrete metric on any non-empty set: 0 between equal points, 1 between distinct ones. Lindström recommends it as a first test — "if you want to check whether a phenomenon from ℝⁿ generalizes to all metric spaces, it's often a good idea first to see what happens in these spaces".
  • The subspace metric: restrict d to a non-empty subset A.
Worked — the sup metric is a metric, and the one move that matters.

Take X = C[a, b] and d₁(f, g) = sup{|f(x) − g(x)| : x ∈ [a, b]}.

The supremum is a real number. f − g is continuous on the closed bounded interval [a, b], hence bounded, so the set has a real upper bound. Both hypotheses were used: continuity of f and g, and closed-boundedness of [a, b]. Drop either and d₁ can be +∞, which Definition 3.1.1's codomain forbids.

(i). d₁ ≥ 0 as a supremum of non-negative numbers. If d₁(f, g) = 0 then |f(x) − g(x)| ≤ 0 for every x, so f = g pointwise, so f = g.

(ii). |f(x) − g(x)| = |g(x) − f(x)| for each x, so the two sets are the same set and have the same supremum.

(iii). Fix x. Then |f(x) − h(x)| ≤ |f(x) − g(x)| + |g(x) − h(x)| ≤ d₁(f, g) + d₁(g, h), because each term is at most the supremum it sits under. So the fixed number d₁(f, g) + d₁(g, h) is an upper bound for every member of the set whose supremum is d₁(f, h) — and therefore an upper bound for that supremum. Hence d₁(f, h) ≤ d₁(f, g) + d₁(g, h). ∎

Mark that last move. "An upper bound for every member is an upper bound for the supremum" is the entire content of the triangle inequality here, and it will come back in the final segment in a form that looks nothing like it.
Faded — the Hamming metric. Messages are strings of length K, and d(x, y) counts the indices n with xₙ ≠ yₙ. Lindström writes only "it is not hard to check" and makes it Exercise 1.

Write [P] for 1 if P holds and 0 otherwise, so that d(x, y) = Σₙ [xₙ ≠ yₙ].

(iii). Fix an index n. If xₙ = zₙ the left side is 0 and there is nothing to prove. If xₙ ≠ zₙ, then yₙ cannot equal both xₙ and zₙ, so at least one of [xₙ ≠ yₙ], [yₙ ≠ zₙ] is 1. Either way [xₙ ≠ zₙ] ≤ [xₙ ≠ yₙ] + [yₙ ≠ zₙ].

⟨your step: sum this over n = 1, …, K and say why summing finitely many valid inequalities is legitimate. Then say what (i) and (ii) amount to here — each is one line, and (i)'s "only if" half is the statement that two strings agreeing at every index are the same string.⟩

Self-check 1. On ℝ², is d(x, y) = |x₁x₂ + y₁y₂| a metric? (This is Abbott's Exercise 8.2.1(d).)

No, and the fastest refutation needs only one point. Take x = (1, 1): then d(x, x) = |1·1 + 1·1| = 2 ≠ 0, so a point is at distance 2 from itself. Condition (i) is dead. Symmetry does in fact hold — swapping x and y leaves x₁x₂ + y₁y₂ unchanged — so the second option is wrong about which condition fails, and the "yes" option is wrong because non-negativity is only half of (i). This is the pattern to internalise: when a proposed distance is not one, look for the failure at a single point first.

Self-check 2. On C[0, 1], is d(f, g) = |f(1) − g(1)| a metric? (Abbott's Exercise 8.2.2(b).)

No, and the failure is precisely located. Take f(x) = x and g(x) = x². These are different elements of C[0, 1], but f(1) = g(1) = 1, so d(f, g) = 0 without f = g. Everything else holds: d(f, f) = 0, symmetry is immediate, and the triangle inequality is inherited from |·| on ℝ. A function satisfying every condition except the "only if" half of (i) is called a pseudometric, and the name matters — it is exactly the word Oudot uses for the bottleneck distance, as the last segment shows.

Segment 2 · 25 min

Convergence and continuity, replayed once for all spaces

Definition 3.2.1 (printed 48). A sequence {xₙ} in a metric space (X, d) converges to a ∈ X if for every ε > 0 there is an N ∈ ℕ such that d(xₙ, a) < ε for all n ≥ N.

Definition 3.2.4 (printed 49). f : X → Y is continuous at a ∈ X if for every ε > 0 there is a δ > 0 such that d_Y(f(x), f(a)) < ε whenever d_X(x, a) < δ. By Definition 3.2.7, f is continuous if it is continuous at every point.

Word for word the definitions from ℝ, with |x − y| replaced by d(x, y) — which is the entire idea of the chapter.
Lemma 3.2.2 (printed 49). A sequence {xₙ} in (X, d) converges to a if and only if lim d(xₙ, a) = 0.

Proposition 3.2.3 (printed 49). A sequence in a metric space cannot converge to more than one point.

Proposition 3.2.5 (printed 50). f is continuous at a if and only if f(xₙ) → f(a) for every sequence xₙ → a.

All three proved in the body. Lindström adds, after 3.2.3: "Observe how we used the conditions in Definition 3.1.1 in the proof above. So far they are all we know about metric spaces."

Lemma 3.2.2 looks like a restatement and is in fact the workhorse. It converts a question about a sequence in a space with no arithmetic into a question about a sequence of real numbers, where every tool from an-05 onward applies. The conversion has a limit, though, and it is worth seeing where: Abbott's Cauchy condition (Definition 8.2.3, printed 223) asks that d(x_m, xₙ) < ε for all m, n ≥ N, and there is no single real sequence to take the limit of, because there is no named point in the second slot. That is why completeness is a separate idea and not a corollary — and it is an2-02's whole subject.

Guided proof — limits are unique, and exactly which condition does it.

Suppose xₙ → a and xₙ → b. Prove a = b, and as you go, label every step with the condition of Definition 3.1.1 it uses. There are three such steps and no others; Lindström's remark above is a claim you should check rather than accept.

Start: the Triangle Inequality gives d(a, b) ≤ d(a, xₙ) + d(xₙ, b) for every n. Note that the left side does not depend on n and the right side does.
Reveal the model answer

By (iii), the Triangle Inequality, for every n, d(a, b) ≤ d(a, xₙ) + d(xₙ, b).

By (ii), Symmetry, d(a, xₙ) = d(xₙ, a). Since xₙ → a and xₙ → b, Lemma 3.2.2 gives d(xₙ, a) → 0 and d(xₙ, b) → 0.

The number d(a, b) is a single constant that is ≤ the n-th term of a sequence tending to 0, for every n. So d(a, b) ≤ 0. Combined with d ≥ 0 we get d(a, b) = 0.

By (i), Positivity — its "only if" half — a = b. ∎

Where each condition was indispensable. (iii) produced the inequality; there is no other way to relate d(a, b) to distances involving xₙ. (ii) let the two convergence hypotheses, both phrased as d(xₙ, ·), be used in an expression that wanted d(a, xₙ). (i) converted the numerical conclusion d(a, b) = 0 into the set-theoretic conclusion a = b — and this is the step with no counterpart outside metric spaces.

Why that last observation is the important one. Take Munkres's three-point space X = {a, b, c} with topology {∅, X, {b}, {a,b}, {b,c}}. The constant sequence xₙ = b converges to a, to b and to c, because every open set containing a or c also contains b. Proposition 3.2.3 forbids that in a metric space — so this topology comes from no metric. A topology has no numerical quantity that could be zero, hence no counterpart of (i)'s "only if" half, and separating points has to be imposed as an extra axiom instead. That axiom is Hausdorff's, and top-03 is where it is imposed. Every metric space is Hausdorff, and the proof is this proposition.

Faded — convergence in a discrete space. Let (X, d) be discrete: d(x, y) = 0 if x = y and 1 otherwise. Lindström's Exercise 1 to §3.2 asks you to show xₙ → a if and only if xₙ = a for all sufficiently large n.

One direction: if xₙ = a for n ≥ N, then d(xₙ, a) = 0 for n ≥ N, and every ε works.

⟨your step: for the converse, take ε = 1/2 in Definition 3.2.1 and read off what d(xₙ, a) < 1/2 can possibly mean when d takes only the values 0 and 1. Then say what has become of Lemma 3.2.2 here — the sequence d(xₙ, a) is a sequence of what, and what does "converging to 0" reduce to?⟩

Self-check 3. Which of these does Lemma 3.2.2 convert into a question about a single sequence of real numbers?

Only the second. Lemma 3.2.2 needs a named limit to put in the second slot of d, and then d(xₙ, a) is one real sequence. "Is it Cauchy?" involves d(x_m, xₙ) with two running indices — not a sequence. "Does it converge to something?" hides an existential quantifier over a, so there is no single a to name. The gap between the second and third options is precisely the gap that completeness fills, and it is why an2-02 exists.

Segment 3 · 30 min

Balls, open sets, and a topology nobody asked for

Definition 3.3.1 (printed 52). For a ∈ X and r > 0, the open ball is B(a; r) = {x ∈ X : d(x, a) < r}, and the closed ball is B̄(a; r) = {x ∈ X : d(x, a) ≤ r}.

Definition 3.3.2 (printed 53). Relative to a subset A, a point x is interior if some B(x; r) ⊆ A, exterior if some B(x; r) ⊆ Aᶜ, and a boundary point if every B(x; r) meets both A and Aᶜ. A is open if it contains none of its boundary points, and closed if it contains all of them.

Abbott takes the other route, defining the ε-neighbourhood V_ε(x) = {y : d(x, y) < ε} at printed 224 and building openness from it. Proposition 3.3.3 is the bridge: A is open if and only if every point of A is an interior point of A. The two definitions agree, and the problem set proves it.

Lindström warns that balls "may look quite different from ordinary balls": in the Manhattan metric a ball "looks like an ace of diamonds", and in the discrete metric it is either a single point or the whole space. He is not being decorative — the shapes are the subject of the figure below.

Lemma 3.3.6 (printed 54). Every open ball B(a; r) is an open set; every closed ball is a closed set.

Proposition 3.3.10 (printed 56). f : X → Y is continuous if and only if f⁻¹(V) is open in X for every open V ⊆ Y.

Proposition 3.3.12 (printed 57). Arbitrary unions of open sets are open; finite intersections of open sets are open.

Proposition 3.3.13 (printed 58). Arbitrary intersections of closed sets are closed; finite unions of closed sets are closed.

Lindström proves Lemma 3.3.6 for open balls and sets the closed half as Exercise 5. He proves Proposition 3.3.10. He states 3.3.12 and 3.3.13 and sends both proofs to Exercises 11 and 12, which also ask for the counterexamples showing "finite" cannot be dropped.

Lemma 3.3.6 is not the tautology its wording suggests. "Open ball" was defined by a strict inequality and "open set" by boundary points; that the first satisfies the second is a theorem, and its proof is where the Triangle Inequality earns its keep. Given x ∈ B(a; r), set ε = r − d(x, a), which is strictly positive because the ball is open. For y ∈ B(x; ε),

d(y, a) ≤ d(y, x) + d(x, a) < ε + d(x, a) = r,

so B(x; ε) ⊆ B(a; r) — printed 54. Every step after the first is arithmetic; the first step is condition (iii).

Now read Proposition 3.3.10 again and count what it mentions. A function, two spaces, preimages, and open sets. No ε, no δ, no distance. The definition of continuity has been rewritten in a vocabulary from which the metric has vanished — and Lindström says out loud what that is for (printed 57): "As already mentioned, the results above are important when we try to extend the notion of continuity to topological spaces. In such spaces we don't have a notion of distance, only a concept of open sets. We shall not look at topological spaces in this book, but I would still like to point out that from a topological point of view, the crucial properties of open and closed sets are the following" — and then 3.3.12 and 3.3.13.

Take the hint. Collect 𝒯_d = {U ⊆ X : U is open}. Then ∅ and X are in it, arbitrary unions stay in it by 3.3.12(a), and finite intersections stay in it by 3.3.12(b). Those are exactly the three axioms of a topology. Every metric space carries a topology, produced by the metric without anyone asking for one — and continuity in the metric sense agrees with continuity defined purely from that topology, which is the content of 3.3.10.

One warning before the figure. It would be natural to expect the metric to be recoverable from the topology it generates. It is not, and the next figure is the counterexample.

The unit balls B(0; 1) of three metrics on ℝ², on one set of axes: the Manhattan diamond inside the Euclidean disc inside the max-metric square. The inclusions are strict — three visibly different sets — although all three boundaries pass through the same four points (±1, 0) and (0, ±1), where the three norms agree. Along the diagonal they are as far apart as they get: the diamond meets it at Euclidean distance 1/√2 from the origin, the disc at 1, the square at √2. Yet all three metrics generate the same topology, because each ball of one kind contains a ball of each other kind around the same centre: from ‖v‖_∞ ≤ ‖v‖₂ ≤ ‖v‖₁ ≤ 2‖v‖_∞ one gets B₁(a; r) ⊆ B₂(a; r) ⊆ B_∞(a; r) and back again with rescaled radii. Lindström sets the Manhattan case as Exercise 2 to §3.3.

Self-check 4. The three unit balls above are visibly different sets, yet the three metrics have exactly the same open sets. What is the resolution?

An open set is one all of whose points are interior — that is, each point has some ball inside the set. It need not be a ball itself. Since every ‖·‖₁-ball contains a ‖·‖₂-ball around the same centre and conversely, a set that passes the test for one metric passes it for the other, even though the individual balls never coincide. The fourth option cannot be right for a reason worth noticing: closed means complement-open (Proposition 3.3.4), so agreeing on open sets forces agreeing on closed ones.

Self-check 5. tda1-05 will hand you these axioms as a checklist for the bottleneck distance between persistence diagrams, and asks which is "least obviously true" for a distance defined by optimising over matchings. tda1-06 then reads Oudot's verdict. Which condition actually fails?

(i), in its "only if" half — and before that, the codomain. tda1-06 reports Oudot at printed 51: the bottleneck distance "is an extended pseudometric … It is not a true distance though", exhibiting ℚ² ∖ Δ and (ℚ+√2)² ∖ Δ as distinct multisets at distance zero. Check against this 1. Three conditions on a bare set buy the whole vocabulary. Definition 3.1.1 assumes no arithmetic, no order, no dimension, so every theorem proved from it holds simultaneously on ℝⁿ, on messages, on function spaces and on any set at all with the discrete metric. The checklist is short enough to run on a candidate, and running it is a skill: the condition that is hardest to prove — (iii) — is not the condition most often false, which is (i)'s "only if" half.

2. Convergence and continuity transfer verbatim, and Lemma 3.2.2 is why. Replacing |x − y| by d(x, y) in the definitions costs nothing, and d(xₙ, a) → 0 turns a question in an arbitrary space into a question about one real sequence. Uniqueness of limits (3.2.3) follows from the three conditions alone, and its final step is (i) — which is why no topology with a non-Hausdorff pathology can come from a metric. The transfer stops at the Cauchy condition, which has no named limit, and that gap is completeness.

3. The metric generates a topology and is then partly forgotten. Open balls are open sets (3.3.6, by the Triangle Inequality); unions and finite intersections of open sets are open (3.3.12); so 𝒯_d is a topology, and continuity has a formulation (3.3.10) mentioning no distance at all. The forgetting is real: the Manhattan, Euclidean and max metrics are three different functions with three visibly different unit balls and one common topology. A property of a metric space need not be a property of the metric.
