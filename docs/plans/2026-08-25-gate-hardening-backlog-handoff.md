## Priority 1 — harvest into `cross-cutting-principles.md` and a Gate-Authoring Checklist

None of these need new code. They need to be written down once, in the place a future author or gate-builder will actually read before making the same mistake a second time. Group them under a new "Gate-Authoring Checklist" section (candidate location: `curriculum/LESSON-RUBRIC.md` or a new `curriculum/GATE-AUTHORING-CHECKLIST.md`), and promote the generalizable ones into `cross-cutting-principles.md` proper (several observations name that file directly as the target).

Recurring principles, deduplicated, with every observation that independently rediscovered them:

1. **A convention is not enforcement.** The interval between "we decided to do X" and "a checker verifies X" is a window where the defect is still live — measured here at two units' worth. When a remedy is instruction-shaped, the observation should stay OPEN, not be closed as if the decision were the fix. — `2026-08-21-a-convention-is-not-a-countermeasure`
2. **A gate's granularity must be derived from the claim the artifact makes, not from the failure that prompted building the gate.** Write down the sentence the gate is meant to stop being self-attested, and check the gate's granularity actually matches that sentence — not the one incident that got noticed. — `2026-08-21-c-a-check-inherits-the-granularity-of-the-last-failure`, `2026-08-21-e-the-same-granularity-mistake-three-rounds-running` (six rounds on one check, same root cause each time)
3. **When a review finding enumerates instances, derive the population before fixing any of them, and report the count** (the gap between what a reviewer named and what a derived query returns is the only calibration available on how much a review actually sees). — `2026-08-21-e`, `2026-08-22-instance-fix-is-not-pattern-fix` (grep the whole changeset for the same lexical construct before marking a thread resolved)
4. **For every `except`/`continue` in a checking path, ask what the gate reports when that branch fires.** If the answer is "PASS," the handler is a hole — defensive error-swallowing inverts its meaning inside a checker. — `2026-08-21-f-a-skipped-parse-is-a-silent-pass`
5. **When narrowing a check's scope to kill a false positive, name what the check is uniquely for and prove the narrowing doesn't intersect it.** Removing a region always passes existing controls and can cost the check its reason to exist. — `2026-08-21-carve-out-gave-away-the-gates-purpose`, `2026-08-21-noise-filter-disabled-the-signal-it-protected` (same failure twice in one session — once by scope reduction, once by noise filtering)
6. **Write a suppression/exemption's control at the boundary of the suppressed region, not its middle.** A filter that suppresses false positives is a second detector and needs its own false-positive analysis. — `2026-08-21-noise-filter-disabled-the-signal-it-protected`
7. **Every property asserted in prose about a gate ("can only shrink," "monotone," "never decreases") needs a control that violates it in the forbidden direction specifically.** Writing the principle down inside the same session as building the gate is not protection against skipping its enforcement. — `2026-08-21-ratchet-asserted-not-enforced`
8. **Every exemption is a claim that a condition can happen only once — write down what makes it unique, and prefer eliminating the exempted state over detecting the difference** when recurrence is possible. — `2026-08-22-closing-a-hole-created-a-new-uniqueness-assumption`
9. **When a gate delegates to an external tool (node, a parser, a linter), name the dialect the tool applies and whether it's the dialect the artifact runs under; write one control where the dialects disagree.** — `2026-08-22-right-check-wrong-grammar` (CommonJS `node --check` silently permitted a top-level `return` that every browser rejects)
10. **A checker is scoped to a container, not a language — ask where else the same language can hide** (event-handler attributes, `javascript:` URLs, `<svg onload>`, CSS `expression()`) before declaring a container's checker complete. — `2026-08-23-inline-script-lived-where-no-checker-looked`
11. **A safety bound imposed on a checker must shorten a candidate to nothing, never to a different, shorter valid value of the same type.** Truncating a token into a plausible-but-wrong token is silent corruption, the one transition every gate here exists to prevent. — `2026-08-23-a-safety-cap-that-silently-changed-a-value`
12. **When a check must be relaxed to stop failing correct work, the discriminator must be read from the source, not asserted as a blanket exemption — and the original failing case must survive as a negative control in the same change.** — `2026-08-23-a-gate-that-failed-a-correct-citation-again`
13. **A relaxation is a partial repeal of every guarantee it overlaps, not just the one it targeted.** When loosening a check, ask "what did this just make reachable that used to be forbidden?", not just "does the loosened case now pass?" Test the *intersection* of the new feature with every old guarantee, not each in isolation. — `2026-08-23-a-relaxation-that-repealed-an-older-guarantee`
14. **A verdict without a denominator cannot be audited — report the size of what was checked, not only the verdict** (`PASS 28 files, 0 wrong` is unfalsifiable; `PASS 28 files, 476 citations compared, 0 wrong` collapses visibly if the parser silently stops feeding it). And: **a denominator added specifically to fix a silent-absence bug needs its own independent derivation** — the fix can itself be silently short, and is *harder* to doubt than the original silence because it looks like the answer. — `2026-08-23-indexing-a-source-is-not-checking-it`, `2026-08-23-the-denominator-added-to-fix-silence-was-itself-short`
15. **Where a check needs two fields (e.g. a result number and a page), the case where one is absent is a third outcome, not a silent pass.** — `2026-08-23-a-result-named-without-a-page-is-checked-by-nothing`
16. **A gate that verifies parts of a composite assertion independently can pass an assertion whose parts don't belong together** (right page, wrong theorem number on that page). Not every such gap is mechanizable — say so explicitly when it isn't, and write the authoring rule instead. — `2026-08-23-the-right-page-and-the-wrong-result-on-it`
17. **When a second checker consumes the same corpus as an existing one, the corpus-reading logic (which book a sentence is about, where a citation ends) is a shared contract, belongs in one module, and should be imported, not re-derived** — a second implementation starts from the naive answer and re-earns every correction the first one already paid for. — `2026-08-23-a-solved-problem-re-solved-worse-in-a-second-checker`
18. **Before first use, run a new gate against a KNOWN-DEFECTIVE input it must rediscover, and spot-verify one finding per distinct source/book format in the corpus** — a gate validated on one book's typography is validated on one book. — `2026-08-21-gate-inverted-four-ways-before-trustworthy` (four wrong-then-fixed passes on the citation gate before it was trustworthy)
19. **Write gate controls from the checker's *spec* (what it should accept/reject, enumerated deliberately), not from the corpus it happens to run against.** A green corpus run is evidence the gate doesn't break today's inputs — it is not evidence the gate is correct; a gate's defects live exactly in the inputs its corpus doesn't contain. — `2026-08-22-only-a-rejecting-failure-hides-from-the-corpus`
20. **A per-artifact gate wired only at authoring time measures the author's diligence, not the corpus — wire the full-corpus CI loop in the same commit that introduces the check**, since a checker with an unbounded, unseen backlog is worse than an honest failure count. — `2026-08-21-first-corpus-run-of-an-authoring-gate`
21. **An artifact can be correct about the procedure that produced it and cited for a property it doesn't establish** (a nearest-neighbour table is correct as nearest-neighbours; it doesn't establish a matching, because the stability theorem permits sending short bars to the diagonal). The fix is usually to make the artifact report the property directly, not to hedge the prose — a measurement can come back against you, a hedge cannot. — `2026-08-21-i-true-of-the-procedure-false-of-the-property`
22. **"Made visible/legible" is a claim about a reader; "is required/forced" is a claim about a structure — and they're distinguishable by a mechanical test whenever a bijection is in play** (barcode ↔ diagram; a picture that makes something easy to see is not evidence the underlying operation requires that representation). — `2026-08-21-h-legibility-restated-as-capability`
23. **A per-item gate suite cannot see a property that isn't a property of any single item** (cross-unit consistency). Ask of every gate "what is the largest object this reads?" — any claim spanning more than that object is unguarded by construction. — `2026-08-21-j-every-gate-is-per-unit-and-the-contradiction-was-cross-unit`
24. **A control should fail when the code is wrong and at no other time.** A fixture that asserts something true of the *environment* (an unrepaired mission strip, a not-yet-authored file, a stdout string that depends on a resource absent in CI) is a tripwire pointed backwards — it breaks exactly when the work it's waiting for succeeds. — `2026-08-22-three-fixtures-pinned-to-the-surroundings`
25. **A configuration value that *selects* a checker, baseline, or comparison target is itself load-bearing and needs its own resolver-failure gate** — a gate that can't start reports nothing, and nothing looks identical to clean. — `2026-08-22-config-that-selects-the-checker-is-load-bearing` (six units' resource pointers resolved to nothing; 156 citations silently never checked)
26. **Never write regex, LaTeX, or any backslash-bearing content through a Bash heredoc** — it has silently mangled word-boundary escapes into literal control characters at least four times this window, reaching a tracked file at least once. Use the Write/Edit tools for anything containing backslashes; if a heredoc was already used, verify with `grep -n <pattern> <file> | cat -v`, not `grep -P` (silently unavailable in this environment's locale, which itself looked like a clean result). — `2026-08-22-heredoc-silently-ate-my-word-boundaries`, `2026-08-23-heredoc-mangling-reached-a-tracked-file`
27. **A local hand-assembled gate runner is a self-attestation** — it reports on the checks its author remembered, and its silence about the rest reads as success. Derive the local runner's check list from the same manifest CI consumes, with a parity test that fails if they diverge. — `2026-08-25-a-hand-rolled-gate-harness-omitted-a-ci-check-and-reported-clean` (a hand-rolled `gate.sh` omitted `scripts/gate.py`'s tag-balance check; three lessons were reported "CLEAN" to Stephen while CI was red)
28. **A gate's own tests cover the gate, not its supply chain.** When a gate's input is assembled by CI (a fetched baseline, a downloaded fixture), the assembly step must fail loudly on failure — `|| true` on an input step turns every upstream failure into a silent, permanent skip. After wiring a gate into CI, read the log for the positive signal that it *ran*, not just the green tick. — `2026-08-21-fix-in-commit-n-broken-by-environment-in-commit-n` — **status unclear, see Priority 2 below.**
29. **A control over a known gap must state the gap's measured size, not just its existence** — "a known limit, asserted so it cannot regress" reads as a decision to a later author; write the actual count (e.g., "190 citations in the corpus") so the gap can't be mistaken for something acceptable. — `2026-08-22-a-control-over-a-gap-makes-it-permanent`
30. **A checker's unit of attribution (the clause, the sentence) has to match the author's unit of composition.** Prose that reads well across two sentences and attributes a folio to the wrong clause is a defect in the writing, not (only) a defect in the checker. — `2026-08-22-page-numbers-attach-per-clause-not-per-citation`, `2026-08-25-citation-page-attribution-crosses-sentence-boundaries`
31. **Reproducibility (a block re-executes and matches its recorded output) and sufficiency (the recorded output supports the prose claim about it) are different properties** — a gate that verifies the first cannot verify the second, and printing only an aggregate is exactly where an unfalsifiable explanation gets room to sit. Print the decomposition the prose reasons about, not the roll-up it summarizes to. — `2026-08-21-g-an-aggregated-output-cannot-support-a-claim-about-its-parts`
32. **A negative control and a permutation-null baseline belong in taught content, not only in tooling** — a fitted score with no non-informative baseline and no label-permutation control is a procedure attesting to its own value. — `2026-08-20-negative-controls-belong-in-content-not-only-in-gates`
33. **A null establishes that an effect is distinguishable from structureless data; it does not calibrate where the signal/artefact cut falls**, because the null's own artefacts are not a model of the data's artefacts. State explicitly which job a control is doing. — `2026-08-20-a-null-is-a-test-not-a-threshold`
34. **A lockfile proves names and versions, not function.** Where the guarantee is a working environment, execute the *specific* thing depended upon (not a top-level import) — the convention adopted here is that a lab's `env` block imports the exact modules its later blocks use, so a broken compiled subpackage shows up as a diff instead of a silent green pin-check. — `2026-08-20-a-lockfile-proves-versions-not-function`
35. **Instantiate a cited theorem at its stated hypothesis boundary when the content is executable** — reading a theorem's hypotheses for completeness is unreliable; running the theorem at the edge of what it claims (e.g. `ω ≡ 1`, the weakest allowed weight) can falsify a printed source that reads as complete. — `2026-08-20-execution-caught-a-printed-theorem-that-reading-would-not` (Dey & Wang Theorem 13.3 is false as printed)
36. **A manual gate that leaves no artifact of having run is functionally unenforced** — under time pressure, the one gate with no trace is the one that gets skipped, indistinguishably from having passed. Where a check is genuinely hard to automate, automate the *evidence* it ran instead (a committed read-back fixture, checked for existence and freshness against the lesson file). — `2026-08-20-gate-7-is-the-only-manual-gate-and-has-no-record`
37. **A review finding names a defect; it does not establish the defect's magnitude — measure the magnitude, don't just apply the fix.** Run the three-way version (original / fixed / isolated variable) of anything a reviewer flags that can be settled by execution; in three-for-three cases here the measured cost was the actual content worth keeping. — `2026-08-21-b-review-findings-are-hypotheses`
38. **Capture the exact set of review-thread IDs at the moment they're read and resolve only by that captured set** — re-querying "unresolved" at resolve time and closing everything returned silently sweeps up threads that arrived in between. — `2026-08-22-i-resolved-review-threads-i-had-not-read`
39. **Before publishing a diagnosis, state what the failure output would look like under the competing hypothesis and check whether it differs**, and don't write a diagnosis into three artifacts (docstring, plan, PR description) until it's survived that test. — `2026-08-22-i-diagnosed-the-tool-not-the-config`
40. **An unversioned authoring tool has no diff, so its regressions are invisible by construction.** A tool used twice belongs under version control from the second use — "promote it later" prices in an unbounded silent-regression window (measured here at three semesters). — `2026-08-21-scratchpad-tools-regress-without-review`
