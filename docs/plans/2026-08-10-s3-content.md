# S3 content build — plan and tracker

**Goal.** Every S3 unit gets its two content artifacts: a problem set
(`problems/sets/<unit>.md`) and a lesson (`lessons/<module>/<unit>.html`),
each passing the six gates below and the rubric in `curriculum/LESSON-RUBRIC.md`.

**Scope.** 26 units — at1 (10), cat (7), tda1 (9). At start: **0 problem sets,
0 lessons** for all three modules (`lessons/at1`, `lessons/cat`, `lessons/tda1`
do not yet exist). Nothing is inherited; every artifact is new.

**Branch.** `s3-content`, cut from `main` at `3c5c2f1` on 2026-08-10, after
PR #13 (S4 content) and PR #14 (the observation 150–153 gate fixes) both merged.
S4's 23 lessons are therefore present on this branch and may be cited by S3
units that point forward. Content-only, as S4's was: no syllabus edits, no gate
edits. Resource problems are recorded under Open decisions and handed to a
separate syllabus pass.

**Order.** `at1 → cat → tda1`.

at1 first is forced: every other S3 module cites it (cat-07 has prereq at1-10;
tda1-01/02/08/09 have at1 prereqs). The cat-before-tda1 choice is not forced by
the DAG — no tda1 unit has a cat prereq — and is taken for three reasons:

1. **cat-04's mission strip is the definition tda1-06/07 need.** It states the
   ε-interleaving as a pair of natural transformations `M ⇒ N(·+ε)`,
   `N ⇒ M(·+ε)` whose composites are the 2ε-shift maps, and names tda1-06/07 as
   where it is used. Writing cat-04 first lets tda1-06 cite that lesson instead
   of re-deriving natural transformations inline.
2. **cat-07 and tda1-03/04/05 share a source.** All four read Oudot ch. 1.
   Extracting and verifying it once, for cat-07, means tda1-03 arrives with the
   reading already done and the folios already checked.
3. **tda1-04's structure theorem reads better with the vocabulary in hand** —
   a tame persistence module decomposing into intervals is a statement about a
   functor from a poset, which is exactly cat-07's subject.

Cost accepted: cat-07 teaches persistence-as-a-functor before tda1-03 teaches
what a persistence module computationally *is*. The syllabus already accepts
this (cat-07's prereqs are cat-06 and at1-10, no tda1 unit), and cat-07's job is
the categorical statement rather than the computation. cat-07 will say so and
point forward to tda1-03.

**Because cat runs second, the Spivak bookmap registration lands early** — its
own commit, before the first cat unit, separate from any content. See Open
decisions.

## Per-unit procedure

1. **Extract.** Pull the sections named in the unit's `resources` from the
   per-page markdown (`scratchpad/pull.py <Book> --pages A-B --out x.md`). Read
   them. Never write from recollection — LESSON-GUIDE §Source discipline.
   For Dexter notes, read the `.tex` (no per-page markdown; pull.py will not work).
2. **Problem set** `problems/sets/<unit>.md`: 5 problems, easy→hard, each with
   `Nudge` / `Strategy` / `Partial` / `Worked start` `<details>` blocks; every
   cited theorem/definition id verified present in the extract. Interleave
   earlier units where the syllabus prereqs invite it. **LaTeX is the convention
   in problem sets.**
3. **Lesson** `lessons/<module>/<unit>.html` from `lessons/_template.html`,
   following LESSON-GUIDE §Structure exactly. Read the problem set *first* —
   every technique it uses must be demonstrated by a worked or faded example and
   every id it names must appear (Gate 0.1). **Literal Unicode maths in lessons,
   never LaTeX.**
4. **Gates** — all six clean (below).
5. **Gate 2 read-back** against the extract: every definition, theorem
   statement, proof step, worked answer, `data-ok` and model answer, checked
   against the page it cites. Not optional; this is where the real defects are.
   In S4 it caught a stability argument running in the wrong direction and an
   artifact credited from its directory name without ever being opened.
6. **Commit by explicit path**, and **update this file's tracker row to ✓ in the
   same commit**. S4 lost this step once because it lived only in commit
   precedent; here it is a written step.

### The six gates

Run from the repo root, per unit:

```bash
python scripts/check_lesson_coverage.py problems/sets/<u>.md lessons/<m>/<u>.html
python scripts/lesson_lint.py lessons/<m>/<u>.html
python -c "from html.parser import HTMLParser; HTMLParser().feed(open('lessons/<m>/<u>.html',encoding='utf-8').read())"
python <scratchpad>/gate.py lessons/<m>/<u>.html
```

Gates 1–3 are the built-ins: coverage, lint, HTML parses. Gates 4–6 are
`gate.py`, which the built-ins miss and each of which caught a real S4 defect:

| # | Gate | Why the built-ins miss it | S4 defect |
|---|---|---|---|
| 4 | **Tag balance** (stack-based `HTMLParser` subclass + void-element set) | `HTMLParser` accepts crossed tags like `<sup>x</sub>` silently | a crossed tag shipped |
| 5 | **No external requests** (`https?://`, `<link`, `src=`, `cdn`, `@import`) | not checked by lint | — |
| 6 | **`node --check` on every inline `<script>`** | a script body is CDATA to `HTMLParser`, so a syntax error inside it is invisible to *every* other gate | an unclosed IIFE shipped in tda2-08 and passed all of the above |

**gate.py negative control — run 2026-08-10, before any authoring.** A control
file carrying a crossed `<sup>x</sub>`, an `https://…cdn` link and a stray `;;)`
inside an IIFE was checked: all three gates returned FAIL, exit 1. The gate can
fire. Re-run the control if gate.py is ever edited.

### Gate 8 — the mission strip is quoted verbatim

Added 2026-08-10, during at1-01. The rubric requires the mission strip verbatim,
and the rescoping discipline below makes that requirement load-bearing: the
lesson quotes the claim exactly and *then* bounds it. Nothing mechanised the
quotation, so a paraphrase — the natural thing to write when the claim
overreaches and you are minded to soften it — would have passed all seven gates.
`scratchpad/mission.py` reads `mission_link` out of `syllabus.yaml`, strips the
lesson's `<p class="mission">` to text, and compares after whitespace
normalisation.

**Negative control — run 2026-08-10.** at1-01's strip with four words appended
returns FAIL, exit 1, printing both strings. The gate can fire.

### Gate 7 — the canvas actually renders

`node --check` proves a script *parses*, not that it *draws inside the viewport*.
cap-04's diagram was laid out at y = 334–368 inside a 340 px canvas — clipped,
silent, and green on all six gates. Therefore, for every lesson:

- Compute node positions on paper and check them against the canvas height
  before writing the script.
- For anything non-trivial, open the file in the browser pane and read back the
  painted bounding box via `getImageData`.

## Mission-strip rescoping

Several units' `mission_link` strings claim more than their own `resources`
establish. The rubric requires the mission strip **verbatim**, so quote it
verbatim — then teach only what the source supports and say so, twice: in a
`.warn` block in the body and in a "Not established here" clause in the footer.
S4 shipped eight of these; tda2-07 is the model (the Nerve Theorem is not
Mapper's guarantee — what holds for a pullback cover is Theorem 9.5/9.9's H₁
surjection).

**Rescope in the open. Do not fill from recollection, and do not ship a
`NOT IN SOURCE:` marker either** — `lesson_lint.py` fails on the marker, and it
is a placeholder, not a resolution.

Watch for it specifically at:

- **tda1-07, the stability theorem.** S4's capstone units established that the
  chain from a data perturbation to a reported statistic does not close for the
  TDL pipeline. tda1-07 is where the theorem itself gets taught. Teach exactly
  what Oudot ch. 3 and Edelsbrunner VIII.2 prove, **in the metric they prove it
  in** — and no further.
- **cat-04 and cat-07**, whose mission strips are unusually substantive
  (cat-04's states the ε-interleaving in full; cat-07's asserts stability is
  expressed *through* interleavings rather than as a natural transformation in
  its own right). Both must be supported from Aluffi/Spivak/Oudot or scoped.
- **at1-01/02/03**, whose strips reach forward into persistence ("features
  survive noise", "chain groups a persistence algorithm can chew", "the Betti-1
  you will compute") from a source — Hatcher ch. 0–1.1 — that contains no
  persistence at all.

**Never carry a theorem number across books.** The same theorem carries
different numbers in different texts: tda1 teaches stability from
Oudot/Edelsbrunner, while S4's cap-01 cites Dey's Theorem 6.3 and Definition 6.1
for the same territory. Re-derive every number from the book being cited.

## Open decisions

- **Spivak is not registered in `resources/bookmap.json`. Must be added before
  cat.** Verified on disk 2026-08-10 at
  `D:\OneDrive - The Open University\NexusCollege Core Texts\md\Applied Category Theory David Spivak.pdf`
  — 354 pages, standard `markdown.md` + `pages/page-N/markdown.md` layout, so
  pull.py works the moment a key exists. It currently appears only as a non-book
  prefix in `resources/resource_sources.json`, which is why the syllabus
  validates without it while the text is unreachable to the extractor. **Action:
  add a `"Spivak"` key to `bookmap.json` pointing at that folder's `markdown.md`
  and `pages`, in its own commit, before the first cat unit and separate from
  content.** Covered by open observation
  `2026-08-09-syllabus-resources-resolve-to-nothing`.

- **Neither source proves the Yoneda lemma. cat-04 must say which one states
  it.** Both halves verified 2026-08-10 by reading the pages:
  - **Spivak** gives only the preorder version. Printed p. 20: "This is known as
    the Yoneda lemma for preorders", followed by the remark that the general
    lemma "is a powerful tool in category theory". At printed p. 245 it says of
    the general lemma, in its own words, "we have not introduced it."
  - **Aluffi** — and this is a correction to the handover brief, which assumed
    Aluffi supplies the proof — states the lemma as **Exercise VIII.1.10**,
    printed p. 497, with a hint, not as a proved theorem in the body. The index
    lists Yoneda at 497 and 591 only; 591 is Exercise IX.2.17, which upgrades it
    to the Freyd–Mitchell setting, far outside cat-04's scope.

  **Resolution.** cat-04's Yoneda content comes from Aluffi VIII.1 (which lists
  first in that unit's `resources` anyway), and the lesson's **guided proof block
  is Aluffi's Exercise 1.10 worked from its own hint** — a legitimate use of the
  source, since the statement is the text's and the proof is the exercise the
  text sets. The lesson must say plainly that Aluffi *sets* the lemma rather than
  proving it, and must not write "Aluffi proves". Spivak supplies natural
  transformations (§3.3.4, printed 95) and the preorder special case, which is a
  good on-ramp and worth using as one — and the lesson says which source carries
  the lemma.

- **cat-05's Spivak section is explicitly introductory.** Verified: §3.5 is
  titled *"Bonus: An introduction to limits and colimits"*, printed p. 107, and
  cat-05's `resources` name Spivak **first**. **Resolution: treat Aluffi Chapter
  0 I.5 as the substantive source for cat-05** and state the split in the lesson
  — Spivak for the intuition and the applied examples, Aluffi for the definitions
  and universal properties. Recorded rather than reordered, because reordering
  `resources` is a syllabus edit and this branch is content-only.

- **cat-02 names only Aluffi I.5, but the brief's Spivak map includes a cat-02
  row** (§3.5 p. 107, §6.2.4 finite colimits p. 191). Source discipline binds to
  the unit's own `resources`, so **cat-02 is authored from Aluffi I.5 alone**.
  The Spivak sections stay in the map above as optional enrichment for cat-05,
  which does name Spivak.

- **Stillwell is unavailable and at1-04 proceeds without it.** It is the
  secondary resource of at1-04 only; the primary, Hatcher 1.1, covers π₁(S¹) and
  its applications (Brouwer, the fundamental theorem of algebra) in full.
  **Author at1-04 from Hatcher and note in the footer that Stillwell was not
  consulted.** No rescope needed — nothing in the unit depends on it.

- **Dexter notes are available but differently shaped, and their citation
  convention is undecided.** At
  `D:\OneDrive - The Open University\Cambridge Lecture Notes\Cambridge Dexter Notes\algebraic_topology.{tex,pdf,html}`,
  plus pre-split `_def` / `_eg` / `_thm` / `_thm_proof` PDFs — all verified
