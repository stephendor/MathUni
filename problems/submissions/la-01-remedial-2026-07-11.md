## R1 - Verification discipline

Solve
$$(2,-5,3,-1)+3x=(-1,4,0,8).$$

Subtract $(2,-5,3,-1)$ from both sides:
$$3x=(-1,4,0,8)-(2,-5,3,-1).$$

Computing componentwise,
$$3x=(-1-2,\;4-(-5),\;0-3,\;8-(-1))
=(-3,9,-3,9).$$

Dividing by $3$,
$$\boxed{x=(-1,3,-1,3)}.$$

### Verification

Substitute $x=(-1,3,-1,3)$ into the original equation:
$$(2,-5,3,-1)+3(-1,3,-1,3).$$

Since
$$3(-1,3,-1,3)=(-3,9,-3,9),$$
we obtain
$$(2,-5,3,-1)+(-3,9,-3,9)
=(-1,4,0,8).$$

The individual components are
$$2+3(-1)=-1,$$
$$-5+3(3)=4,$$
$$3+3(-1)=0,$$
and
$$-1+3(3)=8.$$

Thus every component agrees with the right-hand side, so
$$\boxed{x=(-1,3,-1,3)}$$
is verified.

## R2 - Justifying scalar-times-zero

Let $a\in\mathbb F$, and let $0$ denote the zero vector in $V$.

Because
$$0+0=0,$$
distributivity of scalar multiplication over vector addition gives
$$a\cdot 0
=a(0+0)
=a\cdot 0+a\cdot 0.$$

Add the additive inverse of $a\cdot 0$ to both sides:
$$a\cdot 0+\bigl(-(a\cdot 0)\bigr)
=\bigl(a\cdot 0+a\cdot 0\bigr)
+\bigl(-(a\cdot 0)\bigr).$$

Using associativity and the additive inverse property,
$$0=a\cdot 0.$$

Therefore,
$$\boxed{a\cdot 0=0}$$
for every $a\in\mathbb F$.

## R3 - Vacuous truth

A universally quantified statement over $V=\varnothing$ is true because there are no vectors in $V$ that could provide a counterexample to it. The additive identity axiom cannot be rescued in this way because it requires the existence of an element $0\in V$, but the empty set contains no elements.
