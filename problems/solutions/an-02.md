## Problem 1 — the zig-zag bijection $\mathbb{Z}\sim\mathbb{N}$

**Solution.** $f(n)=(n-1)/2$ if $n$ odd, $-n/2$ if $n$ even.

*Values:* $f(1)=0,f(2)=-1,f(3)=1,f(4)=-2,f(5)=2$ — all distinct integers.

*1–1:* Suppose $f(n_1)=f(n_2)$. If both $n_1,n_2$ are odd: $(n_1-1)/2=(n_2-1)/2\Rightarrow n_1=n_2$. If both even: $-n_1/2=-n_2/2\Rightarrow n_1=n_2$. If one odd, one even: the odd input gives a value $\ge0$ (since $n\ge1$ odd gives $(n-1)/2\ge0$) while the even input gives a value $<0$ (since $n\ge2$ even gives $-n/2\le-1$) — these can never be equal, so mixed cases cannot collide. Hence $f$ is 1–1.

*Onto:* given $k\ge0$, take $n=2k+1$ (odd, positive), so $f(n)=((2k+1)-1)/2=k$. Given $k<0$, take $n=-2k$ (even, positive since $k<0$), so $f(n)=-(-2k)/2=k$. Every integer is reached, so $f$ is onto.

Since $f$ is 1–1 and onto, $\mathbb{Z}\sim\mathbb{N}$: $\mathbb{Z}$ is countable. $\blacksquare$

**Rubric (total 1.0):**
- Correctly computes sample values confirming distinctness — 0.15
- Correct 1–1 argument covering both same-parity cases — 0.35
- Correct 1–1 argument ruling out mixed-parity collisions — 0.2
- Correct onto argument exhibiting $n$ for both $k\ge0$ and $k<0$ — 0.3

## Problem 2 — finite subsets of $\mathbb{N}$ are countable

**Solution.** For each $n\in\mathbb{N}$, let $\mathcal{F}_n$ be the set of subsets of $\{1,\ldots,n\}$ that have $n$ as their largest element (equivalently, subsets $S\subseteq\{1,\ldots,n\}$ with $n\in S$). Each $\mathcal{F}_n$ is finite: it has at most $2^{n-1}$ elements (choices for the remaining $n-1$ potential members).

Every finite, nonempty subset $S$ of $\mathbb{N}$ has a well-defined largest element $m=\max S$ (finite nonempty sets of naturals have a maximum), so $S\in\mathcal{F}_m$ for exactly one $m$ — this partitions all nonempty finite subsets of $\mathbb{N}$ into the disjoint finite layers $\mathcal{F}_1,\mathcal{F}_2,\mathcal{F}_3,\ldots$

List $\mathcal{F}_1$, then $\mathcal{F}_2$, then $\mathcal{F}_3$, and so on, concatenating each finite layer's elements before moving to the next. Since each layer is finite, this concatenation produces a well-defined, exhaustive, $\mathbb{N}$-indexed list of every nonempty finite subset of $\mathbb{N}$ (adjoin the empty set at the start of the list separately). This list is a bijection with $\mathbb{N}$ (using the "finite shells" argument from Theorem 1.4.11(i)'s proof of $\mathbb{Q}$'s countability), so the set of all finite subsets of $\mathbb{N}$ is countable. $\blacksquare$

**Rubric (total 1.0):**
- Correctly defines a finite-layer decomposition (by max element or equivalent) — 0.3
- Verifies each layer is finite — 0.2
- Verifies every finite subset belongs to exactly one layer (well-defined partition) — 0.25
- Correctly concludes countability via concatenation of finite layers, citing the same mechanism as $\mathbb{Q}$'s proof — 0.25

## Problem 3 — the set of 0/1 sequences is uncountable

**Solution.** Suppose, for contradiction, that $S$ (the set of all infinite 0/1 sequences) is countable, via a list $g(1),g(2),g(3),\ldots$ exhausting $S$. Write $g(m)=(a_{m1},a_{m2},a_{m3},\ldots)$ with each $a_{mn}\in\{0,1\}$.

Define the adversary sequence $b=(b_1,b_2,\ldots)$ by
$$b_n = 1-a_{nn} \quad (\text{i.e. } b_n=1 \text{ if } a_{nn}=0, \text{ and } b_n=0 \text{ if } a_{nn}=1).$$

By construction, $b_n\ne a_{nn}$ for every $n$, i.e. $b$ disagrees with $g(n)$ at position $n$, for every $n\in\mathbb{N}$. So $b\ne g(n)$ for any $n$. But $b\in S$ (it is a genuine infinite 0/1 sequence), contradicting the assumption that $g$'s list contained every element of $S$.

Therefore $S$ is uncountable. $\blacksquare$

**Any logically valid alternative construction of the adversary sequence earns full marks.**

**Rubric (total 1.0):**
- Correct contradiction setup (assumes an exhaustive list $g$ exists) — 0.2
- Correctly defines the adversary sequence via digit-flipping on the diagonal — 0.35
- Correctly argues $b$ disagrees with every $g(n)$ at position $n$ — 0.25
- States the explicit contradiction ($b\in S$ but missing from the list) and concludes uncountability — 0.2

## Problem 4 — 1–1 maps $A\to P(A)$ and Cantor's Theorem

**Solution.** Let $A=\{a,b,c\}$.

**(a)** Two distinct 1–1 maps: $f_1(a)=\{a\}, f_1(b)=\{b\}, f_1(c)=\{c\}$; and $f_2(a)=\{a,b\}, f_2(b)=\{b,c\}, f_2(c)=\{a,c\}$. Both are injective (distinct inputs give distinct outputs, checked directly by inspection of the three images in each case).

**(b)** For any $f:A\to P(A)$, define the "Cantor set" $B=\{x\in A : x\notin f(x)\}\subseteq A$. Suppose, for contradiction, $f$ is onto. Then $B=f(a')$ for some $a'\in A$. Ask whether $a'\in B$:

- If $a'\in B$, then by definition of $B$, $a'\notin f(a')=B$ — contradiction.
- If $a'\notin B$, then $a'\notin f(a')=B$ fails to hold as a reason for exclusion — more precisely, $a'\notin B$ means (by definition of $B$) it is *not* the case that $a'\notin f(a')$, i.e. $a'\in f(a')=B$ — contradiction.

Either way, contradiction. So no onto $f$ exists. Crucially, this argument never used finiteness of $A$ — it works verbatim for infinite $A$ too, which is exactly the content of Cantor's Theorem (Theorem 1.5.2): no set can be mapped onto its own power set. $\blacksquare$

**Rubric (total 1.0):**
- Correct construction of two distinct injective maps in (a) — 0.2
- Correctly defines the Cantor set $B$ for an arbitrary $f$ — 0.25
- Correctly derives the contradiction from asking whether $a'\in B$ — 0.35
- Explicitly notes the argument is finiteness-independent, connecting to Cantor's Theorem for general/infinite $A$ — 0.2

## Problem 5 — Schröder–Bernstein sketch

**Solution.** Given 1–1 $f:X\to Y$ and 1–1 $g:Y\to X$, classify each $x\in X$ (and symmetrically each $y\in Y$) by tracing its "ancestry" chain backward: $x \leftarrow g^{-1}(x)$ (if $x\in\operatorname{range}(g)$) $\leftarrow f^{-1}(g^{-1}(x))$ (if that's in range of $f$), and so on, alternating $g^{-1}$ and $f^{-1}$ as far as possible.

Three exhaustive possibilities for this backward chain: (i) it terminates at an element of $X$ with no $g$-preimage ("$X$-stopper"); (ii) it terminates at an element of $Y$ with no $f$-preimage ("$Y$-stopper"); (iii) it never terminates (an infinite chain).

Define $h:X\to Y$ piecewise:
- If $x$'s chain is an $X$-stopper or infinite, set $h(x)=f(x)$.
- If $x$'s chain is a $Y$-stopper, set $h(x)=g^{-1}(x)$ (well-defined since such $x$ is, by construction of its chain, in the range of $g$).

*Well-defined:* every $x$ falls into exactly one of the three chain types (the classification is a genuine partition).

*1–1:* on each piece, $h$ is injective ($f$ and $g^{-1}$ both are), and chain type is preserved under $f$ or $g^{-1}$ in a way that keeps the images of different pieces disjoint (elements of $X$-stopper/infinite type map, under $f$, to $Y$-elements whose own chain type matches; similarly for $Y$-stopper type under $g^{-1}$), so no collision occurs across pieces.

*Onto:* every $y\in Y$ is classified by the same three-way chain analysis (run backward from $y$ using $f^{-1}$ then $g^{-1}$ alternately); tracing which type $y$'s chain is shows it is hit by exactly one $x$ under the corresponding piece of $h$.

Hence $h$ is a 1–1, onto function $X\to Y$, so $X\sim Y$. $\blacksquare$

**Rubric (total 1.0):**
- Correctly sets up the backward-chain classification with all three chain types identified — 0.35
- Correctly defines $h$ piecewise using $f$ and $g^{-1}$ on the appropriate types — 0.3
- Argues (even briefly but correctly) that $h$ is well-defined and injective — 0.2
- Argues $h$ is onto by symmetric chain analysis from the $Y$ side, and concludes $X\sim Y$ — 0.15

## Problem 6 — $\mathbb{I}$ (irrationals) is uncountable

**Solution.** Suppose, for contradiction, that $\mathbb{I}$ is countable. Since $\mathbb{Q}$ is countable (Theorem 1.4.11(i)) and $\mathbb{R}=\mathbb{Q}\cup\mathbb{I}$, $\mathbb{R}$ would be a union of two countable sets. A finite union of countable sets is countable (an-02's lesson establishes this alongside the $\mathbb{Z}\sim\mathbb{N}$ zig-zag, using the same finite-shells / interleaving mechanism as the $\mathbb{Q}$-countability proof), so $\mathbb{R}$ would be countable.

But this contradicts Theorem 1.5.1 (equivalently, via Exercise 1.5.1, the uncountability of $(0,1)$ implies the uncountability of $\mathbb{R}$): $\mathbb{R}$ is uncountable.

This contradiction shows the assumption was false: $\mathbb{I}$ must be uncountable. $\blacksquare$

**Rubric (total 1.0):**
- Correct contradiction setup: assumes $\mathbb{I}$ countable — 0.2
- Correctly invokes $\mathbb{Q}$ countable and $\mathbb{R}=\mathbb{Q}\cup\mathbb{I}$ — 0.25
- Correctly cites "finite union of countable sets is countable" to derive $\mathbb{R}$ countable — 0.3
- Correctly cites $\mathbb{R}$'s uncountability (Theorem 1.5.1 / Exercise 1.5.1) for the contradiction, and concludes $\mathbb{I}$ uncountable — 0.25
