## Problem 1 — penny/nickel swap

**Solution.** Only action: swap. Check Carter's rules:

- **Rule 1.5 (fixed list):** yes — one action, "swap", never added to.
- **Rule 1.6 (reversible):** yes — swapping twice returns the coins to their original positions, so swap undoes itself.
- **Rule 1.7 (deterministic):** yes — swap always exchanges the two coins' positions, with no randomness.
- **Rule 1.8 (combinations are actions):** yes — swap-then-swap is a legitimate combined action, and it equals the do-nothing action.

All four rules hold: this **is** a group, of order 2 (do-nothing, swap), with swap as its own inverse. $\blacksquare$

**Rubric (total 1.0):**
- Correctly checks Rule 1.5 — 0.15
- Correctly checks Rule 1.6, explicitly noting swap is self-inverse — 0.3
- Correctly checks Rule 1.7 — 0.15
- Correctly checks Rule 1.8 and states the final group order/structure — 0.4

## Problem 2 — three-wall art rearrangement

**Solution.** Label the start $(1,2,3)$ (left, centre, right positions holding pictures 1, 2, 3). Generators: $\sigma=$ swap L/C, $\tau=$ swap C/R.

**(a)** Reachable arrangements: start $(1,2,3)$; $\sigma\to(2,1,3)$; $\tau\to(1,3,2)$; $\sigma\tau\to$ from $(2,1,3)$ apply $\tau$: $(2,3,1)$; $\tau\sigma\to$ from $(1,3,2)$ apply $\sigma$: $(3,1,2)$; continuing, $\sigma\tau\sigma\to(3,2,1)$. This exhausts all $3!=6$ permutations of $\{1,2,3\}$: $(1,2,3),(2,1,3),(1,3,2),(2,3,1),(3,1,2),(3,2,1)$.

**(b)** Rules 1.5–1.8 all check out: fixed generator list $\{\sigma,\tau\}$ (1.5); each generator undoes itself since swapping the same pair twice restores it (1.6); each action is deterministic (1.7); all six combinations found above are themselves legitimate actions on the list (1.8).

**(c)** $\sigma$ (swap L/C) undoes itself: applying it twice returns $(1,2,3)$. Similarly $\tau$ undoes itself. But $\sigma\tau$ (swap L/C, then swap C/R) does **not** undo itself: applying $\sigma\tau$ twice from $(1,2,3)$ gives, after the first application, $(2,3,1)$; applying $\sigma\tau$ again to $(2,3,1)$: swap L/C gives $(3,2,1)$, then swap C/R gives $(3,1,2)$ — not back to $(1,2,3)$. The genuine undo of $\sigma\tau$ is the *other order*, $\tau\sigma$: check that $\tau\sigma$ applied after $\sigma\tau$ returns to start. $\blacksquare$

**Rubric (total 1.0):**
- Correctly lists all 6 reachable arrangements (identifying the group as $S_3$) — 0.35
- Correctly checks Rules 1.5–1.8 against this scenario — 0.2
- Correctly verifies both single swaps are self-inverse — 0.2
- Correctly shows $\sigma\tau$ is *not* self-inverse and identifies $\tau\sigma$ as its actual inverse — 0.25

## Problem 3 — does Rule 1.8 force infinitude?

**Solution.** **No.** Rule 1.8 only asserts that every combination of actions is *itself* a legitimate action already recognised by the group — it does not require that combination to be *new*.

Counterexample: the rectangle group (aa-00, Segment 1) has exactly four configurations (solved, H-flip, V-flip, both). Every combination of the two generators (flip-H, flip-V) eventually coincides with one of these four — e.g. flip-H then flip-H again is a combination covered by Rule 1.8, but it equals the do-nothing action, already on the list; flip-H then flip-V equals the "both"/180°-rotation configuration, also already found.

The rectangle group satisfies Rules 1.5–1.8 in full, and is closed at exactly four actions — no new action ever appears past that point. This is a concrete finite group, so Rule 1.8 plainly does not force infinitude: the claim is **false**, disproved directly by this example. $\blacksquare$

**Rubric (total 1.0):**
- Correctly identifies the claim is false — 0.2
- Correctly explains that Rule 1.8 only requires combinations to be *recognised* actions, not *new* ones — 0.35
- Cites the rectangle group (or an equally valid finite example) as an explicit counterexample, verifying closure at four actions — 0.35
- States the conclusion clearly as a direct disproof — 0.1

## Problem 4 — counting actions in four scenarios

**Solution.**

**Coin swap (Exercise 1.1):** a group; 2 actions (do-nothing, swap).

**Coin-plus-dime (Exercise 1.2):** still a group; the dime is never acted on, so it contributes nothing new — still 2 actions (do-nothing, swap-penny-nickel), with the dime as an inert bystander.

**Marbles (Exercise 1.3):** five marbles, actions "move one left-to-right" and "move one right-to-left". Since marbles are indistinguishable, these two actions genuinely undo each other (Rule 1.6 holds). However, this system's actions are configuration-dependent in a way that strains Rule 1.7/1.5: once the left pocket is empty, "move one left-to-right" cannot be performed — the action set effectively depends on the current state, unlike a genuine group where every action applies from every configuration. This scenario is a **borderline/non-group** case unless one is careful to restrict to configurations where both moves remain always available (e.g. treat it as a group only on configurations that don't hit the boundary, or reinterpret "the group" as the full 6-state graph, which is not closed under a uniformly-applicable action pair) — flag this explicitly as a case where naive rule-checking needs care.

**Three-wall art (Exercise 1.4):** a group, with 6 actions (all permutations of 3 objects), from Problem 2 above.

**Rubric (total 1.0):**
- Correct count (2) for coin swap, with justification — 0.2
- Correct count (2) for coin-plus-dime, with justification that the dime is inert — 0.2
- Correctly flags the marbles scenario as boundary/non-uniform (recognising the action-availability issue near empty pockets) rather than blindly asserting a group — 0.35
- Correct count (6) for the three-wall art scenario, consistent with Problem 2 — 0.25

## Problem 5 — rectangle group and light-switch group share structure

**Solution.** Pair the configurations: solved $\leftrightarrow$ off-off, H-flip $\leftrightarrow$ on-off, V-flip $\leftrightarrow$ off-on, both $\leftrightarrow$ on-on. Pair the generators: flip-horizontal $\leftrightarrow$ flip-switch-1, flip-vertical $\leftrightarrow$ flip-switch-2.

Check every configuration against every generator:

- From solved/off-off: flip-H/flip-switch-1 $\to$ H-flip/on-off (matches); flip-V/flip-switch-2 $\to$ V-flip/off-on (matches).
- From H-flip/on-off: flip-H/flip-switch-1 $\to$ solved/off-off (matches, since flipping switch 1 again turns it back off); flip-V/flip-switch-2 $\to$ both/on-on (matches).
- From V-flip/off-on: flip-H/flip-switch-1 $\to$ both/on-on (matches); flip-V/flip-switch-2 $\to$ solved/off-off (matches).
- From both/on-on: flip-H/flip-switch-1 $\to$ V-flip/off-on (matches); flip-V/flip-switch-2 $\to$ H-flip/on-off (matches).

Every configuration, under every generator, maps to paired configurations. Since this holds for all four configurations and both generators, by Rule 1.8 it extends to every combination as well. The pairing is therefore structure-preserving: the two groups share identical combinatorial structure (later called an isomorphism, formalised in aa-27), even though their physical realisations (paper vs. electricity) are entirely different. $\blacksquare$

**Any correct explicit pairing, fully verified across all four configurations and both generators, earns full marks.**

**Rubric (total 1.0):**
- Proposes a valid pairing of the four configurations — 0.15
- Correctly verifies the pairing is preserved under the first generator, for all four configurations — 0.35
- Correctly verifies the pairing is preserved under the second generator, for all four configurations — 0.35
- Explicitly states that this establishes structure-preservation extending to all combinations — 0.15

## Problem 6 — dance-move group vs rectangle group

**Solution.** In the rectangle group, every non-identity action (H-flip, V-flip, 180°-rotation) returns to "solved" after exactly **two** applications: each is its own inverse (Discovered fact 2 of aa-00).

In the dance-move group, the quarter-turn action does not share this property: applying it once gives 90°, twice gives 180°, three times gives 270°, and only the fourth application returns to standing-still (0°/360°). So the quarter-turn's "undo" pattern requires four repetitions to close, not two.

This is a genuine structural difference: the rectangle group has **no** element requiring four repetitions to return to identity (every non-identity element has this "order 2" undo pattern), while the dance-move group **has** such an element (the quarter-turn, with "order 4" in the language aa-23 formalises). Since one group has an element of this repetition-length and the other does not, no relabelling of configurations can turn one group into the other — they are genuinely different groups of the same size, four. $\blacksquare$

**Rubric (total 1.0):**
- Correctly identifies the "every non-identity element is self-inverse" property of the rectangle group — 0.3
- Correctly traces the quarter-turn's repeated application, showing it needs four steps to return to identity — 0.35
- Explicitly states this as a structural difference not present in the rectangle group — 0.25
- Concludes the two groups cannot be relabellings of each other, despite equal size — 0.1
