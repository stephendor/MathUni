## Problem 1 — division with remainder

**Solution.** Apply Theorem 1.3 ($a=bq+r$, $0\le r<|b|$).

- **(a)** $a=100,b=7$: $7\cdot14=98\le100<105=7\cdot15$, so $q=14$, $r=100-98=2$. Check $0\le2<7$. ✓
- **(b)** $a=-17,b=5$: need $0\le r<5$. $5\cdot(-4)=-20\le-17$, so $q=-4$, $r=-17-(-20)=3$. Check $0\le3<5$. ✓
- **(c)** $a=-30,b=-4$: $|b|=4$, need $0\le r<4$. $-30=(-4)\cdot8+2$, so $q=8$, $r=2$. Check $0\le2<4$. ✓

"$-17 = 5\cdot(-3)-2$" is a valid *equation* but not the division-with-remainder decomposition: its remainder $-2$ fails $0\le r<5$. Theorem 1.3 asserts a **unique** decomposition with $r$ in $[0,|b|)$, and that one is $-17=5\cdot(-4)+3$. $\blacksquare$

**Rubric (total 1.0):**
- (a) correct $q=14,r=2$ — 0.2
- (b) correct $q=-4,r=3$ (sign of $q$ handled) — 0.25
- (c) correct $q=8,r=2$ (negative divisor, window $|b|$) — 0.25
- Explains the $-2$ case via the $0\le r<|b|$ uniqueness window — 0.3

## Problem 2 — sum of cubes by induction

**Solution.** Let $P(n)$: $1^3+\cdots+n^3=\left(\tfrac{n(n+1)}{2}\right)^2$.

*Base* $n=1$: LHS $=1$, RHS $=\left(\tfrac{1\cdot2}{2}\right)^2=1$. ✓

*Step.* Assume $P(n)$. Then
$$1^3+\cdots+n^3+(n+1)^3=\left(\tfrac{n(n+1)}{2}\right)^2+(n+1)^3=(n+1)^2\!\left(\tfrac{n^2}{4}+n+1\right)=(n+1)^2\cdot\tfrac{n^2+4n+4}{4}=(n+1)^2\cdot\tfrac{(n+2)^2}{4}=\left(\tfrac{(n+1)(n+2)}{2}\right)^2,$$
which is $P(n+1)$. By induction $P(n)$ holds for all $n\ge1$. $\blacksquare$

**Rubric (total 1.0):**
- Base case verified — 0.2
- States inductive hypothesis and adds $(n+1)^3$ — 0.3
- Correct algebra factoring to $\left(\tfrac{(n+1)(n+2)}{2}\right)^2$ — 0.4
- Concludes "by induction, all $n\ge1$" — 0.1

## Problem 3 — existence of prime factorisation (well-ordering)

**Solution.** Let $S=\{n\in\mathbb{Z}:n\ge2,\ n\text{ is not a product of primes}\}$. Suppose $S\ne\varnothing$. Then $S$ is a nonempty set of nonnegative integers, so by the **well-ordering principle** it has a least element $m$.

If $m$ is prime, then $m$ is a product of a single prime, so $m\notin S$ — contradiction. Hence $m$ is composite: $m=de$ with $1<d,e<m$. Since $2\le d<m$ and $2\le e<m$, minimality of $m$ gives $d\notin S$ and $e\notin S$: each is a product of primes, say $d=p_1\cdots p_j$ and $e=q_1\cdots q_k$. Then $m=de=p_1\cdots p_j q_1\cdots q_k$ is itself a product of primes, so $m\notin S$ — contradiction.

Therefore $S=\varnothing$: every integer $n\ge2$ is a product of primes. $\blacksquare$

**Rubric (total 1.0):**
- Defines the counterexample set and invokes well-ordering for a least element $m$ — 0.35
- Prime case handled — 0.15
- Composite case: writes $m=de$, applies minimality to $d,e$ — 0.35
- Combines the two factorisations, reaches contradiction, concludes $S=\varnothing$ — 0.15

*Common slip:* forgetting to justify $d,e<m$ (needed to apply minimality) — deduct 0.15.

## Problem 4 — bounded-below sets have a least element

**Solution.** Let $T\subseteq\mathbb{Z}$ be nonempty with lower bound $L$ ($L\le t$ for all $t\in T$). Put $T'=\{t-L:t\in T\}$. For each $t\in T$, $t\ge L$ gives $t-L\ge0$, so $T'\subseteq\mathbb{Z}^{\ge0}$, and $T'\ne\varnothing$ since $T\ne\varnothing$.

By the well-ordering principle $T'$ has a least element $m_0$; write $m_0=t_0-L$ with $t_0\in T$. For any $t\in T$: $t-L\in T'$, so $t-L\ge m_0=t_0-L$, hence $t\ge t_0$. Thus $t_0$ is a least element of $T$. $\blacksquare$

**Rubric (total 1.0):**
- Constructs the shifted set $T'=\{t-L:t\in T\}$ — 0.3
- Shows $T'$ is a nonempty set of nonnegative integers — 0.25
- Applies well-ordering to $T'$ — 0.2
- Shifts back to conclude $t_0$ is least in $T$ — 0.25

## Problem 5 — mutual divisibility

**Solution.** Assume $a\mid b$ and $b\mid a$ with $a,b\ne0$. Since $a\mid b$ and $b\ne0$, Lemma 1.2 gives $|a|\le|b|$. Since $b\mid a$ and $a\ne0$, Lemma 1.2 gives $|b|\le|a|$. Hence $|a|=|b|$, i.e. $a=\pm b$. $\blacksquare$

*(Alternative:* $b=ac$, $a=bd$ ⟹ $a=acd$ ⟹ $cd=1$ with $c,d\in\mathbb{Z}$ ⟹ $c,d\in\{\pm1\}$ ⟹ $b=\pm a$.)

**Rubric (total 1.0):**
- Applies Lemma 1.2 to $a\mid b$ to get $|a|\le|b|$ — 0.35
- Applies Lemma 1.2 to $b\mid a$ to get $|b|\le|a|$ — 0.35
- Concludes $|a|=|b|\Rightarrow a=\pm b$ — 0.3
- (Full marks also for a correct $cd=1$ argument.)

## Problem 6 — $3\mid(n^3-n)$

**Solution.** Factor $n^3-n=(n-1)n(n+1)$. By Theorem 1.3, dividing $n$ by $3$ gives $n=3k+r$ with $r\in\{0,1,2\}$ — the three cases are exhaustive.

- $r=0$: $n=3k$, so $3\mid n$.
- $r=1$: $n-1=3k$, so $3\mid(n-1)$.
- $r=2$: $n+1=3k+3=3(k+1)$, so $3\mid(n+1)$.

In each case one of the three consecutive factors $n-1,n,n+1$ is divisible by $3$, so $3\mid(n-1)n(n+1)=n^3-n$. $\blacksquare$

**Rubric (total 1.0):**
- Uses Theorem 1.3 to reduce to remainders $r\in\{0,1,2\}$ (exhaustive cases) — 0.3
- Correctly identifies the divisible-by-3 factor in each case — 0.45
- Concludes $3\mid n^3-n$ (via the factorisation or direct expansion) — 0.25

*Full marks also for expanding $n=3k+r$ into $n^3-n$ directly and checking each residue.*
