## Problem 1 — uniqueness of identity and inverses

**Solution.** *(Uniqueness of identity.)* Suppose $e_1,e_2$ both satisfy axiom (ii) for the group $G$. Taking $g=e_2$ in axiom (ii) for $e_1$: $e_1\cdot e_2=e_2$. Taking $g=e_1$ in axiom (ii) for $e_2$: $e_1\cdot e_2=e_1$. The left-hand sides of both equations are the same expression $e_1\cdot e_2$, so the right-hand sides must agree: $e_1=e_2$.

*(Uniqueness of inverse of $g$.)* Suppose $h_1,h_2$ both satisfy axiom (iii) for the same $g$. Consider $h_1\cdot g\cdot h_2$ bracketed two ways:
$$(h_1\cdot g)\cdot h_2 = e\cdot h_2 = h_2, \qquad h_1\cdot(g\cdot h_2) = h_1\cdot e = h_1.$$
By associativity (axiom (i)), these two bracketings compute the same element, so $h_1=h_2$. $\blacksquare$

**Rubric (total 1.0):**
- Correct identity-uniqueness proof, both substitutions shown — 0.35
- Correct "sandwich" setup $h_1\cdot g\cdot h_2$ for inverse uniqueness — 0.25
- Correct simplification of both bracketings using axioms (ii)/(iii) — 0.25
- Explicit invocation of associativity to equate the two bracketings, concluding $h_1=h_2$ — 0.15

## Problem 2 — $\varphi(e_G)=e_H$ and $\varphi(g^{-1})=\varphi(g)^{-1}$

**Solution.** *($\varphi(e_G)=e_H$.)* Since $e_G\cdot e_G=e_G$ (identity axiom), applying $\varphi$ and using the homomorphism property:
$$\varphi(e_G) = \varphi(e_G\cdot e_G) = \varphi(e_G)\cdot\varphi(e_G).$$
Let $x=\varphi(e_G)\in H$; then $x=x\cdot x$. Multiplying both sides on the left by $x^{-1}$ (which exists in the group $H$): $x^{-1}x = x^{-1}(x\cdot x)$, i.e. $e_H = (x^{-1}x)\cdot x = e_H\cdot x = x$. So $x=e_H$, i.e. $\varphi(e_G)=e_H$.

*($\varphi(g^{-1})=\varphi(g)^{-1}$.)* $\varphi(g)\cdot\varphi(g^{-1}) = \varphi(g\cdot g^{-1}) = \varphi(e_G) = e_H$ (using the result just proved). So $\varphi(g^{-1})$ satisfies the defining property of an inverse of $\varphi(g)$ in $H$: $\varphi(g)\cdot\varphi(g^{-1})=e_H$. By uniqueness of inverses (Problem 1), $\varphi(g^{-1})=\varphi(g)^{-1}$. $\blacksquare$

**Rubric (total 1.0):**
- Correct derivation $\varphi(e_G)=\varphi(e_G)\cdot\varphi(e_G)$ from the homomorphism property — 0.25
- Correct cancellation argument in $H$ to conclude $\varphi(e_G)=e_H$ — 0.25
- Correct computation $\varphi(g)\cdot\varphi(g^{-1})=e_H$ — 0.25
- Correct invocation of inverse uniqueness to conclude $\varphi(g^{-1})=\varphi(g)^{-1}$ — 0.25

## Problem 3 — $g\cdot g=g \Rightarrow g=e$

**Solution.** Assume $g\cdot g=g$. Multiply both sides on the right by $g^{-1}$ (exists by axiom (iii)):
$$(g\cdot g)\cdot g^{-1} = g\cdot g^{-1}.$$
By associativity (axiom (i)), the left side equals $g\cdot(g\cdot g^{-1}) = g\cdot e_G = g$ (using axiom (iii) then axiom (ii)). The right side equals $e_G$ (axiom (iii)). So $g=e_G$. $\blacksquare$

This confirms that gt-01's informally discovered "do-nothing" action is exactly the unique element satisfying $g\cdot g=g$, now derived purely from the group axioms rather than by inspecting a rectangle's configurations.

**Rubric (total 1.0):**
- Correctly multiplies both sides by $g^{-1}$ — 0.3
- Correctly applies associativity to regroup the left side — 0.3
- Correctly simplifies both sides using axioms (ii) and (iii) to reach $g=e_G$ — 0.3
- Connects the result explicitly to gt-01's informal identity discovery — 0.1

## Problem 4 — groups of order 4 are abelian

**Solution.** Let $G$ be a group with $|G|=4$, elements $\{e,g,h,k\}$.

**Case 1: some non-identity element has order 4.** Then that element, say $g$, generates all of $G$: $G=\{e,g,g^2,g^3\}$, cyclic. Powers of a single element always commute: $g^i\cdot g^j=g^{i+j}=g^j\cdot g^i$ for all $i,j$. So $G$ is abelian.

**Case 2: every non-identity element has order 2** (i.e. $x^2=e$ for all $x\in G$, so every element is its own inverse). Take any two distinct non-identity elements $g,h\in G$. Since $(gh)^2=e$ (as $gh\in G$ also satisfies the hypothesis), $(gh)(gh)=e$. Multiply on the left by $g$ and on the right by $h$ (using $g^{-1}=g$, $h^{-1}=h$):
$$g\big[(gh)(gh)\big]h = g\cdot e\cdot h = gh.$$
Expand the left side using associativity: $g(gh)(gh)h = (g\cdot g)h(gh)h = e\cdot h\cdot(gh)\cdot h = h(gh)h$. Continue: $h(gh)h = (hg)(hh) = (hg)\cdot e = hg$ (using $h\cdot h=e$). So the left side simplifies to $hg$, and we showed it equals $gh$. Hence $hg=gh$.

Both cases give a commutative (abelian) group. Since every group of order 4 falls into one of these two cases (either it has an element of order 4, or every non-identity element has order 2 — orders must divide the group order, and the only divisors of 4 are 1, 2, 4), every group of order 4 is abelian. $\blacksquare$

**Any logically valid alternative case analysis earns full marks.**

**Rubric (total 1.0):**
- Correct Case 1 (cyclic order 4 $\Rightarrow$ abelian, via commuting powers) — 0.25
- Correct Case 2 setup: $(gh)^2=e$ and multiplying by $g,h$ appropriately — 0.3
- Correct algebraic simplification chain reaching $hg=gh$ — 0.3
- Explicitly notes the two cases exhaust all groups of order 4 — 0.15

## Problem 5 — every element self-inverse $\Rightarrow$ abelian

**Solution.** Let $G$ be a finite group with $g^2=e$ for all $g\in G$ (equivalently, $g^{-1}=g$ for all $g$). Take arbitrary $g,h\in G$.

Since every element of $G$ (including $gh$) squares to $e$, $(gh)^{-1}=gh$.

Also, in any group, $(gh)^{-1}=h^{-1}g^{-1}$: check $(gh)(h^{-1}g^{-1}) = g(hh^{-1})g^{-1} = g\cdot e\cdot g^{-1} = gg^{-1}=e$, confirming $h^{-1}g^{-1}$ satisfies the defining property of the inverse of $gh$; by uniqueness of inverses, $(gh)^{-1}=h^{-1}g^{-1}$.

Since every element is its own inverse, $g^{-1}=g$ and $h^{-1}=h$, so $h^{-1}g^{-1}=hg$.

Combining: $gh = (gh)^{-1} = h^{-1}g^{-1} = hg$.

So $gh=hg$ for all $g,h\in G$: $G$ is abelian. $\blacksquare$

**Any logically valid alternative proof earns full marks.**

**Rubric (total 1.0):**
- Correctly notes $(gh)^{-1}=gh$ using the hypothesis applied to $gh$ — 0.25
- Correctly proves (or cites with justification) the general group fact $(gh)^{-1}=h^{-1}g^{-1}$ — 0.35
- Correctly substitutes $g^{-1}=g,h^{-1}=h$ from the hypothesis — 0.2
- Explicit final chain $gh=(gh)^{-1}=h^{-1}g^{-1}=hg$, concluding abelian — 0.2

## Problem 6 — orders of elements in $\mathbb{Z}/6\mathbb{Z}$

**Solution.** Computing the cyclic subgroup generated by each element under addition mod 6:

- $\langle[0]\rangle=\{[0]\}$: $|[0]|=1$.
- $\langle[1]\rangle=\{[1],[2],[3],[4],[5],[0]\}$: all six elements before returning to $[0]$; $|[1]|=6$.
- $\langle[2]\rangle=\{[2],[4],[0]\}$: returns after 3 steps; $|[2]|=3$.
- $\langle[3]\rangle=\{[3],[0]\}$: returns after 2 steps; $|[3]|=2$.
- $\langle[4]\rangle=\{[4],[2],[0]\}$: same subgroup as $\langle[2]\rangle$, generated in the reverse direction; $|[4]|=3$.
- $\langle[5]\rangle=\{[5],[4],[3],[2],[1],[0]\}$: all six elements, like $[1]$; $|[5]|=6$.

Summary table: $|[0]|=1,\ |[1]|=6,\ |[2]|=3,\ |[3]|=2,\ |[4]|=3,\ |[5]|=6$.

Every value in $\{1,6,3,2,3,6\}$ divides $6=|\mathbb{Z}/6\mathbb{Z}|$ — consistent with (though not a proof of) Lagrange's theorem, formally established in gt-06: the order of any element of a finite group divides the order of the group. $\blacksquare$

**Rubric (total 1.0):**
- Correct order computation for $[0],[1]$ — 0.2
- Correct order computation for $[2],[4]$ (order 3 each) — 0.3
- Correct order computation for $[3],[5]$ (orders 2 and 6) — 0.3
- Explicitly checks every computed order divides 6 and connects to Lagrange's theorem (previewed, not proved) — 0.2
