## Problem 1 — solve $(4,-3,1,7)+2x=(5,9,-6,8)$

**Solution.** Isolating $x$:
$$2x = (5,9,-6,8)-(4,-3,1,7) = (1,12,-7,1),$$
so
$$x = \left(\tfrac12,\, 6,\, -\tfrac72,\, \tfrac12\right).$$
Check: $(4,-3,1,7)+2(\tfrac12,6,-\tfrac72,\tfrac12) = (4,-3,1,7)+(1,12,-7,1) = (5,9,-6,8)$. ✓ $\blacksquare$

**Rubric (total 1.0):**
- Correctly isolates $2x$ by componentwise subtraction — 0.4
- Correctly divides to find $x$ — 0.4
- Verifies the answer by substitution (or states it clearly as the unique solution) — 0.2

## Problem 2 — $-(-v)=v$

**Solution.** By definition, $-v$ is the additive inverse of $v$, so $v+(-v)=0$. This same equation exhibits $v$ as an additive inverse of $-v$ (since it says "$v$ added to $-v$ gives 0"). Additive inverses are unique in a vector space (an argument identical in style to Theorem 1.25's uniqueness of the additive identity: if $w_1,w_2$ are both additive inverses of $u$, then $w_1 = w_1+0 = w_1+(u+w_2) = (w_1+u)+w_2 = 0+w_2=w_2$). Since $v$ is *an* additive inverse of $-v$, and additive inverses are unique, $v$ must equal *the* additive inverse of $-v$, which is denoted $-(-v)$. Hence $-(-v)=v$. $\blacksquare$

**Rubric (total 1.0):**
- Correctly identifies $v+(-v)=0$ as exhibiting $v$ as an additive inverse of $-v$ — 0.35
- States or proves uniqueness of additive inverses (cites or re-derives) — 0.35
- Explicit final inference: $v=-(-v)$ by uniqueness — 0.3

## Problem 3 — $av=0 \Rightarrow a=0$ or $v=0$

**Solution.** *(Case $a=0$.)* Then the conclusion "$a=0$ or $v=0$" holds immediately.

*(Case $a\ne0$.)* Then $a$ has a multiplicative inverse $a^{-1}\in\mathbb{F}$. Multiply both sides of $av=0$ by $a^{-1}$:
$$a^{-1}(av) = a^{-1}0.$$
By associativity of scalar multiplication, $a^{-1}(av)=(a^{-1}a)v=1v=v$. And $a^{-1}0=0$ (scalar multiplication of any scalar times the zero vector gives the zero vector — provable the same way as Theorem 1.29's $0v=0$: $a^{-1}0 = a^{-1}(0+0)=a^{-1}0+a^{-1}0$, and adding $-(a^{-1}0)$ to both sides gives $0=a^{-1}0$). So $v=0$.

In either case, $a=0$ or $v=0$. $\blacksquare$

**Rubric (total 1.0):**
- Correctly disposes of the $a=0$ case — 0.15
- Correctly multiplies by $a^{-1}$ in the $a\ne0$ case — 0.3
- Correct associativity computation $a^{-1}(av)=v$ — 0.3
- Correctly justifies $a^{-1}0=0$ (not just asserted) — 0.25

## Problem 4 — the empty set is not a vector space

**Solution.** The empty set fails the **additive identity** requirement of Definition 1.19: "there exists $0\in V$ such that $v+0=v$ for all $v\in V$."

*Proof that this fails for $V=\varnothing$.* Suppose, for contradiction, that $\varnothing$ satisfies this clause. Then there must exist some element $0\in\varnothing$. But by definition, the empty set contains no elements whatsoever — no object satisfies "$x\in\varnothing$". This is a direct contradiction. Hence the additive-identity clause cannot hold for $V=\varnothing$; the empty set fails Definition 1.19 and so is not a vector space.

(All the other clauses of Definition 1.19 are universally quantified over $v\in V$ — "for all $v\in V$, …" — and are vacuously true when $V=\varnothing$, since there are no elements to violate them. The additive-identity clause is the only *existential* clause, which cannot be vacuously satisfied.) $\blacksquare$

**Rubric (total 1.0):**
- Correctly identifies the additive identity clause as the one that fails — 0.4
- Gives a clear argument (contradiction or direct) that $\varnothing$ has no element to serve as $0$ — 0.4
- Notes (even briefly) why the other clauses are vacuously satisfied, explaining why only this one clause is the failure point — 0.2

## Problem 5 — find $W$ with $\mathbb{F}^4=U\oplus W$ for $U=\{(x,x,y,y)\}$

**Solution.** Let $W=\{(a,0,c,0) : a,c\in\mathbb{F}\}$.

*$W$ is a subspace:* $(0,0,0,0)\in W$; closed under addition and scalar multiplication since the defining conditions ("2nd and 4th coordinates are 0") are preserved by both operations coordinatewise. (Full three-part Theorem 1.34 check omitted here for brevity but expected in a complete solution.)

*Directness ($U\cap W=\{0\}$, Theorem 1.45):* Suppose $(x,x,y,y)=(a,0,c,0)\in U\cap W$. Comparing coordinates: $x=a$, $x=0$, $y=c$, $y=0$. From $x=0$ and $y=0$, the vector is $(0,0,0,0)$. So $U\cap W=\{0\}$, giving directness.

*Sum equals $\mathbb{F}^4$:* Given any $(p,q,r,s)\in\mathbb{F}^4$, write
$$(p,q,r,s) = (q,q,s,s) + (p-q,\,0,\,r-s,\,0),$$
with the first summand in $U$ (taking $x=q,y=s$) and the second in $W$ (taking $a=p-q,c=r-s$). So $U+W=\mathbb{F}^4$.

Combining, $\mathbb{F}^4=U\oplus W$. $\blacksquare$

**Any logically valid alternative choice of $W$, fully justified, earns full marks.**

**Rubric (total 1.0):**
- Proposes a valid subspace $W$ (need not be this exact one) — 0.15
- Verifies $W$ is a subspace (at least briefly, via Theorem 1.34) — 0.15
- Correctly verifies $U\cap W=\{0\}$ — 0.35
- Correctly verifies $U+W=\mathbb{F}^4$ with an explicit decomposition formula — 0.35

## Problem 6 — is $\mathbb{R}\cup\{\infty\}\cup\{-\infty\}$ a vector space?

**Solution.** No. Associativity of addition fails. Consider the triple $\infty,\infty,-\infty$:
$$(\infty+\infty)+(-\infty) = \infty+(-\infty) = 0,$$
using $\infty+\infty=\infty$ (given rule) and then $\infty+(-\infty)=0$ (given rule). But
$$\infty+(\infty+(-\infty)) = \infty+0 = \infty,$$
using $\infty+(-\infty)=0$ first, then $t+\infty=\infty$ for $t=0$. Since $(\infty+\infty)+(-\infty)=0$ but $\infty+(\infty+(-\infty))=\infty$, and $0\ne\infty$ (they are given as distinct objects), associativity of addition fails for this triple. Since Definition 1.19 requires associativity to hold for *all* $u,v,w$, this single failing triple is enough to show the structure is not a vector space. $\blacksquare$

**Any correct identification of a failing axiom, fully justified with an explicit counterexample, earns full marks** (an alternative valid answer: exploring additive inverses or distributivity with $\infty$ may also expose a failure, depending on how far the "obvious" rules are pushed — full credit requires a genuine, checked counterexample either way).

**Rubric (total 1.0):**
- Identifies a specific axiom to test (associativity, or another correctly-argued failure) — 0.2
- Computes one bracketing of the chosen triple correctly — 0.3
- Computes the other bracketing correctly — 0.3
- States the explicit contradiction (the two bracketings disagree) and concludes "not a vector space" — 0.2
