## Problem 1 — $\sqrt3$ irrational, and why the argument fails for $\sqrt4$

**Solution.** Assume, for contradiction, that $\sqrt3=p/q$ for integers $p,q$ in lowest terms. Squaring: $3q^2=p^2$, so $3\mid p^2$. Since 3 is prime, $3\mid p^2\Rightarrow3\mid p$ (if $p$ were not divisible by 3, none of its prime factors would be 3, so none of $p^2$'s prime factors would be 3 either). Write $p=3k$. Substituting: $3q^2=9k^2$, so $q^2=3k^2$, giving $3\mid q^2$ and hence $3\mid q$. But then both $p,q$ are divisible by 3, contradicting lowest terms. So $\sqrt3$ is irrational. $\blacksquare$

**Why the argument fails for $\sqrt4$:** the key lemma used is "$p\mid k^2 \Rightarrow p\mid k$", which holds specifically because $p$ (here, 2 or 3) is **prime**. The analogous claim for $\sqrt4$ would need "$4\mid p^2\Rightarrow4\mid p$", which is **false**: $p=2$ gives $4\mid 2^2=4$ but $4\nmid2$. Since 4 is composite, the divisibility lemma the whole proof leans on simply does not hold, so the argument cannot even get started — consistent with the fact that $\sqrt4=2$ actually is rational.

**Rubric (total 1.0):**
- Correct contradiction setup with $p/q$ in lowest terms — 0.15
- Correct algebra to $3\mid p^2\Rightarrow3\mid p$, with justification (not just asserted) — 0.25
- Correct substitution and deduction $3\mid q$, and explicit contradiction stated — 0.25
- Correctly identifies that the key lemma requires primality and explains precisely why it fails for 4 — 0.35

## Problem 2 — sup/inf of three sets

**Solution.**

**(a)** $A=\{n/(n+1):n\in\mathbb{N}\}=\{1/2,2/3,3/4,\ldots\}$: the terms increase strictly toward 1 but never equal 1 (since $n/(n+1)<1$ for all finite $n$). $\sup A=1$ (not attained). The smallest term is at $n=1$: $\inf A=1/2$, attained, so it is also the minimum.

**(b)** $\{(-1)^n/n:n\in\mathbb{N}\}$: even $n$ gives positive terms $1/2,1/4,1/6,\ldots\to0^+$; odd $n$ gives negative terms $-1,-1/3,-1/5,\ldots\to0^-$. The largest term is $1/2$ ($n=2$): $\sup=1/2$, attained. The smallest is $-1$ ($n=1$): $\inf=-1$, attained.

**(c)** $\{1/n-1/m : n,m\in\mathbb{N}\}$: fixing $n=1$ and letting $m\to\infty$ gives values approaching $1$ (never reached, since $1/m>0$ always); fixing $m=1$ and letting $n\to\infty$ gives values approaching $-1$ (never reached). $\sup=1$ (not attained), $\inf=-1$ (not attained). $\blacksquare$

**Rubric (total 1.0):** (roughly 0.33 each part, adjusted for depth)
- (a): correct sup and inf values, with correct identification of which is attained — 0.3
- (b): correct sup and inf values, both correctly identified as attained — 0.3
- (c): correct sup and inf values, both correctly identified as not attained — 0.4

## Problem 3 — $a\in A$ and $a$ upper bound $\Rightarrow a=\sup A$

**Solution.** We must verify both conditions of Definition 1.3.2 for $s=a$.

(i) $a$ is an upper bound for $A$ — given.

(ii) $a$ is the *least* upper bound: let $b$ be any upper bound for $A$. Since $a\in A$ and $b$ is an upper bound for $A$, the definition of upper bound gives $a\le b$ directly. This is exactly condition (ii): every upper bound $b$ satisfies $a\le b$.

Both conditions hold for $s=a$, so $a=\sup A$. $\blacksquare$

**Rubric (total 1.0):**
- Correctly notes condition (i) is given/immediate — 0.2
- Correctly sets up condition (ii): takes an arbitrary upper bound $b$ — 0.3
- Correctly derives $a\le b$ directly from $a\in A$ and $b$ being an upper bound — 0.3
- Explicit conclusion $a=\sup A$ citing both conditions of Definition 1.3.2 — 0.2

## Problem 4 — $\sup B=\inf A$ where $B$ is the set of lower bounds of $A$

**Solution.** Since $A$ is bounded below, $B\ne\varnothing$. $B$ is bounded above: any element $a_0\in A$ is an upper bound for $B$ (every lower bound of $A$ is $\le a_0$, by definition of lower bound). So by the Axiom of Completeness, $s:=\sup B$ exists.

*($s$ is a lower bound for $A$.)* Suppose not: some $a_0\in A$ has $a_0<s$. Then $a_0$ would be an upper bound for $B$ smaller than $s$ (since every $b\in B$ satisfies $b\le a_0$ — because $b$ is a lower bound for $A$ and $a_0\in A$ — so $a_0$ bounds $B$ above), contradicting $s=\sup B$ being the *least* upper bound of $B$. So no such $a_0$ exists: every $a\in A$ satisfies $a\ge s$, i.e. $s$ is a lower bound for $A$, meaning $s\in B$.

*($s$ is the greatest lower bound.)* Since $s\in B$ and $s=\sup B$ is an upper bound for $B$, every element of $B$ (i.e. every lower bound of $A$) satisfies $b\le s$. This is exactly condition (ii) for $s=\inf A$.

Both conditions of the infimum definition hold for $s$, so $\sup B=s=\inf A$. $\blacksquare$

**Rubric (total 1.0):**
- Verifies $B$ is nonempty and bounded above, invoking completeness to get $\sup B$ — 0.2
- Correct proof that $s=\sup B$ is a lower bound for $A$ (by contradiction, using minimality of $\sup B$) — 0.4
- Correct proof that $s$ is the *greatest* lower bound (using $s\in B$ and $s$ as upper bound of $B$) — 0.3
- Explicit conclusion $\sup B=\inf A$ — 0.1

## Problem 5 — completing $\alpha^2>2$ leads to contradiction

**Solution.** Let $T=\{t\in\mathbb{R}:t^2<2\}$, $\alpha=\sup T$. Note $\alpha\ge1$ since $1\in T$ (as $1^2=1<2$), so $\alpha>0$.

Suppose $\alpha^2>2$. Let $\epsilon=\dfrac{\alpha^2-2}{2\alpha}$; since $\alpha^2>2$ and $\alpha>0$, $\epsilon>0$. Also $\epsilon<\alpha$ (since $\alpha^2-2<\alpha^2<2\alpha^2$, so $\epsilon=(\alpha^2-2)/(2\alpha)<\alpha$), so $\alpha-\epsilon>0$.

Compute:
$$(\alpha-\epsilon)^2 = \alpha^2-2\alpha\epsilon+\epsilon^2 > \alpha^2-2\alpha\epsilon = \alpha^2-(\alpha^2-2)=2,$$
where the strict inequality drops the positive term $\epsilon^2$, and the middle equality substitutes $2\alpha\epsilon=\alpha^2-2$ by the definition of $\epsilon$.

So $(\alpha-\epsilon)^2>2$. For any $t\in T$, $t^2<2<(\alpha-\epsilon)^2$; since $t$ and $\alpha-\epsilon$ are both positive (for $t>0$; if $t\le0$ the inequality $t<\alpha-\epsilon$ is immediate since $\alpha-\epsilon>0$), this forces $t<\alpha-\epsilon$. So $\alpha-\epsilon$ is an upper bound for $T$.

But $\alpha-\epsilon<\alpha$, contradicting $\alpha=\sup T$ being the *least* upper bound. Therefore $\alpha^2>2$ is impossible. $\blacksquare$

**Any logically valid alternative completion (e.g. a different choice of $\epsilon$) earns full marks provided the contradiction is airtight.**

**Rubric (total 1.0):**
- Correctly establishes $\alpha>0$ (or otherwise handles sign carefully) — 0.1
- Correctly constructs a valid $\epsilon>0$ with $\epsilon<\alpha$ — 0.25
- Correct computation showing $(\alpha-\epsilon)^2>2$ — 0.35
- Correctly concludes $\alpha-\epsilon$ is a smaller upper bound for $T$, contradicting $\sup T=\alpha$ — 0.3

## Problem 6 — $\inf\{1/n:n\in\mathbb{N}\}=0$ via the Archimedean Property

**Solution.** $0$ is a lower bound for $\{1/n:n\in\mathbb{N}\}$, since $1/n>0$ for all $n\in\mathbb{N}$.

Suppose, for contradiction, some $\epsilon>0$ is also a lower bound, i.e. $1/n\ge\epsilon$ for all $n\in\mathbb{N}$. By the Archimedean Property of $\mathbb{R}$, there exists $n\in\mathbb{N}$ with $n>1/\epsilon$. Then $1/n<\epsilon$, contradicting $1/n\ge\epsilon$ for this particular $n$.

So no $\epsilon>0$ is a lower bound; combined with $0$ being a lower bound, $0$ is the *greatest* lower bound: $\inf\{1/n:n\in\mathbb{N}\}=0$. $\blacksquare$

**Rubric (total 1.0):**
- Verifies $0$ is a lower bound — 0.15
- Correct contradiction setup: assumes some $\epsilon>0$ is also a lower bound — 0.2
- Correctly invokes the Archimedean Property to produce $n>1/\epsilon$ — 0.35
- Correctly derives $1/n<\epsilon$ contradicting the lower-bound assumption, and concludes $\inf=0$ — 0.3
