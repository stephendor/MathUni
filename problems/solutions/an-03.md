## Problem 1 — ε-N proof of limit

**Solution.**
We wish to prove $\lim_{n\to\infty} \frac{3n+1}{2n+5} = \frac{3}{2}$ using Definition 2.2.3.

First, simplify the distance $|a_n - L|$:
$$\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \left|\frac{2(3n+1) - 3(2n+5)}{2(2n+5)}\right| = \left|\frac{6n+2 - 6n - 15}{4n+10}\right| = \left|\frac{-13}{4n+10}\right| = \frac{13}{4n+10}.$$

Observe that for all $n \ge 1$, $4n+10 > 4n$, so $\frac{13}{4n+10} < \frac{13}{4n}$.

Let $\epsilon > 0$ be arbitrary. Choose $N \in \mathbb{N}$ such that $N > \frac{13}{4\epsilon}$.

Now let $n \ge N$. Then $n > \frac{13}{4\epsilon}$, which implies $\frac{13}{4n} < \epsilon$.
Therefore,
$$\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \frac{13}{4n+10} < \frac{13}{4n} < \epsilon.$$
By Definition 2.2.3, $\lim_{n\to\infty} \frac{3n+1}{2n+5} = \frac{3}{2}$. $\blacksquare$

**Rubric (total 1.0):**
- Correct algebraic reduction of $|a_n - L|$ to $\frac{13}{4n+10}$ — 0.3
- Explicit choice of $N$ in terms of $\epsilon$ (e.g. $N > 13/(4\epsilon)$) — 0.3
- Verification step: showing $n \ge N \implies |a_n - L| < \epsilon$ — 0.4

## Problem 2 — Uniqueness of limits

**Solution.**
Suppose $(a_n) \to L_1$ and $(a_n) \to L_2$. We wish to show $L_1 = L_2$.

Let $\epsilon > 0$ be arbitrary.
Since $(a_n) \to L_1$, by Definition 2.2.3 there exists $N_1 \in \mathbb{N}$ such that for all $n \ge N_1$, $|a_n - L_1| < \frac{\epsilon}{2}$.
Since $(a_n) \to L_2$, there exists $N_2 \in \mathbb{N}$ such that for all $n \ge N_2$, $|a_n - L_2| < \frac{\epsilon}{2}$.

Choose $N = \max\{N_1, N_2\}$. For any $n \ge N$, both inequalities hold. Using the triangle inequality:
$$|L_1 - L_2| = |(L_1 - a_n) + (a_n - L_2)| \le |a_n - L_1| + |a_n - L_2| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon.$$

Since $|L_1 - L_2| < \epsilon$ for every $\epsilon > 0$, it must be that $|L_1 - L_2| = 0$, which implies $L_1 = L_2$. $\blacksquare$

**Rubric (total 1.0):**
- Correct use of Definition 2.2.3 for both $L_1$ and $L_2$ with $\epsilon/2$ — 0.3
- Correct application of triangle inequality $|L_1 - L_2| \le |a_n - L_1| + |a_n - L_2|$ — 0.4
- Final deduction that $|L_1 - L_2| < \epsilon$ for all $\epsilon > 0$ implies $L_1 = L_2$ — 0.3

## Problem 3 — Convergent sequences are bounded (Theorem 2.3.2)

**Solution.**
Let $(a_n)$ be a convergent sequence with $\lim a_n = L$. We show that $(a_n)$ is bounded (Definition 2.3.1).

Applying Definition 2.2.3 with $\epsilon = 1$, there exists $N \in \mathbb{N}$ such that for all $n \ge N$, $|a_n - L| < 1$.
By the triangle inequality:
$$|a_n| = |(a_n - L) + L| \le |a_n - L| + |L| < |L| + 1 \quad \text{for all } n \ge N.$$

Now define $M = \max\{|a_1|, |a_2|, \dots, |a_{N-1}|, |L| + 1\}$.
For any $n \in \mathbb{N}$:
- If $n < N$, then $|a_n| \le \max\{|a_1|, \dots, |a_{N-1}|\} \le M$.
- If $n \ge N$, then $|a_n| < |L| + 1 \le M$.

Thus $|a_n| \le M$ for all $n \in \mathbb{N}$. Hence $(a_n)$ is bounded. $\blacksquare$

**Rubric (total 1.0):**
- Choosing a specific $\epsilon$ (e.g. $\epsilon = 1$) to get bound on tail terms — 0.3
- Correct bounding of tail terms $|a_n| < |L| + 1$ — 0.3
- Construction of $M = \max\{|a_1|, \dots, |a_{N-1}|, |L|+1\}$ covering all $n \in \mathbb{N}$ — 0.4

## Problem 4 — Order Limit Theorem (Theorem 2.3.4(i))

**Solution.**
Let $(a_n) \to a$ with $a_n \ge 0$ for all $n \in \mathbb{N}$. We prove $a \ge 0$ by contradiction.

Assume, for contradiction, that $a < 0$. Then $|a| = -a > 0$.
Set $\epsilon_0 = -a > 0$.
Since $(a_n) \to a$, by Definition 2.2.3 there exists $N \in \mathbb{N}$ such that for all $n \ge N$,
$$|a_n - a| < \epsilon_0 = -a.$$

Expanding this inequality gives:
$$-(-a) < a_n - a < -a \implies a < a_n - a < -a \implies 2a < a_n < 0.$$

In particular, for $n = N$, we have $a_N < 0$. But this contradicts the hypothesis that $a_n \ge 0$ for all $n \in \mathbb{N}$.
Therefore, our assumption $a < 0$ is false, and we conclude $a \ge 0$. $\blacksquare$

**Rubric (total 1.0):**
- Contradiction setup assuming $a < 0$ — 0.2
- Strategic choice of $\epsilon_0 = -a$ (or $|a|$) — 0.4
- Correct inequality manipulation yielding $a_N < 0$ and stating explicit contradiction — 0.4

## Problem 5 — Product Rule for Limits (Theorem 2.3.3(iii))

**Solution.**
Assume $(a_n) \to a$ and $(b_n) \to b$. We show $(a_n b_n) \to ab$.

First, observe the identity:
$$|a_n b_n - ab| = |a_n b_n - ab_n + ab_n - ab| \le |b_n||a_n - a| + |a||b_n - b|.$$

By Theorem 2.3.2, since $(b_n)$ converges, $(b_n)$ is bounded. Thus, there exists $M > 0$ such that $|b_n| \le M$ for all $n \in \mathbb{N}$.

Let $\epsilon > 0$ be arbitrary.
1. Since $(a_n) \to a$, choose $N_1 \in \mathbb{N}$ such that for all $n \ge N_1$, $|a_n - a| < \frac{\epsilon}{2M}$.
2. Since $(b_n) \to b$, choose $N_2 \in \mathbb{N}$ such that for all $n \ge N_2$, $|b_n - b| < \frac{\epsilon}{2(|a| + 1)}$.

Set $N = \max\{N_1, N_2\}$. For any $n \ge N$, we have:
$$|a_n b_n - ab| \le M |a_n - a| + |a| |b_n - b| < M \left(\frac{\epsilon}{2M}\right) + |a| \left(\frac{\epsilon}{2(|a| + 1)}\right) = \frac{\epsilon}{2} + \frac{|a|}{|a| + 1} \frac{\epsilon}{2} < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon.$$

Therefore, $\lim_{n\to\infty} (a_n b_n) = ab$. $\blacksquare$

**Rubric (total 1.0):**
- Correct split identity $|a_n b_n - ab| \le |b_n||a_n - a| + |a||b_n - b|$ — 0.3
- Using Theorem 2.3.2 to bound $|b_n| \le M$ — 0.3
- Correct choice of $N_1, N_2$ and $N = \max\{N_1, N_2\}$ yielding $< \epsilon$ — 0.4
