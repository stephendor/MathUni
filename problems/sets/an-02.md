## Problem 1 (easy — bijection construction) [interleaves an-01]

Recall $\mathbb{Z}$ is countable via the zig-zag map $f(n) = (n-1)/2$ if $n$ is odd, $-n/2$ if $n$ is even. Verify $f$ is 1–1 by checking small inputs land on distinct integers, and explain in one sentence why the zig-zag pattern guarantees $f$ is onto.

*(Abbott §1.4, Example 1.4.8(ii), p. 23, cited directly in the an-02 lesson's "you try"; interleaves an-01's sup/inf-style rigour about existence and uniqueness of witnessing values)*

<details><summary>Nudge</summary>
Compute $f(1), f(2), f(3), f(4), f(5)$ and see what integers come out.
</details>
<details><summary>Strategy</summary>
For 1–1: show that if $f(n_1)=f(n_2)$, then $n_1=n_2$ — split into cases based on the parity of $n_1, n_2$ (they must match, else one output is $\ge0$ and the other $<0$, or similar). For onto: given any integer $k$, exhibit an $n$ with $f(n)=k$.
</details>
<details><summary>Partial</summary>
$f(1)=0, f(2)=-1, f(3)=1, f(4)=-2, f(5)=2$ — alternating between nonnegative and negative outputs, each new pair of inputs reaching one integer further from 0 in each direction.
</details>
<details><summary>Worked start</summary>
1–1: if $n_1,n_2$ are both odd with $f(n_1)=f(n_2)$, then $(n_1-1)/2=(n_2-1)/2 \Rightarrow n_1=n_2$; similarly for both even; and an odd input always gives a nonnegative output while an even input always gives a negative output, so mixed cases can never collide. Onto: given $k\ge0$, take $n=2k+1$ (odd), so $f(n)=k$; given $k<0$, take $n=-2k$ (even), so $f(n)=k$. Every integer is hit exactly once, confirming the zig-zag never skips or repeats — the same "exhaustive layers" idea an-02's ℚ-countability proof uses, one integer at a time instead of one finite shell at a time.
</details>

## Problem 2 (easy–medium — countability, direct proof)

Show that the set of all finite subsets of $\mathbb{N}$ is a countable set.

*(Abbott §1.4, Exercise 1.4.10, p. 25)*

<details><summary>Nudge</summary>
Try the same "finite shells" trick the an-02 lesson used to show $\mathbb{Q}$ is countable — group finite subsets by some natural finite-valued statistic.
</details>
<details><summary>Strategy</summary>
For each $n\in\mathbb{N}$, let $S_n$ be the (finite) set of subsets of $\{1,\ldots,n\}$ — there are $2^n$ of them, a finite number. Every finite subset of $\mathbb{N}$ lies in some $S_n$ (take $n=$ the largest element).
</details>
<details><summary>Partial</summary>
Each $S_n$ is finite (exactly $2^n$ subsets of $\{1,\ldots,n\}$). Concatenating $S_1, S_2, S_3,\ldots$ (removing repeats already listed) into one list, as in the an-02 lesson's shell-listing proof for $\mathbb{Q}$, gives an $\mathbb{N}$-indexed enumeration.
</details>
<details><summary>Worked start</summary>
List all subsets appearing for the first time as $n$ increases from 1: subsets of $\{1\}$, then new subsets appearing in $\{1,2\}$ not already listed, and so on. Since every finite subset of $\mathbb{N}$ has a largest element $m$, it appears (at the latest) once $n=m$ is reached — so the process eventually lists every finite subset exactly once. Each "new subsets at stage $n$" batch is finite, so by the same finite-shells argument used for $\mathbb{Q}$'s countability, the whole set of finite subsets of $\mathbb{N}$ is countable.
</details>

## Problem 3 (medium — diagonal argument, adapting the template)

Let $S$ be the set of all infinite sequences of 0's and 1's. Show $S$ is uncountable.

*(Abbott §1.5, Exercise 1.5.4, p. 31 — the exact faded worked example in the an-02 lesson; here presented as a full stand-alone problem)*

<details><summary>Nudge</summary>
Adapt Cantor's diagonal argument exactly as in the lesson's decimal-expansion version, but there are only two digits to flip between now, not ten.
</details>
<details><summary>Strategy</summary>
Assume a list $g(1), g(2), g(3),\ldots$ of all sequences in $S$ exists. Build an adversary sequence $b$ that disagrees with $g(n)$ at position $n$, for every $n$.
</details>
<details><summary>Partial</summary>
Write $g(m) = (a_{m1}, a_{m2}, \ldots)$. Define $b_n = 1 - a_{nn}$ (flip the diagonal digit: 0 becomes 1, 1 becomes 0).
</details>
<details><summary>Worked start</summary>
By construction, $b$ disagrees with $g(n)$ in position $n$, for every $n\in\mathbb{N}$. So $b\ne g(n)$ for any $n$ — but $b\in S$ (it's a genuine 0/1 sequence), contradicting the assumption that $g$'s list was exhaustive. Therefore $S$ is uncountable. **Any logically valid alternative construction of the adversary sequence earns full marks.**
</details>

## Problem 4 (medium–hard — proof, applying Cantor's Theorem)

Using the particular set $A=\{a,b,c\}$: (a) exhibit two different 1–1 mappings from $A$ into $P(A)$; (b) explain, referencing Cantor's Theorem, why no such mapping from $A$ into $P(A)$ can ever be onto — even though $A$ is finite here, describe how the same underlying mechanism scales to infinite $A$.

*(Abbott §1.5, Exercises 1.5.6–1.5.8, pp. 30–31)*

<details><summary>Nudge</summary>
$P(A)$ for a 3-element set has 8 elements — plenty of room for an injective (1–1) map from the 3-element $A$, but that's different from being onto.
</details>
<details><summary>Strategy</summary>
For (a), send each element of $A$ to a distinct singleton subset, e.g. $a\mapsto\{a\}$, or to some other injective assignment. For (b), build the Cantor "diagonal" set $B=\{x\in A : x\notin f(x)\}$ for your chosen $f$ and show it can't be in the range.
</details>
<details><summary>Partial</summary>
(a) $f_1(a)=\{a\}, f_1(b)=\{b\}, f_1(c)=\{c\}$ is one 1–1 map; $f_2(a)=\{a,b\}, f_2(b)=\{b,c\}, f_2(c)=\{a,c\}$ is another. (b) For any $f:A\to P(A)$, define $B=\{x\in A:x\notin f(x)\}$.
</details>
<details><summary>Worked start</summary>
Suppose $f$ were onto; then $B=f(a')$ for some $a'\in A$. Ask: is $a'\in B$? By definition of $B$, $a'\in B \iff a'\notin f(a')=B$ — a direct contradiction either way ($a'\in B$ forces $a'\notin B$, and vice versa). So no onto $f$ exists, for any set $A$ including infinite ones (the argument never used finiteness of $A$) — this is exactly Cantor's Theorem (Theorem 1.5.2), and it's the same diagonal mechanism as the real-number and 0/1-sequence versions, wearing the costume of set membership instead of digits.
</details>

## Problem 5 (hard — proof problem, Schröder–Bernstein)

Assume there exists a 1–1 function $f: X\to Y$ and a 1–1 function $g: Y\to X$. Sketch (in your own words, following the standard proof outline) why there must exist a 1–1, onto function $h:X\to Y$, and hence $X\sim Y$. State clearly what role is played by elements that lie in "infinite chains" versus those that eventually trace back to an element with no $g$-preimage.

*(Abbott §1.4, Exercise 1.4.13, "Schröder–Bernstein Theorem", pp. 25–26)*

<details><summary>Nudge</summary>
Think of each element of $X\cup Y$ as sitting in a chain, alternately tracing preimages under $f$ and $g$ backwards as far as possible. What are the possible "shapes" a chain can have?
</details>
<details><summary>Strategy</summary>
Classify elements of $X$ into three types: those whose backward chain terminates in $X$ (an "$X$-stopper"), those terminating in $Y$ (a "$Y$-stopper"), and those that trace back forever (infinite chains). Use $f$ on one type, $g^{-1}$ on another.
</details>
<details><summary>Partial</summary>
For $x\in X$ whose chain traces back to an element of $X$ with no $g$-preimage, or an infinite chain, define $h(x)=f(x)$. For $x\in X$ whose chain traces back to an element of $Y$ with no $f$-preimage, define $h(x)=g^{-1}(x)$ (which exists on this type, since $x$ is itself in the range of $g$ along its chain).
</details>
<details><summary>Worked start</summary>
This piecewise-defined $h$ is well-defined (each $x$ falls into exactly one of the three chain types), 1–1 (each piece is 1–1, and the pieces send elements to disjoint parts of $Y$ by the classification), and onto (every $y\in Y$ is reached by tracing its own chain and checking which type it falls into, symmetric to the argument for $X$). Concluding $X\sim Y$. A fully rigorous write-up should define the three chain types precisely and verify well-definedness, injectivity and surjectivity of $h$ explicitly on each type — a brief but complete sketch along these lines earns full marks.
</details>

## Problem 6 (hard — proof, unions and countability)

Using the fact (established in an-02) that a countable union of countable sets is countable, and that $\mathbb{Q}$ is countable, prove that the set $\mathbb{I}$ of irrational numbers is uncountable, given that $\mathbb{R}$ is uncountable.

*(composed, in the spirit of Abbott §1.4, Exercise 1.4.9 and §1.5's uncountability results, combining both to a natural corollary not stated verbatim in the text)*

<details><summary>Nudge</summary>
Suppose, for contradiction, that $\mathbb{I}$ were countable. What would that make $\mathbb{R} = \mathbb{Q}\cup\mathbb{I}$?
</details>
<details><summary>Strategy</summary>
Use the closure-of-countable-sets-under-finite-union fact (a special case of the countable-union fact), combined with $\mathbb{Q}$ countable and $\mathbb{R}$ uncountable, to derive a contradiction from assuming $\mathbb{I}$ countable.
</details>
<details><summary>Partial</summary>
Suppose for contradiction $\mathbb{I}$ is countable. Since $\mathbb{Q}$ is countable (Theorem 1.4.11(i)) and $\mathbb{R}=\mathbb{Q}\cup\mathbb{I}$, a union of two countable sets, $\mathbb{R}$ would be countable (finite unions of countable sets are countable).
</details>
<details><summary>Worked start</summary>
But this contradicts Theorem 1.5.1 ($\mathbb{R}$, or equivalently $(0,1)$, is uncountable — via Exercise 1.5.1's equivalence). This contradiction shows the assumption was false: $\mathbb{I}$ must be uncountable. Cite explicitly which theorem supplies "finite unions of countable sets are countable" (an-02 lesson references this alongside the $\mathbb{Z}\sim\mathbb{N}$ zig-zag) and which supplies $\mathbb{R}$'s uncountability.
</details>
