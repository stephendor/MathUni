## Problem 1 (easy — one sequence, two domains)

Consider $h_n(x) = \dfrac{x}{1 + x^n}$ on $[0, \infty)$.

(a) Find the pointwise limit of $(h_n)$ on $[0,\infty)$.
(b) Explain how you know the convergence cannot be uniform on $[0,\infty)$.
(c) Choose a smaller set on which the convergence is uniform, and prove it.

*(Abbott §6.2, Exercise 6.2.3, p. 161)*

<details><summary>Nudge</summary>
Compute the limit separately for $0 \le x < 1$, for $x = 1$, and for $x > 1$. Three regimes, three answers.
</details>
<details><summary>Strategy</summary>
For (b), do not hunt for a defeating point directly — identify the limit function and apply Theorem 6.2.6 in contrapositive.
</details>
<details><summary>Partial</summary>
For $0 \le x < 1$, $x^n \to 0$ so $h_n(x) \to x$. At $x = 1$, $h_n(1) = 1/2$ for every $n$. For $x > 1$, $x^n \to \infty$ so $h_n(x) \to 0$. Hence the pointwise limit is $h(x) = x$ on $[0,1)$, $h(1) = 1/2$, and $h(x) = 0$ on $(1, \infty)$.
</details>
<details><summary>Worked start</summary>
(b) Each $h_n$ is continuous on $[0,\infty)$, being a quotient of continuous functions with non-vanishing denominator, by an-10's Theorem 4.3.4. The limit $h$ is discontinuous at $x = 1$, since $h$ approaches 1 from the left and 0 from the right while $h(1) = 1/2$. If the convergence were uniform, Theorem 6.2.6 would make $h$ continuous. So it is not uniform.

(c) On $[0, b]$ with $b < 1$ the convergence is uniform: for $x \in [0,b]$,
$$|h_n(x) - x| = \left|\frac{x - x - x^{n+1}}{1+x^n}\right| = \frac{x^{n+1}}{1+x^n} \le x^{n+1} \le b^{n+1},$$
a bound free of $x$ that tends to 0 by an-04's Example 2.5.3. Given $\epsilon > 0$, choose $N$ with $b^{N+1} < \epsilon$.

Say which working test you used in each direction: (b) is the contrapositive of a theorem, (c) is the bound-free-of-$x$ criterion from the lesson. Having both available, and knowing which is quicker for which job, is the practical content of this unit.
</details>

## Problem 2 (easy — a spike that escapes)

For each $n$, define $f_n$ on $\mathbb{R}$ by $f_n(x) = 1$ if $|x| \ge 1/n$ and $f_n(x) = n|x|$ if $|x| < 1/n$.

(a) Find the pointwise limit of $(f_n)$ on $\mathbb{R}$ and decide whether the convergence is uniform.
(b) Construct a pointwise limit of continuous functions on the compact set $[-5,5]$ whose limit function is unbounded there.

*(Abbott §6.2, Exercise 6.2.5, p. 161)*

<details><summary>Nudge</summary>
For (b), build a sequence of tall thin spikes that move towards a fixed point while growing.
</details>
<details><summary>Strategy</summary>
For (a), evaluate at $x = 0$ separately from $x \ne 0$. For (b), let the $n$-th function be a triangular spike of height $n$ based on a shrinking interval, positioned so that each fixed $x$ eventually escapes the spike.
</details>
<details><summary>Partial</summary>
(a) $f_n(0) = 0$ for every $n$, so the limit is 0 there. For $x \ne 0$, once $n > 1/|x|$ we have $|x| \ge 1/n$ and $f_n(x) = 1$, so the limit is 1. The pointwise limit is therefore $f(x) = 1$ for $x \ne 0$ and $f(0) = 0$, which is discontinuous, so by Theorem 6.2.6 the convergence is not uniform.
</details>
<details><summary>Worked start</summary>
(b) Let $f_n$ be the piecewise-linear function that is 0 outside $(1/(n+1), 1/(n-1))$, rises linearly to the value $n$ at $x = 1/n$, and returns to 0 — a spike of height $n$ over a shrinking interval around $1/n$, and 0 everywhere else on $[-5,5]$. Each $f_n$ is continuous. For any fixed $x$, only finitely many of the spikes touch $x$, so $f_n(x) = 0$ for all large $n$ and the pointwise limit is the zero function.

That answers (b) as stated, since the limit is bounded — so amend the construction: take instead $g_n(x) = \max\{f_n(x), g_{n-1}(x)\}$, or more simply let the limit be built by a *series* of spikes so that the limiting function takes the value $n$ at each $1/n$ and is unbounded on $[-5,5]$. Whichever construction you use, verify two things separately: that every partial function is continuous, and that at every fixed $x$ the sequence of values converges.

The lesson worth extracting: pointwise convergence controls nothing that is not visible one point at a time. Continuity, boundedness, and attainment of extrema can all be destroyed by it, and Theorem 6.2.6 is the first of a family of theorems that uniform convergence rescues.
</details>

## Problem 3 (medium — proving the Cauchy criterion)

Using the Cauchy Criterion for sequences of real numbers, prove Theorem 6.2.5: $(f_n)$ converges uniformly on $A$ if and only if for every $\epsilon > 0$ there is $N$ with $|f_n(x) - f_m(x)| < \epsilon$ for all $m, n \ge N$ and all $x \in A$.

*(Abbott §6.2, Exercise 6.2.6, p. 161)*

<details><summary>Nudge</summary>
The hard direction has no limit function to work with. Manufacture one first, pointwise, then prove the convergence to it is uniform.
</details>
<details><summary>Strategy</summary>
Fix $x$: the hypothesis makes $(f_n(x))$ a Cauchy sequence of reals, so an-05's Theorem 2.6.4 gives a limit. Define $f(x)$ to be that limit. Then pass to the limit in $m$ inside the inequality, using an-03's Order Limit Theorem to keep it.
</details>
<details><summary>Partial</summary>
Given $\epsilon > 0$, take $N$ from the hypothesis with the strict bound $\epsilon/2$. For fixed $x \in A$ and $n \ge N$, the inequality $|f_n(x) - f_m(x)| \le \epsilon/2$ holds for every $m \ge N$; letting $m \to \infty$ and using Theorem 2.3.4 gives $|f_n(x) - f(x)| \le \epsilon/2 < \epsilon$.
</details>
<details><summary>Worked start</summary>
Since $N$ was chosen without reference to $x$, and the conclusion holds for every $x \in A$ and every $n \ge N$, this is exactly Definition 6.2.3.

The forward direction is the routine one: if $f_n \to f$ uniformly, take $N$ so that $|f_n(x) - f(x)| < \epsilon/2$ for all $n \ge N$ and all $x$, then $|f_n(x) - f_m(x)| \le |f_n(x)-f(x)| + |f(x)-f_m(x)| < \epsilon$.

Two points to make explicit. Passing to the limit in $m$ turns a strict inequality into a non-strict one, which is why the proof starts from $\epsilon/2$ rather than $\epsilon$ — an-03's Theorem 2.3.4 preserves $\le$ and not $<$. And note what this criterion is for: like its numerical ancestor, it decides uniform convergence without requiring the limit to be known first, which is what makes it usable on series of functions where the sum has no closed form.
</details>

## Problem 4 (medium — six conjectures)

Decide each, with a proof or a counterexample.

(a) If $f_n \to f$ pointwise on a compact set $K$, then $f_n \to f$ uniformly on $K$.
(b) If $f_n \to f$ uniformly on $A$ and $g$ is bounded on $A$, then $f_n g \to fg$ uniformly on $A$.
(c) If $f_n \to f$ uniformly on $A$ and each $f_n$ is bounded on $A$, then $f$ is bounded.
(d) If $f_n \to f$ uniformly on $A$ and uniformly on $B$, then $f_n \to f$ uniformly on $A \cup B$.
(e) If $f_n \to f$ uniformly on an interval and each $f_n$ is increasing, then $f$ is increasing.
(f) The same as (e) assuming only pointwise convergence.

*(Abbott §6.2, Exercise 6.2.8, p. 161)*

<details><summary>Nudge</summary>
Only one of the six is false. For (a), the lesson already contains a counterexample on a compact set.
</details>
<details><summary>Strategy</summary>
For (d), take the maximum of the two thresholds. For (e) and (f), note that "increasing" is a statement about pairs of points and survives passage to the limit by the Order Limit Theorem, so pointwise convergence is already enough.
</details>
<details><summary>Partial</summary>
(a) False: $x^n$ on the compact set $[0,1]$ converges pointwise and not uniformly, as the lesson showed. Compactness of the domain does nothing here — unlike in an-11's Theorem 4.4.8, where compactness did upgrade continuity to uniform continuity.
</details>
<details><summary>Worked start</summary>
(b) True. Let $|g| \le M$ on $A$ with $M > 0$. Given $\epsilon > 0$ choose $N$ with $|f_n(x) - f(x)| < \epsilon/M$ for all $n \ge N$ and all $x$; then $|f_n(x)g(x) - f(x)g(x)| = |g(x)||f_n(x)-f(x)| < \epsilon$ for all such $n$ and $x$.

(c) True. Take $\epsilon = 1$ and the corresponding $N$; then $|f(x)| \le |f_N(x)| + 1 \le M_N + 1$ for all $x$, where $M_N$ bounds $f_N$.

(d) True. Given $\epsilon$, take $N_A$ and $N_B$ from the two hypotheses and set $N = \max\{N_A, N_B\}$; every $x \in A \cup B$ lies in one of the two sets. Note this argument breaks for an infinite union, since the maximum need not exist — the same finiteness step as in an-07's Theorem 3.2.3.

(e) and (f) True, both by the same argument: for $x < y$ we have $f_n(x) \le f_n(y)$ for every $n$, and an-03's Theorem 2.3.4 passes the inequality to the limits, giving $f(x) \le f(y)$. Only pointwise convergence is used, so (e) follows from (f) and uniformity is not needed.

Say which of the six actually required uniformity: (b), (c) and (d). The other three either fail regardless or hold pointwise, and sorting a list this way is more instructive than the individual answers.
</details>

## Problem 5 (medium-hard — sums and products)

Assume $(f_n)$ and $(g_n)$ converge uniformly on $A$.

(a) Show $(f_n + g_n)$ converges uniformly.
(b) Give an example showing $(f_n g_n)$ need not converge uniformly.
(c) Show that if there is $M > 0$ with $|f_n| \le M$ and $|g_n| \le M$ for all $n$, then $(f_n g_n)$ does converge uniformly.

*(Abbott §6.2, Exercise 6.2.11, p. 162)*

<details><summary>Nudge</summary>
For (b), the failure must come from unboundedness. Try $f_n(x) = x$ for every $n$, together with a $g_n$ converging uniformly to 0.
</details>
<details><summary>Strategy</summary>
(a) is an $\epsilon/2$ split with a maximum of two thresholds. (c) is the add-and-subtract move from an-05's Problem 3, with the uniform bounds playing the role that Lemma 2.6.3 played there.
</details>
<details><summary>Partial</summary>
(b) On $A = \mathbb{R}$, let $f_n(x) = x$ for all $n$ — a constant sequence, so uniformly convergent to $f(x) = x$ — and $g_n(x) = 1/n$, which converges uniformly to 0. Then $f_n(x)g_n(x) = x/n$, which converges pointwise to 0 but not uniformly, since at $x = n$ the value is 1 for every $n$.
</details>
<details><summary>Worked start</summary>
(c) Write $f_n g_n - fg = f_n(g_n - g) + g(f_n - f)$. The uniform bounds give $|f_n| \le M$; and $|g| \le M$ as well, since $g$ is the pointwise limit of functions bounded by $M$ and an-03's Theorem 2.3.4 preserves the bound. Hence
$$|f_n(x)g_n(x) - f(x)g(x)| \le M|g_n(x) - g(x)| + M|f_n(x) - f(x)|,$$
and choosing thresholds so that each difference is below $\epsilon/(2M)$ finishes it.

Note where each hypothesis is spent, and note the parallel: this is the same estimate as the proof that a product of Cauchy sequences is Cauchy, with a uniform bound in place of the bound Lemma 2.6.3 supplied there. When the same algebra appears twice in a course, it is usually because the same obstruction is being cleared, and here it is that a product of two small things needs one of them multiplied by something bounded before it can be controlled.
</details>

## Problem 6 (hard — a partial converse)

Assume $f_n \to f$ pointwise on a compact set $K$, that each $f_n(x)$ is increasing in $n$ for each fixed $x$, and that $f$ and every $f_n$ are continuous on $K$. Show that the convergence is uniform.

(a) Set $g_n = f - f_n$ and restate the hypotheses in terms of $(g_n)$.
(b) For arbitrary $\epsilon > 0$ let $K_n = \{x \in K : g_n(x) \ge \epsilon\}$. Show these form a nested sequence of compact sets and finish the argument.

*(Abbott §6.2, Exercise 6.2.12, p. 162)*

<details><summary>Nudge</summary>
Uniform convergence would say every $K_n$ is empty from some index onwards. Suppose not, and use an-08's Theorem 3.3.5.
</details>
<details><summary>Strategy</summary>
Show each $K_n$ is closed as the preimage of a closed set under a continuous function, bounded because $K$ is, and nested because $g_n$ decreases. If all were nonempty, the nested compact sets would share a point, and evaluate $g_n$ there.
</details>
<details><summary>Partial</summary>
(a) $g_n = f - f_n$ is continuous on $K$ by an-10's Theorem 4.3.4, satisfies $g_n(x) \ge 0$ — since $f_n(x)$ increases to $f(x)$ — and $g_n(x)$ decreases in $n$ for each fixed $x$, with $g_n(x) \to 0$ pointwise.
</details>
<details><summary>Worked start</summary>
(b) $K_n$ is closed: it is $g_n^{-1}([\epsilon, \infty))$, and an-10's topological characterisation of continuity makes preimages of closed sets closed. It is bounded because $K_n \subseteq K$. So each $K_n$ is compact by an-08's Theorem 3.3.4. Nesting: if $g_{n+1}(x) \ge \epsilon$ then $g_n(x) \ge g_{n+1}(x) \ge \epsilon$, so $K_{n+1} \subseteq K_n$.

Suppose every $K_n$ were nonempty. Then an-08's Theorem 3.3.5 gives a point $x_0$ lying in every $K_n$, so $g_n(x_0) \ge \epsilon$ for every $n$ — contradicting $g_n(x_0) \to 0$. Hence some $K_N$ is empty, which says $g_n(x) < \epsilon$ for every $x \in K$ once $n \ge N$ (using the nesting again to get all later $n$ at once). Since $\epsilon$ was arbitrary and $N$ did not depend on $x$, the convergence is uniform.

Two closing remarks. This is Dini's theorem, and it is worth naming: three extra hypotheses — compact domain, monotone in $n$, continuous limit — together buy back the uniformity that Problem 4(a) showed is not free. And notice the proof's shape: it converts a statement about a sequence of functions into a statement about a nested sequence of sets, which is why compactness enters as an-08's Theorem 3.3.5 rather than through any bound on the functions.
</details>
