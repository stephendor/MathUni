## Problem 1 (easy–medium — an action is a homomorphism)

(a) State Definition 11.19 (p. 237) and Definition 11.17 (p. 235).

(b) Prove Proposition 11.20 (p. 237): an action of $G$ on $A$ is the same thing as a group homomorphism $\sigma : G\to S_A$.

(c) Where in the proof is the invertibility of group elements used — specifically, what shows that $a\mapsto ga$ is a *bijection* of $A$?

(d) Compare with Proposition 10.6 (p. 205). State the common principle in one sentence.

<details><summary>Nudge</summary>
(b) Given the action, set $\sigma(g)(a) = ga$. Given $\sigma$, set $ga = \sigma(g)(a)$.
</details>
<details><summary>Strategy</summary>
(c) The inverse map is $a\mapsto g^{-1}a$.
</details>
<details><summary>Partial</summary>
(b) Given an action, define $\sigma(g) : A\to A$ by $\sigma(g)(a) = ga$. The axiom $(gh)a = g(ha)$ says $\sigma(gh) = \sigma(g)\circ\sigma(h)$, and $ea = a$ says $\sigma(e) = \operatorname{id}$. Conversely, given a homomorphism $\sigma$, define $ga := \sigma(g)(a)$; the two axioms are the two displayed statements read backwards.

(c) $\sigma(g)\circ\sigma(g^{-1}) = \sigma(gg^{-1}) = \sigma(e) = \operatorname{id}$, and likewise the other way, so $\sigma(g)$ has a two-sided inverse function and is a bijection. **That is the only place inverses appear**, and it is what makes $\sigma$ land in $S_A$ rather than merely in the monoid of all functions $A\to A$.
</details>
<details><summary>Worked start</summary>
(d) Proposition 10.6 said an $R$-module structure on $M$ is a ring homomorphism $R\to\operatorname{End}(M)$; Proposition 11.20 says a $G$-action on $A$ is a group homomorphism $G\to S_A$. In one sentence: **an action of an algebraic structure on an object is a homomorphism from that structure into the structure's worth of symmetries of the object** — endomorphisms for a ring acting on an abelian group, permutations for a group acting on a set. Every "acting on" in this module is an instance, and the target is always the largest thing of the same kind that the object carries.
</details>

## Problem 2 (medium — orbits partition)

(a) State Definition 11.22 (p. 238) and prove that "lies in the same orbit as" is an equivalence relation on $A$.

(b) Deduce that the orbits partition $A$, and identify the quotient set.

(c) Let $D_8$ act on the square. Compute the orbits on the four vertices, on the four edges, and on the two diagonals. (Aluffi writes $D_{2n}$ for the symmetries of a regular $n$-gon, so the square's group is $D_8$ and has order $8$ — Definition 11.32, p. 242. Many texts, Carter among them, write $D_4$ for the same group; this module follows Aluffi.)

(d) Let $C_2 = \{e,\rho\}$ act on $\{1,2,3\}$ by fixing $1$ and swapping $2,3$. Compute the orbits, and check against Example 11.23 (p. 239).

<details><summary>Nudge</summary>
(a) Reflexivity uses $e$, symmetry uses inverses, transitivity uses products.
</details>
<details><summary>Strategy</summary>
(b) aa-03 Problem 2 already showed every equivalence relation gives a partition.
</details>
<details><summary>Partial</summary>
(a) $a = ea$, so $a\sim a$. If $b = ga$ then $a = g^{-1}b$, so $b\sim a$. If $b=ga$ and $c=hb$ then $c = (hg)a$. So the three group axioms give the three properties of an equivalence relation, one apiece — which is worth noticing, since it means the orbit decomposition is not an extra construction but a restatement of the axioms.

(b) By aa-03 Problem 2, an equivalence relation partitions the set; the quotient is the set of orbits, written $A/G$.
</details>
<details><summary>Worked start</summary>
(c) On the **vertices**: one orbit of size $4$ — every vertex reaches every other by a rotation, so the action is transitive. On the **edges**: one orbit of size $4$, for the same reason. On the **diagonals**: one orbit of size $2$ — the rotation $r$ swaps them and $r^2$ fixes both.

Note the third case is the interesting one: the action of $D_8$ on the diagonals is transitive but not faithful, and its kernel is the subgroup fixing both diagonals, $\{e,r^2,s,r^2s\}$ for a suitable choice of $s$ — of order $4$, so the induced map $D_8\to S_2$ is far from injective.

(d) Orbits $\{1\}$ and $\{2,3\}$, which is Example 11.23 exactly. Two orbits, sizes $1$ and $2$, summing to $3$ — as any partition of $A$ must.
</details>

## Problem 3 (medium — transitive, faithful, free)

(a) State Definition 11.24 (p. 239) and Definition 11.26 (p. 239), and define **free**: no non-identity element fixes any point.

(b) Give an action that is transitive and not faithful.

(c) Give an action that is faithful and not transitive.

(d) Give an action that is faithful and transitive and not free, and one that is free and not transitive.

<details><summary>Nudge</summary>
(b) Problem 2(c)'s diagonals.
</details>
<details><summary>Strategy</summary>
(d) For faithful, transitive, not free, use $S_3$ on $\{1,2,3\}$.
</details>
<details><summary>Partial</summary>
(b) $D_8$ acting on the two diagonals of the square: transitive by Problem 2(c), and not faithful because a subgroup of order $4$ acts trivially.

(c) The $C_2$ action of Problem 2(d) on $\{1,2,3\}$: faithful, since $\rho$ acts non-trivially, and not transitive, since $1$ is its own orbit. Example 11.27 (p. 239) says both actions of Example 11.21 are faithful, and this is one of them.
</details>
<details><summary>Worked start</summary>
(d) *Faithful, transitive, not free:* $S_3$ acting on $\{1,2,3\}$. Faithful because a permutation acting as the identity is the identity; transitive because any point can be sent to any other; not free because the transposition $(2\,3)$ fixes $1$.

*Free, not transitive:* $C_2 = \{e,\rho\}$ acting on a four-element set $\{1,2,3,4\}$ by the double transposition $(1\,2)(3\,4)$. No non-identity element fixes anything, so the action is free; there are two orbits, $\{1,2\}$ and $\{3,4\}$, so it is not transitive.

Free implies faithful — an element acting as the identity fixes every point — and the converse fails by (d)'s first example. Transitivity and faithfulness are independent of each other, as (b) and (c) show in both directions.
</details>

## Problem 4 (medium — Cayley's theorem)

(a) Prove Lemma 11.28 (p. 240): the action of $G$ on itself by left multiplication is free, hence faithful.

(b) Prove Theorem 11.29 (p. 240): every group is isomorphic to a subgroup of a symmetric group; for $|G| = n$ finite, to a subgroup of $S_n$.

(c) Write out the embedding for $C_3$, giving the three permutations explicitly.

(d) Write out the embedding for $S_3$ into $S_6$, and say why $S_3\subseteq S_3$ shows the $n$ in (b) is not optimal.

<details><summary>Nudge</summary>
(a) $gx = x$ with $x$ in the group means $g = e$, by cancelling $x$.
</details>
<details><summary>Strategy</summary>
(b) The homomorphism is $\sigma : G\to S_G$ of Problem 1(b); injectivity is (a).
</details>
<details><summary>Partial</summary>
(a) Suppose $gx = x$ for some $x\in G$. Multiply on the right by $x^{-1}$: $g = e$. So no non-identity element fixes any point, and the action is free; a free action is faithful because an element acting trivially fixes everything, hence is $e$.

(b) By Problem 1(b) the action gives a homomorphism $\sigma : G\to S_G$, and by (a) it is injective — its kernel consists of the elements acting as the identity, which is $\{e\}$. So $G\cong\sigma(G)$, a subgroup of $S_G$ by aa-23 Problem 3(b). If $|G|=n$ then $S_G\cong S_n$ after numbering the elements.
</details>
<details><summary>Worked start</summary>
(c) $C_3 = \{e,g,g^2\}$, numbered $1,2,3$ in that order. Left multiplication by $e$ is the identity; by $g$ sends $e\mapsto g$, $g\mapsto g^2$, $g^2\mapsto e$, i.e. the cycle $(1\,2\,3)$; by $g^2$ the cycle $(1\,3\,2)$. So the image is $A_3\subseteq S_3$ — Example 11.30 (p. 240) is this relabelling.

(d) $|S_3| = 6$, so (b) embeds $S_3$ into $S_6$: each of the six elements of $S_3$ permutes the six by left multiplication, and the image is a subgroup of $S_6$ of order $6$ acting freely.

But $S_3$ is *already* a subgroup of $S_3$, and $3<6$. So Cayley's $n = |G|$ is an upper bound and not the least possible degree — it is produced by one particular action, the regular one, and any faithful action of $G$ on a smaller set does better. Finding the smallest such set is a genuinely harder question, and Cayley's theorem does not address it; what it delivers is that *some* embedding exists, uniformly, for every group.
</details>

## Problem 5 (medium–hard — the orbit and the stabiliser)

For an action of $G$ on $A$ and $a\in A$, let $\operatorname{Stab}(a) = \{g\in G : ga = a\}$.

(a) Prove $\operatorname{Stab}(a)$ is a subgroup of $G$.

(b) Prove the **orbit–stabiliser bijection**: the map $g\operatorname{Stab}(a)\mapsto ga$ is a well-defined bijection from the set of left cosets of $\operatorname{Stab}(a)$ onto the orbit of $a$.

(c) Deduce that for finite $G$, the size of every orbit divides $|G|$.

(d) Apply: the rotation group of a cube acts on the six faces. Given that the action is transitive and that the stabiliser of a face has order $4$, compute the order of the group.

<details><summary>Nudge</summary>
(b) $ga = ha$ if and only if $h^{-1}g\in\operatorname{Stab}(a)$.
</details>
<details><summary>Strategy</summary>
(c) The number of left cosets times $|\operatorname{Stab}(a)|$ is $|G|$, since the cosets partition $G$ into blocks of equal size.
</details>
<details><summary>Partial</summary>
(a) $e\in\operatorname{Stab}(a)$; and if $g,h$ fix $a$ then $gh^{-1}a = g(h^{-1}a) = ga = a$, using $h^{-1}a = a$, which follows by applying $h^{-1}$ to $ha=a$. Proposition 11.7 (p. 232) applies.

(b) *Well defined and injective:* $ga = ha \iff h^{-1}ga = a \iff h^{-1}g\in\operatorname{Stab}(a)\iff g\operatorname{Stab}(a) = h\operatorname{Stab}(a)$ — the chain runs both ways at once, which is why one computation settles both. *Surjective:* every element of the orbit is $ga$ for some $g$.
</details>
<details><summary>Worked start</summary>
(c) Left cosets of a subgroup $H$ partition $G$ into blocks all of size $|H|$ — the map $h\mapsto gh$ is a bijection $H\to gH$. So the number of cosets is $|G|/|H|$, and by (b) that number is the size of the orbit. Hence $|{\rm orbit}|\cdot|\operatorname{Stab}(a)| = |G|$, and in particular the orbit size divides $|G|$. (This is Lagrange's theorem in embryo; aa-28 states it in full.)

(d) The orbit of a face is all six faces, by transitivity, and the stabiliser has order $4$ — the four rotations about the axis through that face and the opposite one. So
$$|G| = 6\cdot4 = 24 .$$
The rotation group of the cube has $24$ elements. Counting by a different orbit checks it: on the eight vertices the action is transitive with stabiliser of order $3$, and $8\cdot3 = 24$ ✓; on the twelve edges, transitive with stabiliser of order $2$, and $12\cdot2 = 24$ ✓.
</details>

## Problem 6 (hard — conjugation)

Let $G$ act on itself by $g\cdot x = gxg^{-1}$.

(a) Check this is an action. Then examine two variants and classify each: $g\cdot x = g^{-1}xg$, and $g\cdot x = xg$. Exactly one of the following holds of each — it is a left action, or it is a right action but not a left one, or it is neither. Say which, and prove it.

(b) Prove the orbits are the conjugacy classes of Definition 11.31 (p. 241), and that the kernel of the corresponding homomorphism $G\to S_G$ is the **centre** $Z(G) = \{z : zg = gz$ for all $g\}$.

(c) Compute the conjugacy classes of $S_3$ and their sizes.

(d) Compute the conjugacy classes of $D_8$ and $Z(D_8)$.

(e) Check in both cases that the class sizes sum to $|G|$ and each divides $|G|$, and say which result of Problem 5 guarantees it.

<details><summary>Nudge</summary>
(a) Check $(gh)\cdot x = g\cdot(h\cdot x)$; the inverses have to reverse order to make it work. For the variants, write both sides out and compare the order in which $g$ and $h$ end up.
</details>
<details><summary>Strategy</summary>
(d) $D_8 = \{e,r,r^2,r^3,s,rs,r^2s,r^3s\}$ with $srs^{-1} = r^{-1}$.
</details>
<details><summary>Partial</summary>
(a) $e\cdot x = exe^{-1} = x$, and
$$(gh)\cdot x = (gh)x(gh)^{-1} = g(hxh^{-1})g^{-1} = g\cdot(h\cdot x),$$
using aa-23 Problem 1(c) for $(gh)^{-1} = h^{-1}g^{-1}$ — the order reversal in the inverse is exactly what makes the two $g$'s end up outside.

The first variant, $g\cdot x = g^{-1}xg$, is **not** a left action. Inversion reverses multiplication, so it undoes the reversal that made conjugation work:
$$(gh)\cdot x = h^{-1}g^{-1}xgh,\qquad g\cdot(h\cdot x) = g^{-1}h^{-1}xhg,$$
and these differ as soon as $g$ and $h$ fail to commute. What it satisfies instead is $(gh)\cdot x = h\cdot(g\cdot x)$, the *right*-action law — equivalently it is a left action of the opposite group. In $S_3$ the left-action law fails for 54 of the 216 triples $(g,h,x)$, while the right-action law holds for all 216.

The second variant is the reverse of what you might expect: $x\mapsto gx$ **is** a left action (left multiplication, Lemma 11.28), and it is $x\mapsto xg$ that is not, since $(gh)\cdot x = xgh$ while $g\cdot(h\cdot x) = xhg$. Right multiplication is the other standard right action.

(b) The orbit of $x$ is $\{gxg^{-1}\}$, which is Definition 11.31's conjugacy class. The kernel is the set of $g$ acting as the identity, i.e. with $gxg^{-1} = x$ for every $x$, i.e. $gx = xg$ for every $x$ — the centre.
</details>
<details><summary>Worked start</summary>
(c) $S_3$: conjugation preserves cycle type, and in $S_3$ each cycle type is a single class. Classes $\{e\}$, the three transpositions, and the two three-cycles — sizes $1, 3, 2$, summing to $6$ ✓.

(d) $D_8$: $\{e\}$; $\{r^2\}$, since $r^2$ is central; $\{r,r^3\}$, since $srs^{-1} = r^{-1} = r^3$; $\{s,r^2s\}$; $\{rs,r^3s\}$. Sizes $1,1,2,2,2$, summing to $8$ ✓. The centre is the union of the classes of size $1$, namely $Z(D_8) = \{e,r^2\}$, of order $2$ — so $D_8$ is not abelian and not centreless either.

(e) Each class size divides the order, by Problem 5(c): a class is an orbit, and orbit sizes divide $|G|$. The sizes summing to $|G|$ is Problem 2(b): the orbits partition the set being acted on, which here is $G$ itself. Those two facts together — the class equation — are what aa-28 turns into a counting tool, and the classes of size $1$ being exactly the centre is the observation that makes it useful.
</details>
