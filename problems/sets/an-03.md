## Problem 1 (easy — ε-N proof of limit) [interleaves an-03]

Using Definition 2.2.3 (the formal $\epsilon$-$N$ definition of convergence), prove that
$$\lim_{n\to\infty} \frac{3n+1}{2n+5} = \frac{3}{2}.$$

*(Abbott §2.2, Exercise 2.2.1(b), p. 43)*

<details><summary>Nudge</summary>
Calculate $\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right|$ algebraically and simplify to a single fraction.
</details>
<details><summary>Strategy</summary>
Bound the simplified fraction above by a simpler term in $n$, e.g., $\frac{13}{2(2n+5)} < \frac{13}{4n}$, then solve $\frac{13}{4n} < \epsilon$ for $n$.
</details>
<details><summary>Partial</summary>
$\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \left|\frac{2(3n+1) - 3(2n+5)}{2(2n+5)}\right| = \left|\frac{-13}{2(2n+5)}\right| = \frac{13}{4n+10} < \frac{13}{4n}$.
</details>
<details><summary>Worked start</summary>
Given $\epsilon > 0$, choose $N \in \mathbb{N}$ with $N > \frac{13}{4\epsilon}$. Then for any $n \ge N$, $n > \frac{13}{4\epsilon} \Rightarrow \frac{13}{4n} < \epsilon$. Thus $\left|\frac{3n+1}{2n+5} - \frac{3}{2}\right| = \frac{13}{4n+10} < \frac{13}{4n} < \epsilon$.
</details>

## Problem 2 (easy — uniqueness of limits)

Prove Exercise 2.3.4 from Abbott: Show that limits, if they exist, are unique. That is, assume $\lim a_n = L_1$ and $\lim a_n = L_2$, using Definition 2.2.3 to prove that $L_1 = L_2$.

*(Abbott §2.3, Exercise 2.3.4, p. 49)*

<details><summary>Nudge</summary>
Use the triangle inequality $|L_1 - L_2| \le |L_1 - a_n| + |a_n - L_2|$.
</details>
<details><summary>Strategy</summary>
For any $\epsilon > 0$, choose $N_1$ for $L_1$ with $\epsilon/2$ and $N_2$ for $L_2$ with $\epsilon/2$. Take $N = \max\{N_1, N_2\}$.
</details>
<details><summary>Partial</summary>
$|L_1 - L_2| < \epsilon/2 + \epsilon/2 = \epsilon$ for all $\epsilon > 0$.
</details>
<details><summary>Worked start</summary>
Since $|L_1 - L_2| < \epsilon$ for every $\epsilon > 0$, it follows that $|L_1 - L_2| = 0$, so $L_1 = L_2$.
</details>

## Problem 3 (medium — proof that convergent sequences are bounded)

Write out a complete, rigorous proof of Theorem 2.3.2: *Every convergent sequence is bounded (Definition 2.3.1).*

*(Abbott §2.3, Theorem 2.3.2, p. 44)*

<details><summary>Nudge</summary>
Set $\epsilon = 1$ in Definition 2.2.3 to control the tail terms $n \ge N$.
</details>
<details><summary>Strategy</summary>
For $n \ge N$, $|a_n| < |L| + 1$. For $n < N$, there are only finitely many initial terms. Take $M = \max\{|a_1|, |a_2|, \ldots, |a_{N-1}|, |L|+1\}$.
</details>
<details><summary>Partial</summary>
Show $|a_n| \le M$ for all $n \in \mathbb{N}$.
</details>
<details><summary>Worked start</summary>
Let $(a_n) \to L$. By Definition 2.2.3 with $\epsilon = 1$, $\exists N \in \mathbb{N}$ such that $n \ge N \Rightarrow |a_n - L| < 1$. Thus $|a_n| = |a_n - L + L| \le |a_n - L| + |L| < |L| + 1$. Setting $M = \max\{|a_1|, \dots, |a_{N-1}|, |L|+1\}$ ensures $|a_n| \le M$ for all $n \in \mathbb{N}$, satisfying Definition 2.3.1.
</details>

## Problem 4 (medium — proof of the Order Limit Theorem)

Prove Theorem 2.3.4 part (i): If $(a_n) \to a$ and $a_n \ge 0$ for all $n \in \mathbb{N}$, then $a \ge 0$.

*(Abbott §2.3, Theorem 2.3.4(i), p. 48)*

<details><summary>Nudge</summary>
Use proof by contradiction: assume $a < 0$ and pick a specific $\epsilon_0 > 0$.
</details>
<details><summary>Strategy</summary>
Let $\epsilon_0 = |a| = -a > 0$. Use Definition 2.2.3 to get $N$ such that $|a_N - a| < |a|$, implying $a_N < 0$.
</details>
<details><summary>Partial</summary>
$|a_N - a| < -a \Rightarrow a - (-a) < a_N < a + (-a) \Rightarrow 2a < a_N < 0$.
</details>
<details><summary>Worked start</summary>
Assume for contradiction $a < 0$. Set $\epsilon_0 = -a > 0$. Since $(a_n) \to a$, there exists $N \in \mathbb{N}$ such that for all $n \ge N$, $|a_n - a| < -a$. In particular, for $n = N$, $a_N - a < -a \Rightarrow a_N < 0$, contradicting $a_N \ge 0$. Hence $a \ge 0$.
</details>

## Problem 5 (hard — proof of product rule in Algebraic Limit Theorem)

Prove Theorem 2.3.3 part (iii) (Product Rule): If $(a_n) \to a$ and $(b_n) \to b$, then $(a_n b_n) \to ab$.

*(Abbott §2.3, Theorem 2.3.3(iii), p. 45)*

<details><summary>Nudge</summary>
Use the identity $|a_n b_n - ab| = |a_n b_n - ab_n + ab_n - ab| \le |b_n||a_n - a| + |a||b_n - b|$.
</details>
<details><summary>Strategy</summary>
By Theorem 2.3.2, $(b_n)$ is bounded, so $\exists M > 0$ such that $|b_n| \le M$ for all $n$. Split $\epsilon$ into two pieces of size $\epsilon/2$.
</details>
<details><summary>Partial</summary>
Choose $N_1$ so $|a_n - a| < \frac{\epsilon}{2M}$ for $n \ge N_1$. If $a \ne 0$, choose $N_2$ so $|b_n - b| < \frac{\epsilon}{2|a|}$ for $n \ge N_2$.
</details>
<details><summary>Worked start</summary>
Since $(b_n)$ converges, Theorem 2.3.2 implies $(b_n)$ is bounded by some $M > 0$. Given $\epsilon > 0$, choose $N_1$ so $n \ge N_1 \Rightarrow |a_n - a| < \frac{\epsilon}{2M}$, and choose $N_2$ so $n \ge N_2 \Rightarrow |b_n - b| < \frac{\epsilon}{2(|a|+1)}$. For $N = \max\{N_1, N_2\}$ and $n \ge N$: $|a_n b_n - ab| \le M|a_n - a| + |a||b_n - b| < M \frac{\epsilon}{2M} + |a| \frac{\epsilon}{2(|a|+1)} < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$.
</details>
