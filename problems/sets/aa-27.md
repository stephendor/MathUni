## Problem 1 (easy–medium — the first theorem)

(a) Prove Theorem 11.68 (p. 260): if $\varphi : G\to H$ is a surjective group homomorphism then $H\cong G/\ker\varphi$.

(b) State Theorem 11.67 (p. 260), the canonical decomposition, and deduce it from (a).

(c) Apply (a) to the sign homomorphism and recover Example 11.69 (p. 260).

(d) Apply (a) to $\det : GL_n(\mathbb{R})\to\mathbb{R}^*$ and name the quotient.

<details><summary>Nudge</summary>
(a) The map is $\bar\varphi(g\ker\varphi) = \varphi(g)$; well-definedness and injectivity are one computation read two ways.
</details>
<details><summary>Strategy</summary>
(b) Restrict the codomain to the image, which is a subgroup by aa-23 Problem 3(b).
</details>
<details><summary>Partial</summary>
(a) Write $K = \ker\varphi$, normal by Proposition 11.58 (p. 256), so $G/K$ is a group. Define $\bar\varphi(gK) = \varphi(g)$. *Well defined:* $gK = g'K$ gives $g^{-1}g'\in K$, so $\varphi(g) = \varphi(g')$. *Injective:* $\varphi(g)=\varphi(g')$ gives $g^{-1}g'\in K$, so $gK = g'K$. *Homomorphism:* $\bar\varphi(gK\cdot g'K) = \varphi(gg') = \bar\varphi(gK)\bar\varphi(g'K)$. *Surjective:* since $\varphi$ is.

(b) For arbitrary $\varphi$, apply (a) to $\varphi : G\to\operatorname{im}\varphi$: every homomorphism factors as the projection $G\to G/\ker\varphi$, an isomorphism onto $\operatorname{im}\varphi$, and the inclusion $\operatorname{im}\varphi\hookrightarrow H$.
</details>
<details><summary>Worked start</summary>
(c) The sign map $S_n\to\{\pm1\}$ is a surjective homomorphism for $n\ge2$ with kernel $\mathcal{A}_n$ (aa-25 Problem 4(d)). So $S_n/\mathcal{A}_n\cong\{\pm1\}\cong C_2$, which is Example 11.69 — and the quotient map *is* the sign, so the abstract isomorphism carries no information the sign did not already carry.

(d) $\det : GL_n(\mathbb{R})\to\mathbb{R}^*$ is a group homomorphism, surjective because $\operatorname{diag}(t,1,\dots,1)$ has determinant $t$ for every $t\ne0$. Its kernel is the matrices of determinant $1$, the **special linear group** $SL_n(\mathbb{R})$. So
$$GL_n(\mathbb{R})/SL_n(\mathbb{R})\ \cong\ \mathbb{R}^* .$$
</details>

## Problem 2 (medium — factoring through a quotient)

Let $\varphi : G\to H$ be a homomorphism and $K\trianglelefteq G$.

(a) Prove that $\varphi$ factors as $\tilde\varphi\circ\pi$ for a homomorphism $\tilde\varphi : G/K\to H$ if and only if $K\subseteq\ker\varphi$, and that $\tilde\varphi$ is then unique.

(b) Compute $\ker\tilde\varphi$ in terms of $\ker\varphi$ and $K$.

(c) Use (a) to determine all homomorphisms $C_{12}\to C_8$.

(d) Compare with Proposition 5.39 (p. 91) and aa-17 Problem 4. State the shared principle.

<details><summary>Nudge</summary>
(a) The only possible formula is $\tilde\varphi(gK) = \varphi(g)$.
</details>
<details><summary>Strategy</summary>
(c) A homomorphism out of $C_{12}$ is a homomorphism out of $\mathbb{Z}$ killing $12\mathbb{Z}$ — aa-21 Problem 6.
</details>
<details><summary>Partial</summary>
(a) *Uniqueness:* $\tilde\varphi\circ\pi = \varphi$ forces $\tilde\varphi(gK) = \varphi(g)$. *Well defined iff $K\subseteq\ker\varphi$:* if $K\subseteq\ker\varphi$ and $gK = g'K$ then $g^{-1}g'\in K\subseteq\ker\varphi$, so $\varphi(g)=\varphi(g')$; conversely if $\tilde\varphi$ exists and $k\in K$, then $\varphi(k) = \tilde\varphi(kK) = \tilde\varphi(K) = e$, so $k\in\ker\varphi$.

(b) $\tilde\varphi(gK) = e$ iff $\varphi(g)=e$ iff $g\in\ker\varphi$, so $\ker\tilde\varphi = (\ker\varphi)/K$ — which makes sense because $K\subseteq\ker\varphi$.
</details>
<details><summary>Worked start</summary>
(c) $C_{12} = \mathbb{Z}/12\mathbb{Z}$, so by (a) a homomorphism $C_{12}\to C_8$ is a homomorphism $\mathbb{Z}\to C_8$ whose kernel contains $12\mathbb{Z}$. A homomorphism out of $\mathbb{Z}$ is a choice of image $a$ of $1$, and the kernel contains $12\mathbb{Z}$ exactly when $12a = 0$ in $C_8$, i.e. $a\in\{0,2,4,6\}$. **Four homomorphisms** — the same four counted twice before, as module maps in aa-15 Problem 6(c) and as maps of abelian groups in aa-21 Problem 6(b). Three descriptions, one answer, which is what it means for these categories to agree on abelian objects.

(d) Every version says: **a map out of a quotient is a map out of the original that kills what was quotiented, and there is exactly one such**. It appeared for rings (Proposition 5.39), for modules (aa-17 Problem 4), and now for groups. In each case the condition on the sub-object is necessary as well as sufficient, so the quotient is characterised by the maps out of it rather than by its construction.
</details>

## Problem 3 (medium — the second theorem)

Let $H\le G$ and $K\trianglelefteq G$.

(a) Prove $HK = \{hk\}$ is a subgroup of $G$, and that $K\trianglelefteq HK$.

(b) Prove $H\cap K\trianglelefteq H$.

(c) Prove Theorem 11.74 (p. 262): $HK/K\cong H/(H\cap K)$.

(d) Apply with $G = D_6$, $H = \{e,x\}$ and $K = \langle y\rangle$, and check by counting. Compare Example 11.72 (p. 262).

<details><summary>Nudge</summary>
(c) Apply Theorem 11.68 to the composite $H\hookrightarrow HK\to HK/K$.
</details>
<details><summary>Strategy</summary>
(a) $K$ normal in $G$ lets you move a $k$ past an $h$: $kh = h(h^{-1}kh)$.
</details>
<details><summary>Partial</summary>
(a) $e = ee\in HK$. For closure, $(h_1k_1)(h_2k_2) = h_1h_2\,(h_2^{-1}k_1h_2)\,k_2\in HK$, using normality of $K$ in $G$. For inverses, $(hk)^{-1} = k^{-1}h^{-1} = h^{-1}(hk^{-1}h^{-1})\in HK$. And $K\subseteq HK$ is normal there because it is normal in the larger $G$.

(b) $H\cap K$ is a subgroup by aa-23 Problem 3(d), and for $h\in H$ and $z\in H\cap K$ we get $hzh^{-1}\in H$ (as $H$ is a subgroup) and $hzh^{-1}\in K$ (as $K\trianglelefteq G$), so it lies in the intersection.
</details>
<details><summary>Worked start</summary>
(c) Let $\psi : H\to HK/K$ be $h\mapsto hK$, the inclusion followed by the projection, hence a homomorphism. *Surjective:* a general element of $HK/K$ is $hkK = hK = \psi(h)$. *Kernel:* $\psi(h) = K$ iff $h\in K$, i.e. $\ker\psi = H\cap K$. Theorem 11.68 (p. 260) gives $HK/K\cong H/(H\cap K)$.

(d) $H = \{e,x\}$, $K = \langle y\rangle = \{e,y,y^2\}$, normal by aa-26 Problem 6(e). Then $HK$ has $2\cdot3 = 6$ elements — all of $D_6$, since $H\cap K = \{e\}$ makes the products $hk$ distinct. So the theorem reads
$$D_6/\langle y\rangle\ \cong\ H/\{e\}\ \cong\ C_2 .$$
Counting: $6/3 = 2 = 2/1$ ✓. In general $|HK| = |H||K|/|H\cap K|$, which falls out of (c) by counting both sides — a formula about sets, obtained from an isomorphism of groups.
</details>

## Problem 4 (medium — the third theorem)

Let $K\trianglelefteq G$ and let $H$ be a subgroup with $K\subseteq H\subseteq G$.

(a) Prove $H/K$ is a subgroup of $G/K$, and that it is normal in $G/K$ if and only if $H$ is normal in $G$.

(b) Prove Theorem 11.75 (p. 263): if $H\trianglelefteq G$ then $(G/K)\big/(H/K)\cong G/H$.

(c) State the correspondence: every subgroup of $G/K$ is $H/K$ for a unique $H$ between $K$ and $G$.

(d) Apply with $G = C_{12}$, $K = \langle g^6\rangle$, $H = \langle g^3\rangle$, and check by counting.

<details><summary>Nudge</summary>
(b) Apply Theorem 11.68 to $G/K\to G/H$, $gK\mapsto gH$.
</details>
<details><summary>Strategy</summary>
(a) Conjugation in $G/K$ is induced by conjugation in $G$, so the two normality statements correspond.
</details>
<details><summary>Partial</summary>
(a) $H/K$ is nonempty and closed under products and inverses because $H$ is. For normality: $(gK)(hK)(gK)^{-1} = (ghg^{-1})K$, so $H/K$ is normal in $G/K$ iff $ghg^{-1}\in H$ for all $g\in G$, $h\in H$ — which is normality of $H$ in $G$. The projection is surjective, which is what makes the two conditions equivalent rather than merely related.

(b) Define $\Phi : G/K\to G/H$ by $\Phi(gK) = gH$. Well defined because $K\subseteq H$; surjective because every $gH$ is hit; and $\Phi(gK) = H$ iff $g\in H$, so $\ker\Phi = H/K$. Theorem 11.68 finishes it.
</details>
<details><summary>Worked start</summary>
(c) The maps $\bar H\mapsto\pi^{-1}(\bar H)$ and $H\mapsto H/K$ are mutually inverse between subgroups of $G/K$ and subgroups of $G$ containing $K$, and both preserve inclusion. Preimages of subgroups are subgroups by aa-23 Problem 3(c), and every preimage contains $\ker\pi = K$. This is aa-11 Problem 4(a) and aa-16 Problem 6(b) a third time.

(d) $C_{12} = \langle g\rangle$, $K = \langle g^6\rangle$ of order $2$, $H = \langle g^3\rangle$ of order $4$, and $K\subseteq H$ because $g^6 = (g^3)^2$. The theorem gives
$$(C_{12}/\langle g^6\rangle)\big/(\langle g^3\rangle/\langle g^6\rangle)\ \cong\ C_{12}/\langle g^3\rangle\ \cong\ C_3 .$$
Counting: $|C_{12}/K| = 6$, $|H/K| = 2$, and $6/2 = 3 = 12/4$ ✓. Everything is abelian here, so every subgroup is normal and (a)'s condition is automatic — which is why the abelian case gives no feel for what (a) is doing.
</details>

## Problem 5 (medium–hard — four quotients)

Compute each quotient, identifying it as a group already named.

(a) $D_8/\langle y^2\rangle$, where $y$ is the rotation of order $4$.

(b) $\mathcal{A}_4/V$, with $V$ as in aa-26 Problem 6.

(c) $(G_1\times G_2)/(K_1\times K_2)$ for $K_i\trianglelefteq G_i$ — Example 11.70 (p. 261).

(d) $F(\{a\})/\langle\!\langle a^n\rangle\!\rangle$, the free group on one generator modulo the normal subgroup generated by $a^n$ — compare Example 11.71 (p. 261).

<details><summary>Nudge</summary>
(a) Every element of the quotient squares to the identity; that settles which group of order 4 it is.
</details>
<details><summary>Strategy</summary>
(c) Project each coordinate and use Theorem 11.68.
</details>
<details><summary>Partial</summary>
(a) $\langle y^2\rangle = \{e,y^2\}$ is central in $D_8$, hence normal, and the quotient has order $8/2 = 4$. In it, $\bar y^2 = \bar e$ and $\bar x^2 = \bar e$, so every element squares to the identity; by aa-23 Problem 6(c) the quotient is $C_2\times C_2$, not $C_4$.

(b) $V\trianglelefteq\mathcal{A}_4$ by aa-26 Problem 6(a), and $|\mathcal{A}_4/V| = 12/4 = 3$. A group of order $3$ is cyclic (aa-25 Problem 2(b)), so $\mathcal{A}_4/V\cong C_3$.
</details>
<details><summary>Worked start</summary>
(c) The map $G_1\times G_2\to (G_1/K_1)\times(G_2/K_2)$, $(g_1,g_2)\mapsto(g_1K_1,g_2K_2)$, is a surjective homomorphism with kernel $K_1\times K_2$. So
$$(G_1\times G_2)/(K_1\times K_2)\ \cong\ (G_1/K_1)\times(G_2/K_2),$$
which is Example 11.70. Quotients of products are products of quotients — an assertion that is false for many other constructions and true here because everything is defined coordinatewise.

(d) $F(\{a\})\cong\mathbb{Z}$ by aa-25 Problem 5(b), and the normal subgroup generated by $a^n$ is just $\langle a^n\rangle$, since $\mathbb{Z}$ is abelian and every subgroup is normal. So the quotient is $\mathbb{Z}/n\mathbb{Z} = C_n$. This is the smallest instance of a **presentation**: $C_n = \langle a\mid a^n\rangle$, and by aa-25 Problem 5(c) every group arises this way from some free group.
</details>

## Problem 6 (hard — G/Z(G) cyclic forces G abelian)

Let $Z = Z(G)$ be the centre, normal by aa-26 Problem 2(d).

(a) Prove that if $G/Z$ is cyclic then $G$ is abelian.

(b) Deduce that $G/Z$ is never a nontrivial cyclic group — in particular $[G:Z]$ is never prime.

(c) Deduce that a group of order $p^2$, for $p$ prime, is abelian **given** that its centre is nontrivial. Which part of that is proved here and which is assumed?

(d) Show (a) is sharp: give a non-abelian $G$ with $G/Z$ noncyclic of order $4$.

<details><summary>Nudge</summary>
(a) If $G/Z = \langle gZ\rangle$, every element of $G$ is $g^kz$ for some $k$ and some $z\in Z$.
</details>
<details><summary>Strategy</summary>
(b) If $G/Z$ is cyclic then $G$ is abelian by (a), which makes $Z = G$ and $G/Z$ trivial.
</details>
<details><summary>Partial</summary>
(a) Suppose $G/Z = \langle gZ\rangle$. Every coset is $g^kZ$, so every element of $G$ has the form $g^kz$ with $z\in Z$. Take $a = g^jz_1$ and $b = g^kz_2$. Then
$$ab = g^jz_1g^kz_2 = g^{j+k}z_1z_2 = g^kz_2g^jz_1 = ba,$$
moving the central elements freely past the powers of $g$. So $G$ is abelian.

(b) If $G/Z$ were cyclic then $G$ would be abelian by (a), so $Z = G$ and $G/Z$ would be trivial. So a nontrivial $G/Z$ is never cyclic; and a group of prime order is cyclic (aa-25 Problem 2(b)), so $[G:Z]$ is never prime.
</details>
<details><summary>Worked start</summary>
(c) $|G| = p^2$ and $Z\ne\{e\}$, so $|Z|\in\{p,p^2\}$ by Problem 1(b) of aa-26 — the order of a subgroup divides the order of the group. If $|Z| = p$ then $[G:Z] = p$ is prime, which (b) forbids. So $|Z| = p^2$ and $G = Z$ is abelian.

**Proved here:** that $[G:Z]$ prime is impossible, and the deduction from a nontrivial centre. **Assumed:** that the centre of a $p$-group is nontrivial. That is a genuine theorem, and it is proved from the class equation in aa-28 — the classes of size $1$ are exactly the central elements, all class sizes divide $p^2$, and the sizes must sum to $p^2$, which forces more than one class of size $1$. Recorded as the step this set does not supply.

(d) $D_8$: it is not abelian, $Z(D_8) = \{e,y^2\}$ by aa-24 Problem 6(d), and $D_8/Z(D_8)\cong C_2\times C_2$ by Problem 5(a) — of order $4$ and not cyclic. So the hypothesis of (a) cannot be weakened to "$G/Z$ is small" or "$G/Z$ is abelian": the quotient here is abelian and $G$ is not. Cyclic is exactly the right condition, because it is what lets a single $g$ generate every coset.
</details>
