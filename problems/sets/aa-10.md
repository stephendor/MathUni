## Problem 1 (easy–medium — every ideal is a kernel)

(a) Prove Proposition 5.35 (p. 89): for an ideal $I$ of $R$, the map $\pi : R \to R/I$ given by $\pi(a) = a + I$ is a surjective ring homomorphism with $\ker\pi = I$.

(b) Deduce Remark 5.36 (p. 89): every ideal of every ring is the kernel of some ring homomorphism.

(c) aa-09 Problem 2 showed that every kernel is an ideal. State the two facts together as one sentence, and say why neither half alone would justify the definition of "ideal".

<details><summary>Nudge</summary>
(a) The three clauses of Definition 4.15 (p. 64) are precisely the three lines of Definition 5.24 (p. 84) read in the other direction. For the kernel, $a + I = 0 + I$ means $a \in I$.
</details>
<details><summary>Strategy</summary>
(c) One half says the definition is not too narrow; the other says it is not too wide.
</details>
<details><summary>Partial</summary>
(a) $\pi(a+b) = (a+b)+I = (a+I)+(b+I)$ and $\pi(ab) = ab + I = (a+I)(b+I)$, both by Definition 5.24; and $\pi(1_R) = 1_R + I = 1_{R/I}$ by Theorem 5.26 (p. 85). Surjective because every coset is $a + I$ for some $a$. Finally $\pi(a) = 0_{R/I}$ means $a + I = 0 + I$, i.e. $a - 0 \in I$, i.e. $a \in I$.
</details>
<details><summary>Worked start</summary>
(b) Given an ideal $I$, the homomorphism is $\pi$ itself, and (a) says $\ker\pi = I$. Nothing has to be found: the quotient construction manufactures the homomorphism out of the ideal.

(c) **A subset of a ring is an ideal if and only if it is the kernel of some ring homomorphism.** Neither half alone would do. "Every kernel is an ideal" without the converse would leave open that the definition captures more subsets than kernels do — that ideals are a larger, and so possibly less meaningful, class. "Every ideal is a kernel" without the converse would leave open that some kernel is not an ideal, in which case the theory of quotients would miss cases it was built to cover. Together they say the two descriptions pick out the same objects, which is what licenses using either as the definition — and Aluffi's Definition 5.8 (p. 80) chose the intrinsic one so that ideals can be recognised without producing a homomorphism first.
</details>

## Problem 2 (medium — one theorem replacing four ad hoc arguments)

(a) Prove Theorem 5.38 (p. 91), the First Isomorphism Theorem: if $f : R\to S$ is a **surjective** ring homomorphism, then $R/\ker f \cong S$.

(b) Where is surjectivity used? State the version of the theorem for an arbitrary $f$ — this is Theorem 5.37 (p. 90).

(c) Redo aa-09 Problem 5(b), (c) and (d) using (a), in a line each.

(d) In aa-09 you proved $\mathbb{R}[x]/(x^2+1)\cong\mathbb{C}$ by checking injectivity by hand, via division with remainder. Say exactly which step of that argument the First Isomorphism Theorem has absorbed.

<details><summary>Nudge</summary>
(a) The map is $\bar f(a + \ker f) = f(a)$. Well defined, injective, surjective — and the first two are the same computation read forwards and backwards.
</details>
<details><summary>Strategy</summary>
(c) In each case name a surjective homomorphism out of the polynomial ring and compute its kernel; the theorem does the rest.
</details>
<details><summary>Partial</summary>
(a) Define $\bar f(a + \ker f) = f(a)$. *Well defined:* if $a + \ker f = a' + \ker f$ then $a - a' \in\ker f$, so $f(a) = f(a')$. *Injective:* if $f(a) = f(a')$ then $f(a-a') = 0$, so $a - a'\in\ker f$ and the cosets agree. *Homomorphism:* immediate from Definition 5.24 (p. 84). *Surjective:* because $f$ is.
</details>
<details><summary>Worked start</summary>
(b) Surjectivity is used only for the surjectivity of $\bar f$. Without it the same map is an isomorphism onto its image, and since $\operatorname{im} f$ is a subring of $S$ by Proposition 5.1 (p. 78), the general statement is
$$R/\ker f\ \cong\ \operatorname{im} f,$$
which with the projection and the inclusion is the commutative diagram of Theorem 5.37 (p. 90): every homomorphism is a surjection followed by an isomorphism followed by an injection.

(c) $e_0 : \mathbb{Z}[x]\to\mathbb{Z}$ is onto with kernel $(x)$, so $\mathbb{Z}[x]/(x)\cong\mathbb{Z}$ — Example 5.40 (p. 92). Evaluation $e_r : R[x]\to R$ is onto with kernel $(x-r)$, so $R[x]/(x-r)\cong R$ — Example 5.41 (p. 92). And $\alpha(x)\mapsto\alpha(i)$ maps $\mathbb{R}[x]$ onto $\mathbb{C}$ with kernel $(x^2+1)$, so $\mathbb{R}[x]/(x^2+1)\cong\mathbb{C}$ — Example 5.42 (p. 93).

(d) The injectivity step. Proving $\bar f$ injective by hand required knowing that every coset has a representative of degree $\le 1$ and that $a + bi = 0$ forces $a = b = 0$ — a computation about $\mathbb{R}[x]$ specifically. The theorem replaces it with the observation that *the kernel is exactly what one quotients by*, so injectivity is automatic and the only work left is identifying $\ker f$ — here, showing that $\alpha(i) = 0$ implies $(x^2+1)\mid\alpha(x)$. The labour has not vanished; it has moved to a place where it is a single statement about one ideal rather than a bespoke argument per example.
</details>

## Problem 3 (medium — factoring a homomorphism through a quotient)

(a) Prove Proposition 5.39 (p. 91): if $f : R\to S$ is a ring homomorphism and $I\subseteq\ker f$ is an ideal, then there is a **unique** ring homomorphism $\tilde f : R/I\to S$ with $\tilde f\circ\pi = f$.

(b) Show the hypothesis $I\subseteq\ker f$ is necessary as well as sufficient: if such an $\tilde f$ exists then $I\subseteq\ker f$.

(c) Use (a) and (b) to recount the ring homomorphisms $\mathbb{Z}/n\mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$, which aa-08 Problem 3(c) counted by hand.

<details><summary>Nudge</summary>
(a) There is only one possible formula, $\tilde f(a+I) = f(a)$; the work is showing it is well defined.
</details>
<details><summary>Strategy</summary>
(c) A homomorphism $\mathbb{Z}/n\mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$ is the same thing as a homomorphism $\mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$ killing $n\mathbb{Z}$.
</details>
<details><summary>Partial</summary>
(a) *Uniqueness:* $\tilde f\circ\pi = f$ forces $\tilde f(a+I) = f(a)$, so there is at most one candidate. *Well defined:* if $a + I = a'+I$ then $a - a'\in I\subseteq\ker f$, so $f(a) = f(a')$ — and this is the only place the hypothesis is used. The homomorphism clauses are then Definition 5.24 (p. 84) again.
</details>
<details><summary>Worked start</summary>
(b) Suppose $\tilde f$ exists with $\tilde f\circ\pi = f$, and let $a \in I$. Then $\pi(a) = a + I = 0_{R/I}$, so $f(a) = \tilde f(0_{R/I}) = 0_S$ by Proposition 4.16 (p. 65). Hence $a\in\ker f$. So the condition is exactly right, not merely convenient — it is the necessary and sufficient condition for $f$ to descend.

(c) By aa-08 Problem 3(a) there is exactly one homomorphism $\sigma : \mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$, namely $a\mapsto[a]_m$, with kernel $m\mathbb{Z}$. Every homomorphism $\mathbb{Z}/n\mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$ composed with $\pi$ gives a homomorphism $\mathbb{Z}\to\mathbb{Z}/m\mathbb{Z}$, so it must be $\sigma$; and by (a) and (b), $\sigma$ descends to $\mathbb{Z}/n\mathbb{Z}$ if and only if $n\mathbb{Z}\subseteq\ker\sigma = m\mathbb{Z}$, i.e. if and only if $m \mid n$. So: exactly one when $m\mid n$, none otherwise.

The same answer as aa-08, and the same content — but "$n\mathbb{Z}\subseteq m\mathbb{Z}$" has replaced a well-definedness check, and containment of ideals is a statement one can look up rather than recompute.
</details>

## Problem 4 (medium — arithmetic of ideals in ℤ)

Let $a, b$ be nonzero integers. Recall Definition 5.43 (p. 94) and Definition 5.44 (p. 95) for the sum and product of ideals.

(a) Prove $(a) + (b) = (\gcd(a,b))$ — Example 5.45 (p. 95).

(b) Prove $(a)\cap(b) = (\operatorname{lcm}(a,b))$ — Example 5.46 (p. 95).

(c) Prove $(a)(b) = (ab)$ — Example 5.47 (p. 95).

(d) Show $IJ\subseteq I\cap J$ for **any** two ideals of any commutative ring, and determine exactly when equality holds in $\mathbb{Z}$.

<details><summary>Nudge</summary>
(a) is Bézout in the language of ideals: $(a)+(b)$ is the set of integer linear combinations $ma+nb$.
</details>
<details><summary>Strategy</summary>
(d) $\subseteq$ needs only absorption. For the equality condition, compare $|ab|$ with $\operatorname{lcm}(a,b)$.
</details>
<details><summary>Partial</summary>
(a) $(a)+(b) = \{ma+nb : m,n\in\mathbb{Z}\}$. Every such combination is divisible by $d=\gcd(a,b)$, so $(a)+(b)\subseteq(d)$; and $d$ itself is such a combination by Theorem 1.8 (p. 8), so $(d)\subseteq(a)+(b)$. **Bézout's theorem is the statement that this containment is an equality**, and in ideal language it is the statement that a sum of principal ideals is principal.

(b) $c \in (a)\cap(b)$ means $a \mid c$ and $b\mid c$, i.e. $c$ is a common multiple of $a$ and $b$; and the common multiples of $a$ and $b$ are exactly the multiples of $\operatorname{lcm}(a,b)$.
</details>
<details><summary>Worked start</summary>
(c) $(a)(b)$ consists of finite sums $\sum (r_ia)(s_ib) = \left(\sum r_is_i\right)ab$, each of which is a multiple of $ab$; and $ab = (1\cdot a)(1\cdot b)$ lies in $(a)(b)$. So $(a)(b)=(ab)$.

(d) For any ideals $I, J$ of a commutative ring, a generator $xy$ of $IJ$ with $x\in I$, $y\in J$ lies in $I$ by absorption (as $y\in R$) and in $J$ by absorption (as $x\in R$), hence in $I\cap J$; sums of such elements stay in the ideal $I\cap J$. So $IJ\subseteq I\cap J$ always, and the containment needs nothing but absorption.

In $\mathbb{Z}$, (b) and (c) turn the question into $(ab) = (\operatorname{lcm}(a,b))$, i.e. $|ab| = \operatorname{lcm}(a,b)$. Since $\gcd(a,b)\operatorname{lcm}(a,b) = |ab|$, equality holds **exactly when $\gcd(a,b)=1$**. With $a = b = 2$: $IJ = (4)$ and $I\cap J = (2)$, and the containment is strict. Lemma 5.51 (p. 97) is the general version of the easy direction, and $I + J = (1)$ — coprimality written as ideals — is its hypothesis.
</details>

## Problem 5 (medium–hard — the Chinese Remainder Theorem)

Let $R$ be a commutative ring and $I, J$ ideals with $I + J = (1)$.

(a) Prove Proposition 5.48 (p. 96): the map $\rho : R\to R/I\times R/J$, $r\mapsto(r+I,\,r+J)$, is surjective.

(b) Compute $\ker\rho$, and prove Lemma 5.51 (p. 97): $I\cap J = IJ$.

(c) Deduce Theorem 5.52 (p. 97): $R/IJ\cong R/I\times R/J$.

(d) Deduce Corollary 5.53 (p. 98) for $\mathbb{Z}$, and solve: find all integers $x$ with $x\equiv 2\bmod 3$, $x\equiv 3\bmod 5$, $x\equiv 2\bmod 7$.

<details><summary>Nudge</summary>
(a) Write $1 = i + j$ with $i\in I$, $j\in J$. To hit $(a+I, b+J)$, try $r = bi + aj$ — Remark 5.49 (p. 96).
</details>
<details><summary>Strategy</summary>
(b) $\ker\rho = I\cap J$ is immediate; the content is the reverse containment $I\cap J\subseteq IJ$, which uses $1 = i+j$ again.
</details>
<details><summary>Partial</summary>
(a) Let $1 = i + j$ with $i\in I$, $j\in J$, and set $r = bi + aj$. Then $r - a = bi + aj - a = bi + a(j-1) = bi - ai \in I$, so $r + I = a + I$; and $r - b = bi - b + aj = b(i-1) + aj \in J$, so $r+J = b+J$. Hence $\rho(r) = (a+I, b+J)$.
</details>
<details><summary>Worked start</summary>
(b) $\rho(r) = 0$ means $r\in I$ and $r\in J$, so $\ker\rho = I\cap J$. Now $IJ\subseteq I\cap J$ by Problem 4(d). Conversely let $r\in I\cap J$ and write $1 = i+j$; then
$$r = r\cdot 1 = ri + rj,$$
and $ri \in JI = IJ$ since $r\in J$ and $i\in I$, while $rj\in IJ$ since $r\in I$ and $j\in J$. So $r\in IJ$, and $I\cap J = IJ$. Commutativity is used here to identify $JI$ with $IJ$.

(c) $\rho$ is surjective by (a) with kernel $IJ$ by (b), so Theorem 5.38 (p. 91) gives $R/IJ\cong R/I\times R/J$.

(d) In $\mathbb{Z}$, $(n_1)+(n_2) = (\gcd(n_1,n_2)) = (1)$ exactly when $n_1, n_2$ are coprime — Problem 4(a). Iterating (c) over pairwise coprime $n_1,\dots,n_r$ with $N = n_1\cdots n_r$ gives $\mathbb{Z}/N\mathbb{Z}\cong\mathbb{Z}/n_1\mathbb{Z}\times\cdots\times\mathbb{Z}/n_r\mathbb{Z}$, which is Corollary 5.53.

For the system: $N = 3\cdot 5\cdot 7 = 105$. The moduli $3$ and $7$ carry the same residue, so $x\equiv 2\bmod 3$ and $x\equiv 2\bmod 7$ together say $x\equiv 2\bmod 21$; write $x = 2+21t$. Then $x\equiv 3\bmod 5$ reads $2 + 21t\equiv 3$, and $21\equiv 1\bmod 5$, so $t\equiv 1\bmod 5$. Hence $t = 1+5s$ and
$$x = 2 + 21(1+5s) = 23 + 105s.$$
Check: $23 = 21+2$, so $23\equiv 2\bmod 3$ ✓ and $23\equiv 2\bmod 7$ ✓; $23 = 20+3$, so $23\equiv 3\bmod 5$ ✓.

The solution set is a single class mod $105$, and that is not luck — it is the isomorphism read backwards. A solution is a preimage of one point of $\mathbb{Z}/3\mathbb{Z}\times\mathbb{Z}/5\mathbb{Z}\times\mathbb{Z}/7\mathbb{Z}$, and a bijection has exactly one of those. Existence and uniqueness of the answer are surjectivity and injectivity, one apiece.
</details>

## Problem 6 (hard — Euler's function, and quotients of quotients)

(a) Prove Proposition 5.56 (p. 100): if $a, b$ are relatively prime then $\phi(ab) = \phi(a)\phi(b)$, where $\phi(n)$ counts the units of $\mathbb{Z}/n\mathbb{Z}$.

(b) Compute $\phi(360)$.

(c) Prove Theorem 5.57 (p. 100), the Third Isomorphism Theorem: for ideals $I\subseteq J$ of $R$, $J/I$ is an ideal of $R/I$ and $(R/I)\big/(J/I)\cong R/J$.

(d) Apply (c) to $R=\mathbb{Z}$, $I = 12\mathbb{Z}$, $J = 3\mathbb{Z}$, and check the answer by counting.

(e) Identify $\mathbb{Z}[x]/(2,x)$ — Example 5.58 (p. 101).

<details><summary>Nudge</summary>
(a) The units of a product ring are the pairs of units. Combine with Corollary 5.53 (p. 98). (c) Apply the First Isomorphism Theorem to a map $R/I\to R/J$.
</details>
<details><summary>Strategy</summary>
(c) Send $a + I$ to $a + J$; this is well defined because $I\subseteq J$, and it is Proposition 5.39 (p. 91) applied to $\pi_J : R\to R/J$.
</details>
<details><summary>Partial</summary>
(a) $\gcd(a,b)=1$ gives $\mathbb{Z}/ab\mathbb{Z}\cong\mathbb{Z}/a\mathbb{Z}\times\mathbb{Z}/b\mathbb{Z}$ by Corollary 5.53. An element of a product is a unit exactly when both coordinates are — $(u,v)(u',v') = (1,1)$ if and only if $uu'=1$ and $vv'=1$ — so the unit count of the product is the product of the unit counts. Isomorphic rings have equally many units by Proposition 4.36 (p. 72), so $\phi(ab)=\phi(a)\phi(b)$.

(b) $360 = 2^3\cdot 3^2\cdot 5$, so $\phi(360) = \phi(8)\phi(9)\phi(5) = 4\cdot 6\cdot 4 = 96$.
</details>
<details><summary>Worked start</summary>
(c) $J/I = \{a + I : a\in J\}$ is an ideal of $R/I$: it is closed under addition, and $(r+I)(a+I) = ra + I$ with $ra\in J$ by absorption in $R$. Now let $\pi_J : R\to R/J$ be the projection; since $I\subseteq J = \ker\pi_J$, Proposition 5.39 (p. 91) gives a homomorphism $\widetilde{\pi_J} : R/I\to R/J$ with $a + I\mapsto a+J$. It is surjective because $\pi_J$ is, and its kernel is $\{a+I : a\in J\} = J/I$. Theorem 5.38 (p. 91) finishes it.

(d) $12\mathbb{Z}\subseteq 3\mathbb{Z}$, and $3\mathbb{Z}/12\mathbb{Z} = \{[0],[3],[6],[9]\}$, four elements. The theorem gives
$$(\mathbb{Z}/12\mathbb{Z})\big/(3\mathbb{Z}/12\mathbb{Z})\ \cong\ \mathbb{Z}/3\mathbb{Z}.$$
Counting agrees: $12/4 = 3$. Note the hypothesis $I\subseteq J$ is $12\mathbb{Z}\subseteq3\mathbb{Z}$, i.e. $3\mid 12$ — the containment of ideals runs opposite to the divisibility of the generators, which is worth fixing in mind now, because aa-11 reads maximality the same way round.

(e) $(2,x)$ is the ideal of linear combinations $2f(x) + xg(x)$, i.e. the polynomials with even constant term. Map $\mathbb{Z}[x]\to\mathbb{Z}/2\mathbb{Z}$ by $\alpha(x)\mapsto[\alpha(0)]_2$: this is a composition of the two surjective homomorphisms $e_0$ and $\mathbb{Z}\to\mathbb{Z}/2\mathbb{Z}$, hence a surjective homomorphism by Proposition 4.27 (p. 68), and its kernel is exactly $(2,x)$. So $\mathbb{Z}[x]/(2,x)\cong\mathbb{Z}/2\mathbb{Z}$, a field — and the ideal $(2,x)$ needs two generators, which is the first ideal in this module that is not principal.
</details>
