## Problem 1 (easy — what a zigzag filtration is) [interleaves tda1-04]

(a) Write down the general form of a zigzag filtration $\mathcal{F}$ and say
precisely what each $X_i \leftrightarrow X_{i+1}$ is allowed to be.
(b) Explain the sentence "reverse arrows can be interpreted as simplex
deletions", and say what this allows the complex to do that a filtration in the
sense of tda1-04 cannot.
(c) Write down the induced zigzag persistence module $\mathsf{H}_p\mathcal{F}$,
stating what kind of object sits at each node and on each arrow, and over which
coefficient field Dey and Wang work.
(d) Why is it *not obvious a priori* that such a module has a barcode? Name the
property of the ordinary filtration case that is no longer available.

*(Dey §4.3, pp. 125–126)*

<details><summary>Nudge</summary>
In tda1-04 every map was induced by an inclusion pointing the same way, so the
module was a sequence of maps all in one direction.
</details>
<details><summary>Strategy</summary>
(d) is asking what the one-parameter structure theorem actually used — the
directedness of the sequence, which let it be read as a graded module over
$\mathbf{k}[t]$.
</details>
<details><summary>Partial</summary>
$\mathcal{F}: X_0 \leftrightarrow X_1 \leftrightarrow \dots \leftrightarrow X_n$
where each arrow is a forward or a backward inclusion.
</details>
<details><summary>Worked start</summary>
(a) $\mathcal{F}: X_0 \leftrightarrow X_1 \leftrightarrow \cdots \leftrightarrow X_n$
where each $X_i$ is a subcomplex $K_i \subseteq K$ (or subspace
$\mathbb{T}_i \subseteq \mathbb{T}$) and each $X_i \leftrightarrow X_{i+1}$ is
either a forward inclusion $X_i \hookrightarrow X_{i+1}$ or a backward inclusion
$X_i \hookleftarrow X_{i+1}$.
(b) A backward inclusion $X_i \hookleftarrow X_{i+1}$ says $X_{i+1}$ sits inside
$X_i$, so moving forward along the filtration removes simplices. The complex may
therefore both grow and shrink, which a monotone filtration — where each step
only adds — cannot do.
(c) Taking $p$-th homology with coefficients in a field $\mathbf{k}$, which is
$\mathbb{Z}_2$ in Dey and Wang, gives
$\mathsf{H}_p\mathcal{F} : \mathsf{H}_p(X_0) \xleftrightarrow{\varphi_0} \mathsf{H}_p(X_1) \xleftrightarrow{\varphi_1} \cdots$:
a vector space at each node and a linear map on each arrow, pointing in whichever
direction the corresponding inclusion does.
(d) In the monotone case the module is a sequence of maps all pointing the same
way, which is what lets it be treated as a graded $\mathbf{k}[t]$-module and
decomposed by the structure theorem. With arrows in both directions there is no
single variable acting, so nothing in the tda1-04 argument applies and the
existence of a barcode has to be re-established — which quiver theory does.
</details>

## Problem 2 (easy — quivers and interval modules)

(a) State Definition 4.10 and say what makes a quiver representation of
$A_n$ type.
(b) State Definition 4.11 and describe the interval module
$\mathcal{I}_{[b,d]}$ explicitly: which vector spaces, which maps.
(c) State Theorem 4.10 and say exactly what it provides that Problem 1(d) said
was missing.
(d) Remark 4.2 observes that these bars differ from the ones defined in
Chapter 3 for non-zigzag filtrations. Explain the difference in the endpoints
and why the zigzag setting produces it.

*(Dey §4.3, Definition 4.10, Definition 4.11, Remark 4.2, Theorem 4.10, pp. 126–128)*

<details><summary>Nudge</summary>
An $A_n$-type quiver is finite and linear-shaped: every node has at most two
directed edges incident to it.
</details>
<details><summary>Strategy</summary>
For (d), ask what index set the interval module is non-zero on, and compare with
the half-open intervals of ordinary persistence.
</details>
<details><summary>Partial</summary>
$I_k = \mathbf{k}$ for $b \leq k \leq d$ and $0$ otherwise, all non-trivial maps
being identities.
</details>
<details><summary>Worked start</summary>
(a) Definition 4.10: a quiver $Q = (N,E)$ is a directed graph, finite or
infinite; a representation $\mathbb{V}(Q)$ assigns a vector space $V_i$ to each
node and a linear map $v_{ij} : V_i \to V_j$ to each directed edge. A zigzag
persistence module is the special case in which the graph is finite and linear
shaped — $A_n$ type — every node having at most two incident directed edges.
(b) Definition 4.11: $\mathcal{I}_{[b,d]} : I_0 \leftrightarrow I_1 \leftrightarrow \cdots \leftrightarrow I_n$
with $I_k = \mathbf{k}$ for $b \leq k \leq d$ and $0$ otherwise, and the maps
$\mathbf{k} \leftarrow \mathbf{k}$ and $\mathbf{k} \rightarrow \mathbf{k}$ being
identities. It is a single copy of $\mathbf{k}$ switched on over the index range
$[b,d]$ and off elsewhere.
(c) Theorem 4.10: every quiver representation of an $A_n$-type quiver has an
interval decomposition $\mathbb{V}(Q) \cong \bigoplus_i \mathcal{I}_{[b_i,d_i]}$,
unique up to isomorphism and permutation of the intervals. Since a zigzag
persistence module is of $A_n$ type, $\mathsf{H}_p\mathcal{F}$ decomposes into
intervals, and the multiset of those intervals is the barcode. That is exactly
what Problem 1(d) found was no longer supplied by the one-parameter argument.
(d) In Chapter 3's non-zigzag setting the bars are half-open, $[b,d)$: the class
exists at index $b$ and no longer exists at index $d$. Here the interval module
is non-zero precisely on the closed index range $b \leq k \leq d$, so the bar
$[b,d]$ is closed at both ends — the last index at which the class is present is
$d$ itself. The zigzag setting produces this because a class can be killed by a
*backward* arrow, so there is no next index at which to record a death in the
usual way; the interval simply stops.
</details>

## Problem 3 (medium — reading a zigzag barcode)

Dey's Figure 4.4 shows a zigzag filtration
$K_0 \leftrightarrow K_1 \leftrightarrow K_2 \leftrightarrow K_3 \leftrightarrow K_4$
whose one-dimensional homology has the four bars $[0,4]$, $[1,1]$, $[3,4]$ and
$[4,4]$.

(a) For each of the four bars, state at which indices the corresponding class is
present and at which it is absent.
(b) Using the decomposition of Theorem 4.10, write down
$\dim \mathsf{H}_1(K_i)$ for each $i = 0, \dots, 4$, and explain the counting
rule you used.
(c) The bar $[1,1]$ occupies a single index. Describe in words what must happen
at the arrows on either side of index $1$ for such a bar to arise, treating the
two possible arrow directions separately.
(d) Explain why the multiset of bars, and not merely the sequence of dimensions
$\dim \mathsf{H}_1(K_i)$, is what answers Ghrist's consistency question — "is it
the same hole?".

*(Dey §4.3, Figure 4.4, p. 126; Ghrist §5.15, pp. 108–109)*

<details><summary>Nudge</summary>
$\dim \mathsf{H}_1(K_i)$ is the number of bars whose closed index range contains
$i$.
</details>
<details><summary>Strategy</summary>
A direct sum of interval modules has, at each index, dimension equal to the
number of summands switched on there.
</details>
<details><summary>Partial</summary>
Index $4$ lies in $[0,4]$, $[3,4]$ and $[4,4]$, so
$\dim \mathsf{H}_1(K_4) = 3$.
</details>
<details><summary>Worked start</summary>
(a) $[0,4]$: present at every index $0$ to $4$. $[1,1]$: present only at index
$1$. $[3,4]$: present at $3$ and $4$. $[4,4]$: present only at $4$.
(b) Counting the bars containing each index: $\dim \mathsf{H}_1(K_0) = 1$,
$\dim \mathsf{H}_1(K_1) = 2$, $\dim \mathsf{H}_1(K_2) = 1$,
$\dim \mathsf{H}_1(K_3) = 2$, $\dim \mathsf{H}_1(K_4) = 3$. The rule is that the
decomposition $\bigoplus_i \mathcal{I}_{[b_i,d_i]}$ contributes one dimension at
index $k$ for every interval whose closed range contains $k$.
(c) A bar occupying only index $1$ means the class is present at index $1$ and is
matched to nothing at index $0$ or index $2$. Which condition expresses that
depends on which way each arrow points, and the rule is worth stating once:
**an arrow pointing into index $1$ gives an image condition; an arrow pointing
away from index $1$ gives a kernel condition.** So, at the left:

- forward, $\mathsf{H}_p(K_0) \to \mathsf{H}_p(K_1)$: the class is not in the
  image — it is newly born at $1$;
- backward, $\mathsf{H}_p(K_1) \to \mathsf{H}_p(K_0)$: nothing maps *into* index
  $1$ at all, so there is no image to be outside of. The condition is on the
  outgoing map — the class must go to zero in $\mathsf{H}_p(K_0)$. It is present
  at $1$ and absent at $0$ because the simplices carrying it are not in $K_0$.

And at the right:

- forward, $\mathsf{H}_p(K_1) \to \mathsf{H}_p(K_2)$: the class dies by mapping
  to zero — again a kernel condition;
- backward, $\mathsf{H}_p(K_2) \to \mathsf{H}_p(K_1)$: the class is not in the
  image of that map — an image condition.

The temptation is to say "not in the image from index $0$" in every left-hand
case, and for a backward left arrow that sentence names a map that does not
exist.
(d) The dimensions record only how many holes are present at each index; they
cannot distinguish "one hole surviving all samples" from "a different hole in
each sample". The bars record the *correspondence* — a bar spanning the whole
index range says a single class is carried across every map, which is Ghrist's
point that a long bar means a homological feature is sampled consistently, and
that the homology of a sequence is worth more than a sequence of homologies.
</details>

## Problem 4 (medium — representative cycles) [interleaves tda1-03]

(a) State Definition 4.12 and explain, clause by clause, what an indexed set of
$p$-cycles $\{c_i \mid i \in [b,d]\}$ must satisfy to be a set of representative
cycles for the bar $[b,d]$.
(b) State Theorem 4.11 and identify precisely what it strengthens: which word in
Theorem 4.10's conclusion does it upgrade, and to what?
(c) Explain why the hypothesis $\mathsf{H}_p(K_0) = 0$ appears in Theorem 4.11,
and give the geometric reading of that hypothesis for a filtration starting from
the empty complex.
(d) Why is a *representative* cycle a more useful output than the bar alone?
Give one concrete use, and say what at2-08 required of a representative for a
quite different purpose.

*(Dey §4.3, Definition 4.12 and Theorem 4.11, pp. 129–131)*

<details><summary>Nudge</summary>
Theorem 4.10 gives an isomorphism; Theorem 4.11 gives an equality.
</details>
<details><summary>Strategy</summary>
For (b), read the two statements side by side and notice that "is equal to (not
merely isomorphic to)" is doing all the work.
</details>
<details><summary>Partial</summary>
For $b > 0$, $[c_b]$ is required not to be in the image of $\varphi_{b-1}$ when
the arrow points forward into index $b$.
</details>
<details><summary>Worked start</summary>
(a) Definition 4.12 asks for a $p$-cycle $c_i \subseteq K_i$ for each index $i$
in $[b,d]$, such that the classes $[c_i]$ are carried to one another by the maps
of the module across the interval, and such that the bar genuinely begins at $b$
and ends at $d$: for $b > 0$ the class $[c_b]$ is not in the image of
$\varphi_{b-1}$ when that arrow points into index $b$, and symmetrically at the
right endpoint. The indexed set thus realises the interval module
$\mathcal{I}_{[b,d]}$ concretely, by actual cycles in the complexes rather than
by abstract vector spaces.
(b) Theorem 4.11 says that, under its hypothesis, $\mathsf{H}_p\mathcal{F}$ is
*equal* to — not merely isomorphic to — a direct sum of interval submodules,
precisely when each summand is induced by a set of representative $p$-cycles.
It upgrades Theorem 4.10's "isomorphic to" into "equal to", at the price of
requiring the representatives.
(c) The hypothesis $\mathsf{H}_p(K_0) = 0$ removes classes already present at the
start, which have no birth inside the filtration and so no representative set
beginning at their birth index. Geometrically it is the normalisation that the
filtration begins with nothing — the empty complex has no $p$-cycles at all for
$p \geq 0$ apart from the degenerate case, so every class one meets is born
somewhere in the sequence.
(d) A bar tells you a feature exists and how long it lasts; a representative
tells you *where* in the data it is, which is what allows a feature to be
localised, visualised, or fed to a downstream computation. In at2-08 the
requirement was different in kind: there the representative cocycle was the
object that had to be lifted to integral coefficients and then smoothed, so the
class alone was useless — only an actual cochain can be smoothed and integrated.
</details>

## Problem 5 (hard — levelset zigzag and what it recovers)

(a) State Definition 4.14, explaining what a regular interval is and what it
means for $f$ to be of Morse type.
(b) State Definition 4.15 and explain why barycentric subdivision can always
make a complex compatible with the levelsets of a PL-function.
(c) State Proposition 4.14 and say what it licenses: why may one compute with
the simplicial levelset zigzag filtration instead of the space-level one?
(d) The sublevel-set filtration of tda1-08 has bars of just two kinds,
$[a_i, a_j)$ with $j \leq n$ and $[a_i, \infty)$. State Theorem 4.15 in full and
explain what it says about each of these two kinds. In particular, say what
becomes of an *essential* class — one whose sublevel-set bar is infinite — in
the levelset picture, and why the levelset barcode needs four kinds of endpoint
where the sublevel-set barcode needed one.

*(Dey §4.5, Definition 4.14 p. 138, Definition 4.15 and Proposition 4.14 pp. 140–141,
the two types of sublevel-set bar and Theorem 4.15, pp. 142–143)*

<details><summary>Nudge</summary>
In Theorem 4.15(b) an infinite sublevel-set bar corresponds to a closed-closed
levelset bar in the same degree, or to an open-open levelset bar one degree
down.
</details>
<details><summary>Strategy</summary>
The sublevel-set filtration only ever grows, so its bars are always closed on
the left and open on the right. The levelset zigzag can start and stop for two
different reasons at each end, which is what multiplies the endpoint types.
</details>
<details><summary>Partial</summary>
$\mathcal{X}: X_{[0,0]} \to X_{[0,1]} \to \cdots \to X_{[0,n]}$ with
$X_{[0,i]} = f^{-1}(-\infty, s_i]$ for $s_i$ a regular value in
$(a_i, a_{i+1})$.
</details>
<details><summary>Worked start</summary>
(a) Definition 4.14: an open interval $I \subseteq \mathbb{R}$ is a regular
interval if there is a space $Y$ and a homeomorphism
$\Phi : Y \times I \to X_I$ with $f \circ \Phi$ the projection onto $I$, and
$\Phi$ extending continuously to the closure. $f$ is of Morse type if each
levelset $X_{=s}$ has finitely generated homology and there are finitely many
critical values $a_0 = -\infty < a_1 < \cdots < a_n < a_{n+1} = +\infty$, the
complementary open intervals being regular.
(b) Definition 4.15: $K$ is compatible with the levelsets of a PL-function
$f : |K| \to \mathbb{R}$ if for every simplex $\sigma$, the function values on
$|\sigma|$ contain at most one critical value. Barycentric subdivision suffices
because it can be iterated to make simplices as small as required, and the
critical values are finite in number and separated, so eventually no simplex
spans two of them.
(c) Proposition 4.14: for $K$ compatible with the levelsets and $X = |K|$, the
interval set $X_{(a_i,a_j)}$ deformation retracts to $|K_{(i,j)}|$ for any two
critical values $a_i < a_j$; therefore the zigzag modules induced by the space
and the simplicial levelset zigzag filtrations are isomorphic. This licenses
computing with the finite simplicial object and reading the answer as a
statement about the space.
(d) The sublevel-set diagram is
$\mathcal{X}: X_{[0,0]} \to \cdots \to X_{[0,n]}$, with bars $[a_i,a_j)$ —
closed on the left because the class exists at $K_{[0,i]}$, open on the right
because it does not exist at $K_{[0,j]}$ — of which the ones with
$j = n+1$ are the infinite bars, corresponding to essential classes since
$\mathsf{H}_p(K) \cong \bigoplus_i [a_i,\infty)$. Theorem 4.15 states: (a) for
$j \neq n+1$, $[a_i,a_j)$ is a bar of $\mathrm{Dgm}_p(\mathcal{K})$ iff it is a
bar of $\mathrm{Dgm}_p(\mathcal{K}')$; (b) $[a_i, a_{n+1})$ is a bar of
$\mathrm{Dgm}_p(\mathcal{K})$ iff either $[a_i,a_j]$ is a closed-closed bar of
$\mathrm{Dgm}_p(\mathcal{K}')$ for some $a_j > a_i$, or $(a_j,a_i)$ is an
open-open bar of $\mathrm{Dgm}_{p-1}(\mathcal{K}')$ for some $a_j < a_i$.
So finite sublevel-set bars transfer unchanged, while an essential class is
recorded in the levelset barcode either as a closed-closed bar in the same
degree or as an open-open bar one degree down — the infinite bar is replaced by
finite information, which is the practical gain. The four endpoint types are
needed because a levelset zigzag bar can begin or end for two distinct reasons
at each end — the class fails to come from the previous term, or fails to map
into the next — and the direction of the adjoining arrow decides which, whereas
a monotone filtration only ever offers one of the two.
</details>
