## Problem 1 (easy — six sets, one definition) [interleaves an-07]

Decide which of the following are compact. For each one that is not, exhibit a sequence in it with no subsequence converging to a limit in the set — that is, show exactly how Definition 3.3.1 fails.

(a) $\mathbb{Q}$  (b) $\mathbb{Q} \cap [0,1]$  (c) $\mathbb{R}$  (d) $\mathbb{R} \cap [0,1]$  (e) $\{1, 1/2, 1/3, 1/4, \dots\}$  (f) $\{1, 1/2, 2/3, 3/4, 4/5, \dots\}$

*(Abbott §3.3, Exercise 3.3.5, p. 88)*

<details><summary>Nudge</summary>
Theorem 3.3.4 decides every case in one line each. The work the problem actually asks for is the *sequence* witnessing failure, which the theorem does not hand you.
</details>
<details><summary>Strategy</summary>
Classify first with closed-and-bounded, then construct. For an unbounded set take a sequence marching to infinity; for a bounded but non-closed set take a sequence converging to a missing limit point.
</details>
<details><summary>Partial</summary>
(a) Not compact: unbounded, and $x_n = n$ has no convergent subsequence. (b) Not compact: bounded but not closed, since an-07's Theorem 3.2.10 makes every real in $[0,1]$ a limit point; take rationals increasing to $1/\sqrt{2}$, so every subsequence converges to an irrational. (c) Not compact: unbounded. (d) Compact: $\mathbb{R} \cap [0,1] = [0,1]$, closed and bounded.
</details>
<details><summary>Worked start</summary>
(e) Not compact. The set is bounded by 1 but omits its only limit point 0, as an-07's Example 3.2.9 showed. The sequence $x_n = 1/n$ lies in the set, and by an-04's Theorem 2.5.2 every subsequence of it also converges to 0, which is not in the set.

(f) Compact. Writing the terms as $x_1 = 1$ and $x_n = (n-1)/n$ for $n \ge 2$, the set is bounded by 1 and its only limit point is 1, which is in the set (it is the first listed element). So the set is closed and bounded.

The moral to record: (e) and (f) look alike and differ by whether the limit point is a member. That single point is the whole difference between compact and not, which is why Definition 3.3.1 asks for the limit to be *in* the set rather than merely to exist.
</details>

## Problem 2 (medium — the same failures, seen through covers)

For each set in Problem 1 that is not compact, find an open cover of it that has no finite subcover.

*(Abbott §3.3, Exercise 3.3.9, p. 89)*

<details><summary>Nudge</summary>
There are two shapes of failure, matching the two hypotheses of Theorem 3.3.4. Unbounded sets need a cover that grows outwards; non-closed sets need a cover that avoids the missing limit point.
</details>
<details><summary>Strategy</summary>
For an unbounded set use $O_n = (-n, n)$. For a set missing the limit point $p$, use the complements of shrinking closed neighbourhoods of $p$ — concretely, $O_n = \{x : |x - p| > 1/n\}$, which is open by an-07's Theorem 3.2.13.
</details>
<details><summary>Partial</summary>
For (a) and (c): $\{(-n, n) : n \in \mathbb{N}\}$ covers all of $\mathbb{R}$, but any finite subcollection is contained in the largest one, $(-N, N)$, which misses the point $N$. For (e), with missing limit point $0$: the sets $O_n = (1/n, 2)$ cover $\{1/k : k \in \mathbb{N}\}$, since each $1/k$ lies in $O_n$ for any $n > k$.
</details>
<details><summary>Worked start</summary>
Finish (e) by the argument of Example 3.3.7: a finite subcollection $O_{n_1}, \dots, O_{n_j}$ has union $(1/N, 2)$ where $N = \max\{n_1, \dots, n_j\}$, and the point $1/(N+1)$ of the set is not in it. As in the lesson, it is a maximum over a *finite* set that makes the argument work, and the same sentence would be false for the whole collection.

For (b), $\mathbb{Q} \cap [0,1]$ with missing limit point $p = 1/\sqrt{2}$: take $O_n = \{x : |x - p| > 1/n\}$. Each is open as the complement of a closed set, together they cover every rational in $[0,1]$ because no rational equals $p$, and a finite subcollection is the single largest set $\{x : |x - p| > 1/N\}$, which omits every rational within $1/N$ of $p$ — and there are such rationals by density.

Write one sentence at the end connecting the two problems: a cover with no finite subcover is precisely the negation of Theorem 3.3.8(iii), and each cover above was built out of the same feature of the set that broke Definition 3.3.1 in Problem 1.
</details>

## Problem 3 (medium — five propositions)

Decide whether each is true or false, with a short proof or a counterexample.

(a) An arbitrary intersection of compact sets is compact.
(b) If $A \subseteq \mathbb{R}$ is arbitrary and $K$ is compact, then $A \cap K$ is compact.
(c) If $F_1 \supseteq F_2 \supseteq F_3 \supseteq \cdots$ is a nested sequence of nonempty closed sets, then $\bigcap_{n=1}^{\infty} F_n \ne \emptyset$.
(d) A finite set is always compact.
(e) A countable set is always compact.

*(Abbott §3.3, Exercise 3.3.7, p. 88)*

<details><summary>Nudge</summary>
For (c), compare against Theorem 3.3.5 and ask which hypothesis has been dropped. Then look for closed sets that escape to infinity.
</details>
<details><summary>Strategy</summary>
(a) and (d) are true and short. (b) and (e) are false, and one counterexample serves for both. (c) is false and is the instructive one, because it isolates exactly what Theorem 3.3.5 is buying with the word "compact".
</details>
<details><summary>Partial</summary>
(a) True **for a nonempty family**, and the qualification is worth saying out loud rather than letting it pass, because the proof itself is what tells you it is needed. An intersection of closed sets is closed by an-07's Theorem 3.2.14; the intersection is bounded because it sits inside any one member — and to sit inside a member you must have one.

Under the standard convention an intersection over the empty family is the whole ambient set, so $\bigcap \emptyset = \mathbb{R}$, which is closed, unbounded and emphatically not compact. As literally quantified the proposition is therefore false on a technicality, and the technicality is precisely the step the proof used without comment. The substance of "arbitrary intersection" is that no restriction is placed on the *size* of the family — not that the family may be absent — so answer the intended question and record the boundary case beside it.

(d) True: a finite set is bounded, and closed by an-07's vacuous-limit-point argument. The empty set is finite and is compact, vacuously — every sequence in it has a convergent subsequence, there being no sequences in it. Degenerate inputs go the proposition's way here and against it in (a), which is the argument for checking them rather than assuming.
</details>
<details><summary>Worked start</summary>
(b) False. Take $K = [0,1]$, which is compact, and $A = (0,1)$; then $A \cap K = (0,1)$, which is bounded but not closed. The true statement is Exercise 3.3.4: the intersection is compact when $A$ is *closed*.

(e) False, and (b)'s counterexample nearly suffices; more simply, $\mathbb{N}$ is countable and unbounded, and $\{1/n\}$ is countable, bounded and not closed. Countability has nothing to do with compactness in either direction — $[0,1]$ is compact and uncountable.

(c) False. Take $F_n = [n, \infty)$, each closed and nonempty and nested, with empty intersection: no real number is at least $n$ for every $n$. Comparing this with Theorem 3.3.5 shows what the compactness hypothesis pays for — boundedness, which is what stops the sets escaping. A second counterexample worth noting, if you want the sets bounded as well as closed, is harder to find, and that is not an accident: nested nonempty *compact* sets always meet.
</details>

## Problem 4 (medium-hard — closing the equivalence)

Follow these steps to prove the implication of Theorem 3.3.8 not proved in the lesson: if $K$ is closed and bounded, then every open cover of $K$ has a finite subcover.

*(Abbott §3.3, Exercise 3.3.8, p. 88)*

<details><summary>Nudge</summary>
Argue by contradiction and bisect. If some open cover of $K \subseteq [-M, M]$ has no finite subcover, then one half of the interval must also fail to be finitely covered.
</details>
<details><summary>Strategy</summary>
Let $I_0 = [-M, M]$ contain $K$ and suppose the cover $\{O_\lambda\}$ has no finite subcover of $K$. Bisect: if both halves met $K$ in a finitely coverable piece, joining the two finite subcovers would finitely cover $K$. So some half fails; call it $I_1$ and repeat. Use the nested intervals to produce a point, then derive a contradiction from the single open set containing it.
</details>
<details><summary>Partial</summary>
The construction gives nested closed intervals $I_0 \supseteq I_1 \supseteq I_2 \supseteq \cdots$ with lengths $2M/2^n \to 0$, such that $K \cap I_n$ has no finite subcover from $\{O_\lambda\}$; in particular each $K \cap I_n$ is nonempty, since the empty set is covered by the empty subcollection. By an-01's Nested Interval Property there is a point $x$ in every $I_n$, and choosing $x_n \in K \cap I_n$ gives a sequence converging to $x$ — because $|x_n - x| \le 2M/2^n$.
</details>
<details><summary>Worked start</summary>
Since $K$ is closed and each $x_n \in K$, an-07's Theorem 3.2.8 gives $x \in K$. The collection covers $K$, so $x \in O_{\lambda_0}$ for some single index, and $O_{\lambda_0}$ is open, so $V_\epsilon(x) \subseteq O_{\lambda_0}$ for some $\epsilon > 0$. Now take $n$ large enough that $2M/2^n < \epsilon$; since $x \in I_n$ and $I_n$ has length below $\epsilon$, the whole of $I_n$ lies inside $V_\epsilon(x)$, hence inside $O_{\lambda_0}$.

But then $K \cap I_n$ is covered by the single set $O_{\lambda_0}$ — a finite subcover — contradicting the construction. So no such cover exists.

Two comments earn the marks. Say why each $K \cap I_n$ is nonempty, since the argument silently needs it to choose $x_n$. And note the shape: this is an-04's bisection proof of Bolzano-Weierstrass with "infinitely many terms" replaced by "no finite subcover" as the property propagated downwards. Recognising that a proof technique transfers when the propagated property changes is worth more than the theorem.
</details>

## Problem 5 (hard — an unexpectedly large sum)

Let $C$ be the Cantor set of Abbott's Section 3.1. Show that $C + C = \{x + y : x, y \in C\}$ is the whole closed interval $[0, 2]$, even though $C$ has zero length and contains no interval.

(a) Show that for each $n$ there are $x_n, y_n \in C_n$ with $x_n + y_n = s$, where $C_n$ is the $n$-th stage of the construction and $s \in [0,2]$ is given.
(b) The sequences $(x_n)$ and $(y_n)$ need not converge. Show how to produce nevertheless the required $x, y \in C$ with $x + y = s$.

*(Abbott §3.3, Exercise 3.3.6, p. 88)*

<details><summary>Nudge</summary>
For (b) you have two bounded sequences and you need both to converge at once. Extract a convergent subsequence from one, then extract again from the corresponding terms of the other.
</details>
<details><summary>Strategy</summary>
Part (a) is an induction on $n$, and it is the part with real content — do not wave at it. The lever is that $C_{n+1}$ is built from $C_n$ by two similarities, so $C_{n+1} + C_{n+1}$ can be expressed in terms of $C_n + C_n$ and the inductive hypothesis applied directly. For (b), apply Theorem 2.5.5 twice and use that each $C_n$ is closed with $C = \bigcap C_n$.
</details>
<details><summary>Partial</summary>
By Theorem 2.5.5 the bounded sequence $(x_n)$ has a convergent subsequence $(x_{n_k}) \to x$. Now look at the matching terms $(y_{n_k})$, which are also bounded; extract a further subsequence converging to some $y$. Along that final index set both sequences converge, and $x_{n} + y_{n} = s$ throughout, so $x + y = s$ by an-03's Algebraic Limit Theorem.
</details>
<details><summary>Worked start</summary>
**Part (a), in full**, because this is where the theorem is actually proved and "one checks that $C_n + C_n = [0,2]$" is not a proof of it.

Write the construction as two similarities. Removing middle thirds means
$$C_{n+1} = \tfrac13 C_n \ \cup\ \left(\tfrac23 + \tfrac13 C_n\right),$$
where $\lambda S = \{\lambda t : t \in S\}$ and $c + S = \{c + t : t \in S\}$. Check it once at the bottom: $C_0 = [0,1]$ gives $\frac13[0,1] \cup (\frac23 + \frac13[0,1]) = [0,\frac13] \cup [\frac23, 1] = C_1$, as it should.

*Claim: $C_n + C_n = [0,2]$ for every $n \ge 0$.*

*Base.* $C_0 + C_0 = [0,1] + [0,1] = [0,2]$.

*Step.* Assume $C_n + C_n = [0,2]$. Adding one of the two pieces of $C_{n+1}$ to the other gives three sets, and each is a scaled and shifted copy of $C_n + C_n$:
$$\tfrac13 C_n + \tfrac13 C_n = \tfrac13(C_n + C_n) = \tfrac13[0,2] = [0, \tfrac23],$$
$$\tfrac13 C_n + \left(\tfrac23 + \tfrac13 C_n\right) = \tfrac23 + \tfrac13(C_n+C_n) = [\tfrac23, \tfrac43],$$
$$\left(\tfrac23 + \tfrac13 C_n\right) + \left(\tfrac23 + \tfrac13 C_n\right) = \tfrac43 + \tfrac13(C_n+C_n) = [\tfrac43, 2].$$
Their union is $[0,\frac23] \cup [\frac23,\frac43] \cup [\frac43,2] = [0,2]$, and all three are contained in $C_{n+1} + C_{n+1}$. The reverse inclusion is immediate since $C_{n+1} \subseteq [0,1]$. Hence $C_{n+1} + C_{n+1} = [0,2]$, closing the induction. ∎

Notice the three intervals abut exactly, at $\frac23$ and $\frac43$: nothing is left over and nothing to spare. That is why the result is true at all, and it is what "$C$ has zero length" fails to predict — length is lost under the construction, but the *sum* set loses nothing, because two thirds add to a whole.

So for the given $s \in [0,2]$ and each $n$ there are $x_n, y_n \in C_n$ with $x_n + y_n = s$. What (a) does **not** give is any compatibility between the choices at different stages, which is exactly why (b) is a separate problem and why it needs subsequences rather than a limit.

**Part (b).** It remains to see $x \in C$ and $y \in C$. Fix $m$. For all indices beyond $m$ the terms $x_n$ lie in $C_n \subseteq C_m$, so the tail of the subsequence lies in the closed set $C_m$, and an-07's Theorem 3.2.8 puts the limit $x$ in $C_m$. Since $m$ was arbitrary, $x \in \bigcap_m C_m = C$, and the same for $y$.

The double extraction in the Partial is the step to write out rather than wave at: a subsequence of a subsequence is a subsequence, so the final index set works for both sequences simultaneously, and choosing them independently would give two unrelated index sets and no equation to pass to the limit.

Then say what the result shows. $C$ is compact, uncountable, has empty interior and, in the sense of length, is negligible; and yet adding it to itself fills an interval. Sets can be small in one sense and large in another, which is exactly the observation that dimension theory -- and the mission's fractal dimension for $C$ -- is built to make precise.
</details>

## Problem 6 (hard — a definition that collapses)

Call a set *clompact* if every cover of it by *closed* sets admits a finite subcover. Describe all the clompact subsets of $\mathbb{R}$, with proof.

*(Abbott §3.3, Exercise 3.3.10, p. 89)*

<details><summary>Nudge</summary>
Try to cover a set by closed sets in the most wasteful way possible. Single points are closed.
</details>
<details><summary>Strategy</summary>
Given any set $A$, the collection $\{\{a\} : a \in A\}$ is a cover of $A$ by closed sets. Ask what a finite subcover of *that* cover would have to be.
</details>
<details><summary>Partial</summary>
A finite subcollection of $\{\{a\} : a \in A\}$ is a finite set of points, and its union contains $A$ only if $A$ is itself finite. So a clompact set must be finite.
</details>
<details><summary>Worked start</summary>
Conversely every finite set is clompact: if $A = \{a_1, \dots, a_n\}$ is covered by any collection whatsoever, choose for each $a_i$ one member of the cover containing it, and those $n$ members form a finite subcover. Note this argument never used closedness, so a finite set has the finite-subcover property for *every* kind of cover.

Hence the clompact sets are exactly the finite sets.

The point of the exercise is what it says about Theorem 3.3.8(iii). Requiring a finite subcover from every cover is far too strong a demand in general; it is only interesting because the covers are restricted to open ones, and openness is what lets a single set do the work of infinitely many near a limit point. Say that explicitly -- a definition that collapses to the trivial case is telling you which hypothesis was carrying the content.
</details>
