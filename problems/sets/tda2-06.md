## Problem 1 (easy — the quotient that defines the graph) [interleaves top-12]

(a) State Definition 7.1 in full: the equivalence relation $\sim$, both of its
conditions, and what the Reeb graph $\mathsf{R}_f$ is as a space. Name the
quotient map.
(b) What is a *contour*? Say, in one sentence, what the quotient does to each
contour.
(c) $f$ is constant on each contour. Use that to define the induced function
$\tilde{f} : \mathsf{R}_f \to \mathbb{R}$ and check it is well defined.
(d) Definition 7.1 alone does not guarantee that $\mathsf{R}_f$ is a graph. State
the standing hypothesis Dey and Wang impose from that point on, both of its
clauses, and name two classes of function known to satisfy it.

*(Dey §7.1, Definition 7.1 and the levelset-tameness hypothesis, pp. 208–209)*

<details><summary>Nudge</summary>
The quotient topology on $X/\sim$ is top-12's construction; the only new content
is which relation you quotient by.
</details>
<details><summary>Strategy</summary>
For (c), "well defined" means: independent of the representative chosen in
$\Phi^{-1}(z)$. That is exactly condition (i) of the relation.
</details>
<details><summary>Partial</summary>
Levelset tameness has two clauses — one about the components of each levelset,
one about $f$ being of Morse type in the sense of Definition 4.14.
</details>
<details><summary>Worked start</summary>
(a) Definition 7.1: define $x \sim y$ if and only if (i) $f(x) = f(y) = \alpha$
and (ii) $x$ and $y$ belong to the same connected component of the levelset
$f^{-1}(\alpha)$. Writing $[x]$ for the class of $x$, the Reeb graph
$\mathsf{R}_f$ of $f : X \to \mathbb{R}$ is the quotient space $X/\sim$ — the set
of equivalence classes with the quotient topology. The quotient map is
$\Phi : X \to \mathsf{R}_f$, $x \mapsto [x]$.
(b) A levelset may have several connected components; each one is a *contour*.
The quotient collapses each contour to a single point of $\mathsf{R}_f$.
(c) Set $\tilde{f}(z) = f(x)$ for any pre-image $x \in \Phi^{-1}(z)$. Any two
pre-images of $z$ are equivalent, and condition (i) of $\sim$ says equivalent
points have the same $f$-value, so the choice of $x$ does not matter. Dey and
Wang usually write $f(z)$ for $\tilde{f}(z)$ and keep the tilde only to
emphasise the different domains.
(d) From Definition 7.1 onwards they tacitly assume $f$ is *levelset tame*:
(i) each levelset $f^{-1}(a)$ has finitely many components and each component is
path connected; and (ii) $f$ is of Morse type (Definition 4.14). Morse functions
on a compact smooth manifold and PL-functions on finite simplicial complexes are
both levelset tame. Under such a hypothesis $\mathsf{R}_f$ is a finite
one-dimensional regular CW complex — a graph, which is what the name promises.
</details>

## Problem 2 (easy — critical points, and the tree variants)

(a) A Reeb graph is viewed as a graph $(V,E)$ with $\tilde{f}$ monotone along
each edge. Explain how that view is arranged when $\tilde{f}$ is not already
monotone on an edge, and why only finitely many new nodes are needed.
(b) Define the up-degree and down-degree of a node, and give the resulting
classification: regular, minimum, maximum, down-fork, up-fork. Give an example of
a degenerate critical point.
(c) Dey and Wang say the Reeb graph together with its function is completely
described, up to function-preserving homeomorphism, by the function values at the
critical points. Which property of the regular points is doing that work?
(d) State Definition 7.2, both trees. Name the loop-free Reeb graph, and say what
a *Reeb space* is and how it differs.

*(Dey §7.1, the critical-point classification pp. 210, "Variants of Reeb Graphs"
and Definition 7.2, pp. 210–211)*

<details><summary>Nudge</summary>
Up-degree counts incident edges with higher $\tilde{f}$-value; down-degree counts
those with lower.
</details>
<details><summary>Strategy</summary>
For (c), between two critical values nothing happens: the picture is a disjoint
union of arcs on which $\tilde{f}$ rises monotonically.
</details>
<details><summary>Partial</summary>
The merge tree uses the sublevel set $f^{-1}((-\infty,a])$, the split tree the
superlevel set $f^{-1}([a,+\infty))$.
</details>
<details><summary>Worked start</summary>
(a) If $\tilde{f}$ fails to be monotone along a 1-cell, insert a new node where
it fails. The tameness of $f$ guarantees only finitely many such nodes are
needed. One may insert further nodes into an edge, breaking it into several — the
augmented Reeb graph of Definition 7.3 is an instance.
(b) For a node $x \in V(\mathsf{R}_f)$, the up-degree (down-degree) is the number
of incident edges with higher (lower) $\tilde{f}$-value than $x$. A node is
*regular* if both are equal to $1$, and *critical* otherwise. A critical point is
a minimum if its down-degree is $0$, a maximum if its up-degree is $0$, a
down-fork if its down-degree exceeds $1$, and an up-fork if its up-degree exceeds
$1$. A point may carry more than one type of criticality: down-degree $0$ with
up-degree $2$ is both a minimum and an up-fork.
(c) Monotonicity of $\tilde{f}$ at regular points. Along an edge of regular
points $\tilde{f}$ climbs without turning, so nothing about the pair
$(\mathsf{R}_f,\tilde{f})$ is undetermined there beyond the two endpoint values —
a function-preserving homeomorphism can reparametrise the arc freely. All the
information is therefore concentrated at the critical values.
(d) Definition 7.2: define $x \sim_M y$ if and only if $f(x) = f(y) = a$ and $x$
is connected to $y$ within the sublevel set $f^{-1}((-\infty,a])$; the quotient
$T_M = X/\!\sim_M$ is the *merge tree*. Define $x \sim_S y$ if and only if
$f(x) = f(y) = a$ and $x$ is connected to $y$ within the superlevel set
$f^{-1}([a,+\infty))$; the quotient $T_S = X/\!\sim_S$ is the *split tree*. For
levelset tame $f$ both are finite trees, and when $\mathsf{R}_f$ is loop-free it
is called a *contour tree*, which is determined by and computable from the merge
and split trees. Replacing $\mathbb{R}$ by a general metric space $Z$ and taking
the same quotient for $f : X \to Z$ gives the *Reeb space*; it is the object
§9.3 generalises to in the mapper setting.
</details>

## Problem 3 (medium — computing it, and what the complexity rests on)

(a) Describe the pre-image graph $G_a = (W_a, F_a)$ of a PL-function on a
simplicial 2-complex: what its vertices and edges correspond to, and why its
connected components are the right thing to track. Why can its combinatorial
structure only change as the sweep passes a vertex of $K$?
(b) State Definition 7.3. Why is every critical point of $\mathsf{R}_f$ already
in $\Phi_f(V)$, and what does augmentation add?
(c) State Theorem 7.1. The sweep needs dynamic connectivity under insertions and
deletions, which is expensive in general. Explain the weighting trick that makes
it cheap here, and why the problem being *offline* is what licenses it.
(d) State Theorem 7.2. Give the worst-case running time of REEB-RANDOMALG and say
why randomising the vertex order improves the expectation. Why is the complex
returned in the last line necessarily a simplicial 1-complex?

*(Dey §7.2, the pre-image graph pp. 212–213, Definition 7.3 p. 212, REEB-SWEEPALG
and the time-complexity analysis pp. 214–216, Theorem 7.1 p. 217, the randomised
algorithm pp. 217–219, Theorem 7.2 p. 220)*

<details><summary>Nudge</summary>
For (c), the weight of a pre-image edge is the time at which it will be deleted.
</details>
<details><summary>Strategy</summary>
For (d), ask what has to be true of a vertex before it can be the mid-vertex of a
triangle.
</details>
<details><summary>Partial</summary>
Maintaining a *maximum* spanning forest under those weights means a deleted tree
edge never needs a replacement search.
</details>
<details><summary>Worked start</summary>
(a) For $K = (V,E,T)$ a simplicial 2-complex and a generic PL-function $f$, the
levelset $f^{-1}(a)$ meets edges of $E$ in points and triangles of $T$ in
segments. The pre-image graph $G_a = (W_a,F_a)$ records this: each vertex of
$W_a$ corresponds to an edge of $E$ cut by the levelset, and each edge of $F_a$
joins two such vertices and corresponds to a pair of edges of $E$ adjoining a
triangle of $T$. Connected components of $G_a$ correspond to connected components
of $f^{-1}(a)$, and $\Phi$ sends each to a single point of $\mathsf{R}_f$ — so
tracking components of $G_a$ is exactly tracking points of the Reeb graph. Since
$f$ is piecewise linear, the combinatorial structure of $G_a$ can only change
when the sweep passes a vertex $v \in V$, and then only simplices incident to $v$
are affected, giving $O(s_v)$ insertions and deletions for $s_v$ the number of
simplices incident on $v$.
(b) Definition 7.3: for a PL-function $f : |K| \to \mathbb{R}$ with Reeb graph
$\mathsf{R}_f$ and quotient map $\Phi_f$, the *augmented Reeb graph*
$\widehat{\mathsf{R}}_f$ is obtained by inserting every point of
$\Phi_f(V) = \{\Phi_f(v) : v \in V\}$ into $\mathsf{R}_f$ as a graph node, if not
already present. For a PL-function each critical point of $\mathsf{R}_f$ is
necessarily the image of some vertex of $K$, so the critical points form a subset
of $\Phi_f(V)$; augmentation adds the remaining images as degree-two nodes.
(c) Theorem 7.1: given a PL-function $f : |K| \to \mathbb{R}$ with $m$ the total
number of simplices in the 2-skeleton of $K$, one can compute the (augmented)
Reeb graph $\mathsf{R}_f$ in $O(m \log m)$ time. The trick: assign each pre-image
edge the weight equal to the time ($f$-value) at which it will be deleted, and
maintain a *maximum* spanning forest. In general, deleting a spanning-tree edge
$(u,v)$ forces a search for a replacement, since $u$ and $v$ may remain
connected; under this weighting no replacement is ever needed — a maximum
spanning tree edge being deleted simply breaks its tree. This is legitimate only
because the problem is offline: all insertions and deletions are known in
advance, so the deletion time of every edge can be precomputed and used as its
weight. Link-cut trees then give $O(\log m)$ amortised time per operation, and
$O(m)$ operations give $O(m \log m)$.
(d) Theorem 7.2: given a PL-function $f : |K| \to \mathbb{R}$ on a simplicial
2-complex $K$ with $m$ simplices, one can compute the (augmented) Reeb graph in
$O(m \log m)$ expected time. REEB-RANDOMALG collapses, for each vertex in turn,
the contour through that vertex; the cost for $v$ is proportional to the number
of triangles the contour $C_v$ meets, which in the worst case is $n_t$, giving a
worst-case $O(n_v n_t)$ that is tight. Processing in random order makes that
worst case unlikely: an original triangle is split $O(\log n_v)$ times in
expectation, so each collapse costs $O(\log m)$ expected time — an argument in
the spirit of the path length in a randomly built binary search tree. The final
complex $K_{n_v}$ has no vertex that is the mid-vertex of a triangle, which
forces it to contain no triangle at all, so it is a simplicial 1-complex; by
construction it is the augmented Reeb graph.
</details>

## Problem 4 (medium — what homology survives the collapse) [interleaves tda2-01]

(a) State Fact 7.1. Explain why the $\beta_0$ statement is an equality, and give
the consequence Dey and Wang draw for simply connected $X$.
(b) State Theorem 7.3, both cases. What extra hypotheses does it carry that
Fact 7.1 does not?
(c) Define the horizontal homology group $\overline{\mathsf{H}}_p(X)$ and the
vertical homology group $\check{\mathsf{H}}_p(X)$ with respect to $f$, and state
Fact 7.2. Why is $\overline{\mathsf{H}}_1(\mathsf{R}_f(X)) = 0$?
(d) State Theorem 7.4 and Proposition 7.5. Say what each buys: one is a
structural identification, the other a computational shortcut — name which is
which and what the shortcut saves.

*(Dey §7.2.3, Fact 7.1 and Theorem 7.3 p. 220, horizontal and vertical homology
and Fact 7.2 pp. 220–221, Theorem 7.4 p. 222, Proposition 7.5 p. 223)*

<details><summary>Nudge</summary>
Each equivalence class of $\sim$ is itself connected — it is a component of a
levelset.
</details>
<details><summary>Strategy</summary>
For (c), a levelset of the Reeb graph is a finite set of disjoint points, and a
finite set of points carries no 1-cycles.
</details>
<details><summary>Partial</summary>
Theorem 7.4 also asserts the equality of heights, $height(h) = height(\tilde{\Phi}(h))$.
</details>
<details><summary>Worked start</summary>
(a) Fact 7.1: for a tame function $f : X \to \mathbb{R}$,
$\beta_0(X) = \beta_0(\mathsf{R}_f)$ and $\beta_1(X) \geq \beta_1(\mathsf{R}_f)$.
The $\beta_0$ equality follows because $\mathsf{R}_f$ is the quotient $X/\sim$
and each equivalence class is itself connected, being a component of a levelset —
collapsing connected sets cannot change the number of components. The stated
consequence: if $X$ is simply connected then $\mathsf{R}_f$ is loop-free.
(b) Theorem 7.3: let $f : X \to \mathbb{R}$ be a Morse function on a connected
and compact 2-manifold. Then (a) if $X$ is orientable,
$\beta_1(\mathsf{R}_f) = \beta_1(X)/2$; and (b) if $X$ is non-orientable,
$\beta_1(\mathsf{R}_f) \leq \beta_1(X)/2$. Fact 7.1 asks only for tameness;
Theorem 7.3 additionally demands a *Morse* function on a *connected, compact
2-manifold*, and pays for it with an exact count in the orientable case.
(c) A class $h \in \mathsf{H}_p(X)$ is *horizontal* if there is a finite set of
values $\{a_i\}_{i \in A}$ such that $h$ has a pre-image under the inclusion-induced
map $\mathsf{H}_p(\bigcup_{i \in A} X_{=a_i}) \to \mathsf{H}_p(X)$. The horizontal
classes form a subgroup $\overline{\mathsf{H}}_p(X)$ — the trivial class is
horizontal and a sum of horizontal classes is horizontal — called the horizontal
homology group of $X$ with respect to $f$. The vertical homology group is the
quotient $\check{\mathsf{H}}_p(X) := \mathsf{H}_p(X)/\overline{\mathsf{H}}_p(X)$.
Fact 7.2: by definition,
$\mathrm{rank}(\mathsf{H}_p(X)) = \mathrm{rank}(\overline{\mathsf{H}}_p(X)) + \mathrm{rank}(\check{\mathsf{H}}_p(X))$.
And $\overline{\mathsf{H}}_1(\mathsf{R}_f(X)) = 0$ because levelset tameness makes
every levelset of $\mathsf{R}_f(X)$ a finite set of disjoint points, and a finite
union of finite point sets supports no nonzero 1-cycle.
(d) Theorem 7.4: for a levelset tame $f : X \to \mathbb{R}$, the homomorphism
$\tilde{\Phi} : \check{\mathsf{H}}_1(X) \to \mathsf{H}_1(\mathsf{R}_f(X))$ induced
by the surjection $\Phi$ is an isomorphism; furthermore
$height(h) = height(\tilde{\Phi}(h))$ for every vertical class $h$.
Proposition 7.5: $\mathrm{Dgm}_0(f^X) = \mathrm{Dgm}_0(f^R)$, the diagrams being
those of the zeroth levelset zigzag persistence. Theorem 7.4 is the structural
identification — it says precisely which part of $\mathsf{H}_1(X)$ the Reeb graph
retains, namely the vertical part, and that the collapse preserves heights.
Proposition 7.5 is the computational shortcut: the zeroth levelset zigzag diagram
of a function on a space may be read off the Reeb graph instead, and processing a
graph is far cheaper than processing the underlying space of a simplicial
complex. The proof is a commuting ladder between the two levelset zigzag modules
whose vertical maps are isomorphisms because $X_i^j$ and
$\mathsf{R}_i^j = X_i^j/\!\sim$ have the same number of components.
</details>

## Problem 5 (hard — two distances, their equivalence, and what may be claimed) [interleaves tda1-06]

(a) State Definition 7.4. Then explain the two limiting cases Dey and Wang use to
motivate the interleaving distance: what happens for $\varepsilon$ sufficiently
large, and what $\varepsilon = 0$ forces.
(b) State Definition 7.5 and Definition 7.6. Which of the two commutativity
requirements is the easy one, and which carries the interaction between $\phi$
and $\psi$?
(c) State Definition 7.7 and Definition 7.8. In what precise sense is
$\mathsf{d}_{FD}$ a function-adapted Gromov–Hausdorff distance — which two terms
of the definition would you drop, and what other hypothesis would you relax, to
recover the Gromov–Hausdorff distance itself?
(d) State Theorem 7.6, Definition 7.9, Theorem 7.7 and Definition 7.10. Then
write a short paragraph a practitioner could use: given two Reeb graphs built
from scalar fields on the same domain, what is provable about $\mathsf{d}_I$ and
$\mathsf{d}_{FD}$, what is known about universality, and what is the position on
actually computing any of it?

*(Dey §7.3, Definition 7.4 p. 224, Definition 7.5 p. 225, Definition 7.6 and
Definition 7.7 p. 226, Definition 7.8 and Theorem 7.6 p. 227, Definition 7.9
pp. 227–228, Theorem 7.7 and Definition 7.10 and the computation remarks p. 228)*

<details><summary>Nudge</summary>
$X_\varepsilon := X \times [-\varepsilon,\varepsilon]$, and
$f_\varepsilon(x,t) = f(x) + t$.
</details>
<details><summary>Strategy</summary>
For (d), separate three things: an equivalence between the two distances, a lower
bound by a computable quantity, and a hardness statement.
</details>
<details><summary>Partial</summary>
Theorem 7.6 reads $\mathsf{d}_{FD} \leq 3\mathsf{d}_I \leq 3\mathsf{d}_{FD}$, and
Theorem 7.7 reads
$\mathsf{d}_b(\mathrm{Dgm}_0(f),\mathrm{Dgm}_0(g)) \leq 2\mathsf{d}_I \leq 2\mathsf{d}_{FD}$.
</details>
<details><summary>Worked start</summary>
(a) Definition 7.4: given a Reeb graph $(\mathbb{F},f)$ and writing
$\mathbb{F}_\varepsilon := \mathbb{F} \times [-\varepsilon,\varepsilon]$, its
*$\varepsilon$-smoothing* $S_\varepsilon(\mathbb{F},f)$ is the Reeb graph of
$f_\varepsilon : \mathbb{F}_\varepsilon \to \mathbb{R}$,
$f_\varepsilon(x,t) = f(x) + t$; that is,
$S_\varepsilon(\mathbb{F},f) = \mathbb{F}_\varepsilon/\!\sim_{f_\varepsilon}$,
where $x \sim_{f_\varepsilon} y$ iff $x,y$ lie on the same contour of
$f_\varepsilon$. There is a natural quotiented-inclusion
$\iota(x) = [x,0]$. The two limits: for $\varepsilon$ sufficiently large,
$S_\varepsilon(A,f_a)$ degenerates to a single segment with monotone function
values, so $\varepsilon$-interleaved maps always exist eventually and the
infimum is over a nonempty set; and at $\varepsilon = 0$ the interleaving
conditions force $\psi = \phi^{-1}$, that is, an honest function-preserving
isomorphism. The smallest admissible $\varepsilon$ therefore measures how far the
graphs are from being identical.
(b) Definition 7.5: a pair of continuous maps
$\phi : (\mathbb{F},f) \to S_\varepsilon(\mathbb{G},g)$ and
$\psi : (\mathbb{G},g) \to S_\varepsilon(\mathbb{F},f)$ are
*$\varepsilon$-interleaved* if (i) both are function-preserving, and (ii) the
diagram built from $\iota, \iota_\varepsilon, \phi_\varepsilon, \psi_\varepsilon$
commutes. Definition 7.6: the *interleaving distance* is
$\mathsf{d}_I(\mathbb{F},\mathbb{G}) = \inf\{\varepsilon \mid$ there exists a pair
of $\varepsilon$-interleaved maps between $(\mathbb{F},f)$ and
$(\mathbb{G},g)\}$. The rectangular commutativity is the easy one — Dey and Wang
say it is easy to verify and it does not involve $\phi$ and $\psi$ together. The
*triangular* commutativity is the key technicality: it is what makes $\phi$ and
$\psi$ inverse to one another up to a shift of $2\varepsilon$. Both mirror the
rectangular and triangular commutativity of persistence-module interleaving in
Definition 3.16.
(c) Definition 7.7: for a path $\pi$ from $u$ to $v$ in $(A,f_a)$, put
$height(\pi) = \max_{x \in \pi} f_a(x) - \min_{x \in \pi} f_a(x)$; with
$\Pi(u,v)$ the set of paths from $u$ to $v$, the *function-induced metric* is
$\mathsf{d}_{f_a}(u,v) = \min_{\pi \in \Pi(u,v)} height(\pi)$ — equivalently the
minimum length of a closed interval $I$ with $u,v$ in the same path component of
$f_a^{-1}(I)$. Definition 7.8: for continuous $\Phi : \mathbb{F} \to \mathbb{G}$
and $\Psi : \mathbb{G} \to \mathbb{F}$, set
$C(\Phi,\Psi) = \{(x,y) : \Phi(x) = y \text{ or } x = \Psi(y)\}$ and
$D(\Phi,\Psi) = \sup_{(x,y),(x',y') \in C} \tfrac{1}{2}|\mathsf{d}_f(x,x') - \mathsf{d}_g(y,y')|$;
the *functional distortion distance* is
$\mathsf{d}_{FD}(\mathbb{F},\mathbb{G}) = \inf_{\Phi,\Psi} \max\{D(\Phi,\Psi), \|f - g \circ \Phi\|_\infty, \|g - f \circ \Psi\|_\infty\}$.
Drop the two sup-norm terms — which are what bound the discrepancy in function
values, since $\Phi$ and $\Psi$ are *not* required to preserve them — and relax
the requirement that $\Phi$ and $\Psi$ be continuous, and what remains is exactly
the Gromov–Hausdorff distance between the metric spaces
$(\mathbb{F},\mathsf{d}_f)$ and $(\mathbb{G},\mathsf{d}_g)$.
(d) Theorem 7.6 (bi-Lipschitz equivalence):
$\mathsf{d}_{FD} \leq 3\mathsf{d}_I \leq 3\mathsf{d}_{FD}$. Definition 7.9: a
Reeb graph distance $\mathsf{d}_R$ is *stable* if
$\mathsf{d}_R((\mathbb{F},\tilde{f}),(\mathbb{G},\tilde{g})) \leq \|f - g\|_\infty$
for $f,g : X \to \mathbb{R}$ with Reeb graphs $\mathbb{F}, \mathbb{G}$.
Theorem 7.7:
$\mathsf{d}_b(\mathrm{Dgm}_0(f),\mathrm{Dgm}_0(g)) \leq 2\mathsf{d}_I(\mathbb{F},\mathbb{G}) \leq 2\mathsf{d}_{FD}(\mathbb{F},\mathbb{G})$.
Definition 7.10: a Reeb graph distance $\mathsf{d}_U$ is *universal* if (i)
$\mathsf{d}_U$ is stable and (ii) $\mathsf{d}_S \leq \mathsf{d}_U$ for every other
stable Reeb graph distance $\mathsf{d}_S$. For the practitioner: the two distances
are interchangeable up to the factor $3$ of Theorem 7.6, so a claim about one is
a claim about the other up to that constant; both are stable for Reeb graphs of
nice functions on a common domain, so a perturbation of the field by $\delta$ in
sup-norm moves either distance by at most $\delta$; and Theorem 7.7 gives a
computable lower bound, the bottleneck distance between the zeroth levelset
zigzag diagrams, which by Proposition 7.5 may be computed on the graphs
themselves. Neither $\mathsf{d}_I$ nor $\mathsf{d}_{FD}$ is universal — that is
known, and a universal distance does exist for Reeb graphs of PL-functions on
compact triangulable spaces, constructed by a pullback to a common space, with
two edit-like universal distances proposed. Whether $\mathsf{d}_I$ is within a
constant factor of the universal distance remains open. Finally the practical
verdict: except for the bottleneck distance $\mathsf{d}_b$, computing any of these
is at least as hard as graph isomorphism, and even for merge trees the
interleaving distance is NP-hard, though a fixed-parameter tractable algorithm
exists in that case. So what one reports in practice is the bottleneck lower
bound, and one says explicitly that it is a lower bound.
</details>
