### Socratic exchange

**Q:** The Axiom of Completeness needs the word "least" in "least upper bound" — what would go wrong if we only required some upper bound to exist?

**A:** Correctly identified that Q already has plenty of ordinary upper bounds for a bounded set, so requiring merely "an" upper bound wouldn't distinguish R from Q. Only the *least* upper bound pins the boundary to the true edge of the set, which is what forces irrational boundary points (like sup{x : x^2<2} = sqrt(2)) to exist as actual points rather than gaps.
