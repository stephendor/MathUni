# Module: Real Analysis I (an) — Semester 1

**Mission link:** Metric spaces are where TDA's theory actually lives —
persistence diagrams, bottleneck distance, and point clouds are all metric
spaces, and every stability-theorem argument is an epsilon-delta argument in
disguise. This module builds the rigour that makes the stability theorem
(Semester 3+) checkable rather than folklore.

**Primary text:** Abbott, *Understanding Analysis* — Core Texts folder
(prefer `md\`, cite PDF pages).
**Support:** Cummings, *Real Analysis* (long-form companion, alternative
explanations and extra problems); Brannan; Oxford M2 Analysis I; Spivak
*Calculus*.

**Video strands:**
- Primary: Chris Staecker's Real Analysis playlist (Abbott-based, unit-aligned).
- Secondary: Marc Renault's Real Analysis playlist (Abbott-based) plus his
  companion docx notes/exercises in the Core Texts `md\` folder.
- Enrichment: Francis Su's Real Analysis lectures (Rudin-based) — map to
  Abbott units where topics align; use for a second proof style, not primary
  instruction.

**Units (in DAG order):** an-01 … an-14 (see syllabus.yaml; an-07 branches
toward point-set topology on-ramp via an-08/an-09, while an-06/an-13 track
series and uniform convergence into an-14's metric-space bridge).

**Teaching notes:**
- Treat an-14 (metric spaces) as the module's destination, not an afterthought
  — every earlier unit should be narrated as "this, but for R" in advance.
- Pair an-04 (epsilon-delta craft, via pw-04) explicitly with the adversarial
  framing already used in Proof Workshop.
- Uniform convergence (an-13) deserves extra worked counterexamples; it is
  the most common exam-level failure point before stability-theorem readiness.

**Assessment:**
- Unit mastery quizzes (SRS + 3-5 questions).
- Module problem set: ~10 problems, mix of Abbott exercises, Cummings
  Real Analysis problems, one Tripos IA-adapted problem. Graded per spec §7,
  80% gate.

**Common misconceptions to watch** (seed for learning-records):
- Sequence vs series (confusing convergence criteria between the two).
- Sup vs max (assuming a bound is attained when it need not be).
- Pointwise vs uniform convergence (swapping limit and integral/derivative
  without justification).
- "Compact = closed and bounded everywhere" (true in R^n, false in general
  metric spaces — an-14 must correct this explicitly).
