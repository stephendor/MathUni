# Module: Group Theory (gt) — Semester 1

**Mission link:** Homology groups are quotient groups before they are
anything else, and induced maps on homology are homomorphisms — functoriality
starts here. Normal subgroups and quotients (gt-07) are the single most
mission-critical unit in the semester: it is homology's defining construction,
rehearsed a year early.

**Primary text:** Aluffi, *Algebra: Notes from the Underground* — Core Texts
folder (prefer `md\`, cite PDF pages).
**Support:** Carter, *Visual Group Theory*; Oxford M1 Groups and Group
Actions notes.

**Visual strand:** Macauley's Visual Group Theory playlist is the primary
visual layer — assign the mapped Macauley video alongside each unit that
lists it in `resources` (gt-01, gt-03, gt-05). Borcherds' Group Theory
playlist is a depth/enrichment layer for learners who want a second, more
formal pass — optional, not required for unit mastery.

**Units (in DAG order):** gt-01 … gt-12 (see syllabus.yaml; gt-06/gt-07
converge into gt-08's isomorphism theorems, while gt-09→gt-10 group actions
and gt-11→gt-12 symmetric/direct-product tracks run in parallel before both
feed the module's close).

**Teaching notes:**
- Draw the Cayley diagram for every new group as it's introduced, even after
  gt-03 — the visual habit should outlast the unit that taught it.
- Explicitly cross-reference gt-07 (quotient groups) against la-09 (quotient
  spaces): same construction, different category — name the analogy aloud.
- Emphasise functoriality informally from gt-05 onward: "a homomorphism is a
  map that respects structure" should recur as a refrain, not a one-off
  definition.

**Assessment:**
- Unit mastery quizzes (SRS + 3-5 questions).
- Module problem set: ~10 problems, mix of Aluffi exercises, Carter/Macauley
  worksheet problems, one Tripos IA-adapted problem. Graded per spec §7,
  80% gate.

**Common misconceptions to watch** (seed for learning-records):
- Normality as commutativity (assuming a normal subgroup means the group is
  abelian, rather than gH = Hg).
- Cosets as subgroups (forgetting cosets need not contain the identity or be
  closed under the operation).
- "Isomorphic = equal" (treating an isomorphism as identifying literal
  elements rather than preserving structure).
