# Lesson Acceptance Rubric (scored)

Operationalises `curriculum/LESSON-GUIDE.md` into a **repeatable pass/fail record**.
Every lesson — whoever or whatever generated it — is scored here before it is
committed. Purpose: make "the standard held" a *measurement*, not an impression,
so a batch generated by a cheaper model can be admitted (or rejected) on evidence.

**How to use.** Fill one scorecard per lesson. For a drift A/B, score the
reference (a known-good Opus lesson) and the candidate side by side and read the
**delta** per row — drift is a regression against the reference, not an absolute.

The four gates are ordered. A lesson must clear each to reach the next.

---

## Gate 0 — Mechanical admission (binary; all must pass)

Model-agnostic, free, run before a human looks. Any FAIL ⇒ reject, do not score further.

| # | Check | Command / method | Pass? |
|---|-------|------------------|:---:|
| 0.1 | Coverage: every theorem/def id the problem set names appears in the lesson; the checked-ref denominator must be reported | `python scripts/check_lesson_coverage.py problems/sets/<u>.md lessons/<m>/<u>.html` → `PASS checked N refs, 0 missing`; `UNCHECKED checked 0 refs` requires an explicit source-gap disposition, while `--min-refs N` enforces a non-zero expectation | ☐ |
| 0.2 | HTML tokenises without an exception; this is not a tag-balance guarantee | `python -c "from html.parser import HTMLParser; HTMLParser().feed(open(PATH,encoding='utf-8').read())"` | ☐ |
| 0.3 | Self-contained: zero external requests | grep the file for `http://`, `https://`, `src=`, `cdn`, `<link`, external `<script src>` → none | ☐ |
| 0.4 | Zero browser console errors on load | open in browser pane, read console | ☐ |
| 0.5a | No unresolved source gaps: the lesson carries no `NOT IN SOURCE:` marker (LESSON-GUIDE §Source discipline). **Drift candidates are exempt** — `drift_bundle --check` drops this one row and reports the count instead, which is then read at Gate 2 | `python scripts/lesson_lint.py lessons/<m>/<u>.html` | ☐ |
| 0.5 | Renders faithfully + structural counts: no invalid HTML entities or LaTeX leak, governed non-void tags balance (`p` excluded because its end tag is optional), and countable structure items are sufficient (>=4 self-checks, 2-3 segments, breaks, >=1 faded, guided proof, visual, blank-page, mission, footer) | `python scripts/lesson_lint.py lessons/<m>/<u>.html` | ☐ |

> ⚠️ Gate 0 proves **form and mention**, never truth. 0.1-0.4 confirm a ref is
> *present*, parses, and does not error; **0.5** (added after the aa-01 drift test)
> catches invalid-entity / LaTeX-leak rendering and structural undercounts that emit no
> error -- the two drifts a cheaper model actually produced. None of Gate 0 checks whether
> a statement or proof is *correct*; that is Gate 2.

---

## Gate 1 — Structural conformance (binary; all 12 required)

Straight from LESSON-GUIDE §Structure — "non-negotiable". Any FAIL ⇒ revise.

> Items 1.4-1.6 and 1.8-1.11 are **mechanically pre-screened** by `scripts/lesson_lint.py` (Gate 0.5): a failure there bounces the lesson before a human scores this gate. The lint keys on semantic signals (e.g. `<textarea>` for the guided proof, "reconstruct" for the blank page), so it accepts either the reference's or a generator's markup conventions. Passing Gate 0.5 is **necessary, not sufficient** — it checks only presence and counts (is there a `<textarea>`? are there >=4 self-checks?), never quality; every item below still requires human scoring for mathematical correctness and pedagogy.

| # | Item | Pass? |
|---|------|:---:|
| 1.1 | **Hook first** — 2–4 sentences, concrete/fun instance, never opens on a definition | ☐ |
| 1.2 | **Prediction gate** — one commit-first question the learner answers *before* segment 1; lesson later reveals the answer | ☐ |
| 1.3 | **Mission strip** — the unit's `mission_link`, one sentence | ☐ |
| 1.4 | **2–3 segments**, each `<div class="segment">` with a `timebox` span + title | ☐ |
| 1.5 | **Break card(s)** — `<div class="break">` between segments | ☐ |
| 1.6 | **Faded examples** — fully worked → `.worked.fade` (gaps "⟨your step⟩") → `.you-try`; *every technique the problem set uses* is demonstrated | ☐ |
| 1.7 | **Intermediate lemmas** any problem-set step relies on are stated **and proved** in-body (nothing left to invent cold at grading) | ☐ |
| 1.8 | **≥4 self-checks** total, each with 3–4 buttons, `data-ok` on the right one, and a `.explain` giving WHY | ☐ |
| 1.9 | **Guided proof** — a free-response prompt (not multiple choice), distinct from self-checks, with a revealed model answer | ☐ |
| 1.10 | **Visual** — ≥1 `<canvas>` (≤60 lines inline JS) or inline SVG; geometry, not decoration | ☐ |
| 1.11 | **Blank-page ending** — reconstruct the 2–3 load-bearing claims from nothing, with a collapsed `<details>` reveal | ☐ |
| 1.12 | **Footer citations** — every def/theorem cites book + section + PDF page(s), paths resolved via `resources/bookmap.json` | ☐ |

## Gate 2 — Mathematical correctness (VETO; pass/fail)

The one gate no script can run and the whole batch leans on. **Any single defect
here fails the lesson outright**, whatever Gates 1/3 look like — a lesson that
teaches a false statement is worse than no lesson.

Check every one and cite the location of any defect:

- [ ] Every **definition** is stated correctly and is verbatim-faithful to the cited text.
- [ ] Every **theorem/lemma statement** is correct (hypotheses and conclusion both).
- [ ] Every **proof** is valid — no gaps papered over, no circularity, no false step.
- [ ] Every **worked example** computes the right answer and the shown method actually produces it.
- [ ] Every **self-check** `data-ok` marks a genuinely correct option and the `.explain` is true.
- [ ] The **guided-proof model answer** is a correct proof.
- [ ] **Citations resolve** — the section/pages exist and actually contain what is attributed to them.
- [ ] **Nothing is supplied from outside the source.** Every statement traces to the
      cited sections. Where the source did not cover something, the lesson says so
      with a `NOT IN SOURCE:` marker rather than filling the hole.

> **Read the gap count before scoring.** On hard material a candidate that
> declares **zero** gaps is not thereby complete — the likelier reading is that it
> filled silently from recollection, which is precisely the drift being measured.
> Zero gaps plus full coverage is a claim to be checked, not a result. Record the
> count either way.

**Verdict:** ☐ PASS  ☐ FAIL — defects: ________________________________________

## Gate 3 — Depth & pedagogy (scored 0–3 each; drift shows here)

Score against the LESSON-GUIDE §Register bar (Aluffi/Stillwell voice, British English).
`3` = matches the reference exemplar; `2` = acceptable; `≤1` = drift.

| # | Dimension | What "3" looks like | Ref | Cand |
|---|-----------|---------------------|:---:|:---:|
| 3.1 | **Depth** | proofs proved not asserted; reaches the cited sections' depth scoped to one lecture; deferrals named with target unit | | |
| 3.2 | **Register / voice** | vivid, precise, never breathless; definitions verbatim-faithful; British English | | |
| 3.3 | **Scaffolding quality** | the fade is *meaningful* (real omitted step), self-check distractors are plausible, guided proof is genuine proof-writing | | |
| 3.4 | **Prediction gate** | the gate question creates productive prediction error — non-trivial, and the reveal actually pays it off | | |

**Requirement:** each dimension ≥ 2, and Σ ≥ 10 / 12.

## Scorecard summary

```
Unit: __________   Generator: __________ (model/tier)   Date: __________
Gate 0 admission : PASS / FAIL
Declared gaps    : __  (NOT IN SOURCE markers; zero is a claim, not a result)
Gate 1 structure : __ / 12 pass   (list any fails)
Gate 2 correctness: PASS / FAIL   (list any defects)
Gate 3 depth      : 3.1__ 3.2__ 3.3__ 3.4__  Σ__/12
VERDICT: ACCEPT / REVISE / REJECT
Notes / drift vs reference:
```

**Accept** iff Gate 0 PASS · Gate 1 = 12/12 · Gate 2 PASS · Gate 3 each ≥2 and Σ≥10.
Anything else is **Revise** (fixable in place) or **Reject** (regenerate).
